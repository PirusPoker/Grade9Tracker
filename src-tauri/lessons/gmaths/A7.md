## What it is

A **function** is a rule that takes an **input** and gives exactly one **output**. You have met this as a function machine; GCSE Higher expects the formal notation, the **inverse function** (the machine run backwards) and **composite functions** (two machines one after the other).

### Function notation

$f(x) = 3x - 5$ means "the function $f$ multiplies the input by 3 and then subtracts 5". Read $f(x)$ as "f of x".

- $f(4) = 3(4) - 5 = 7$: the input 4 gives the output 7.
- $f(-2) = 3(-2) - 5 = -11$.
- $f(a + 1) = 3(a + 1) - 5 = 3a - 2$: the input can be an expression — replace every $x$ with it, in brackets.

$f(x) = 13$ is a different kind of question: the **output** is 13 and you want the **input**. Solve $3x - 5 = 13$, so $x = 6$.

With $g(x) = x^2 + 1$: $g(-3) = (-3)^2 + 1 = 10$. Note $g(x) = 10$ has **two** solutions, $x = 3$ and $x = -3$.

As a function machine, $f$ is:

$$x \;\longrightarrow\; \boxed{\times 3} \;\longrightarrow\; \boxed{-5} \;\longrightarrow\; f(x)$$

### Inverse functions

The **inverse function** $f^{-1}$ undoes $f$: if $f$ sends 6 to 13, then $f^{-1}$ sends 13 back to 6. So $f^{-1}f(x) = x$.

**Method 1 — reverse the machine.** Undo each step in reverse order: add 5, then divide by 3.

$$f^{-1}(x) = \frac{x + 5}{3}$$

**Method 2 — rearrange (works for every GCSE function).** Write $y = f(x)$, make $x$ the subject, then swap the letter back to $x$.

$$y = 3x - 5 \;\Rightarrow\; y + 5 = 3x \;\Rightarrow\; x = \frac{y + 5}{3} \;\Rightarrow\; f^{-1}(x) = \frac{x + 5}{3}$$

Check: $f^{-1}(7) = \dfrac{12}{3} = 4$ and $f(4) = 7$. ✓

When $x$ appears twice, rearrange with the "collect and factorise" method from changing the subject:

$h(x) = \dfrac{2x + 1}{x - 3}$. Let $y = \dfrac{2x + 1}{x - 3}$:

$$y(x - 3) = 2x + 1 \Rightarrow xy - 2x = 3y + 1 \Rightarrow x(y - 2) = 3y + 1 \Rightarrow x = \frac{3y + 1}{y - 2}$$

$$h^{-1}(x) = \frac{3x + 1}{x - 2}$$

Graphically, the graph of $y = f^{-1}(x)$ is the reflection of $y = f(x)$ in the line $y = x$, because inputs and outputs swap.

$f^{-1}(x)$ is **not** $\dfrac{1}{f(x)}$ — the $-1$ is notation for "inverse", not a power.

### Composite functions

A **composite function** applies one function and then another. $fg(x)$ means $f(g(x))$: **do $g$ first** (the one nearest $x$), then put the result into $f$.

With $f(x) = 3x - 5$ and $g(x) = x^2 + 1$:

$$fg(2) = f(g(2)) = f(5) = 10 \qquad gf(2) = g(f(2)) = g(1) = 2$$

So $fg$ and $gf$ are usually different.

For the expression, substitute the whole of the inner function, in brackets, for $x$ in the outer one:

$$fg(x) = 3(x^2 + 1) - 5 = 3x^2 - 2$$

$$gf(x) = (3x - 5)^2 + 1 = 9x^2 - 30x + 26$$

$ff(x)$ means $f(f(x))$: $\;ff(x) = 3(3x - 5) - 5 = 9x - 20$.

### Equations involving functions

Once you have written the functions as expressions, these become ordinary equations.

- **Solve $ff(x) = 16$:** $9x - 20 = 16 \Rightarrow x = 4$.
- **Solve $f(x) = f^{-1}(x)$:** $3x - 5 = \dfrac{x + 5}{3} \Rightarrow 9x - 15 = x + 5 \Rightarrow x = 2.5$. (Solutions lie on the line $y = x$.)
- **Solve $fg(x) = gf(x)$** — often a quadratic, the grade 9 end of this topic.
- **Find unknown constants:** if $f(x) = ax + b$ with $f(2) = 11$ and $f(-1) = 2$, then $2a + b = 11$ and $-a + b = 2$, simultaneous equations giving $a = 3$, $b = 5$.

::: terms
- **Function**: a rule that maps each input to exactly one output, written like f(x) = 3x − 5.
- **Input and output**: the value put into a function (x) and the value that comes out (f(x)).
- **Inverse function**: the function f⁻¹ that reverses f, so that f⁻¹(f(x)) = x.
- **Composite function**: two functions applied in turn; fg(x) means f(g(x)), with g applied first.
- **Function machine**: a diagram showing the operations of a function as boxes applied in order.
:::

::: method
1. **Evaluating $f(a)$:** replace **every** $x$ by $a$ in brackets. For $f(\text{expression})$, bracket the expression and simplify.
2. **"Solve $f(x) = k$":** set the expression equal to $k$ and solve — you are finding the input, not the output.
3. **Inverse:** write $y = f(x)$, make $x$ the subject line by line, then write the answer as $f^{-1}(x) = \ldots$ **in terms of $x$**. Leaving it in $y$ can lose the final mark. Check with a number: $f^{-1}(f(3))$ should be 3.
4. **Composite:** $fg(x)$ — **$g$ first**, working from the inside out. For a number, find $g(\text{number})$ then feed it to $f$. For the expression, put the whole of $g(x)$, in brackets, in place of every $x$ in $f$, then expand and simplify.
5. **Equations with composite or inverse functions:** turn each side into an expression first, then solve as normal (often a quadratic — factorise, formula or complete the square for exact answers).
6. **Paper choice:** these are usually non-calculator friendly. When the question says "exact", leave surds. "Show that $gf(x) = \ldots$" needs the substitution line written out before the simplified answer.
:::

::: example Using function notation
$f(x) = 5x + 2$. (a) Find $f(-3)$. (b) Solve $f(x) = 27$. (c) Write $f(2a)$ in terms of $a$.

(a) $5(-3) + 2 = -13$. (b) $5x + 2 = 27 \Rightarrow x = 5$. (c) $5(2a) + 2 = 10a + 2$.
:::

::: example Finding inverses
Find $f^{-1}(x)$ for (a) $f(x) = \dfrac{4x - 3}{5}$ (b) $f(x) = x^3 + 2$.

(a) $y = \dfrac{4x - 3}{5} \Rightarrow 5y = 4x - 3 \Rightarrow x = \dfrac{5y + 3}{4}$, so $f^{-1}(x) = \dfrac{5x + 3}{4}$.

(b) $y = x^3 + 2 \Rightarrow x^3 = y - 2 \Rightarrow x = \sqrt[3]{y - 2}$, so $f^{-1}(x) = \sqrt[3]{x - 2}$.
:::

::: example Composite functions
$f(x) = 2x - 1$ and $g(x) = \dfrac{1}{x + 2}$. Find (a) $fg(0)$ (b) $gf(x)$ (c) $fg(x)$ as a single fraction.

(a) $g(0) = \frac12$, then $f\!\left(\tfrac12\right) = 2\left(\tfrac12\right) - 1 = 0$.

(b) $gf(x) = \dfrac{1}{(2x - 1) + 2} = \dfrac{1}{2x + 1}$.

(c) $fg(x) = 2\left(\dfrac{1}{x + 2}\right) - 1 = \dfrac{2}{x + 2} - \dfrac{x + 2}{x + 2} = \dfrac{-x}{x + 2}$.
:::

::: example Finding the constants
$f(x) = ax + b$. $f(2) = 11$ and $f(-1) = 2$. Find $f^{-1}(20)$.

$2a + b = 11$ and $-a + b = 2$. Subtract: $3a = 9$, so $a = 3$ and $b = 5$.

$f(x) = 3x + 5$. $f^{-1}(20)$ is the input giving 20: $3x + 5 = 20 \Rightarrow x = 5$. (No need to find $f^{-1}(x)$ in full.)
:::

::: example Solving fg(x) = gf(x) (grade 9)
$f(x) = 2x + 3$ and $g(x) = x^2$. Solve $fg(x) = gf(x)$, giving your answers in surd form.

$fg(x) = 2x^2 + 3$ and $gf(x) = (2x + 3)^2 = 4x^2 + 12x + 9$.

$$2x^2 + 3 = 4x^2 + 12x + 9 \Rightarrow 0 = 2x^2 + 12x + 6 \Rightarrow x^2 + 6x + 3 = 0$$

Complete the square: $(x + 3)^2 - 9 + 3 = 0 \Rightarrow (x + 3)^2 = 6 \Rightarrow x = -3 \pm \sqrt6$.
:::

::: q
$f(x) = 5 - 2x$. Find $f(3)$ and $f(-4)$.
---
$f(3) = 5 - 6 = -1$. $\quad f(-4) = 5 + 8 = 13$.
:::

::: q
$g(x) = x^2 - 3x$. Find $g(-2)$ and solve $g(x) = 0$.
---
$g(-2) = 4 + 6 = 10$. $\quad x(x - 3) = 0 \Rightarrow x = 0$ or $x = 3$.
:::

::: q
Find the inverse of (a) $f(x) = 4x + 1$ (b) $h(x) = \dfrac{x - 2}{5}$.
---
(a) $y = 4x + 1 \Rightarrow x = \dfrac{y - 1}{4}$: $f^{-1}(x) = \dfrac{x - 1}{4}$.
(b) $y = \dfrac{x - 2}{5} \Rightarrow x = 5y + 2$: $h^{-1}(x) = 5x + 2$.
:::

::: q
$f(x) = 2x + 1$ and $g(x) = x^2$. Find $fg(3)$ and $gf(3)$.
---
$fg(3) = f(9) = 19$. $\quad gf(3) = g(7) = 49$.
:::

::: q
With the same $f$ and $g$, find expressions for $fg(x)$ and $gf(x)$.
---
$fg(x) = 2x^2 + 1$. $\quad gf(x) = (2x + 1)^2 = 4x^2 + 4x + 1$.
:::

::: q
$f(x) = x^3 - 4$. Find $f^{-1}(x)$ and $f^{-1}(23)$.
---
$y = x^3 - 4 \Rightarrow x = \sqrt[3]{y + 4}$: $f^{-1}(x) = \sqrt[3]{x + 4}$. $\;f^{-1}(23) = \sqrt[3]{27} = 3$.
:::

::: q
$k(x) = \dfrac{3}{x - 1}$. Find $k^{-1}(x)$.
---
$y = \dfrac{3}{x - 1} \Rightarrow x - 1 = \dfrac{3}{y} \Rightarrow x = \dfrac{3}{y} + 1$. $\;k^{-1}(x) = \dfrac{3}{x} + 1 = \dfrac{x + 3}{x}$.
:::

::: q
$f(x) = 3x - 5$. Find $ff(x)$ and solve $ff(x) = 16$.
---
$ff(x) = 3(3x - 5) - 5 = 9x - 20$. $\;9x - 20 = 16 \Rightarrow x = 4$.
:::

::: q
$f(x) = 3x - 5$. Solve $f(x) = f^{-1}(x)$.
---
$f^{-1}(x) = \dfrac{x + 5}{3}$. $\;3x - 5 = \dfrac{x + 5}{3} \Rightarrow 9x - 15 = x + 5 \Rightarrow 8x = 20 \Rightarrow x = 2.5$.
:::

::: watch
- **Order in $fg(x)$:** $g$ acts first. Working out $f$ first gives $gf$ and scores nothing.
- **Missing brackets in composites:** $gf(x)$ with $f(x) = 3x - 5$ and $g(x) = x^2 + 1$ is $(3x - 5)^2 + 1$, not $3x - 5^2 + 1$ or $3x^2 - 25 + 1$.
- **$f^{-1}(x)$ is not $\dfrac{1}{f(x)}$.**
- **Leaving the inverse in $y$:** the answer must be written as $f^{-1}(x) = \ldots$ in terms of $x$.
- **Confusing $f(x) = k$ with $f(k)$:** one asks for an input, the other an output.
- **Reversing a machine in the wrong order:** undo the **last** operation first.
:::

---
$gh(x) = (2x - 3)^2 + 1$ (M1) $= 4x^2 - 12x + 9 + 1 = 4x^2 - 12x + 10$ (A1).

::: test
$f(x) = 3x - 5$ and $f^{-1}$ is its inverse. Solve $f(x) = f^{-1}(x)$. (3)
---
$f^{-1}(x) = \dfrac{x + 5}{3}$ (M1). $3x - 5 = \dfrac{x + 5}{3}$, so $9x - 15 = x + 5$ (M1). $x = 2.5$ (A1).
:::

::: test
$f(x) = ax + b$. $f(1) = 1$ and $f(3) = 11$. Find the values of $a$ and $b$, and hence find $f^{-1}(21)$. (4)
---
$a + b = 1$ and $3a + b = 11$ (M1). $2a = 10$, $a = 5$, $b = -4$ (A1, A1). $5x - 4 = 21 \Rightarrow f^{-1}(21) = 5$ (A1).
:::

::: test
$f(x) = \dfrac{x + 1}{x - 2}$. Find $f^{-1}(x)$. (4)
---
$y(x - 2) = x + 1$ (M1). $xy - 2y = x + 1 \Rightarrow xy - x = 2y + 1$ (M1). $x(y - 1) = 2y + 1$ (M1). $f^{-1}(x) = \dfrac{2x + 1}{x - 1}$ (A1).
:::

::: test
$g(x) = \dfrac{x}{x + 1}$. Show that $gg(x) = \dfrac{x}{2x + 1}$. (3)
---
$gg(x) = \dfrac{\frac{x}{x + 1}}{\frac{x}{x + 1} + 1}$ (M1). Denominator $\dfrac{x + x + 1}{x + 1} = \dfrac{2x + 1}{x + 1}$ (M1). $\dfrac{x}{x + 1} \times \dfrac{x + 1}{2x + 1} = \dfrac{x}{2x + 1}$ (A1).
:::

::: test
$f(x) = 3x - 1$ and $g(x) = x^2$. Show that the equation $fg(x) = gf(x)$ has no real solutions. (4)
---
$fg(x) = 3x^2 - 1$, $gf(x) = (3x - 1)^2 = 9x^2 - 6x + 1$ (M1). $3x^2 - 1 = 9x^2 - 6x + 1 \Rightarrow 6x^2 - 6x + 2 = 0 \Rightarrow 3x^2 - 3x + 1 = 0$ (M1). Discriminant $b^2 - 4ac = 9 - 12 = -3$ (M1). This is negative, so there are no real solutions (A1).
:::
