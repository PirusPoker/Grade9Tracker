## What it is

A **power** (or **index**) tells you how many times a number is multiplied by itself: $3^4 = 3 \times 3 \times 3 \times 3 = 81$. A **root** undoes a power: $\sqrt[4]{81} = 3$ because $3^4 = 81$. At Higher tier you must calculate with positive, zero, negative and fractional indices, recognise common powers on sight, and estimate powers and roots of any positive number.

### Powers and roots to know by sight

On Paper 1 you are expected to recognise these without working:

| | Powers |
|---|---|
| Squares | $1, 4, 9, 16, 25, 36, 49, 64, 81, 100, 121, 144, 169, 196, 225$ |
| Cubes | $1, 8, 27, 64, 125, 216, 343, 512, 729, 1000$ |
| Powers of 2 | $2, 4, 8, 16, 32, 64, 128, 256, 512, 1024$ |
| Powers of 3 | $3, 9, 27, 81, 243, 729$ |
| Powers of 4 | $4, 16, 64, 256, 1024$ |
| Powers of 5 | $5, 25, 125, 625, 3125$ |

So $\sqrt{196} = 14$, $\sqrt[3]{343} = 7$, $\sqrt[5]{32} = 2$, $\sqrt[4]{625} = 5$, and $\sqrt[3]{-125} = -5$ (odd roots of negative numbers exist; even roots of negative numbers do not, in real numbers).

Every positive number has **two** square roots: $x^2 = 49$ gives $x = 7$ or $x = -7$, written $\pm 7$. The symbol $\sqrt{49}$ on its own means the positive root, 7.

### Estimating powers and roots

Trap the number between known powers.

- $\sqrt{70}$: $64 < 70 < 81$, so $8 < \sqrt{70} < 9$, and 70 is nearer 64, so about $8.4$ (calculator: $8.37$).
- $\sqrt[3]{100}$: $64 < 100 < 125$, so it lies between 4 and 5, nearer 5: about $4.6$.
- $2.9^3$: close to $3^3 = 27$, a little less: about 24 (exactly $24.389$).
- $0.3^3 = 0.027$ and $\sqrt{0.09} = 0.3$: square and cube numbers with decimals keep the same digits; count decimal places ($0.3^2$ has 2 d.p., $0.3^3$ has 3 d.p.).

### The index laws

For the same base $a$:

$$a^m \times a^n = a^{m+n} \qquad a^m \div a^n = a^{m-n} \qquad (a^m)^n = a^{mn}$$

$$3^5 \times 3^2 = 3^7 \qquad 7^{10} \div 7^4 = 7^6 \qquad (5^3)^4 = 5^{12}$$

They work with letters too, with any numbers in front handled separately: $6x^5 \div 2x^2 = 3x^3$, $(3y^4)^2 = 9y^8$.

### Zero and negative indices

Dividing $a^3$ by itself gives $a^{3-3} = a^0$, but it is also 1. So

$$a^0 = 1 \quad (a \ne 0)$$

Dividing $a^2$ by $a^5$ gives $a^{-3}$, but it is also $\frac{a \times a}{a \times a \times a \times a \times a} = \frac{1}{a^3}$. So

$$a^{-n} = \frac{1}{a^n}$$

A negative index means **reciprocal**, not a negative answer: $2^{-3} = \frac18$, $10^{-2} = 0.01$. For a fraction, flip it and make the power positive: $\left(\frac{2}{3}\right)^{-3} = \left(\frac32\right)^3 = \frac{27}{8}$.

### Fractional indices

Since $(a^{1/2})^2 = a^1 = a$, the power $\frac12$ is the square root. In general

$$a^{\frac1n} = \sqrt[n]{a} \qquad a^{\frac{m}{n}} = \left(\sqrt[n]{a}\right)^m$$

The **denominator is the root, the numerator is the power**. Take the root first to keep the numbers small:

$$32^{\frac35} = \left(\sqrt[5]{32}\right)^3 = 2^3 = 8 \qquad 49^{\frac12} = 7 \qquad 1000^{\frac23} = 10^2 = 100$$

Negative fractional index — three jobs, in any order: reciprocal, root, power.

$$\left(\frac{16}{81}\right)^{-\frac34} = \left(\frac{81}{16}\right)^{\frac34} = \left(\frac{3}{2}\right)^3 = \frac{27}{8}$$

### Calculating with roots

Roots of products and quotients split up: $\sqrt{ab} = \sqrt a \times \sqrt b$ and $\sqrt{\frac{a}{b}} = \frac{\sqrt a}{\sqrt b}$. So $\sqrt{36 \times 49} = 6 \times 7 = 42$ and $\sqrt{\frac{25}{64}} = \frac58$. They do **not** split over addition: $\sqrt{9 + 16} = 5$, not 7. (Surds such as $\sqrt{12} = 2\sqrt3$ are covered in N8.)

Roots can be written as powers so the index laws apply: $\sqrt[3]{x} \times x^2 = x^{\frac13 + 2} = x^{\frac73}$.

### Writing numbers as powers of a base

Many Higher questions ask for an answer "in the form $2^n$" or give $a^x = b$. Rewrite everything with the same base:

- $8 = 2^3$, $\frac14 = 2^{-2}$, $\sqrt{2} = 2^{\frac12}$, $4\sqrt2 = 2^2 \times 2^{\frac12} = 2^{\frac52}$.
- Solve $27^x = 9$: $3^{3x} = 3^2$, so $3x = 2$ and $x = \frac23$.
- Solve $\frac{1}{125} = 5^k$: $5^{-3} = 5^k$, so $k = -3$.

::: terms
- **Index (power)**: the small raised number showing how many times the base is multiplied by itself, as in 3⁴.
- **Base**: the number being raised to a power, e.g. 3 in 3⁴.
- **nth root**: the number which, raised to the power n, gives the original number; the cube root of 343 is 7.
- **Zero index**: any non-zero number to the power 0 equals 1, e.g. 7⁰ = 1.
- **Negative index**: means the reciprocal, a⁻ⁿ = 1/aⁿ, e.g. 2⁻³ = 1/8.
- **Fractional index**: a^(m/n) is the nth root of a, raised to the power m; the denominator is the root.
- **Reciprocal**: 1 divided by a number; the reciprocal of 3/4 is 4/3.
:::

::: method
1. **Non-calculator (Paper 1) is where these are tested hardest.** Know the table of squares, cubes and powers of 2, 3, 4, 5 so you can spot $243 = 3^5$ or $625 = 5^4$ instantly.
2. **Evaluate a power like $a^{-m/n}$ in three jobs:** negative → flip the base; denominator → take that root; numerator → raise to that power. Do the root before the power. Write each step — one mark usually goes to the first correct step (e.g. the reciprocal or the root).
3. **Simplify with the index laws** only when the bases match. Handle numbers in front separately: multiply or divide them normally, and apply an outside power to them too.
4. **"Write as a power of 2 (or 3, 5…)":** convert every number to that base, including roots ($\sqrt{a} = a^{1/2}$) and reciprocals, then combine indices. "Give your answer in the form $2^n$" means a single power — $2^3 \times 2^{1/2}$ is not finished.
5. **Solving $a^x = b$:** write both sides as powers of the same base and equate the indices, then solve the linear equation.
6. **Estimating:** trap between consecutive known powers and state both, then say which it is nearer. On a calculator paper, use the calculator to check, and give the unrounded display before rounding.
7. **Answer form:** "Give your answer as a fraction" means never leave a negative index; "exact" means no decimals from rounding.
:::

::: example Recognising powers
Work out (a) $\sqrt[3]{216}$, (b) $4^5$, (c) $\sqrt[4]{0.0016}$, (d) $(-3)^5$.

(a) $6^3 = 216$, so 6. (b) $4^5 = 1024$ (or $2^{10}$). (c) $2^4 = 16$, and 0.0016 has 4 decimal places, so the fourth root has 1 decimal place: $0.2$. Check: $0.2^4 = 0.0016$. (d) An odd power of a negative is negative: $-243$.
:::

::: example Negative and fractional indices
Evaluate (a) $5^{-2}$, (b) $81^{\frac34}$, (c) $\left(\frac{8}{125}\right)^{-\frac23}$, (d) $0.25^{-\frac32}$.

(a) $\frac{1}{25}$.

(b) $\left(\sqrt[4]{81}\right)^3 = 3^3 = 27$.

(c) Flip: $\left(\frac{125}{8}\right)^{\frac23}$. Cube root: $\frac52$. Square: $\frac{25}{4}$.

(d) $0.25 = \frac14$. Flip: $4^{\frac32} = (\sqrt4)^3 = 8$.
:::

::: example Simplifying with index laws
Simplify (a) $\dfrac{4x^3 \times 5x^{-1}}{10x^4}$, (b) $(27a^6)^{\frac23}$.

(a) Numbers: $\frac{4 \times 5}{10} = 2$. Powers: $x^{3 + (-1) - 4} = x^{-2}$. Answer $2x^{-2}$ or $\dfrac{2}{x^2}$.

(b) $27^{\frac23} = (\sqrt[3]{27})^2 = 9$ and $(a^6)^{\frac23} = a^4$. Answer $9a^4$.
:::

::: example Estimating a root
Without a calculator, estimate $\sqrt{140}$ to 1 decimal place.

$11^2 = 121$ and $12^2 = 144$, so $11 < \sqrt{140} < 12$, very close to 12. Try $11.8^2 = 139.24$ and $11.9^2 = 141.61$. 140 lies between, nearer $139.24$ ($0.76$ away against $1.61$). So $\sqrt{140} \approx 11.8$.
:::

::: example Grade 8–9: powers of the same base
(a) Write $\dfrac{8^{x}}{\sqrt{2}}$ as a single power of 2. (b) Hence solve $\dfrac{8^{x}}{\sqrt{2}} = 4^{x+1}$.

(a) $8^x = (2^3)^x = 2^{3x}$ and $\sqrt 2 = 2^{\frac12}$, so $\dfrac{8^x}{\sqrt 2} = 2^{3x - \frac12}$.

(b) $4^{x+1} = 2^{2x + 2}$. Equate indices: $3x - \frac12 = 2x + 2$, so $x = \frac52$.

Check: $x = 2.5$ gives $2^{7} = 128$ on the left and $4^{3.5} = 2^7 = 128$ on the right. ✓
:::

::: q
Solve (a) $5^x = 125$, (b) $4^x = \frac{1}{8}$, (c) $9^{x-1} = 27^{x}$.
---
(a) $x = 3$. (b) $2^{2x} = 2^{-3}$, so $x = -\frac32$. (c) $3^{2x - 2} = 3^{3x}$, so $2x - 2 = 3x$ and $x = -2$.

::: q
Work out $\sqrt{\dfrac{0.49 \times 64}{0.0001}}$ without a calculator.
---
$\sqrt{0.49} = 0.7$, $\sqrt{64} = 8$, $\sqrt{0.0001} = 0.01$. $\dfrac{0.7 \times 8}{0.01} = \dfrac{5.6}{0.01} = 560$.
:::

::: q
Given that $2^{10} = 1024$, estimate $2^{20}$ and $2^{-10}$ in ordinary form, each to 1 significant figure.
---
$2^{20} = 1024^2 \approx 1\,000\,000$ (it is $1\,048\,576$). $2^{-10} = \frac{1}{1024} \approx 0.001$.
:::

::: watch
- **Negative index read as a negative number.** $3^{-2} = \frac19$, not $-9$ or $-6$.
- **Power multiplied instead of root taken.** $64^{\frac12}$ is $\sqrt{64} = 8$, not $64 \times \frac12 = 32$.
- **Power before root with big numbers.** $27^{\frac43}$ via $27^4 = 531\,441$ invites errors; via $\sqrt[3]{27} = 3$ gives $3^4 = 81$ at once.
- **Index laws on different bases.** $2^3 \times 3^2 \ne 6^5$. Convert to the same base first.
- **The number in front forgotten.** $(3x^2)^3 = 27x^6$, not $3x^6$; and $2x^{-1} = \frac{2}{x}$, not $\frac{1}{2x}$.
- **Roots split over addition.** $\sqrt{a + b} \ne \sqrt a + \sqrt b$.
- **Answer not in the form asked.** "As a power of 5" needs $5^n$; "as a fraction" means no negative index left.
:::
