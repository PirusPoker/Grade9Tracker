## What it is

Some equations, such as $x^3 + 2x - 7 = 0$, cannot be solved with any exact method you know. **Iteration** finds an approximate solution by repeating a calculation: each answer is fed back in to get a better one, until the values settle down to the accuracy you need.

### Step 1: locate the root with a change of sign

Put everything on one side and call it $f(x)$. If $f(x)$ is **negative** at one value and **positive** at another, the graph must cross the $x$-axis in between (for a smooth, unbroken graph like a polynomial), so there is a solution there.

For $x^3 + 2x - 7 = 0$:

- $x = 1$: $1 + 2 - 7 = -4$ (negative)
- $x = 2$: $8 + 4 - 7 = 5$ (positive)

There is a **change of sign**, so there is a solution between $x = 1$ and $x = 2$. You must *state* the sign change and the conclusion to get the mark.

### Step 2: rearrange into the form $x = g(x)$

Rearrange the equation so $x$ is on its own on one side, with $x$ still appearing on the other:

$$x^3 + 2x - 7 = 0 \Rightarrow x^3 = 7 - 2x \Rightarrow x = \sqrt[3]{7 - 2x}$$

There is usually more than one way to do this. The exam tells you which one to show — "Show that the equation can be rearranged to give..." — and you must reach it with every step visible.

### Step 3: turn it into an iterative formula

Write the rearrangement with subscripts:

$$x_{n+1} = \sqrt[3]{7 - 2x_n}$$

$x_n$ is the current estimate, $x_{n+1}$ is the next one. You are given a **starting value** $x_0$ (or sometimes $x_1$).

### Step 4: iterate

With $x_0 = 1.5$:

- $x_1 = \sqrt[3]{7 - 2(1.5)} = \sqrt[3]{4} = 1.5874\ldots$
- $x_2 = \sqrt[3]{7 - 2(1.5874\ldots)} = 1.5639\ldots$
- $x_3 = 1.5703\ldots$, $x_4 = 1.5685\ldots$, $x_5 = 1.5690\ldots$, $x_6 = 1.5689\ldots$

The values are **converging** towards about $1.569$. That limit is a solution of $x^3 + 2x - 7 = 0$.

**Calculator trick:** type $1.5$ and press `=`. Then type the formula using the `Ans` key, $\sqrt[3]{7 - 2\,\text{Ans}}$, and press `=` repeatedly. Each press gives the next term, using the full unrounded value.

### Step 5: check the accuracy with another sign change

To show the root is $1.569$ correct to 3 decimal places, test the **bounds** of that interval, $1.5685$ and $1.5695$:

- $f(1.5685) = -0.0041\ldots$ (negative)
- $f(1.5695) = 0.0051\ldots$ (positive)

A sign change, so the root lies between $1.5685$ and $1.5695$ and rounds to $1.569$.

### What the terms mean

Each $x_n$ is an **estimate** of a solution of the original equation. If the sequence converges to $L$, then $L = g(L)$, which is the rearranged equation — so $L$ solves the original equation. You can be asked to reverse this: given $x_{n+1} = \sqrt[3]{12 - 3x_n^2}$, the equation being solved is $x^3 = 12 - 3x^2$, i.e. $x^3 + 3x^2 - 12 = 0$.

### When iteration fails

Not every rearrangement works. From $x^3 + 4x - 7 = 0$, the formula $x_{n+1} = \dfrac{7 - x_n^3}{4}$ with $x_0 = 1$ gives $1.5, 0.906, 1.564, 0.794, 1.625, 0.677, \ldots$ — the values swing further and further away from the root. The sequence **diverges**, so you need a different rearrangement. A rearrangement can also converge to a *different* root from the one you wanted.

::: terms
- **Iteration**: repeating a calculation, feeding each answer back in, to get closer and closer to a solution.
- **Iterative formula**: a rule such as xₙ₊₁ = ∛(7 − 2xₙ) that gives the next estimate from the current one.
- **Starting value**: the first estimate x₀ (or x₁) given in the question, from which the iteration begins.
- **Change of sign**: when f(x) is negative at one value and positive at another, so a root lies between them.
- **Converge**: the terms settle towards a single value, which is a solution of the equation.
- **Diverge**: the terms move away from the solution, so the rearrangement is no use.
:::

::: method
1. **This is a calculator topic.** It appears on Papers 2 and 3 almost every series. Use the `Ans` key so every step uses the full, unrounded previous value.
2. **"Show that the equation has a solution between $a$ and $b$":** substitute both values into the equation arranged as $= 0$, write both answers down, then **state** "there is a change of sign, so there is a solution between $a$ and $b$". The conclusion is the final mark.
3. **"Show that the equation can be rearranged to give...":** start from the given equation and end on exactly the given form, one operation per line. It is a "show that" — you cannot use the answer you were given in your working.
4. **"Find the values of $x_1$, $x_2$ and $x_3$":** write each one down, to at least 4 decimal places (or as the question says). One correct substitution shown earns M1 even if you slip later.
5. **"Find the solution correct to $k$ decimal places":** keep pressing `=` until successive terms agree to that many places, and write down the terms you used as evidence.
6. **To prove the accuracy,** substitute the lower and upper bounds (e.g. $2.105$ and $2.115$ for $2.11$) into $f(x)$, show a change of sign, and conclude.
7. **"What does $x_3$ represent?"** — it is an estimate of a solution of the original equation. **"What equation is being solved?"** — replace $x_{n+1}$ and $x_n$ by $x$ and rearrange to $= 0$.
:::

::: example Locating a root and rearranging
(a) Show that $x^3 + 5x = 20$ has a solution between $x = 2$ and $x = 3$.

(b) Show that $x^3 + 5x = 20$ can be rearranged to give $x = \sqrt[3]{20 - 5x}$.

(a) Let $f(x) = x^3 + 5x - 20$. $f(2) = 8 + 10 - 20 = -2$; $f(3) = 27 + 15 - 20 = 22$. There is a change of sign, so there is a solution between 2 and 3.

(b) $x^3 = 20 - 5x$, so $x = \sqrt[3]{20 - 5x}$.
:::

::: example Iterating to a required accuracy
Using $x_{n+1} = \sqrt[3]{20 - 5x_n}$ with $x_0 = 2$, find the solution of $x^3 + 5x = 20$ correct to 2 decimal places.

$x_1 = \sqrt[3]{10} = 2.1544\ldots$, $x_2 = 2.0975\ldots$, $x_3 = 2.1188\ldots$, $x_4 = 2.1108\ldots$, $x_5 = 2.1138\ldots$, $x_6 = 2.1127\ldots$

From $x_4$ onwards every term rounds to $2.11$, so $x = 2.11$ to 2 d.p.

Confirm: $f(2.105) = -0.147\ldots < 0$ and $f(2.115) = 0.035\ldots > 0$. A change of sign, so the root lies in $[2.105, 2.115]$ and is $2.11$ to 2 d.p.
:::

::: example A rearrangement that divides by x²
(a) Show that $x^3 - 4x^2 - 3 = 0$ can be rearranged to $x = 4 + \dfrac{3}{x^2}$.

(b) Starting with $x_0 = 4$, use $x_{n+1} = 4 + \dfrac{3}{x_n^2}$ to find $x_3$ to 4 decimal places.

(a) $x^3 = 4x^2 + 3$. Divide every term by $x^2$: $x = 4 + \dfrac{3}{x^2}$.

(b) $x_1 = 4 + \dfrac{3}{16} = 4.1875$, $x_2 = 4 + \dfrac{3}{4.1875^2} = 4.1710\ldots$, $x_3 = 4.1724\ldots$. So $x_3 = 4.1724$.
:::

::: example Grade 8: working backwards to the equation
The iterative formula $x_{n+1} = \sqrt[3]{4x_n^2 - 9}$ is used to find a solution of an equation. Find the equation, in the form $x^3 + ax^2 + b = 0$.

Replace both $x_{n+1}$ and $x_n$ with $x$: $x = \sqrt[3]{4x^2 - 9}$. Cube: $x^3 = 4x^2 - 9$. So $x^3 - 4x^2 + 9 = 0$, i.e. $a = -4$, $b = 9$.
:::

::: example Grade 9: finding the limit exactly
The sequence $x_{n+1} = \sqrt{2x_n + 8}$, $x_0 = 1$, converges. Find its limit exactly.

The terms are $3.162\ldots, 3.785\ldots, 3.946\ldots, 3.986\ldots$ — heading upwards. At the limit $L$ the next term equals the last, so $L = \sqrt{2L + 8}$.

$L^2 = 2L + 8 \Rightarrow L^2 - 2L - 8 = 0 \Rightarrow (L - 4)(L + 2) = 0$.

A square root is never negative, so $L = 4$.
:::

::: q
Show that $x^3 - 3x - 5 = 0$ has a solution between $x = 2$ and $x = 3$.
---
$x = 2$: $8 - 6 - 5 = -3$. $x = 3$: $27 - 9 - 5 = 13$. Change of sign, so there is a solution between 2 and 3.
:::

::: q
Show that the solution of $x^3 - 3x - 5 = 0$ in Question 1 is $2.28$ correct to 2 decimal places.
---
$f(2.275) = -0.0504\ldots$ (negative), $f(2.285) = 0.0754\ldots$ (positive). Change of sign, so the root lies between $2.275$ and $2.285$ and rounds to $2.28$.
:::

::: q
Show that $x^2 - 7x + 2 = 0$ can be rearranged to give $x = 7 - \dfrac{2}{x}$.
---
$x^2 = 7x - 2$. Divide every term by $x$: $x = 7 - \dfrac{2}{x}$.
:::

::: q
Using $x_{n+1} = 7 - \dfrac{2}{x_n}$ with $x_0 = 6$, find $x_1$, $x_2$ and $x_3$, giving $x_3$ to 4 decimal places.
---
$x_1 = 7 - \dfrac13 = 6.6667$, $x_2 = 7 - \dfrac{2}{6.6667} = 6.7$, $x_3 = 7 - \dfrac{2}{6.7} = 6.7015$.
:::

::: q
Show that $x^3 + 4x - 1 = 0$ can be written as $x = \dfrac{1}{x^2 + 4}$. Starting with $x_0 = 0$, iterate to find the solution to 4 decimal places.
---
$x^3 + 4x = 1$, $x(x^2 + 4) = 1$, $x = \dfrac{1}{x^2 + 4}$. $x_1 = 0.25$, $x_2 = 0.24615\ldots$, $x_3 = 0.24627\ldots$, $x_4 = 0.24627\ldots$ So $x = 0.2463$.
:::

::: q
Show that $x^3 - 5x - 2 = 0$ can be rearranged to $x = \sqrt{5 + \dfrac{2}{x}}$. Using $x_0 = 2$, find the positive solution to 3 decimal places.
---
$x^3 = 5x + 2$; divide by $x$: $x^2 = 5 + \dfrac2x$; square-root. $x_1 = 2.4495$, $x_2 = 2.4117$, $x_3 = 2.4144$, $x_4 = 2.4142$, $x_5 = 2.4142$. So $x = 2.414$.
:::

::: q
The formula $x_{n+1} = \dfrac{x_n^2 + 6}{5}$ is used with $x_0 = 1$. Find the equation it is solving, and the exact value the sequence converges to.
---
$x = \dfrac{x^2 + 6}{5}$, so $x^2 - 5x + 6 = 0$, roots 2 and 3. The terms $1.4, 1.592, 1.707, \ldots$ creep up towards 2, so the sequence converges to $2$.
:::

::: q
In the iteration $x_{n+1} = \sqrt[3]{20 - 5x_n}$, what does $x_3$ represent?
---
An estimate of a solution of the equation $x^3 + 5x - 20 = 0$ (i.e. $x^3 + 5x = 20$), after three iterations.
:::

::: watch
- **No conclusion after a sign change.** Working out $f(2) = -3$ and $f(3) = 13$ earns the M1; the A1 needs the sentence "change of sign, so there is a solution between 2 and 3".
- **Rounding each term before feeding it back in.** Use `Ans` so the calculator keeps full accuracy; write rounded values down but never type them back in.
- **Wrong bounds when checking accuracy.** For $2.28$ to 2 d.p., test $2.275$ and $2.285$ — not $2.27$ and $2.29$.
- **Starting the count wrongly.** If you are given $x_0$, the first new value is $x_1$. If you are given $x_1$, the first new value is $x_2$. Read the subscript.
- **"Show that" rearrangements with a step skipped.** Dividing $x^3 = 4x^2 + 3$ by $x^2$ must show $x = 4 + \frac{3}{x^2}$ with every term divided.
- **Calculator in the wrong mode** is rarely the issue here, but brackets are: $\sqrt[3]{20 - 5\,\text{Ans}}$ needs the whole of $20 - 5\,\text{Ans}$ inside the root.
:::

::: test
The sequence $x_{n+1} = 2 + \dfrac{3}{x_n}$ has $x_0 = 1$. (a) Find $x_1$, $x_2$ and $x_3$. (b) The sequence converges to a limit $L$. Find the exact value of $L$, explaining your reasoning. (5)

:::
