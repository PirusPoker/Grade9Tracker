## What it is

When two or more things happen — two dice, two spins, picking two counters — you need to **list every outcome systematically** before you can count. GCSE uses four tools: lists, **sample space grids** (tables), **Venn diagrams** and **tree diagrams**.

### Systematic lists and sample space grids

A **sample space** (possibility space) is the set of all possible outcomes. List it in an order that cannot miss anything.

- Three coins: fix the first coin, then the second: HHH, HHT, HTH, HTT, THH, THT, TTH, TTT — 8 outcomes.
- Two dice: a $6 \times 6$ grid, so **36** equally likely outcomes. For "total $= 8$" there are 5 cells: $(2,6), (3,5), (4,4), (5,3), (6,2)$, so $P = \frac{5}{36}$.

Two spinners, one numbered 1–4 and one numbered 1–3, give $4 \times 3 = 12$ outcomes. For "product is even", count the odd products instead: both numbers odd, $2 \times 2 = 4$ cells, so $P(\text{even}) = \frac{12 - 4}{12} = \frac23$.

A grid only gives probabilities by counting if **every cell is equally likely** — fair dice, fair spinners.

### Venn diagrams and set notation

A **Venn diagram** shows sets as overlapping circles inside a rectangle, the **universal set** $\xi$ (everything being considered). The notation:

| Notation | Meaning | Region |
|---|---|---|
| $A \cap B$ | $A$ **and** $B$ (intersection) | the overlap |
| $A \cup B$ | $A$ **or** $B$ or both (union) | everything inside either circle |
| $A'$ | **not** $A$ (complement) | everything outside circle $A$ |
| $A \cap B'$ | in $A$ but not in $B$ | the crescent of $A$ only |
| $n(A)$ | number of elements in $A$ | |

$\xi = \{1, 2, \dots, 12\}$, $A$ = even numbers, $B$ = multiples of 3. Then $A \cap B = \{6, 12\}$; $A$ only $= \{2, 4, 8, 10\}$; $B$ only $= \{3, 9\}$; outside both $= \{1, 5, 7, 11\}$.

$P(A \cup B) = \frac{8}{12} = \frac23$, $\quad P(A \cap B') = \frac{4}{12} = \frac13$.

**Fill a Venn diagram from the middle outwards.** If 28 study French, 22 study Spanish and 9 study both, the French-only region is $28 - 9 = 19$, not 28.

Adding the circles counts the overlap twice, which gives the rule
$$P(A \cup B) = P(A) + P(B) - P(A \cap B).$$
If $A$ and $B$ are mutually exclusive the circles do not overlap and this is just $P(A) + P(B)$.

### The AND and OR rules

- **OR** (mutually exclusive outcomes): **add**.
- **AND** (one thing then another): **multiply** along the branches.

Two events are **independent** if one happening does not change the probability of the other — separate spins of a spinner, rolls of a dice, picks **with replacement**. For independent events
$$P(A \text{ and } B) = P(A) \times P(B).$$

You can use this as a test: if $P(A) = 0.5$, $P(B) = 0.4$ and $P(A \cap B) = 0.2 = 0.5 \times 0.4$, then $A$ and $B$ are independent.

### Tree diagrams

A **tree diagram** shows each stage as a set of branches, with the probability written on each branch.

- Branches from one point **add to 1**.
- Multiply **along** a path to get the probability of that combined outcome.
- **Add** the paths that give the event you want.
- All the end probabilities add to 1 — a useful check.

**Independent (with replacement):** a spinner lands red with probability 0.4. Spun twice, $P(\text{exactly one red}) = 0.4 \times 0.6 + 0.6 \times 0.4 = 0.48$.

**Dependent (without replacement):** a bag holds 5 red and 3 blue counters; two are taken without replacement. After a red is taken there are 4 red out of 7, so the second-stage fractions change:
$$P(\text{both red}) = \frac58 \times \frac47 = \frac{20}{56} = \frac{5}{14}.$$

The probabilities on a dependent tree can also come from the context: "if it rains on Monday, the probability it rains on Tuesday is 0.6; if not, it is 0.2."

### "At least one"

"At least one" covers many paths; its complement "none" is just one path:
$$P(\text{at least one}) = 1 - P(\text{none}).$$
Three independent shots each hitting with probability 0.7: $P(\text{at least one hit}) = 1 - 0.3^3 = 0.973$.

### The underlying assumptions

Every calculation rests on assumptions you may be asked to state:

- outcomes in a grid are **equally likely** (fair dice, random selection);
- events multiplied as $P(A) \times P(B)$ are **independent** — for example, "the probability of being late on each day is the same and does not depend on the other days";
- in a "without replacement" problem, each counter is equally likely to be picked **from those remaining**.

If an assumption is false (a player gets better with practice, a bus that is late on Monday is more likely to be late on Tuesday), the answer is only an estimate.

::: terms
- **Sample space**: the list, grid or table of every possible outcome of an experiment.
- **Universal set (ξ)**: the set of everything being considered, drawn as the rectangle of a Venn diagram.
- **Intersection (A ∩ B)**: the elements in both A and B — the overlap of the circles.
- **Union (A ∪ B)**: the elements in A or B or both — everything inside either circle.
- **Complement (A′)**: every element of the universal set that is not in A.
- **Independent events**: events where one happening does not change the probability of the other, so P(A and B) = P(A) × P(B).
- **Dependent events**: events where the first outcome changes the probabilities for the second, as when picking without replacement.
- **Tree diagram**: a diagram of branches for each stage, with probabilities on the branches that are multiplied along a path.
:::

::: method
1. **Choose the diagram.** Two dice or two spinners → sample space grid. Overlapping categories (studies French / Spanish) → Venn diagram. Stages one after another, especially with changing probabilities → tree diagram.
2. **Venn diagrams:** fill the **intersection first**, then each "only" region by subtraction, then the outside region from the total. If a region is unknown, call it $x$ and form an equation using the total.
3. **Trees:** write every branch probability; check each pair adds to 1. For "without replacement" reduce **both** the numerator and the denominator on the second stage.
4. **Multiply along, add between.** List the paths you need ("RB and BR") before you calculate — this written list is often the method mark.
5. **"At least one"** → $1 - P(\text{none})$.
6. **"Show that" with an unknown number of counters:** write the tree product with $n$, e.g. $\dfrac{6}{n} \times \dfrac{5}{n - 1}$, set it equal to the given probability, clear fractions and rearrange to the stated quadratic **exactly**. Then solve and reject the impossible root.
7. **Non-calculator paper:** leave fractions unsimplified until the end, add over a common denominator, then cancel. On the calculator papers, give decimals to 3 s.f. if they do not terminate.
8. **"State an assumption"** → name the specific assumption: independence, fairness, or random selection — in context.
:::

::: example A sample space grid
Two fair six-sided dice are rolled. The score is the difference between the two numbers. Find $P(\text{score} = 2)$ and $P(\text{score} \ge 1)$.

Difference 2: $(1,3), (3,1), (2,4), (4,2), (3,5), (5,3), (4,6), (6,4)$ — 8 of 36 cells, so $P = \dfrac{8}{36} = \dfrac29$.

Score 0 happens on the 6 doubles, so $P(\text{score} \ge 1) = 1 - \dfrac{6}{36} = \dfrac56$.
:::

::: example A Venn diagram with an unknown
60 people were asked whether they swim or cycle. 30 swim, 24 cycle, $x$ do both, and twice as many do neither as do both. Find $x$, and the probability that a person picked at random does exactly one of the two activities.

Swim only $30 - x$, cycle only $24 - x$, both $x$, neither $2x$:
$$(30 - x) + (24 - x) + x + 2x = 60 \Rightarrow 54 + x = 60 \Rightarrow x = 6.$$

Swim only 24, cycle only 18, both 6, neither 12 (total 60 ✓). $P(\text{exactly one}) = \dfrac{24 + 18}{60} = \dfrac{42}{60} = \dfrac{7}{10}$.
:::

::: example Without replacement
A bag has 5 red and 3 blue counters. Two are taken at random without replacement. Find the probability they are the same colour.

$P(\text{RR}) = \dfrac58 \times \dfrac47 = \dfrac{20}{56}$, $\quad P(\text{BB}) = \dfrac38 \times \dfrac27 = \dfrac{6}{56}$.

$P(\text{same}) = \dfrac{20 + 6}{56} = \dfrac{26}{56} = \dfrac{13}{28}$.
:::

::: example A dependent tree from context
Priya walks or cycles to school. $P(\text{walks}) = 0.4$. If she walks, the probability she is late is $0.3$; if she cycles, it is $0.1$. (a) Find the probability she is late on a given day. (b) Assuming days are independent, find the probability she is late on at least one of two days.

(a) $0.4 \times 0.3 + 0.6 \times 0.1 = 0.12 + 0.06 = 0.18$.

(b) $P(\text{not late on a day}) = 0.82$. $P(\text{at least once}) = 1 - 0.82^2 = 1 - 0.6724 = 0.3276$.
:::

::: example Grade 9: forming a quadratic
A bag contains $n$ sweets, of which 6 are orange. Two sweets are taken at random without replacement. The probability that both are orange is $\frac13$. Show that $n^2 - n - 90 = 0$, and hence find $n$.

$$\frac{6}{n} \times \frac{5}{n - 1} = \frac13 \Rightarrow \frac{30}{n(n - 1)} = \frac13 \Rightarrow 90 = n^2 - n \Rightarrow n^2 - n - 90 = 0.$$

$(n - 10)(n + 9) = 0$, so $n = 10$ ($n = -9$ is impossible).
:::

::: q
A fair spinner numbered 1 to 4 and a fair spinner numbered 1 to 3 are spun and the scores added. Find $P(\text{total} = 5)$.
---
12 outcomes; total 5: $(2,3), (3,2), (4,1)$. $P = \dfrac{3}{12} = \dfrac14$.
:::

::: q
$\xi = \{1, 2, \dots, 15\}$, $A$ = prime numbers, $B$ = odd numbers. List $A \cap B$, and find $P(A \cup B)$ and $P(A \cap B')$.
---
$A = \{2,3,5,7,11,13\}$. $A \cap B = \{3, 5, 7, 11, 13\}$. $A \cup B = \{1,2,3,5,7,9,11,13,15\}$: $P = \dfrac{9}{15} = \dfrac35$. $A \cap B' = \{2\}$: $P = \dfrac{1}{15}$.
:::

::: q
40 people: 18 own a dog, 15 own a cat, 7 own both. Find the probability that a person chosen at random owns a cat but not a dog, and the probability they own neither.
---
Cat only $15 - 7 = 8$: $\dfrac{8}{40} = \dfrac15$. Dog only 11; neither $40 - (11 + 7 + 8) = 14$: $\dfrac{14}{40} = \dfrac{7}{20}$.
:::

::: q
A spinner lands on green with probability $0.25$. It is spun twice. Find the probability that both spins give the same result (green–green or not green–not green).
---
$0.25^2 + 0.75^2 = 0.0625 + 0.5625 = 0.625$.
:::

::: q
A bag has 4 green and 6 yellow balls. Two are taken without replacement. Find the probability that at least one is green.
---
$1 - P(\text{YY}) = 1 - \dfrac{6}{10} \times \dfrac59 = 1 - \dfrac{30}{90} = \dfrac23$.
:::

::: q
$P(\text{rain on Monday}) = 0.3$. If it rains on Monday, $P(\text{rain on Tuesday}) = 0.6$; otherwise $0.2$. Find the probability it rains on exactly one of the two days.
---
Rain then dry: $0.3 \times 0.4 = 0.12$. Dry then rain: $0.7 \times 0.2 = 0.14$. Total $0.26$.
:::

::: q
Three fair coins are flipped. Find the probability of at least one tail.
---
$1 - P(\text{HHH}) = 1 - \dfrac18 = \dfrac78$.
:::

::: q
$P(A) = 0.6$, $P(B) = 0.3$ and $P(A \cap B) = 0.15$. Are $A$ and $B$ independent? Explain.
---
$P(A) \times P(B) = 0.18 \ne 0.15$, so they are not independent.
:::

::: q
$P(A) = 0.45$, $P(B) = 0.3$, $P(A \cap B) = 0.1$. Find $P(A \cup B)$ and $P(\text{neither})$.
---
$P(A \cup B) = 0.45 + 0.3 - 0.1 = 0.65$. Neither: $1 - 0.65 = 0.35$.
:::

::: q
Kim says the probability she scores a penalty is $0.8$, so the probability she scores three in a row is $0.8^3 = 0.512$. State an assumption she has made.
---
That each penalty is independent of the others and the probability of scoring stays $0.8$ every time (she does not get nervous or improve).
:::

::: watch
- **Without replacement** changes the second branch: numerator **and** denominator drop. $\frac58 \times \frac58$ for two reds without replacement scores zero.
- **Venn diagrams:** the number given for a set includes the overlap. Put the intersection in first, then subtract.
- Adding when you should multiply (or the reverse): **AND along a branch → multiply; OR between paths → add**.
- "Exactly one" needs **both orders** (RB and BR). Forgetting the second path halves the answer.
- Branches from one point must add to 1 — check before you multiply.
- In a "show that", every line of algebra must be seen; jumping from the fractions straight to the quadratic loses the marks.
- Reject the negative root of the quadratic and say why.
:::

::: test
Two fair six-sided dice are rolled. Find the probability that the total is at least 10. (2)
---
Totals of 10, 11, 12: $(4,6),(5,5),(6,4),(5,6),(6,5),(6,6)$ — 6 outcomes (M1). $P = \dfrac{6}{36} = \dfrac16$ (A1).
:::

::: test
$\xi = \{1, 2, 3, \dots, 10\}$, $A = \{1, 2, 3, 4, 5, 6\}$ and $B = \{2, 4, 6, 8, 10\}$. (a) List the elements of $A \cap B$. (b) A number is chosen at random from $\xi$. Find $P\big((A \cup B)'\big)$. (c) Find $P(B \cap A')$. (4)
---
(a) $\{2, 4, 6\}$ (B1).

(b) $A \cup B = \{1,2,3,4,5,6,8,10\}$, so $(A \cup B)' = \{7, 9\}$ (M1); $P = \dfrac{2}{10} = \dfrac15$ (A1).

(c) $B \cap A' = \{8, 10\}$: $P = \dfrac{2}{10} = \dfrac15$ (B1).
:::

::: test
50 students were asked if they like tea or coffee. 23 like tea, 19 like coffee, and $x$ like both. Three times as many like neither as like both. Find the probability that a student chosen at random likes exactly one of the drinks. (4)
---
$(23 - x) + (19 - x) + x + 3x = 50$ (M1). $42 + 2x = 50$, so $x = 4$ (A1).

Tea only 19, coffee only 15 (M1). $P = \dfrac{34}{50} = \dfrac{17}{25}$ (A1).
:::

::: test
The probability that Tom's bus is late is $0.2$ on any day, independently of other days. Find the probability that over two days the bus is (a) late on both days, (b) late on exactly one day. (3)
---
(a) $0.2 \times 0.2 = 0.04$ (B1).

(b) $0.2 \times 0.8 + 0.8 \times 0.2$ (M1) $= 0.32$ (A1).
:::

::: test
A bag contains 4 red, 3 blue and 2 green counters. Two counters are taken at random without replacement. Work out the probability that they are different colours. (4)
---
$P(\text{same}) = \dfrac49 \cdot \dfrac38 + \dfrac39 \cdot \dfrac28 + \dfrac29 \cdot \dfrac18$ (M1 for one product, M1 for the sum) $= \dfrac{12 + 6 + 2}{72} = \dfrac{20}{72}$ (A1).

$P(\text{different}) = 1 - \dfrac{20}{72} = \dfrac{52}{72} = \dfrac{13}{18}$ (A1).
:::

::: test
The probability that a train is late is $0.15$ on each day, independently. Work out the probability that the train is late on at least one of three days. Give your answer to 3 significant figures. (3)
---
$P(\text{not late on all three}) = 0.85^3 = 0.614125$ (M1). $1 - 0.614125$ (M1) $= 0.386$ (A1).
:::

::: test
The probability that Saturday is sunny is $0.7$. If Saturday is sunny, the probability that Sunday is sunny is $0.8$. If Saturday is not sunny, the probability that Sunday is sunny is $0.5$. (a) Find the probability that exactly one day is sunny. (b) Find the probability that at least one day is sunny. (4)
---
(a) $0.7 \times 0.2 + 0.3 \times 0.5$ (M1) $= 0.14 + 0.15 = 0.29$ (A1).

(b) $P(\text{neither}) = 0.3 \times 0.5 = 0.15$ (M1); $1 - 0.15 = 0.85$ (A1).
:::

::: test
A bag contains $n$ counters, 3 of which are blue. Two counters are taken at random without replacement. The probability that both are blue is $\frac{1}{12}$. (a) Show that $n^2 - n - 72 = 0$. (b) Find $n$. (5)
---
(a) $\dfrac{3}{n} \times \dfrac{2}{n - 1} = \dfrac{1}{12}$ (M1). $\dfrac{6}{n(n - 1)} = \dfrac{1}{12}$, so $72 = n(n - 1)$ (M1), giving $n^2 - n - 72 = 0$ (A1).

(b) $(n - 9)(n + 8) = 0$ (M1); $n = 9$ since $n$ must be positive (A1).
:::

::: test
A bag contains 5 red and 4 blue counters. Three counters are taken at random without replacement. Work out the probability that exactly two of them are red. (4)
---
Paths RRB, RBR, BRR (M1). $P(\text{RRB}) = \dfrac59 \times \dfrac48 \times \dfrac47 = \dfrac{80}{504}$ (M1); each path has the same product (M1).

$3 \times \dfrac{80}{504} = \dfrac{240}{504} = \dfrac{10}{21}$ (A1).
:::
