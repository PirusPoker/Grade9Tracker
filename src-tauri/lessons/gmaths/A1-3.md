## What it is

Algebra uses letters to stand for numbers. Before you can manipulate anything you need to read the notation exactly as mathematicians write it, substitute numbers into it without sign errors, and know the names of the things you are working with — exam questions ask "which of these is an identity?" or "write down a factor of…" and expect the precise word.

### Notation (the shorthand)

| We write | It means |
|---|---|
| $ab$ | $a \times b$ |
| $3y$ | $y + y + y$, or $3 \times y$ |
| $a^2$ | $a \times a$ |
| $a^3$ | $a \times a \times a$ |
| $a^2b$ | $a \times a \times b$ (only $a$ is squared) |
| $\dfrac{a}{b}$ | $a \div b$ |
| $\frac12 x$ or $\dfrac{x}{2}$ | half of $x$ — written as a fraction, not $0.5x$ |
| $3(x + 2)$ | $3 \times (x + 2)$: the whole bracket is multiplied by 3 |

Conventions: the number goes first ($3y$, not $y3$), letters usually go in alphabetical order ($3ab$, not $3ba$), and we do not write a 1 in front ($x$, not $1x$). Coefficients are written as fractions rather than decimals: $\frac13 x$, not $0.333x$, because $\frac13$ is exact.

**Watch the powers.** $2x^2$ means $2 \times x^2$ — only $x$ is squared. $(2x)^2 = 4x^2$ because the bracket squares everything inside. Likewise $-x^2$ means $-(x^2)$: when $x = -3$, $-x^2 = -9$ but $(-x)^2 = 9$.

### Substitution

To **substitute**, replace each letter by its value **in brackets**, then follow the order of operations (brackets, indices, division and multiplication, addition and subtraction).

If $a = -3$ and $b = 4$:

$$2a^2 - 3ab = 2(-3)^2 - 3(-3)(4) = 2(9) + 36 = 54$$

$$\frac{(a - b)^2}{2b} = \frac{(-7)^2}{8} = \frac{49}{8} = 6.125$$

The brackets around $-3$ are what stop you writing $2 \times -3^2 = -18$.

**Scientific formulae** are substitution with context. The equations of motion $v = u + at$ and $s = ut + \frac12 at^2$ (where $u$ is initial velocity, $v$ final velocity, $a$ acceleration, $t$ time and $s$ displacement) often appear:

$u = 4$, $t = 3$, $a = -2$: $\quad s = 4(3) + \frac12(-2)(3)^2 = 12 - 9 = 3$.

Units follow the inputs: if $u$ is in m/s and $t$ in seconds, $s$ is in metres. On a calculator paper you may substitute standard-form values: use the $\times 10^x$ key and put the whole denominator in brackets.

### Vocabulary

- A **term** is a single number, letter, or product of them: $5x$, $-3ab$, $7$, $x^2y$. Terms are separated by $+$ and $-$ signs. The number in a term is its **coefficient**; a term with no letter is a **constant**.
- An **expression** is a collection of terms with no equals sign: $3x^2 - 5x + 2$. You **simplify** an expression; you cannot solve it.
- An **equation** is true only for particular values of the letter: $3x + 1 = 10$ is true only when $x = 3$. You **solve** an equation.
- A **formula** is a rule connecting two or more quantities, each letter standing for something: $A = \pi r^2$, $v = u + at$. You **substitute** into a formula or **rearrange** it.
- An **identity** is true for **every** value of the letters. It is written with $\equiv$: $2(x + 3) \equiv 2x + 6$, or $(x + 1)^2 \equiv x^2 + 2x + 1$. You **prove** or **show** an identity by making one side look exactly like the other.
- An **inequality** compares with $<$, $>$, $\le$ or $\ge$: $2x - 1 > 7$. Its solution is a range of values ($x > 4$).
- A **factor** is something that multiplies to make the expression: $3$, $x$, $3x$ and $(x - 2)$ are all factors of $3x(x - 2)$. Factors are joined by $\times$; terms are joined by $+$ or $-$.

**Test the difference between an equation and an identity** by trying two values. $x^2 - 9 = (x - 3)(x + 3)$ works for $x = 0$ ($-9 = -9$), $x = 5$ ($16 = 16$), and every other value — it is an identity. $x^2 = 3x$ works for $x = 3$ but fails at $x = 1$ — it is an equation. One counter-example is enough to show something is **not** an identity; to show it **is** one you must use algebra, not examples.

::: terms
- **Term**: a single number, letter or product of them, separated from other terms by + or − signs.
- **Coefficient**: the number multiplying a letter in a term, such as the 5 in 5x² or the ⅓ in ⅓x.
- **Expression**: a collection of terms with no equals sign, such as 3x² − 5x + 2; it can be simplified but not solved.
- **Equation**: a statement with an equals sign that is true only for particular values of the letter.
- **Formula**: a rule linking quantities, such as A = πr², into which values are substituted.
- **Identity**: a statement true for every value of the letters, written with the symbol ≡.
- **Inequality**: a statement using <, >, ≤ or ≥ whose solution is a range of values.
- **Factor**: a number or expression that multiplies with others to make a given expression.
:::

::: method
1. **Read the notation literally.** $ab = a \times b$; $a^2b = a \times a \times b$; $2x^2$ squares only the $x$; $(2x)^2$ squares the lot. Write coefficients as fractions, not rounded decimals.
2. **Substituting: brackets first.** Write the formula, then rewrite it with every value in brackets, e.g. $s = (4)(3) + \frac12(-2)(3)^2$. This line earns M1 even if the arithmetic later slips.
3. **Order of operations:** powers before multiplying, multiplying before adding. $-3^2 = -9$ but $(-3)^2 = 9$.
4. **Paper 1 (non-calculator):** expect negatives and fractions — keep fractions exact ($\frac78$, not $0.88$). **Papers 2 and 3:** expect standard form and scientific formulae. Enter fractions with the fraction key, put whole numerators and denominators in brackets, and write the full display before rounding.
5. **Vocabulary questions:** check for an equals sign (none → expression), then ask "true for all values?" (yes → identity; no → equation). A formula links named quantities. Terms are added; factors are multiplied.
6. **"Show that … is not an identity":** one numerical counter-example is enough. **"Prove … is an identity":** expand or simplify one side until it matches the other, writing every step; examples alone score nothing.
7. **Include units** when the formula is in context, and round only at the end.
:::

::: example Writing in algebraic notation
Simplify (a) $4 \times a \times b \times a$ (b) $x \div 3 + x \div 3$ (c) $p \times p \times p \times q \times 5$.

(a) $4a^2b$ (b) $\dfrac{x}{3} + \dfrac{x}{3} = \dfrac{2x}{3}$, also written $\frac23 x$ (c) $5p^3q$.
:::

::: example Substituting negatives and fractions (non-calculator)
Find the value of $x^3 - 2x$ when $x = -\frac12$.

$$\left(-\tfrac12\right)^3 - 2\left(-\tfrac12\right) = -\tfrac18 + 1 = \tfrac78$$

A negative number cubed stays negative; minus a negative becomes plus.
:::

::: example A scientific formula in standard form (calculator)
The force of attraction between the Earth and the Moon is $F = \dfrac{Gm_1m_2}{r^2}$ where $G = 6.67 \times 10^{-11}$, $m_1 = 5.97 \times 10^{24}$, $m_2 = 7.35 \times 10^{22}$ and $r = 3.84 \times 10^{8}$. Work out $F$, giving your answer in standard form to 3 significant figures.

$$F = \frac{(6.67 \times 10^{-11})(5.97 \times 10^{24})(7.35 \times 10^{22})}{(3.84 \times 10^{8})^2} = 1.98483\ldots \times 10^{20}$$

$F = 1.98 \times 10^{20}$ newtons (3 s.f.).
:::

::: example Naming the statement
For each, write expression, equation, formula or identity:
(a) $5x - 2 = 13$ (b) $5x - 2$ (c) $P = 2l + 2w$ (d) $5(x - 2) \equiv 5x - 10$.

(a) Equation — true only for $x = 3$. (b) Expression — no equals sign. (c) Formula — links perimeter, length and width. (d) Identity — true for every $x$.
:::

::: example Using an identity to find unknowns (grade 8)
$3(2x - a) + b(x + 4) \equiv 10x + 4$. Find the values of $a$ and $b$.

Expand the left: $6x - 3a + bx + 4b = (6 + b)x + (4b - 3a)$.

Because it is an identity, the coefficients of $x$ must match and the constants must match:

$x$: $6 + b = 10 \Rightarrow b = 4$. Constants: $4b - 3a = 4 \Rightarrow 16 - 3a = 4 \Rightarrow a = 4$.

Check with $x = 1$: $3(2 - 4) + 4(5) = -6 + 20 = 14 = 10 + 4$. ✓
:::

::: q
Simplify (a) $y \times y \times 7 \times y$ (b) $2 \times m \div n$ (c) $a \times b \times 3 \times a \times b$.
---
(a) $7y^3$ (b) $\dfrac{2m}{n}$ (c) $3a^2b^2$.
:::

::: q
$x = -3$. Find the values of $-x^2$, $(-x)^2$ and $2x^3$.
---
$-x^2 = -(9) = -9$. $\quad (-x)^2 = 3^2 = 9$. $\quad 2x^3 = 2(-27) = -54$.
:::

::: q
$p = -2$ and $q = 5$. Work out the value of $\dfrac{p^2q - 3q}{2p - q}$.
---
Numerator: $(-2)^2(5) - 3(5) = 20 - 15 = 5$. Denominator: $2(-2) - 5 = -9$. Value $= -\dfrac59$.
:::

::: q
Use $v = u + at$ to find $v$ when $u = 12$, $a = -9.8$ and $t = 1.5$.
---
$v = 12 + (-9.8)(1.5) = 12 - 14.7 = -2.7$ (the object is now moving the other way).
:::

::: q
Kinetic energy is $E = \frac12 mv^2$. Find $E$ when $m = 0.4$ and $v = 15$.
---
$E = \frac12(0.4)(15)^2 = 0.2 \times 225 = 45$ joules.
:::

::: q
The period of a pendulum is $T = 2\pi\sqrt{\dfrac{L}{g}}$. Find $T$ when $L = 0.8$ and $g = 9.8$, to 3 significant figures.
---
$T = 2\pi\sqrt{0.8 \div 9.8} = 2\pi \times 0.2857\ldots = 1.7951\ldots = 1.80$ s (3 s.f.).
:::

::: q
Show that $x^2 + 1 = (x + 1)^2$ is not an identity.
---
Try $x = 1$: left side $= 2$, right side $= 4$. They differ, so it is not true for all $x$ — it is not an identity. (It is an equation, true only when $x = 0$.)
:::

::: q
For the expression $4x^2y - 6xy$, write down (a) its two terms (b) the highest common factor of the terms.
---
(a) $4x^2y$ and $-6xy$. (b) $2xy$, since $4x^2y = 2xy \times 2x$ and $6xy = 2xy \times 3$.
:::

::: q
$4(x + a) - 2(bx - 1) \equiv -2x + 14$. Find $a$ and $b$.
---
Expand: $(4 - 2b)x + (4a + 2)$. $x$: $4 - 2b = -2 \Rightarrow b = 3$. Constants: $4a + 2 = 14 \Rightarrow a = 3$.
:::

::: watch
- **Squaring negatives:** type $(-3)^2$ with brackets. $-3^2$ on a calculator gives $-9$ and loses the mark.
- **$2x^2$ is not $(2x)^2$.** When $x = 5$, $2x^2 = 50$ but $(2x)^2 = 100$.
- **Rounding a fraction coefficient:** $\frac13 x$ is exact; $0.33x$ is wrong.
- **Terms versus factors:** in $3x + 6$ the terms are $3x$ and $6$; in $3(x + 2)$ the factors are $3$ and $(x + 2)$. Many candidates swap the words.
- **"Prove it is an identity" with numbers:** testing values can only disprove. A proof needs algebra.
- **Standard form substitution:** forgetting to bracket the whole denominator divides by only part of it.
:::

::: test
$s = ut + \frac12 at^2$. Work out the value of $s$ when $u = 6$, $t = 4$ and $a = -1.5$. (2)
---
$s = 6(4) + \frac12(-1.5)(4)^2$ (M1) $= 24 - 12 = 12$ (A1).

::: test
$v^2 = u^2 + 2as$. Work out $v$ when $u = 0$, $a = 9.8$ and $s = 12.5$, given $v > 0$. Give your answer correct to 3 significant figures. (3)
---
$v^2 = 0 + 2(9.8)(12.5) = 245$ (M1). $v = \sqrt{245}$ (M1) $= 15.7$ (A1).
:::

::: test
Without a calculator, work out the value of $\dfrac{4a^2 - b}{ab}$ when $a = \frac12$ and $b = -3$. (3)
---
Numerator $4\left(\tfrac14\right) - (-3) = 1 + 3 = 4$ (M1). Denominator $\tfrac12 \times (-3) = -\tfrac32$ (M1). $4 \div \left(-\tfrac32\right) = -\dfrac83$ (A1).
:::

::: test
Kai says $(x + 2)^2 \equiv x^2 + 4$. Show that Kai is wrong. (2)
---
Counter-example, e.g. $x = 1$: $(1 + 2)^2 = 9$ but $1 + 4 = 5$ (M1); $9 \ne 5$ so it is not true for all $x$ (A1). (Or expand: $(x + 2)^2 = x^2 + 4x + 4$.)
:::

::: test
The force on a charged particle is $F = qvB$. Work out $F$ when $q = 1.6 \times 10^{-19}$, $v = 2.4 \times 10^{5}$ and $B = 3.2 \times 10^{-3}$. Give your answer in standard form to 3 significant figures. (3)
---
$(1.6 \times 10^{-19})(2.4 \times 10^{5})(3.2 \times 10^{-3})$ (M1) $= 1.2288 \times 10^{-16}$ (A1) $= 1.23 \times 10^{-16}$ (A1).
:::

::: test
$x = 3$ is a solution of the equation $2x^2 - kx = 3k$. Find the value of $k$. (3)
---
$2(3)^2 - 3k = 3k$ (M1). $18 = 6k$ (M1). $k = 3$ (A1).
:::

::: test
$a(x + 2)^2 + b(x - 1) \equiv 3x^2 + 13x + c$. Find the values of $a$, $b$ and $c$. (4)
---
LHS $= ax^2 + 4ax + 4a + bx - b$ (M1). $x^2$: $a = 3$ (A1). $x$: $4a + b = 13 \Rightarrow b = 1$ (A1). Constant: $c = 4a - b = 12 - 1 = 11$ (A1).
:::
