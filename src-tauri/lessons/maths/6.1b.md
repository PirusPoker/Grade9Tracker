## What it is

A **histogram** looks like a bar chart but works differently: it is for **continuous** data grouped into classes, the bars **touch**, and — the crucial part — the **area** of each bar represents the frequency, not the height. The height is the **frequency density**:

$$\text{frequency density} = \frac{\text{frequency}}{\text{class width}} \qquad\Longleftrightarrow\qquad \text{frequency} = \text{frequency density} \times \text{class width}$$

That is what allows classes of **unequal width**: a wide class with a modest frequency gets a low bar, so the picture is not distorted by how the classes happened to be chosen.

The questions go both ways — draw a histogram from a table (compute densities), or read a histogram back into a table (multiply height by width), then use the frequencies: totals, a fraction above a value, an estimate of the mean, or the number in part of a class (proportional to the part of the width).

::: terms
- **Histogram**: a chart for grouped continuous data in which the area of each bar is proportional to the frequency.
- **Frequency density**: frequency ÷ class width — the height of a histogram bar.
- **Class width**: the difference between the upper and lower boundaries of a class.
- **Frequency from a histogram**: frequency = frequency density × class width.
:::

::: method
1. **From table to histogram:** add a "class width" column and a "frequency density" column ($f \div w$). Plot the vertical axis as frequency density; draw each bar over its class interval with that height; no gaps.
2. **From histogram to table:** read the height (density) of each bar and multiply by the class width for the frequency.
3. **If the density axis has no scale:** one bar's frequency is usually given; use it to find the scale (density $= f \div w$ for that bar), then read the others.
4. **Part of a class:** frequency is proportional to width within a class, e.g. the number in $15 \le x < 20$ of a class $10 \le x < 20$ is half that class's frequency.
5. **Estimate the mean:** midpoints times frequencies, summed, over the total — see 6.2.
6. **Choose the axis scale** so the tallest bar fits; label it "frequency density".
:::

::: example Table to histogram
Times taken (minutes) by 60 runners: $0 < t \le 10$: 8; $10 < t \le 15$: 15; $15 < t \le 20$: 21; $20 < t \le 30$: 16. Find the frequency densities.

Widths $10, 5, 5, 10$. Densities $0.8, 3, 4.2, 1.6$. Bars of those heights over each interval.
:::

::: example Histogram to table
A histogram of masses (kg) has bars: $0$–$5$ height 2; $5$–$8$ height 6; $8$–$10$ height 9; $10$–$20$ height 1.5. Find the frequencies and the total.

$2 \times 5 = 10$; $6 \times 3 = 18$; $9 \times 2 = 18$; $1.5 \times 10 = 15$. Total $61$.
:::

::: example Finding the scale from one bar
A histogram has no numbers on the density axis. The bar for $20 < x \le 30$ is 4 cm tall and represents 24 people. The bar for $30 < x \le 35$ is 5 cm tall. How many people are in $30 < x \le 35$?

For the first bar, density $= 24 \div 10 = 2.4$ per unit, so 1 cm of height $= 0.6$. The second bar has density $5 \times 0.6 = 3$; frequency $= 3 \times 5 = 15$.
:::

::: example Part of a class
Using the runners' data above, estimate how many took more than 25 minutes.

The class $20 < t \le 30$ has 16 runners over a width of 10; the part $25$ to $30$ is half the width, so about $8$.
:::

::: example Estimating the mean from a histogram
For the masses above (frequencies 10, 18, 18, 15), estimate the mean mass.

Midpoints $2.5, 6.5, 9, 15$. $\sum fx = 25 + 117 + 162 + 225 = 529$. Mean $\approx 529 \div 61 = 8.67$ kg.
:::

::: example Why the area matters
A survey groups ages as $0$–$20$ (frequency 40) and $20$–$25$ (frequency 20). Explain why drawing bars of heights 40 and 20 would mislead.

The first class is four times as wide; with heights equal to frequency, it would look twice as popular per year when in fact the $20$–$25$ group is denser: densities are $2$ and $4$ per year — the narrow class is the busier one.
:::

::: q
Complete the frequency densities: $0 \le x < 4$: 12; $4 \le x < 6$: 9; $6 \le x < 10$: 6; $10 \le x < 20$: 5.
---
$3$; $4.5$; $1.5$; $0.5$.
:::

::: q
A histogram has bars: $0$–$10$ density 1.2; $10$–$15$ density 3.6; $15$–$25$ density 0.9. Find the frequencies.
---
$12$; $18$; $9$.
:::

::: q
Using the previous histogram, what fraction of the data is less than 15?
---
$\dfrac{30}{39} = \dfrac{10}{13}$.
:::

::: q
A bar for $5 < x \le 15$ has frequency 30. What height should the bar for $15 < x \le 20$ have if its frequency is 25, in the same units?
---
First density $3$; second density $5$ — the second bar is $\frac53$ times as tall.
:::

::: q
On a histogram with no scale, the $0$–$20$ bar is 3 cm high and represents 60 items. The $20$–$25$ bar is 6 cm high. How many items does it represent?
---
First bar: density $60 \div 20 = 3$ per unit, so 1 cm of height $= 1$ per unit. Second bar: density $6$; frequency $6 \times 5 = 30$.
:::

::: q
Estimate how many values lie between 12 and 15 in the class $10 \le x < 15$ of frequency 18.
---
$\dfrac35 \times 18 = 10.8 \approx 11$.
:::

::: q
Estimate the mean from the table: $0 \le x < 4$: 12; $4 \le x < 6$: 9; $6 \le x < 10$: 6; $10 \le x < 20$: 5.
---
$\dfrac{2 \times 12 + 5 \times 9 + 8 \times 6 + 15 \times 5}{32} = \dfrac{192}{32} = 6$.
:::

::: q
Why do the bars of a histogram touch, while those of a bar chart do not?
---
Histogram classes are continuous intervals that share boundaries; bar chart categories are separate.
:::

::: q
Two classes have the same frequency, but one is twice as wide as the other. Compare their bar heights.
---
The wider class's bar is half as tall.
:::

::: watch
- **Height is frequency density, not frequency.** Multiply by the width to get frequency; divide by the width to get height.
- Bars **touch**; the horizontal axis is a continuous scale, not category labels.
- Class width is upper bound minus lower bound — read the boundaries, not the frequency.
- Label the vertical axis "Frequency density".
- Reading a fraction within a class assumes the data is spread evenly — say "estimate".
- Check the total frequency against any total the question gives; it is a free check on your reading.
:::

::: test
A class $10 < x \le 15$ has frequency 20. Find its frequency density. (1)
---
$20 \div 5 = 4$.
:::

::: test
A class $20 < x \le 40$ has frequency density 1.5. Find its frequency. (1)
---
$1.5 \times 20 = 30$.
:::

::: test
Explain why a histogram with unequal class widths must use frequency density, not frequency, on the vertical axis. (1)
---
So that the area of each bar represents the frequency; with frequency as height, wider classes would look more common than they are.
:::

::: test
A histogram has bars: $0$–$5$ with frequency density 2, $5$–$15$ with density 3, $15$–$20$ with density 1. Find the total frequency. (2)
---
Frequencies $10$, $30$, $5$ (1); total $45$ (1).
:::

::: test
From the same histogram, estimate how many values lie between 10 and 20. (2)
---
Half of the $5$–$15$ bar $= 15$ (1), plus the whole of $15$–$20$ $= 5$: estimate 20 (1).
:::

::: test
One class, $30 < x \le 50$, has frequency 24. Another, $50 < x \le 55$, has frequency 8. Which bar is taller on a histogram? Show why. (2)
---
Densities $24 \div 20 = 1.2$ and $8 \div 5 = 1.6$ (1); the $50$–$55$ bar is taller even though it has the smaller frequency (1).
:::

::: test
A histogram has a bar from 0 to 20 of height 0.8 and a bar from 20 to 30 of height 2.4. Find the frequency of each class and state the modal class. (2)
---
$0.8 \times 20 = 16$ and $2.4 \times 10 = 24$ (1); modal class is $20$–$30$ (the tallest bar, i.e. highest density) (1).
:::

::: test
Classes $0$–$5$, $5$–$15$ and $15$–$20$ have frequencies 10, 30 and 5. Which class contains the median? (1)
---
$45 \div 2 = 22.5$, and the cumulative frequency passes 22.5 in the $5$–$15$ class.
:::
