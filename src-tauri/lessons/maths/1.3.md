## What it is

A decimal is a fraction whose denominator is a power of ten, written with a point: $0.37 = \dfrac{37}{100}$, $2.125 = 2 + \dfrac{125}{1000} = 2\dfrac18$. That is why every **terminating** decimal is a fraction — read the last place value, write it over that power of ten, simplify.

Some fractions give **recurring** decimals instead: $\dfrac13 = 0.333\ldots = 0.\dot3$, $\dfrac{5}{11} = 0.454545\ldots = 0.\dot4\dot5$. The dots mark the start and end of the repeating block. A fraction terminates only when its simplified denominator has no prime factors other than 2 and 5.

The Higher-tier skill is going backwards — turning a recurring decimal into a fraction — and it is a **proof**-style question: you must show the algebra, not just write down the answer.

Converting between fractions, decimals and percentages: fraction → decimal is a division ($\frac38 = 3 \div 8 = 0.375$); decimal → percentage multiply by 100; percentage → fraction is over 100 then simplify.

::: method
1. **Terminating decimal → fraction:** write it over $10$, $100$, $1000$ … according to the last decimal place, then cancel. $0.375 = \dfrac{375}{1000} = \dfrac{3}{8}$.
2. **Recurring decimal → fraction:** let $x$ equal the decimal. Multiply by $10^n$ where $n$ is the length of the repeating block, so the repeating parts line up. Subtract the two equations — the recurring tails cancel. Solve for $x$, simplify.
3. If there are non-repeating digits before the block, multiply by two different powers of 10 so that in *both* equations the repeating block starts immediately after the point, then subtract.
4. **Ordering decimals:** compare place by place from the left; pad with zeros so they have the same number of decimal places.
5. **Will it terminate?** Simplify the fraction; if the denominator is only $2$s and $5$s ($2^a 5^b$), it terminates; otherwise it recurs.
:::

::: example Terminating decimal to a fraction
Write $0.264$ as a fraction in its simplest form.

$0.264 = \dfrac{264}{1000} = \dfrac{33}{125}$ (dividing top and bottom by 8).
:::

::: example One recurring digit
Show that $0.\dot7 = \dfrac{7}{9}$.

Let $x = 0.777\ldots$. Then $10x = 7.777\ldots$

Subtract: $10x - x = 7.777\ldots - 0.777\ldots$, so $9x = 7$, so $x = \dfrac79$. ∎
:::

::: example A two-digit block
Convert $0.\dot2\dot7$ to a fraction.

$x = 0.272727\ldots$; the block has two digits, so $100x = 27.272727\ldots$

$100x - x = 27$, so $99x = 27$, $x = \dfrac{27}{99} = \dfrac{3}{11}$.
:::

::: example Digits before the block
Convert $0.4\dot1\dot6$ to a fraction.

$x = 0.4161616\ldots$

$10x = 4.161616\ldots$ (block now starts straight after the point) and $1000x = 416.161616\ldots$

$1000x - 10x = 416 - 4 = 412$, so $990x = 412$, $x = \dfrac{412}{990} = \dfrac{206}{495}$.
:::

::: example Whole-number part too
Write $2.\dot3\dot6$ as a mixed number.

$x = 2.363636\ldots$, $100x = 236.363636\ldots$, $99x = 234$, $x = \dfrac{234}{99} = \dfrac{26}{11} = 2\dfrac{4}{11}$.
:::

::: example Will it terminate?
Without dividing, decide whether $\dfrac{7}{40}$ and $\dfrac{5}{12}$ give terminating decimals.

$40 = 2^3 \times 5$: only 2s and 5s, so $\dfrac{7}{40}$ terminates ($= 0.175$).

$12 = 2^2 \times 3$: a factor of 3, so $\dfrac{5}{12}$ recurs ($= 0.41\dot6$).
:::

::: q
Write $0.68$ and $0.0325$ as fractions in their simplest form.
---
$\dfrac{68}{100} = \dfrac{17}{25}$; $\dfrac{325}{10000} = \dfrac{13}{400}$.
:::

::: q
Write $\dfrac{7}{16}$ as a decimal and as a percentage.
---
$7 \div 16 = 0.4375 = 43.75\%$.
:::

::: q
Prove that $0.\dot5 = \dfrac59$.
---
$x = 0.555\ldots$, $10x = 5.555\ldots$, $9x = 5$, $x = \dfrac59$. ∎
:::

::: q
Convert $0.\dot4\dot5$ to a fraction in its simplest form.
---
$100x - x = 45 \Rightarrow 99x = 45 \Rightarrow x = \dfrac{45}{99} = \dfrac{5}{11}$.
:::

::: q
Convert $0.\dot1\dot2\dot3$ to a fraction in its simplest form.
---
Three-digit block: $1000x - x = 123 \Rightarrow x = \dfrac{123}{999} = \dfrac{41}{333}$.
:::

::: q
Convert $0.2\dot7$ to a fraction in its simplest form.
---
$10x = 2.777\ldots$, $100x = 27.777\ldots$, $90x = 25$, $x = \dfrac{25}{90} = \dfrac{5}{18}$.
:::

::: q
Convert $0.5\dot3\dot8$ to a fraction.
---
$10x = 5.383838\ldots$, $1000x = 538.383838\ldots$, $990x = 533$, $x = \dfrac{533}{990}$.
:::

::: q
Write $1.\dot8\dot1$ as a mixed number in its simplest form.
---
$99x = 181 - 1 = 180$, $x = \dfrac{180}{99} = \dfrac{20}{11} = 1\dfrac{9}{11}$.
:::

::: q
Put $0.72$, $0.7\dot2$, $0.\dot7\dot2$ and $0.702$ in order, smallest first.
---
$0.702 < 0.72 < 0.7222\ldots < 0.7272\ldots$: $\ 0.702,\ 0.72,\ 0.7\dot2,\ 0.\dot7\dot2$.
:::

::: q
Which of $\dfrac{9}{25}$, $\dfrac{4}{15}$, $\dfrac{11}{80}$ and $\dfrac{3}{14}$ terminate?
---
$25 = 5^2$ ✓; $15 = 3 \times 5$ ✗; $80 = 2^4 \times 5$ ✓; $14 = 2 \times 7$ ✗. $\dfrac{9}{25}$ and $\dfrac{11}{80}$ terminate.
:::

::: watch
- "**Prove**" or "**show that**" means the algebra must be on the page: define $x$, multiply, subtract, solve. Writing $\frac79$ with no working scores zero.
- Multiply by $10^{\text{length of block}}$ — for a two-digit block it is $100x$, not $10x$.
- When digits sit before the block, multiply by **two** powers of ten so both equations have the block starting right after the point; then subtract those two.
- Simplify the fraction at the end. $\frac{27}{99}$ is not the final answer; $\frac{3}{11}$ is.
- The dot goes over the first and last digit of the block: $0.\dot2\dot7$ means $27$ repeats; $0.2\dot7$ means only the 7 repeats.
:::
