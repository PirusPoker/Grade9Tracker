## What it is

Algebra is arithmetic with some of the numbers hidden behind letters. Every rule you use with numbers still holds: $3 \times 4 = 4 \times 3$, so $ab = ba$; $2 \times (3 + 4) = 2 \times 3 + 2 \times 4$, so $a(b + c) = ab + ac$.

The conventions you have to read fluently:

- $3x$ means $3 \times x$; $xy$ means $x \times y$; $\dfrac{x}{4}$ means $x \div 4$.
- $x^2$ is $x \times x$; $2x^2$ is $2 \times (x^2)$, **not** $(2x)^2$.
- A **term** is a piece joined by $+$ or $-$; **like terms** have exactly the same letters with the same powers ($3x^2y$ and $-5x^2y$ are like; $3x^2y$ and $3xy^2$ are not).
- An **expression** has no equals sign ($3x + 2$); an **equation** does ($3x + 2 = 11$); an **identity** is true for every value ($2(x + 1) \equiv 2x + 2$); a **formula** links quantities ($A = \pi r^2$).

The index laws carry straight across from number: $x^a \times x^b = x^{a+b}$, $x^a \div x^b = x^{a-b}$, $(x^a)^b = x^{ab}$, $x^0 = 1$, $x^{-n} = \dfrac{1}{x^n}$, $x^{1/n} = \sqrt[n]{x}$.

::: terms
- **Variable**: a letter representing a quantity that can take different values.
- **Term**: a single number, letter, or product of numbers and letters, e.g. 5x²y.
- **Expression**: a collection of terms with no equals sign, e.g. 3x + 2y.
- **Like terms**: terms with exactly the same letters and powers, e.g. 3x² and −5x².
- **Coefficient**: the number in front of a letter in a term; in 7x the coefficient is 7.
- **Index laws in algebra**: xᵐ × xⁿ = xᵐ⁺ⁿ, xᵐ ÷ xⁿ = xᵐ⁻ⁿ, (xᵐ)ⁿ = xᵐⁿ, x⁰ = 1.
:::

::: method
1. **Collect like terms** by adding their coefficients; leave unlike terms alone. $3a + 5b - a + 2b = 2a + 7b$.
2. **Multiply terms:** numbers times numbers, then each letter's powers added. $4x^2y \times 3xy^3 = 12x^3y^4$.
3. **Divide terms:** divide the numbers, subtract the powers. $\dfrac{12x^5}{4x^2} = 3x^3$. A letter with a bigger power on the bottom leaves a negative power, or stays on the bottom: $\dfrac{x^2}{x^5} = x^{-3} = \dfrac{1}{x^3}$.
4. **Powers of a product:** every factor gets the power. $(3x^2)^3 = 27x^6$.
5. **Negative and fractional powers in algebra** work as for numbers: $x^{-2} = \dfrac{1}{x^2}$, $x^{1/2} = \sqrt x$, $x^{3/2} = (\sqrt x)^3$, $(16x^4)^{1/2} = 4x^2$.
6. **Substitute** in brackets, especially negatives: if $x = -3$, $x^2 = (-3)^2 = 9$ and $-x^2 = -9$.
:::

::: example Collecting like terms
Simplify $5x^2 + 3x - 2x^2 + 7 - 8x$.

$x^2$ terms: $5x^2 - 2x^2 = 3x^2$. $x$ terms: $3x - 8x = -5x$. Constant: $7$.

$3x^2 - 5x + 7$.
:::

::: example Multiplying and dividing
Simplify (a) $2a^3b \times 5ab^4$, (b) $\dfrac{15p^6q^2}{5p^2q^5}$, (c) $(2m^3n)^4$.

(a) $10a^4b^5$. (b) $3p^4q^{-3} = \dfrac{3p^4}{q^3}$. (c) $16m^{12}n^4$.
:::

::: example Negative and fractional powers
Simplify (a) $(9x^6)^{1/2}$, (b) $(8y^3)^{-1/3}$, (c) $\dfrac{x^{1/2} \times x^{2}}{x^{-1}}$.

(a) $3x^3$. (b) $\dfrac{1}{2y}$. (c) $x^{1/2 + 2 + 1} = x^{7/2}$.
:::

::: example Substituting with negatives
$p = -2$, $q = 5$. Evaluate $3p^2 - pq + q$.

$3(-2)^2 - (-2)(5) + 5 = 12 + 10 + 5 = 27$.
:::

::: example Writing an expression from words
A rectangle is $x$ cm wide and 3 cm longer than it is wide. Write expressions for its perimeter and area.

Length $= x + 3$. Perimeter $= 2x + 2(x + 3) = 4x + 6$. Area $= x(x + 3) = x^2 + 3x$.
:::

A square has side $2x$. Write and simplify expressions for its perimeter and its area.
---
Perimeter $8x$; area $(2x)^2 = 4x^2$.

::: q
Simplify $2x \times 3x^2 \times 4x^3 \div 6x^4$.
---
$\dfrac{24x^6}{6x^4} = 4x^2$.
:::

::: watch
- **$2x^2 \ne (2x)^2$.** The power applies only to what it touches; $(2x)^2 = 4x^2$.
- Only **like** terms combine. $3x + 2x^2$ stays as it is.
- $x$ means $1x$: $5x - x = 4x$, not $5$.
- Substituting a negative: put it in **brackets**. $(-2)^2 = 4$; the calculator's $-2^2$ gives $-4$.
- $x^0 = 1$, and $x^1 = x$ — write $x$, not $x^1$.
- $(3x^2)^3$: the 3 gets cubed too: $27x^6$, not $3x^6$.
:::

::: test
$\dfrac{x^a \times x^{2a}}{x^{a - 1}} = x^9$. Find $a$. (3)
