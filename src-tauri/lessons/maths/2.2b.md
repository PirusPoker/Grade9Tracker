## What it is

Three Higher-only algebra skills, all built on factorising.

**Algebraic fractions** behave exactly like numerical ones: cancel only whole *factors* (never single terms), add with a common denominator, divide by flipping. The move that unlocks most questions is *factorise top and bottom first* — then the common factor shows itself and cancels.

**Completing the square** rewrites $x^2 + bx + c$ as $(x + p)^2 + q$. It hands you the minimum point of the parabola (at $x = -p$, value $q$), solves quadratics that do not factorise, and is where the quadratic formula comes from.

**Algebraic proof** shows a statement is true for *every* number, not just the ones you tried. The standard tools: an even number is $2n$, an odd number is $2n + 1$, consecutive integers are $n, n + 1, n + 2$, a multiple of 3 is $3n$. You expand, simplify, and then *say why* the result has the property claimed.

::: terms
- **Algebraic fraction**: a fraction with algebraic expressions on the top, the bottom or both.
- **Simplifying an algebraic fraction**: factorise the numerator and denominator fully, then cancel common factors.
- **Completing the square**: writing x² + bx + c as (x + b/2)² − (b/2)² + c.
- **Turning point from completed square**: for (x + p)² + q, the minimum point is (−p, q).
- **Algebraic proof**: showing a statement is always true using algebra, e.g. an even number is 2n, an odd number 2n + 1.
- **Identity (≡)**: an equation true for every value of the variable.
:::

::: method
1. **Simplify a fraction:** factorise numerator and denominator completely; cancel any factor that appears in both. $\dfrac{x^2 - 9}{x^2 + 5x + 6} = \dfrac{(x+3)(x-3)}{(x+3)(x+2)} = \dfrac{x - 3}{x + 2}$.
2. **Add / subtract:** common denominator (the product of the denominators, unless one is a factor of the other), write each fraction over it, expand the tops, collect. Keep the denominator factorised.
3. **Multiply / divide:** factorise everything, flip the second fraction if dividing, cancel diagonally, multiply what is left.
4. **Solve an equation with fractions:** multiply every term by the common denominator to clear them, then solve what remains (often a quadratic).
5. **Complete the square, $a = 1$:** halve the coefficient of $x$ to get $p$; write $(x + p)^2$; subtract $p^2$; add the constant. $x^2 + 6x - 1 = (x + 3)^2 - 9 - 1 = (x + 3)^2 - 10$.
6. **Complete the square, $a \ne 1$:** take $a$ out of the $x^2$ and $x$ terms only, complete inside, multiply back out.
7. **Proof:** name your general number(s) with letters; write the expression; expand and simplify; **factorise** the result to show the property ("$= 2(2n^2 + 2n + 1)$, which is even"); finish with a sentence.
:::

::: example Simplifying
Simplify $\dfrac{2x^2 + 5x - 3}{x^2 - 9}$.

Top: $(2x - 1)(x + 3)$. Bottom: $(x + 3)(x - 3)$.

$= \dfrac{2x - 1}{x - 3}$.
:::

::: example Adding
Write $\dfrac{3}{x + 2} + \dfrac{2}{x - 1}$ as a single fraction.

$\dfrac{3(x - 1) + 2(x + 2)}{(x + 2)(x - 1)} = \dfrac{3x - 3 + 2x + 4}{(x + 2)(x - 1)} = \dfrac{5x + 1}{(x + 2)(x - 1)}$.
:::

::: example Solving an equation with fractions
Solve $\dfrac{4}{x} + \dfrac{3}{x + 1} = 2$.

Multiply through by $x(x + 1)$: $4(x + 1) + 3x = 2x(x + 1)$.

$7x + 4 = 2x^2 + 2x \Rightarrow 2x^2 - 5x - 4 = 0$.

$x = \dfrac{5 \pm \sqrt{25 + 32}}{4} = \dfrac{5 \pm \sqrt{57}}{4}$, so $x = 3.14$ or $x = -0.637$ (3 s.f.).
:::

::: example Completing the square
Write $x^2 - 8x + 3$ in the form $(x - p)^2 + q$, and hence state the minimum value of $x^2 - 8x + 3$ and the $x$ at which it occurs.

$(x - 4)^2 - 16 + 3 = (x - 4)^2 - 13$.

Minimum value $-13$, at $x = 4$.
:::

::: example Completing the square with $a \ne 1$
Write $2x^2 + 12x + 5$ in the form $a(x + p)^2 + q$.

$2(x^2 + 6x) + 5 = 2\big((x + 3)^2 - 9\big) + 5 = 2(x + 3)^2 - 18 + 5 = 2(x + 3)^2 - 13$.
:::

::: example Proof
Prove that the sum of any three consecutive integers is a multiple of 3.

Let the integers be $n$, $n + 1$, $n + 2$. Sum $= 3n + 3 = 3(n + 1)$, which is 3 times an integer, so it is a multiple of 3. ∎
:::

::: example Proof with odd numbers
Prove that the square of any odd number is one more than a multiple of 4.

Odd number: $2n + 1$. $(2n + 1)^2 = 4n^2 + 4n + 1 = 4(n^2 + n) + 1$, which is one more than a multiple of 4. ∎
:::

::: q
Simplify $\dfrac{x^2 - 4x}{x^2 - 16}$.
---
$\dfrac{x(x - 4)}{(x + 4)(x - 4)} = \dfrac{x}{x + 4}$.
:::

::: q
Simplify $\dfrac{3x^2 + 7x + 2}{6x + 2}$.
---
$\dfrac{(3x + 1)(x + 2)}{2(3x + 1)} = \dfrac{x + 2}{2}$.
:::

::: q
Write $\dfrac{5}{x} - \dfrac{2}{x + 3}$ as a single fraction.
---
$\dfrac{5(x + 3) - 2x}{x(x + 3)} = \dfrac{3x + 15}{x(x + 3)}$.
:::

::: q
Simplify $\dfrac{x^2 - 1}{x + 4} \div \dfrac{x - 1}{2x + 8}$.
---
$\dfrac{(x + 1)(x - 1)}{x + 4} \times \dfrac{2(x + 4)}{x - 1} = 2(x + 1)$.
:::

::: q
Solve $\dfrac{2}{x - 1} + \dfrac{1}{x + 2} = 1$.
---
$2(x + 2) + (x - 1) = (x - 1)(x + 2) \Rightarrow 3x + 3 = x^2 + x - 2 \Rightarrow x^2 - 2x - 5 = 0 \Rightarrow x = 1 \pm \sqrt6$.
:::

::: q
Write $x^2 + 10x + 7$ in the form $(x + p)^2 + q$.
---
$(x + 5)^2 - 18$.
:::

::: q
Write $x^2 - 3x + 1$ in the form $(x - p)^2 + q$.
---
$\left(x - \dfrac32\right)^2 - \dfrac94 + 1 = \left(x - \dfrac32\right)^2 - \dfrac54$.
:::

::: q
Write $3x^2 - 12x + 7$ in the form $a(x - p)^2 + q$ and state the coordinates of the turning point of $y = 3x^2 - 12x + 7$.
---
$3(x^2 - 4x) + 7 = 3(x - 2)^2 - 12 + 7 = 3(x - 2)^2 - 5$. Turning point $(2, -5)$.
:::

::: q
Prove that the sum of two consecutive odd numbers is a multiple of 4.
---
$(2n + 1) + (2n + 3) = 4n + 4 = 4(n + 1)$, a multiple of 4. ∎
:::

::: q
Prove that $(n + 3)^2 - (n - 3)^2$ is a multiple of 12 for every integer $n$.
---
$(n^2 + 6n + 9) - (n^2 - 6n + 9) = 12n$, which is 12 times an integer. ∎
:::

::: q
Prove that the product of two consecutive even numbers is a multiple of 8.
---
$2n(2n + 2) = 4n(n + 1)$. One of $n$, $n + 1$ is even, so $n(n + 1)$ is even, so $4n(n + 1)$ is a multiple of 8. ∎
:::

::: q
Show that $\dfrac{1}{x - 2} - \dfrac{1}{x + 2} = \dfrac{4}{x^2 - 4}$.
---
$\dfrac{(x + 2) - (x - 2)}{(x - 2)(x + 2)} = \dfrac{4}{x^2 - 4}$. ∎
:::

::: watch
- **Cancel factors, not terms.** $\dfrac{x + 3}{x + 5}$ does not simplify; the 3 and 5 are not factors of the whole top and bottom.
- Factorise before anything else in an algebraic fraction question. Every single one.
- When subtracting fractions, the minus applies to the **whole** second numerator — bracket it.
- Completing the square: halve the $x$ coefficient, and remember to subtract its **square**. With $a \ne 1$, the number you subtract inside gets multiplied by $a$ on the way out.
- Proof needs a **general** number ($2n$, $2n + 1$), the algebra, and a **concluding sentence** that names the property. Testing with $n = 3$ proves nothing.
- Two consecutive odd numbers are $2n + 1$ and $2n + 3$ — not $2n + 1$ and $2n + 2$.
:::

$(n + 3)^2 = n^2 + 6n + 9$ and $(n - 3)^2 = n^2 - 6n + 9$ (1). Difference $= 12n$ (1), which is $12 \times n$, a multiple of 12 for any integer $n$ (1).

Simplify $\dfrac{2x^2 + 5x - 3}{4x^2 - 1}$. (3)
---
Numerator $= (2x - 1)(x + 3)$ (1). Denominator $= (2x - 1)(2x + 1)$ (1). Answer $\dfrac{x + 3}{2x + 1}$ (1).
:::

::: test
Write $\dfrac{x}{x - 3} - \dfrac{2}{x + 1}$ as a single fraction in its simplest form. (3)
---
$\dfrac{x(x + 1) - 2(x - 3)}{(x - 3)(x + 1)}$ (1). Numerator $= x^2 + x - 2x + 6$ (1). Answer $\dfrac{x^2 - x + 6}{(x - 3)(x + 1)}$ (1).
:::

::: test
Write $x^2 - 10x + 30$ in the form $(x - a)^2 + b$. Hence write down the coordinates of the turning point of $y = x^2 - 10x + 30$. (3)
---
$(x - 5)^2 - 25 + 30$ (1) $= (x - 5)^2 + 5$ (1). Turning point $(5, 5)$ (1).
:::

::: test
Prove that $x^2 - 6x + 11$ is positive for all values of $x$. (3)
---
$x^2 - 6x + 11 = (x - 3)^2 + 2$ (1). $(x - 3)^2 \ge 0$ for all $x$ (1), so the expression is at least 2, which is positive (1).
:::

::: test
Prove that the difference between the squares of any two consecutive odd numbers is a multiple of 8. (3)
---
Consecutive odd numbers $2n - 1$ and $2n + 1$ (1). $(2n + 1)^2 - (2n - 1)^2 = 4n^2 + 4n + 1 - 4n^2 + 4n - 1$ (1) $= 8n$, a multiple of 8 (1).
:::

::: test
Solve $\dfrac{3}{x} + \dfrac{2}{x + 1} = 2$. Give your answers to 2 decimal places. (5)
---
Multiply by $x(x + 1)$: $3(x + 1) + 2x = 2x(x + 1)$ (1). $5x + 3 = 2x^2 + 2x$, so $2x^2 - 3x - 3 = 0$ (1). $x = \dfrac{3 \pm \sqrt{9 + 24}}{4}$ (1) $= \dfrac{3 \pm \sqrt{33}}{4}$ (1). $x = 2.19$ or $x = -0.69$ (1).
:::
