## What it is

A straight line on a coordinate grid has an equation of the form

$$y = mx + c$$

where $m$ is the **gradient** (how steep: the rise for each 1 across) and $c$ is the **$y$-intercept** (where it crosses the $y$-axis). $y = 2x - 3$ climbs 2 for every 1 to the right and crosses the $y$-axis at $(0, -3)$. A negative gradient slopes down.

From two points, gradient $= \dfrac{\text{change in } y}{\text{change in } x} = \dfrac{y_2 - y_1}{x_2 - x_1}$, and the midpoint is $\left(\dfrac{x_1 + x_2}{2}, \dfrac{y_1 + y_2}{2}\right)$.

**Parallel** lines have the same gradient. **Perpendicular** lines have gradients that multiply to $-1$: perpendicular to gradient $m$ is gradient $-\dfrac1m$ (flip it, change the sign).

Lines also appear as $ax + by = c$ (rearrange to read $m$ and $c$), as vertical lines $x = k$ (no $y$ at all), and as horizontal lines $y = k$ (gradient 0). Real-life straight-line graphs — conversion graphs, taxi fares, phone tariffs — use the same $m$ and $c$ with meanings: $m$ is the rate, $c$ the fixed charge.

::: terms
- **Coordinates (x, y)**: the position of a point — x across, then y up.
- **Gradient**: the steepness of a line: change in y ÷ change in x.
- **y-intercept**: the point where a line crosses the y-axis.
- **Equation of a straight line**: y = mx + c, where m is the gradient and c the y-intercept.
- **Midpoint**: ((x₁ + x₂)/2, (y₁ + y₂)/2).
- **Parallel lines**: have equal gradients.
- **Perpendicular lines**: have gradients that multiply to −1, e.g. 2 and −½.
:::

::: method
1. **Read a line's equation:** rearrange to $y = mx + c$; then $m$ is the number with $x$, $c$ the constant. $3x + 2y = 8 \Rightarrow y = -\frac32 x + 4$.
2. **Draw a line:** either plot the intercept then step by the gradient, or make a table of three $x$ values (three, so an error shows as a kink).
3. **Gradient from two points:** difference in $y$ over difference in $x$, keeping the points in the same order top and bottom.
4. **Equation through a point with known gradient:** substitute the point into $y = mx + c$ to find $c$. Or use $y - y_1 = m(x - x_1)$.
5. **Equation through two points:** find $m$ first, then step 4.
6. **Parallel:** copy $m$. **Perpendicular:** $m \to -\dfrac1m$. Then step 4 with the point given.
7. **Perpendicular bisector** of $AB$: midpoint of $AB$, perpendicular gradient, then the line through the midpoint.
8. **Interpret real graphs:** gradient $=$ rate (£ per km, litres per second); intercept $=$ the value when $x = 0$ (the fixed charge, the starting amount).
:::

::: example Reading and drawing
Write down the gradient and $y$-intercept of $2y - 6x = 5$, and sketch it.

$y = 3x + 2.5$: gradient 3, intercept $(0, 2.5)$. Sketch: start at $(0, 2.5)$, go along 1 and up 3 to $(1, 5.5)$, draw through.
:::

::: example Line through two points
Find the equation of the line through $(2, 7)$ and $(5, 1)$.

$m = \dfrac{1 - 7}{5 - 2} = \dfrac{-6}{3} = -2$.

$y = -2x + c$; at $(2, 7)$: $7 = -4 + c \Rightarrow c = 11$. $y = -2x + 11$.
:::

::: example Parallel line
Find the equation of the line parallel to $y = \dfrac12 x - 4$ through $(6, 1)$.

$m = \dfrac12$: $1 = 3 + c \Rightarrow c = -2$. $y = \dfrac12 x - 2$.
:::

::: example Perpendicular line
Find the equation of the line perpendicular to $y = 3x + 1$ passing through $(3, 5)$. Give it in the form $ax + by = c$.

Perpendicular gradient $-\dfrac13$: $5 = -1 + c \Rightarrow c = 6$. $y = -\dfrac13 x + 6$; times 3: $3y = -x + 18$, so $x + 3y = 18$.
:::

::: example Perpendicular bisector
$A = (1, 2)$, $B = (7, 6)$. Find the equation of the perpendicular bisector of $AB$.

Midpoint $(4, 4)$. Gradient of $AB$: $\dfrac{4}{6} = \dfrac23$; perpendicular gradient $-\dfrac32$.

$4 = -6 + c \Rightarrow c = 10$. $y = -\dfrac32 x + 10$.
:::

::: example A real-life line
A taxi fare graph is a straight line through $(0, 3)$ and $(10, 21)$, with distance in km on the $x$-axis and fare in £ on the $y$-axis. What do the gradient and intercept mean?

Gradient $= \dfrac{18}{10} = 1.8$: £1.80 per km. Intercept 3: a £3 fixed charge before any distance. Fare $= 1.8d + 3$.
:::

::: q
Write down the gradient and $y$-intercept of $y = 4 - 3x$ and of $5x + 2y = 10$.
---
$m = -3$, $c = 4$; $y = -2.5x + 5$: $m = -2.5$, $c = 5$.
:::

::: q
Find the gradient of the line through $(-3, 4)$ and $(5, -2)$, and the midpoint.
---
$m = \dfrac{-6}{8} = -\dfrac34$; midpoint $(1, 1)$.
:::

::: q
Find the equation of the line with gradient 4 through $(2, -1)$.
---
$-1 = 8 + c \Rightarrow c = -9$: $y = 4x - 9$.
:::

::: q
Find the equation of the line through $(0, 5)$ and $(4, -3)$.
---
$m = -2$, $c = 5$: $y = -2x + 5$.
:::

::: q
Which of these lines are parallel, and which perpendicular, to $y = 2x + 3$: $y = 2x - 7$; $2y = x + 1$; $y = -\frac12 x$; $y + 2x = 4$?
---
Parallel: $y = 2x - 7$. Perpendicular: $y = -\frac12 x$. ($2y = x + 1$ has gradient $\frac12$; $y + 2x = 4$ has gradient $-2$: neither.)
:::

::: q
Find the equation of the line parallel to $3x + y = 7$ through $(2, 4)$.
---
$m = -3$: $4 = -6 + c \Rightarrow c = 10$: $y = -3x + 10$.
:::

::: q
Find the equation of the line perpendicular to $y = \dfrac25 x + 1$ through $(4, 3)$.
---
$m = -\dfrac52$: $3 = -10 + c \Rightarrow c = 13$: $y = -\dfrac52 x + 13$.
:::

::: q
$P = (-2, 3)$ and $Q = (4, -1)$. Find the equation of the perpendicular bisector of $PQ$.
---
Midpoint $(1, 1)$; gradient $PQ = -\dfrac23$, perpendicular $\dfrac32$; $1 = \dfrac32 + c \Rightarrow c = -\dfrac12$: $y = \dfrac32 x - \dfrac12$.
:::

::: q
Show that the points $(1, 1)$, $(3, 5)$ and $(6, 11)$ lie on a straight line.
---
Gradient $(1,1) \to (3,5)$ is $2$; $(3,5) \to (6,11)$ is $\dfrac{6}{3} = 2$. Same gradient through a shared point: collinear.
:::

::: q
A phone contract costs £15 a month plus 8p per minute. Write the equation of the cost graph and find the cost of 250 minutes.
---
$C = 15 + 0.08m$; $C = \pounds 35$.
:::

::: q
The line $y = mx + c$ passes through $(2, 9)$ and is perpendicular to $y = -\dfrac12 x + 4$. Find $m$ and $c$.
---
$m = 2$; $9 = 4 + c \Rightarrow c = 5$.
:::

::: watch
- **Rearrange to $y = mx + c$ before reading the gradient.** In $2y - 6x = 5$ the gradient is 3, not $-6$.
- Gradient is $\dfrac{\text{change in } y}{\text{change in } x}$, with the points in the **same order** on top and bottom.
- Perpendicular gradient: **flip and change sign**. From $\frac23$ it is $-\frac32$; from $3$ it is $-\frac13$.
- After finding $c$, write the full equation — "$c = 11$" is not the equation of the line.
- Vertical lines are $x = k$; they have no gradient and are not $y = \dots$ anything.
- In context, say what the gradient **means** with units: "£1.80 per km".
:::
