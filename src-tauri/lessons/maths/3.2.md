## What it is

A **function** is a rule that turns each input into exactly one output. $f(x) = 2x + 3$ means "double it and add 3": $f(5) = 13$, $f(-1) = 1$, $f(a) = 2a + 3$. Also written $f : x \mapsto 2x + 3$ ("$x$ maps to").

- The **domain** is the set of inputs allowed. Some values must be excluded: you cannot divide by zero, so $f(x) = \dfrac{1}{x - 2}$ has $x \ne 2$; you cannot square-root a negative, so $g(x) = \sqrt{x - 3}$ needs $x \ge 3$.
- The **range** is the set of outputs that actually come out. $h(x) = x^2$ has range $h(x) \ge 0$.

Two ways to build new functions:

- **Composite:** $fg(x)$ means do $g$ first, then $f$: $fg(x) = f(g(x))$. Order matters — $fg$ and $gf$ are usually different.
- **Inverse:** $f^{-1}$ undoes $f$. If $f(x) = 2x + 3$, then $f^{-1}(x) = \dfrac{x - 3}{2}$, because to undo "double and add 3" you subtract 3 and halve. $f^{-1}(f(x)) = x$ always.

::: method
1. **Evaluate:** replace every $x$ in the rule by the input, in brackets. $f(-3)$ for $f(x) = x^2 - 4x$ is $(-3)^2 - 4(-3) = 21$.
2. **Solve $f(x) = k$:** set the rule equal to $k$ and solve — it may be a quadratic with two answers.
3. **Domain — excluded values:** set any denominator equal to zero (exclude those $x$); set anything under a square root $\ge 0$ (keep those $x$).
4. **Range:** think about what outputs are possible — squares are $\ge 0$, $\sqrt{\ }$ gives $\ge 0$, a fraction $\dfrac{1}{x}$ can never be $0$. A sketch helps; for a restricted domain, evaluate at the ends.
5. **Composite $fg(x)$:** write $g(x)$ out, then substitute that whole expression wherever $f$ has an $x$. Simplify. For a number, work from the inside out: $fg(2) = f(g(2))$.
6. **Inverse:** write $y = f(x)$; swap $x$ and $y$; make $y$ the subject; that is $f^{-1}(x)$. (Or: rearrange $y = f(x)$ for $x$, then relabel.)
7. **Solve $f^{-1}(x) = k$** by writing $x = f(k)$ — no need to find the inverse.
:::

::: example Evaluating and solving
$f(x) = 3x - 5$ and $g(x) = x^2 + 1$. Find $f(4)$ and $g(-2)$, then solve $f(x) = 10$ and $g(x) = 10$.

$f(4) = 12 - 5 = 7$; $g(-2) = (-2)^2 + 1 = 5$.

$3x - 5 = 10 \Rightarrow x = 5$.

$x^2 + 1 = 10 \Rightarrow x^2 = 9 \Rightarrow x = 3$ or $x = -3$ — a quadratic gives two answers.
:::

::: example Domain and range
State the domain and range of (a) $f(x) = \dfrac{5}{x + 3}$, (b) $g(x) = \sqrt{2x - 8}$, (c) $h(x) = x^2 - 4$ for $-1 \le x \le 3$.

(a) Domain: all $x$ except $x = -3$. Range: all values except $0$.

(b) Domain: $2x - 8 \ge 0$, so $x \ge 4$. Range: $g(x) \ge 0$.

(c) Minimum at $x = 0$: $-4$; ends give $-3$ and $5$. Range: $-4 \le h(x) \le 5$.
:::

::: example Composite functions
$f(x) = 2x + 1$ and $g(x) = x^2$. Find $fg(x)$, $gf(x)$, and $fg(3)$.

$fg(x) = f(x^2) = 2x^2 + 1$.

$gf(x) = g(2x + 1) = (2x + 1)^2 = 4x^2 + 4x + 1$.

$fg(3) = 2 \times 9 + 1 = 19$. (Check via $gf(3) = 49$ — different, as expected.)
:::

::: example Inverse of a linear function
$f(x) = \dfrac{x + 4}{3}$. Find $f^{-1}(x)$.

$y = \dfrac{x + 4}{3} \Rightarrow 3y = x + 4 \Rightarrow x = 3y - 4$. So $f^{-1}(x) = 3x - 4$.

Check: $f(5) = 3$, $f^{-1}(3) = 5$ ✓.
:::

::: example Inverse with $x$ in the denominator
$g(x) = \dfrac{2x}{x - 1}$, $x \ne 1$. Find $g^{-1}(x)$.

$y(x - 1) = 2x \Rightarrow xy - y = 2x \Rightarrow xy - 2x = y \Rightarrow x(y - 2) = y \Rightarrow x = \dfrac{y}{y - 2}$.

$g^{-1}(x) = \dfrac{x}{x - 2}$, $x \ne 2$.
:::

::: example Composite equation
$f(x) = x - 3$ and $g(x) = 2x^2$. Solve $gf(x) = 32$.

$gf(x) = 2(x - 3)^2 = 32 \Rightarrow (x - 3)^2 = 16 \Rightarrow x - 3 = \pm 4 \Rightarrow x = 7$ or $x = -1$.
:::

::: q
$f(x) = 5 - 2x$. Find $f(3)$, $f(-4)$ and $f\!\left(\frac12\right)$.
---
$-1$; $13$; $4$.
:::

::: q
$g(x) = x^2 - 3x$. Solve $g(x) = 10$.
---
$x^2 - 3x - 10 = 0 \Rightarrow (x - 5)(x + 2) = 0$: $x = 5$ or $-2$.
:::

::: q
State the value of $x$ that must be excluded from the domain of $f(x) = \dfrac{x + 1}{2x - 7}$.
---
$x = 3.5$.
:::

::: q
State the domain of $f(x) = \sqrt{10 - 2x}$ and its range.
---
$x \le 5$; $f(x) \ge 0$.
:::

::: q
$f(x) = x^2 + 2$ for $-2 \le x \le 1$. Find the range.
---
Minimum $2$ at $x = 0$; maximum $6$ at $x = -2$. $2 \le f(x) \le 6$.
:::

::: q
$f(x) = 3x - 2$, $g(x) = x^2 + x$. Find $fg(x)$, $gf(x)$ and $gf(1)$.
---
$fg(x) = 3x^2 + 3x - 2$; $gf(x) = (3x - 2)^2 + (3x - 2) = 9x^2 - 9x + 2$; $gf(1) = 2$.
:::

::: q
$f(x) = \dfrac{1}{x}$ and $g(x) = x + 4$. Find $fg(x)$ and $gf(x)$, and state the value excluded from the domain of each.
---
$fg(x) = \dfrac{1}{x + 4}$, $x \ne -4$; $gf(x) = \dfrac1x + 4$, $x \ne 0$.
:::

::: q
$f(x) = 4x - 7$. Find $f^{-1}(x)$ and $f^{-1}(9)$.
---
$f^{-1}(x) = \dfrac{x + 7}{4}$; $f^{-1}(9) = 4$.
:::

::: q
$g(x) = \dfrac{3}{x} + 2$. Find $g^{-1}(x)$.
---
$y - 2 = \dfrac3x \Rightarrow x = \dfrac{3}{y - 2}$: $g^{-1}(x) = \dfrac{3}{x - 2}$.
:::

::: q
$h(x) = \dfrac{x + 2}{x - 5}$. Find $h^{-1}(x)$.
---
$y(x - 5) = x + 2 \Rightarrow xy - x = 5y + 2 \Rightarrow x = \dfrac{5y + 2}{y - 1}$: $h^{-1}(x) = \dfrac{5x + 2}{x - 1}$.
:::

::: q
$f(x) = 2x + 1$ and $g(x) = x^2 - 5$. Solve $fg(x) = 9$.
---
$2(x^2 - 5) + 1 = 9 \Rightarrow x^2 = 9 \Rightarrow x = \pm 3$.
:::

::: q
$f(x) = 3x + 2$. Solve $f^{-1}(x) = 4$.
---
$x = f(4) = 14$.
:::

::: watch
- **$fg(x)$ means $g$ first.** Substitute $g(x)$ into $f$. Getting the order backwards gives a different function.
- $f(x)^2$ and $f(x^2)$ are different; $f^{-1}(x)$ is the inverse, **not** $\dfrac{1}{f(x)}$.
- Domain exclusions: denominator $\ne 0$; under a root $\ge 0$. State them as "$x \ne 2$" or "$x \ge 3$".
- Range is about **outputs** — write it as $f(x) \ge 0$ or $y \ge 0$, not $x \ge 0$.
- To find an inverse, **swap and rearrange**; when $x$ appears twice, collect and factorise (see 2.3).
- Evaluate negatives in brackets: $g(-2)$ for $g(x) = x^2 + 1$ is $(-2)^2 + 1 = 5$.
:::
