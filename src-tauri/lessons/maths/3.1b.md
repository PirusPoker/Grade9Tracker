## What it is

An **arithmetic sequence** goes up or down by the same amount each time. Two letters describe it completely: the **first term** $a$ and the **common difference** $d$.

$$\text{$n$th term: } u_n = a + (n - 1)d$$

$5, 8, 11, 14, \dots$ has $a = 5$, $d = 3$, so $u_n = 5 + 3(n - 1) = 3n + 2$ — the same $n$th term as in 3.1a, written a different way.

An **arithmetic series** is the sum of the terms. The sum of the first $n$ terms:

$$S_n = \frac{n}{2}\big(2a + (n - 1)d\big) \qquad \text{or} \qquad S_n = \frac{n}{2}(a + l)$$

where $l$ is the last term. The second form is the story of the formula: pair the first with the last, the second with the second-last — every pair adds to $a + l$, and there are $\frac n2$ pairs.

::: method
1. **Identify $a$ and $d$** from the sequence (subtract consecutive terms for $d$).
2. **Any term:** $u_n = a + (n - 1)d$. To find which term equals a value, set $u_n$ equal to it and solve for $n$.
3. **Given two terms**, write $a + (p - 1)d = \dots$ and $a + (q - 1)d = \dots$ and solve simultaneously — subtracting kills $a$.
4. **Sum:** if you know the last term, $\frac n2(a + l)$; otherwise $\frac n2(2a + (n - 1)d)$.
5. **Sum of a list like $7 + 10 + \dots + 121$:** find $n$ first from the last term, then sum.
6. **"Find $n$ so that $S_n = \dots$":** the formula gives a quadratic in $n$; solve and take the positive integer.
7. **Context:** rows of seats, savings increasing each month, a stack of logs — identify $a$ and $d$ from the words and the question is one of the above.
:::

::: example Term formula
An arithmetic sequence has first term 7 and common difference 4. Find the 20th term, and which term is 143.

$u_{20} = 7 + 19 \times 4 = 83$.

$7 + (n - 1) \times 4 = 143 \Rightarrow (n - 1) = 34 \Rightarrow n = 35$.
:::

::: example From two terms
The 5th term of an arithmetic sequence is 22 and the 12th term is 50. Find $a$ and $d$, and the 30th term.

$a + 4d = 22$, $a + 11d = 50$. Subtract: $7d = 28$, $d = 4$, $a = 6$.

$u_{30} = 6 + 29 \times 4 = 122$.
:::

::: example Sum with last term known
Find $3 + 7 + 11 + \dots + 99$.

$a = 3$, $d = 4$, $l = 99$: $3 + 4(n - 1) = 99 \Rightarrow n = 25$.

$S_{25} = \dfrac{25}{2}(3 + 99) = 25 \times 51 = 1275$.
:::

::: example Sum without the last term
Find the sum of the first 40 terms of the sequence $12, 9, 6, 3, \dots$

$a = 12$, $d = -3$: $S_{40} = \dfrac{40}{2}\big(24 + 39 \times (-3)\big) = 20 \times (-93) = -1860$.
:::

::: example Finding $n$ from a sum
The sum of the first $n$ terms of $4, 10, 16, \dots$ is 602. Find $n$.

$a = 4$, $d = 6$: $\dfrac n2\big(8 + 6(n - 1)\big) = 602 \Rightarrow \dfrac n2(6n + 2) = 602 \Rightarrow n(3n + 1) = 602$.

$3n^2 + n - 602 = 0 \Rightarrow (3n + 43)(n - 14) = 0$.

$n$ must be a positive integer, so $n = 14$. (Check: $S_{14} = 7 \times (8 + 78) = 602$ ✓)
:::

::: example In context
A theatre has 20 seats in the front row and each row has 3 more seats than the one in front. There are 25 rows. How many seats are there?

$a = 20$, $d = 3$, $n = 25$: $S = \dfrac{25}{2}(40 + 24 \times 3) = \dfrac{25}{2} \times 112 = 1400$ seats.
:::

::: q
Find the 15th term of the arithmetic sequence with $a = -4$ and $d = 5$.
---
$-4 + 14 \times 5 = 66$.
:::

::: q
The 3rd term of an arithmetic sequence is 10 and the 9th term is 34. Find the first term and the common difference.
---
$6d = 24 \Rightarrow d = 4$; $a = 10 - 8 = 2$.
:::

::: q
Which term of $5, 12, 19, \dots$ is 215?
---
$5 + 7(n - 1) = 215 \Rightarrow n - 1 = 30 \Rightarrow n = 31$.
:::

::: q
Find the sum of the first 30 terms of $2, 5, 8, 11, \dots$
---
$\dfrac{30}{2}(4 + 29 \times 3) = 15 \times 91 = 1365$.
:::

::: q
Find $10 + 15 + 20 + \dots + 200$.
---
$n = 39$; $S = \dfrac{39}{2}(10 + 200) = 4095$.
:::

::: q
Find the sum of the first 25 terms of the sequence with $n$th term $6n - 1$.
---
$a = 5$, $l = 149$: $\dfrac{25}{2}(5 + 149) = 1925$.
:::

::: q
The sum of the first $n$ terms of $3, 7, 11, \dots$ is 465. Find $n$.
---
$\dfrac n2(6 + 4(n - 1)) = 465 \Rightarrow n(2n + 1) = 465 \Rightarrow 2n^2 + n - 465 = 0 \Rightarrow (2n + 31)(n - 15) = 0 \Rightarrow n = 15$.
:::

::: q
Ravi saves £20 in the first month and £5 more each month than the month before. How much has he saved after 2 years?
---
$a = 20$, $d = 5$, $n = 24$: $\dfrac{24}{2}(40 + 23 \times 5) = 12 \times 155 = \pounds 1860$.
:::

::: q
The first term of an arithmetic sequence is 50 and the 10th term is 5. Find the sum of the first 10 terms.
---
$\dfrac{10}{2}(50 + 5) = 275$.
:::

::: q
The sum of the first 8 terms of an arithmetic sequence is 100 and the first term is 2. Find the common difference.
---
$4(4 + 7d) = 100 \Rightarrow 4 + 7d = 25 \Rightarrow d = 3$.
:::

::: q
Show that the sum of the first $n$ odd numbers is $n^2$.
---
$a = 1$, $d = 2$: $S_n = \dfrac n2(2 + 2(n - 1)) = \dfrac n2 \times 2n = n^2$. ∎
:::

::: watch
- **$(n - 1)$, not $n$**, in $a + (n - 1)d$. The 20th term has 19 differences added.
- $\frac n2(a + l)$ needs the **last term**; if you only know $n$, use the $2a + (n - 1)d$ form.
- Finding $n$ from a sum gives a quadratic — reject the negative or non-integer root and state the integer.
- Two-term questions: **subtract** the equations; $a$ cancels and $d$ falls out.
- In context, decide whether the question wants a **term** (the 25th row) or a **sum** (all the seats).
- Show the formula with the numbers substituted before the answer — that line is the method mark.
:::
