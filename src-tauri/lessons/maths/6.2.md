## What it is

An **average** is one number standing for a whole set. Three of them:

- **Mean**: add up, divide by how many. Uses every value; dragged by extremes.
- **Median**: the middle value when sorted (the mean of the middle two if there is an even number). Not affected by extremes.
- **Mode**: the most common value. The only average that works for categories; there may be none or several.

**Spread** says how consistent the data is:

- **Range** $=$ largest $-$ smallest. Simple, but one outlier wrecks it.
- **Interquartile range** $= Q_3 - Q_1$: the width of the middle half.

For **grouped** data you cannot find the exact mean — you **estimate** it using the midpoint of each class as if every value sat there: $\text{mean} \approx \dfrac{\sum (\text{midpoint} \times f)}{\sum f}$. The **modal class** is the class with the highest frequency; the class containing the median is found from the running total.

::: terms
- **Mean**: the total of the values divided by the number of values.
- **Median**: the middle value when the data is in order.
- **Mode**: the most common value.
- **Range**: the largest value minus the smallest value — a measure of spread.
- **Modal class**: the class with the highest frequency in grouped data.
- **Estimated mean of grouped data**: Σ(midpoint × frequency) ÷ Σfrequency.
- **Interquartile range**: upper quartile − lower quartile — the spread of the middle half of the data, not affected by extreme values.
:::

::: method
1. **Mean:** $\dfrac{\sum x}{n}$. From a frequency table: add an $fx$ column, then $\dfrac{\sum fx}{\sum f}$.
2. **Median of a list:** sort first. Position $\dfrac{n + 1}{2}$; if that is a half, average the two neighbours.
3. **Quartiles of a list:** $Q_1$ at position $\dfrac{n + 1}{4}$, $Q_3$ at $\dfrac{3(n + 1)}{4}$; for a list where these are not whole, take the median of each half (the exam's usual method): IQR $= Q_3 - Q_1$.
4. **Grouped mean:** midpoint column ($\frac{\text{lower} + \text{upper}}{2}$), $f \times$ midpoint column, sum, divide by $\sum f$. Say "estimate".
5. **Median class:** find $\frac n2$ in the cumulative frequencies; the class that takes the total past it.
6. **Working backwards:** if the mean of $n$ values is $m$, their total is $nm$. Add or remove a value by adjusting the total and the count.
7. **Choosing the average:** mean when all values matter and there are no outliers; median when there are outliers or skew; mode for categories or "most popular".
:::

::: example Mean, median, mode, range
Data: $7, 3, 9, 3, 12, 5, 3, 8$. Find all four.

Sorted: $3, 3, 3, 5, 7, 8, 9, 12$. Mean $= 50 \div 8 = 6.25$. Median: middle two are $5$ and $7$: $6$. Mode $3$. Range $9$.
:::

::: example Mean from a frequency table
Number of goals per match: 0 goals in 4 matches, 1 in 7, 2 in 6, 3 in 2, 4 in 1. Find the mean.

$\sum fx = 0 + 7 + 12 + 6 + 4 = 29$; $\sum f = 20$. Mean $= 1.45$ goals.
:::

::: example Estimated mean of grouped data
Heights (cm): $150 \le h < 160$: 5; $160 \le h < 170$: 12; $170 \le h < 180$: 9; $180 \le h < 190$: 4. Estimate the mean and state the modal class.

Midpoints $155, 165, 175, 185$. $\sum fx = 775 + 1980 + 1575 + 740 = 5070$; $n = 30$. Mean $\approx 169$ cm. Modal class $160 \le h < 170$.
:::

::: example Median class
For the heights above, which class contains the median?

$\frac n2 = 15$. Cumulative: $5, 17, \dots$ — the 15th value is in $160 \le h < 170$.
:::

::: example Quartiles of a list
Find the IQR of $4, 7, 8, 10, 12, 15, 18, 21, 25$.

$n = 9$; median $12$ (5th). Lower half $4, 7, 8, 10$: $Q_1 = 7.5$. Upper half $15, 18, 21, 25$: $Q_3 = 19.5$. IQR $= 12$.
:::

::: example Working backwards
The mean of 8 numbers is 14. A ninth number is added and the mean becomes 15. What was the ninth number?

Total before $112$; after $135$. Ninth number $= 23$.
:::

::: example Choosing an average
House prices in a street: eight around £250,000 and one at £2,000,000. Which average best represents a typical house, and why?

The median — the £2m house drags the mean up to about £444,000, which is typical of no house in the street.
:::

::: q
Find the mean, median, mode and range of $11, 4, 6, 9, 4, 14, 8$.
---
Mean $8$; sorted $4, 4, 6, 8, 9, 11, 14$: median $8$; mode $4$; range $10$.
:::

::: q
Find the median of $2, 9, 5, 12, 7, 3$.
---
Sorted $2, 3, 5, 7, 9, 12$: median $6$.
:::

::: q
Shoe sizes: size 4 (3 people), 5 (8), 6 (11), 7 (6), 8 (2). Find the mean, median and mode.
---
Mean $= \dfrac{12 + 40 + 66 + 42 + 16}{30} = 5.87$; median (15th and 16th values) $= 6$; mode $6$.
:::

::: q
Estimate the mean: $0 \le t < 10$: 8; $10 \le t < 20$: 15; $20 \le t < 40$: 12; $40 \le t < 60$: 5.
---
$\dfrac{40 + 225 + 360 + 250}{40} = \dfrac{875}{40} = 21.9$.
:::

::: q
For the table above, state the modal class and the class containing the median.
---
Modal $10 \le t < 20$; median (20th value) in $10 \le t < 20$ (cumulative 8, 23).
:::

::: q
Find the IQR of $3, 5, 6, 8, 9, 11, 14, 16, 20, 22$.
---
Lower half $3, 5, 6, 8, 9$: $Q_1 = 6$; upper half $11, 14, 16, 20, 22$: $Q_3 = 16$. IQR $10$.
:::

::: q
The mean of 5 numbers is 12. Four of them are $9, 15, 8, 14$. Find the fifth.
---
Total $60$; fifth $= 60 - 46 = 14$.
:::

::: q
A class of 20 has mean mark 62; another class of 30 has mean mark 70. Find the mean of all 50.
---
$\dfrac{1240 + 2100}{50} = 66.8$.
:::

::: q
Why is the range of $2, 3, 3, 4, 4, 5, 40$ a poor measure of spread, and what would you use instead?
---
The 40 is an outlier making the range 38, though nearly all the values lie within 3 of each other; the IQR ($1$ or so) describes the spread better.
:::

::: q
Which average would you use for the most popular shirt size in a shop, and why?
---
The mode — sizes are categories and the shop wants the one most people buy.
:::

::: q
A student says the mean of a grouped table is exact. Explain the error.
---
The individual values are unknown; each is replaced by its class midpoint, so the mean is an estimate.
:::

::: watch
- **Sort before finding the median.** An unsorted middle value is meaningless.
- Mean from a table: divide by $\sum f$ (the number of people), **not** by the number of rows.
- Grouped mean uses **midpoints**, and the answer is an **estimate** — say so.
- Median position is $\frac{n + 1}{2}$ in a list; in a cumulative table, the $\frac n2$-th value's class.
- Working backwards: work with **totals** ($n \times$ mean), never with the means themselves.
- Range and IQR are single numbers (differences), not "from 3 to 12".
:::
