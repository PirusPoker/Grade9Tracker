## What it is

An **inequality** says one thing is bigger than another, so its answer is a **range** of values, not a single number. The four symbols: $<$ less than, $\le$ less than or equal, $>$ greater than, $\ge$ greater than or equal. On a number line an open circle means the end is *not* included ($<$, $>$); a filled circle means it *is* ($\le$, $\ge$).

**Linear** inequalities solve like equations, with one extra rule: **multiplying or dividing by a negative number reverses the sign.**

**Quadratic** inequalities have answers that are either *between* two numbers or *outside* them — a sketch of the parabola decides which.

**Graphical** inequalities describe regions of the plane. $y < 2x + 1$ is everything below the line $y = 2x + 1$; several inequalities together fence off a region, and questions ask you to shade it, name the integer points inside it, or write the inequalities that define a given region.

::: method
1. **Linear:** collect and divide as for an equation; if you divide by a negative, flip the sign. Write the answer as an inequality, and show it on a number line if asked (open/closed circle, arrow or segment).
2. **Double inequality** $-3 < 2x + 1 \le 7$: do the same to all three parts. $-4 < 2x \le 6 \Rightarrow -2 < x \le 3$.
3. **Integer solutions:** list them. $-2 < x \le 3$ gives $-1, 0, 1, 2, 3$.
4. **Quadratic:** rearrange to $ax^2 + bx + c \lessgtr 0$ with $a > 0$; find the roots (critical values); sketch the U; $> 0$ outside the roots (two separate pieces, written with "or"), $< 0$ between them (one piece).
5. **Region on a graph:** draw each boundary line (solid for $\le$/$\ge$, dashed for $<$/$>$); test a point such as $(0, 0)$ to see which side satisfies the inequality; the wanted region is where **all** the inequalities hold.
6. **Reading inequalities off a region:** find each boundary's equation, then decide the direction by testing a point inside the region.
:::

::: example Linear, dividing by a negative
Solve $7 - 3x \ge 1$ and show the solution on a number line.

$-3x \ge -6 \Rightarrow x \le 2$ (dividing by $-3$ flips the sign).

Number line: filled circle at 2, arrow to the left.
:::

::: example A double inequality with integers
Find the integer values of $n$ satisfying $-5 \le 3n - 2 < 10$.

$-3 \le 3n < 12 \Rightarrow -1 \le n < 4$. Integers: $-1, 0, 1, 2, 3$.
:::

::: example Quadratic, between
Solve $x^2 - 3x - 10 \le 0$.

$(x - 5)(x + 2) \le 0$; roots $-2$ and $5$. U-shape is below the axis between: $-2 \le x \le 5$.
:::

::: example Quadratic, outside
Solve $2x^2 > 7x + 4$.

$2x^2 - 7x - 4 > 0 \Rightarrow (2x + 1)(x - 4) > 0$; roots $-\frac12$ and $4$. Above the axis outside: $x < -\dfrac12$ or $x > 4$.
:::

::: example Shading a region
Shade the region satisfying $x \ge 1$, $y \le 4$ and $y \ge x - 1$.

$x = 1$: vertical solid line, region to the right. $y = 4$: horizontal solid line, region below. $y = x - 1$: through $(1, 0)$ and $(5, 4)$, solid; test $(1, 4)$: $4 \ge 0$ true, so the region is above that line.

The region is the triangle with vertices $(1, 0)$, $(1, 4)$ and $(5, 4)$.
:::

::: example Writing inequalities for a region
A region is bounded by the $x$-axis, the line $x = 3$ and the line through $(0, 6)$ and $(3, 0)$, and lies inside the triangle they form. Write the three inequalities.

The sloping line: gradient $-2$, intercept 6: $y = 6 - 2x$. Inside the triangle contains $(1, 1)$: $1 \ge 0$, $1 \le 3$, $1 \le 4$ ✓.

$y \ge 0$, $x \le 3$, $y \le 6 - 2x$.
:::

::: q
Solve $4x - 5 > 11$ and $3(x + 2) \le x - 4$.
---
$x > 4$; $3x + 6 \le x - 4 \Rightarrow x \le -5$.
:::

::: q
Solve $5 - 2x < 13$.
---
$-2x < 8 \Rightarrow x > -4$.
:::

::: q
Find all integers $x$ with $-8 < 4x \le 12$.
---
$-2 < x \le 3$: $-1, 0, 1, 2, 3$.
:::

::: q
Solve $\dfrac{x - 1}{3} \ge \dfrac{x + 2}{4}$.
---
$4(x - 1) \ge 3(x + 2) \Rightarrow 4x - 4 \ge 3x + 6 \Rightarrow x \ge 10$.
:::

::: q
Solve $x^2 - 6x + 8 < 0$.
---
$(x - 2)(x - 4) < 0$: $2 < x < 4$.
:::

::: q
Solve $x^2 + x - 12 \ge 0$.
---
$(x + 4)(x - 3) \ge 0$: $x \le -4$ or $x \ge 3$.
:::

::: q
Solve $x^2 < 49$.
---
$-7 < x < 7$.
:::

::: q
Solve $3x^2 + 5x \le 2$.
---
$3x^2 + 5x - 2 \le 0 \Rightarrow (3x - 1)(x + 2) \le 0$: $-2 \le x \le \dfrac13$.
:::

::: q
On a grid, shade the region where $y > x$, $x + y < 6$ and $x \ge 0$. List the integer points $(x, y)$ inside it with $y \le 4$.
---
Region: above $y = x$ (dashed), below $x + y = 6$ (dashed), right of the $y$-axis (solid). Integer points with $y \le 4$: $(0, 1), (0, 2), (0, 3), (0, 4), (1, 2), (1, 3), (1, 4), (2, 3)$.
:::

::: q
A region is bounded by $y = 2$, $y = x + 1$ and $y = 7 - x$, lying above $y = 2$ and below both sloping lines. Write down the three inequalities.
---
$y \ge 2$, $y \le x + 1$, $y \le 7 - x$ (solid lines assumed; use $>$/$<$ if dashed).
:::

::: q
The region $R$ satisfies $x \ge 0$, $y \ge 0$, $2x + 3y \le 12$ and $x + y \ge 2$. Find the vertices of $R$.
---
$(2, 0)$, $(6, 0)$, $(0, 4)$, $(0, 2)$.
:::

::: watch
- **Dividing by a negative flips the sign.** $-3x \ge -6$ gives $x \le 2$.
- $x^2 < 49$ is $-7 < x < 7$, not $x < 7$. A quadratic inequality has two critical values — find both, then sketch.
- "Or" answers are **two separate inequalities**: $x < -\frac12$ or $x > 4$. Never write $4 < x < -\frac12$.
- Solid line for $\le$ and $\ge$; dashed for $<$ and $>$. Points on a dashed line are **not** in the region.
- Test a point (usually $(0, 0)$) to choose the side — do not guess from the direction of the sign.
- Integer solutions: list them all, including negatives and zero, and check the ends against $<$ versus $\le$.
:::
