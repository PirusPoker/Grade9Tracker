## What it is

A **quadratic equation** has an $x^2$ term: $ax^2 + bx + c = 0$. It usually has two solutions (**roots**), because a parabola crosses the $x$-axis twice — or one repeated root if it just touches, or none if it never reaches the axis.

Three ways to solve, in order of preference:

1. **Factorise** — if it factorises, it is the quickest: $(x - 3)(x + 5) = 0$ means $x = 3$ or $x = -5$, because a product is zero only when a factor is zero.
2. **The formula** — always works: $$x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}$$ (on the formula sheet, but know it anyway).
3. **Complete the square** — gives exact surd answers and the turning point: $(x + 3)^2 = 10 \Rightarrow x = -3 \pm \sqrt{10}$.

The quantity under the root, $b^2 - 4ac$, is the **discriminant**: positive → two roots; zero → one repeated root; negative → no real roots.

::: terms
- **Quadratic equation**: an equation of the form ax² + bx + c = 0.
- **Roots (solutions)**: the values of x that satisfy the equation — where the graph crosses the x-axis.
- **Solving by factorising**: factorise, then set each bracket equal to zero.
- **Quadratic formula**: x = (−b ± √(b² − 4ac)) ÷ 2a.
- **Discriminant**: b² − 4ac; if it is negative there are no real roots.
:::

::: method
1. **Rearrange to $= 0$** with the $x^2$ term positive. $x^2 = 5x - 6$ becomes $x^2 - 5x + 6 = 0$. Never divide both sides by $x$ — you lose the root $x = 0$.
2. **Try to factorise.** Two numbers with product $c$, sum $b$ (or product $ac$ if $a \ne 1$). Set each bracket to zero.
3. **If it will not factorise, use the formula.** Write $a$, $b$, $c$ with their signs, substitute in brackets, and evaluate $b^2 - 4ac$ first on its own line.
4. **Give the form asked for:** "3 s.f." → decimals; "exact" or "surd form" → simplify the square root; "in the form $p \pm \sqrt q$" → complete the square.
5. **Complete the square to solve:** $(x + p)^2 = $ number; square-root both sides with $\pm$; subtract $p$.
6. **Reject impossible roots** in context — a negative length, a time before the start.
:::

::: example Factorising
Solve $x^2 - 7x + 10 = 0$ and $2x^2 + x - 6 = 0$.

$(x - 2)(x - 5) = 0 \Rightarrow x = 2$ or $x = 5$.

$2x^2 + x - 6$: $ac = -12$, sum 1: $4, -3$. $2x^2 + 4x - 3x - 6 = 2x(x + 2) - 3(x + 2) = (2x - 3)(x + 2) = 0 \Rightarrow x = \dfrac32$ or $x = -2$.
:::

::: example Rearranging first
Solve $x(x + 4) = 21$.

$x^2 + 4x - 21 = 0 \Rightarrow (x + 7)(x - 3) = 0 \Rightarrow x = -7$ or $x = 3$.
:::

::: example No constant term
Solve $3x^2 = 12x$.

$3x^2 - 12x = 0 \Rightarrow 3x(x - 4) = 0 \Rightarrow x = 0$ or $x = 4$. (Dividing by $x$ would have lost $x = 0$.)
:::

::: example The formula
Solve $2x^2 - 5x - 4 = 0$, giving your answers to 3 significant figures.

$a = 2$, $b = -5$, $c = -4$. $b^2 - 4ac = 25 + 32 = 57$.

$x = \dfrac{5 \pm \sqrt{57}}{4}$: $x = 3.14$ or $x = -0.637$.
:::

::: example Exact answers by completing the square
Solve $x^2 + 6x - 2 = 0$, giving your answers in the form $p \pm \sqrt q$.

$(x + 3)^2 - 9 - 2 = 0 \Rightarrow (x + 3)^2 = 11 \Rightarrow x = -3 \pm \sqrt{11}$.
:::

::: example Surd form from the formula
Solve $x^2 - 4x - 8 = 0$ exactly.

$x = \dfrac{4 \pm \sqrt{16 + 32}}{2} = \dfrac{4 \pm \sqrt{48}}{2} = \dfrac{4 \pm 4\sqrt3}{2} = 2 \pm 2\sqrt3$.
:::

::: q
Solve $x^2 + 3x - 18 = 0$.
---
$(x + 6)(x - 3) = 0$: $x = -6$ or $3$.
:::

::: q
Solve $x^2 = 9x - 20$.
---
$x^2 - 9x + 20 = 0 \Rightarrow (x - 4)(x - 5) = 0$: $x = 4$ or $5$.
:::

::: q
Solve $3x^2 - 11x - 4 = 0$.
---
$(3x + 1)(x - 4) = 0$: $x = -\dfrac13$ or $4$.
:::

::: q
Solve $5x^2 - 20 = 0$ and $4x^2 = 7x$.
---
$x^2 = 4 \Rightarrow x = \pm 2$. $\quad x(4x - 7) = 0 \Rightarrow x = 0$ or $\dfrac74$.
:::

::: q
Solve $x^2 + 5x + 2 = 0$ to 2 decimal places.
---
$x = \dfrac{-5 \pm \sqrt{17}}{2}$: $-0.44$ or $-4.56$.
:::

::: q
Solve $3x^2 - 2x - 7 = 0$ to 3 significant figures.
---
$x = \dfrac{2 \pm \sqrt{4 + 84}}{6} = \dfrac{2 \pm \sqrt{88}}{6}$: $1.90$ or $-1.23$.
:::

::: q
Solve $x^2 - 10x + 7 = 0$ in the form $p \pm \sqrt q$.
---
$(x - 5)^2 = 18 \Rightarrow x = 5 \pm \sqrt{18} = 5 \pm 3\sqrt2$.
:::

::: q
Solve $2x^2 + 8x - 1 = 0$ in the form $p \pm \sqrt q$.
---
$x^2 + 4x - \frac12 = 0 \Rightarrow (x + 2)^2 = 4.5 \Rightarrow x = -2 \pm \sqrt{4.5}$ (or $-2 \pm \dfrac{3\sqrt2}{2}$).
:::

::: q
Solve $(x + 2)(x - 3) = 6$.
---
$x^2 - x - 6 = 6 \Rightarrow x^2 - x - 12 = 0 \Rightarrow (x - 4)(x + 3) = 0$: $x = 4$ or $-3$.
:::

::: q
Solve $\dfrac{6}{x} = x - 1$.
---
$6 = x^2 - x \Rightarrow x^2 - x - 6 = 0 \Rightarrow (x - 3)(x + 2) = 0$: $x = 3$ or $-2$.
:::

::: q
How many real roots does $x^2 + 4x + 7 = 0$ have? Explain.
---
$b^2 - 4ac = 16 - 28 = -12 < 0$: no real roots.
:::

::: watch
- **Get zero on one side first.** $(x + 2)(x - 3) = 6$ does **not** mean $x + 2 = 6$ or $x - 3 = 6$.
- **Never divide by $x$.** Factorise it out instead, and keep $x = 0$.
- In the formula, $b$ keeps its sign: for $2x^2 - 5x - 4$, $-b = 5$, and $-4ac = -4(2)(-4) = +32$.
- A quadratic has **two** answers. Stopping at one loses marks; so does forgetting the $\pm$ after square-rooting.
- "Exact" means surds, simplified: $\sqrt{48} = 4\sqrt3$, and cancel with the denominator.
- Check one root in the original equation — it takes ten seconds and catches sign errors in factorising.
:::

::: test
Solve $\dfrac{6}{x + 2} - \dfrac{1}{x} = 1$. (4)
---
$6x - (x + 2) = x(x + 2)$ (1). $5x - 2 = x^2 + 2x$, so $x^2 - 3x + 2 = 0$ (1). $(x - 1)(x - 2) = 0$ (1). $x = 1$ or $x = 2$ (1).
:::
