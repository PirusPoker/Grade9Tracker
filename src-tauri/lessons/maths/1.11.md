## What it is

Both 4MA1 papers allow a calculator, so knowing your calculator is worth marks in every topic. The skills below assume a modern scientific calculator (Casio ClassWiz fx-83GT X / fx-991 or similar); the key names may differ slightly on yours — find each function once and it stays found.

What you need to be able to do without thinking:

- Enter **fractions and mixed numbers** with the fraction key, and switch an answer between fraction and decimal (**S⇔D**).
- Enter **powers and roots**: $x^2$, $x^\square$ (any power), $\sqrt{\ }$, $\sqrt[\square]{\ }$, and $x^{-1}$ for reciprocals.
- Use the **$\times 10^x$** key for standard form, and read a standard-form answer.
- Use **brackets** for anything divided by a sum, and know that the calculator does BIDMAS — it will not add first just because you typed it first.
- Use **sin, cos, tan and their inverses** (SHIFT + sin gives $\sin^{-1}$), in **degrees** mode (check for a D at the top of the screen).
- **Store** a long answer (STO or the Ans key) so you never retype a rounded number.
- Read the **mode** and **display settings**: degree mode, "Math" input, and how to set a fixed number of decimal places if you want.
- Use the **table** function to evaluate a formula for many $x$ values (drawing graphs), and the **statistics** mode for a mean from a list.

::: terms
- **Scientific calculator**: follows BIDMAS; brackets and the fraction key keep a calculation in the right order.
- **Ans key**: recalls the previous answer so a calculation can be chained without retyping rounded values.
- **S⇔D key**: switches an answer between fraction (or surd) form and decimal form.
- **Degree mode**: the calculator setting (D) needed for trigonometry with angles in degrees.
- **Standard form key (×10ˣ)**: enters a number in standard form.
:::

::: method
1. **Type the expression exactly as printed**, using the fraction key for anything over anything and brackets round any numerator or denominator that has more than one term. $\dfrac{3.2 + 4.7}{1.6 \times 2}$ needs both the top and the bottom in brackets if you use $\div$.
2. **Use Ans.** After a calculation, "Ans" holds the full-precision result; press $\times$ and it starts a new line with Ans in it. For multi-step problems, chain with Ans rather than retyping.
3. **Check the mode before trig.** D for degrees. If $\sin 30$ gives $-0.988$, you are in radians.
4. **Convert on demand:** S⇔D toggles fraction ↔ decimal; SHIFT + S⇔D gives a mixed number. Surd answers appear automatically in Math mode.
5. **Standard form:** enter $5.2 \times 10^{-4}$ as $5.2$ [$\times 10^x$] $(-)$ $4$. Use the sign key $(-)$, not the minus operator.
6. **Sanity-check** every answer with a rough estimate. A calculator does exactly what you pressed, including the wrong thing.
:::

::: example A fraction with a sum on top
Evaluate $\dfrac{4.8^2 - 3.1}{2.6 + 1.9}$ to 3 s.f.

Type it with the fraction key, top and bottom as written, or with brackets: $(4.8^2 - 3.1) \div (2.6 + 1.9) = 19.93 \div 4.5 = 4.43$.

Without the brackets you would get $4.8^2 - 3.1 \div 2.6 + 1.9 = 23.75$ — wrong.
:::

::: example Roots and powers
Evaluate $\sqrt[3]{7.5^2 + 12}$ and $2.3^{-2}$.

$7.5^2 + 12 = 68.25$, cube root $= 4.087$ (4 s.f.). Enter with SHIFT + $\sqrt[\square]{\ }$: index 3, then the expression.

$2.3^{-2} = \dfrac{1}{5.29} = 0.189$ (3 s.f.).
:::

::: example Fraction answers and S⇔D
Work out $\dfrac{2}{3} + \dfrac{5}{8}$ and give the answer as a mixed number and as a decimal.

Fraction key: $\dfrac{31}{24}$. SHIFT + S⇔D: $1\dfrac{7}{24}$. S⇔D: $1.291\dot6$.
:::

::: example Trig on the calculator
Find the angle $\theta$ with $\tan\theta = \dfrac{5.2}{8.9}$.

Check D for degrees. SHIFT + tan, then the fraction: $\tan^{-1}\!\left(\dfrac{5.2}{8.9}\right) = 30.3°$ (1 d.p.).
:::

::: example Chaining with Ans
A cylinder has radius $4.7$ cm and height $11.2$ cm. Find its volume, then the mass if the density is $2.7$ g/cm$^3$.

$\pi \times 4.7^2 \times 11.2 = 777.26\ldots$ cm$^3$. Then Ans $\times 2.7 = 2098.6$ g $\approx 2.10$ kg.

Using $777$ instead of Ans would give $2097.9$ — a rounding error you did not need to make.
:::

::: example Standard form and the sign key
Work out $\dfrac{6.4 \times 10^{7}}{2.5 \times 10^{-3}}$.

Type $6.4$ [$\times 10^x$] $7$, divide, then bracket $(2.5$ [$\times 10^x$] $(-)3)$: $2.56 \times 10^{10}$.
:::

::: q
Use the table function (or repeated substitution) to find the value of $x$ between 2 and 3, to 1 d.p., where $x^3 - 2x = 10$.
---
$x = 2.6$: $17.576 - 5.2 = 12.4$; $x = 2.5$: $15.625 - 5 = 10.6$; $x = 2.4$: $13.824 - 4.8 = 9.0$. Root between 2.4 and 2.5, closer to 2.5: $x \approx 2.5$ (check $2.45$: $14.7 - 4.9 = 9.8 < 10$, so $x = 2.5$ to 1 d.p.).
:::

::: q
A rounded intermediate value causes an error. Compute $\sqrt{2} \times \sqrt{8}$ exactly using Ans, and compare with $1.41 \times 2.83$.
---
Exact: $\sqrt{16} = 4$. Rounded: $3.9903$. The difference is the error from rounding early.
:::

::: q
Find the mean of $12, 15, 9, 21, 18, 14$ using statistics mode, and check by adding.
---
Sum $89$, mean $14.8$ (3 s.f.).
:::

::: watch
- **Degrees mode.** Check the D every time you pick the calculator up in a trig question.
- **Brackets round numerators and denominators**, or use the fraction key. $a + b \div c + d$ is not $\dfrac{a+b}{c+d}$.
- Use the **sign key** $(-)$ for negative numbers, and put a negative in brackets before squaring: $(-3)^2$, not $-3^2$.
- Never retype a rounded value into the next step — use **Ans** or store it.
- Write down what you typed (the calculation line) — if the answer is wrong, the method mark survives.
- Estimate first: if the calculator says $23.75$ for something that should be about $4$, a bracket is missing.
:::
