## What it is

A **sequence** is a list of numbers made by a rule: $5, 8, 11, 14, \dots$ or $2, 6, 18, 54, \dots$ or $1, 4, 9, 16, \dots$ Each entry is a **term**; the position is $n$ (first term $n = 1$).

The **$n$th term** is a formula that gives any term directly from its position. For $5, 8, 11, 14$ it is $3n + 2$: put $n = 1$ and you get 5; put $n = 100$ and you get 302 without listing anything.

Types you must recognise:

- **Arithmetic** (linear): constant difference. $n$th term $= dn + (a - d)$, where $d$ is the difference and $a$ the first term — "difference times $n$, then adjust".
- **Geometric**: constant ratio. $2, 6, 18, 54$ has ratio 3; $n$th term $= 2 \times 3^{n-1}$.
- **Quadratic**: the *second* differences are constant. $n$th term contains $n^2$; the coefficient of $n^2$ is half the second difference.
- **Square, cube, triangular, Fibonacci** — recognised by sight: $1, 4, 9, 16$; $1, 8, 27$; $1, 3, 6, 10, 15$; $1, 1, 2, 3, 5, 8$.

::: method
1. **Write the differences** under the sequence. Constant → arithmetic. Not constant → write the second differences; constant → quadratic. Otherwise check ratios (geometric) or the famous sequences.
2. **Arithmetic $n$th term:** the difference is the coefficient of $n$; then compare $dn$ with the actual terms to find the constant. $5, 8, 11$: $3n$ gives $3, 6, 9$; add 2: $3n + 2$.
3. **Quadratic $n$th term:** coefficient of $n^2$ is half the second difference; subtract that $an^2$ from each term; what is left is arithmetic — find its $n$th term and add.
4. **Is a number in the sequence?** Set the $n$th term equal to it and solve; it is in the sequence only if $n$ comes out a positive integer.
5. **Term-to-term rules** ("multiply by 2 and subtract 1") generate terms one at a time; "position-to-term" is the $n$th term. Read which the question wants.
6. **Generating from a formula:** substitute $n = 1, 2, 3, \dots$ carefully, especially with $n^2$ and negatives.
:::

::: example Finding a linear $n$th term
Find the $n$th term of $7, 11, 15, 19, \dots$ and the 50th term.

Difference $4$, so $4n + c$. $4 \times 1 = 4$, need 7: $c = 3$. $n$th term $4n + 3$. 50th term: $203$.
:::

::: example A decreasing sequence
Find the $n$th term of $20, 17, 14, 11, \dots$

Difference $-3$: $-3n + c$. $-3 + c = 20 \Rightarrow c = 23$. $23 - 3n$.
:::

::: example Is it a term?
Is 150 a term of the sequence with $n$th term $4n + 3$? Is 151?

$4n + 3 = 150 \Rightarrow n = 36.75$ — not an integer, so no.

$4n + 3 = 151 \Rightarrow n = 37$ — yes, the 37th term.
:::

::: example A quadratic sequence
Find the $n$th term of $3, 8, 15, 24, 35, \dots$

First differences $5, 7, 9, 11$; second differences $2$, so the $n^2$ coefficient is 1.

Subtract $n^2$: $3 - 1, 8 - 4, 15 - 9, 24 - 16 = 2, 4, 6, 8$, which is $2n$.

$n$th term: $n^2 + 2n$.
:::

::: example A quadratic sequence with a larger second difference
Find the $n$th term of $4, 13, 28, 49, \dots$

Differences $9, 15, 21$; second differences $6$; coefficient $3$. Subtract $3n^2$: $4 - 3, 13 - 12, 28 - 27, 49 - 48 = 1, 1, 1, 1$.

$n$th term: $3n^2 + 1$.
:::

::: example Geometric and term-to-term
The first term of a sequence is 3 and each term is double the previous one minus 1. Write the first five terms. Separately, find the 8th term of $5, 10, 20, 40, \dots$

Term-to-term: $3, 5, 9, 17, 33$.

Geometric with $a = 5$, $r = 2$: 8th term $= 5 \times 2^7 = 640$.
:::

::: q
Find the $n$th term of $2, 9, 16, 23, \dots$ and the 30th term.
---
$7n - 5$; $205$.
:::

::: q
Find the $n$th term of $50, 44, 38, 32, \dots$
---
$56 - 6n$.
:::

::: q
Write down the first four terms of the sequence with $n$th term $n^2 - 3n$.
---
$-2, -2, 0, 4$.
:::

::: q
Is 200 a term of the sequence $6n - 4$? If so, which term?
---
$6n - 4 = 200 \Rightarrow n = 34$. Yes, the 34th.
:::

::: q
Find the $n$th term of $2, 6, 12, 20, 30, \dots$
---
Second difference 2: $n^2$; remainder $1, 2, 3, 4, 5 = n$. $n^2 + n$.
:::

::: q
Find the $n$th term of $5, 11, 21, 35, 53, \dots$
---
Differences $6, 10, 14, 18$; second difference 4: $2n^2$. Remainder $3, 3, 3, 3, 3$. $2n^2 + 3$.
:::

::: q
Find the $n$th term of $0, 3, 8, 15, 24, \dots$
---
$n^2 - 1$ (differences $3, 5, 7, 9$; subtract $n^2$: $-1$ each time).
:::

::: q
The $n$th term of a sequence is $3 \times 2^n$. Find the first three terms and the 10th term.
---
$6, 12, 24$; $3 \times 1024 = 3072$.
:::

::: q
A sequence has first term 4 and term-to-term rule "multiply by 3 then subtract 2". Find the 4th term.
---
$4, 10, 28, 82$: the 4th term is $82$.
:::

::: q
The $n$th term of an arithmetic sequence is $an + b$. The 3rd term is 14 and the 7th term is 30. Find $a$ and $b$.
---
$3a + b = 14$, $7a + b = 30 \Rightarrow 4a = 16$, $a = 4$, $b = 2$.
:::

::: q
Which term of the sequence $n^2 + 2n$ is 168?
---
$n^2 + 2n - 168 = 0 \Rightarrow (n + 14)(n - 12) = 0 \Rightarrow n = 12$.
:::

::: watch
- The coefficient of $n$ is the **difference**, not the first term. $7, 11, 15$ is $4n + 3$, not $7n + 4$.
- Quadratic sequences: the $n^2$ coefficient is **half** the second difference.
- "Is 150 in the sequence?" needs $n$ to be a **positive whole number** — show the equation and the non-integer result.
- A term-to-term rule needs the first term as well; on its own it does not define the sequence.
- Substitute carefully: for $n^2 - 3n$ at $n = 1$, that is $1 - 3 = -2$.
- Write "$n$th term $= 4n + 3$", not just "$4n + 3$" floating on the page; and if asked for the 50th term, give the number.
:::

::: test
Is 150 a term of the sequence with $n$th term $4n + 3$? Show how you decide. (2)
---
$4n + 3 = 150$ gives $4n = 147$, $n = 36.75$ (1). $n$ is not a whole number, so 150 is not a term (1).

::: test
Find the $n$th term of the quadratic sequence 3, 8, 15, 24, 35, … (3)
---
First differences 5, 7, 9, 11; second difference 2, so the sequence starts $n^2$ (1). Subtract $n^2$: 2, 4, 6, 8, 10 $= 2n$ (1). $n$th term $= n^2 + 2n$ (1).
:::

::: test
Find the $n$th term of the quadratic sequence 2, 9, 20, 35, 54, … (3)
---
First differences 7, 11, 15, 19; second difference 4, so $2n^2$ (1). Subtract $2n^2$ (2, 8, 18, 32, 50): 0, 1, 2, 3, 4 $= n - 1$ (1). $n$th term $= 2n^2 + n - 1$ (1).
:::

::: test
Write down the first three terms of the sequence with $n$th term $n^2 - 3n$. (1)
---
$-2, -2, 0$.
:::

::: test
A geometric sequence is 3, 6, 12, 24, … Write down its $n$th term and find the 10th term. (2)
---
$3 \times 2^{n-1}$ (1); 10th term $= 3 \times 2^9 = 1536$ (1).
:::

::: test
A sequence has $n$th term $\dfrac{2n + 1}{n + 3}$. Find the 5th term, and show that no term of the sequence is equal to 2. (2)
---
5th term $= \dfrac{11}{8}$ (1). $\dfrac{2n + 1}{n + 3} = 2$ gives $2n + 1 = 2n + 6$, i.e. $1 = 6$, impossible (1).
:::
