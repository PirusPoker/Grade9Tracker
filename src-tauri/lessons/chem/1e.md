## What it is

**Formulae of ionic compounds** — the charges must cancel. Learn the common ions:

| Positive ions (cations) | | Negative ions (anions) | |
|---|---|---|---|
| Na⁺, K⁺, Li⁺, Ag⁺, H⁺, NH₄⁺ (ammonium) | +1 | Cl⁻, Br⁻, I⁻, OH⁻ (hydroxide), NO₃⁻ (nitrate), HCO₃⁻ | −1 |
| Mg²⁺, Ca²⁺, Zn²⁺, Cu²⁺, Fe²⁺, Ba²⁺, Pb²⁺ | +2 | O²⁻, S²⁻, SO₄²⁻ (sulfate), CO₃²⁻ (carbonate) | −2 |
| Al³⁺, Fe³⁺ | +3 | PO₄³⁻ (phosphate), N³⁻ | −3 |

Metals in Groups 1, 2 and 3 form +1, +2, +3 ions; non-metals in Groups 5, 6, 7 form −3, −2, −1. **Swap and cross**: aluminium sulfate — Al³⁺ and SO₄²⁻ → need 2 Al (6+) and 3 SO₄ (6−) → **Al₂(SO₄)₃**. Brackets go round a polyatomic ion when there is more than one of it: Ca(NO₃)₂, Mg(OH)₂. The overall charge is zero, so no charges appear in the formula.

**Molecular formulae** you must know: H₂, O₂, N₂, Cl₂, Br₂, I₂ (diatomic elements), H₂O, CO₂, NH₃, CH₄, HCl, H₂SO₄, HNO₃, NaOH.

**Relative formula mass (Mr)** = the sum of the relative atomic masses of all the atoms in the formula (Ar values from the periodic table). CaCO₃: $40 + 12 + (3 \times 16) = 100$. Mg(OH)₂: $24 + 2 \times (16 + 1) = 58$. **Hydrated** compounds include the water of crystallisation: CuSO₄·5H₂O: $63.5 + 32 + 64 + 5 \times 18 = 249.5$.

**Equations**:

- **Word equation**: magnesium + hydrochloric acid → magnesium chloride + hydrogen.
- **Balanced symbol equation**: Mg + 2HCl → MgCl₂ + H₂. The same number of each type of atom on both sides — atoms are neither created nor destroyed.
- **State symbols**: (s) solid, (l) liquid, (g) gas, (aq) dissolved in water: Mg(s) + 2HCl(aq) → MgCl₂(aq) + H₂(g).

**Balancing** — change only the **large numbers in front** (coefficients), never the small subscripts, which would change the substance:

1. Write the correct formulae.
2. Count each element on both sides.
3. Balance one element at a time by adding coefficients — leave hydrogen and oxygen till last; balance elements that appear in only one compound each side first.
4. Re-count everything. Use fractions for O₂ if needed, then double everything.

Example: C₃H₈ + O₂ → CO₂ + H₂O. Carbon: 3 → 3CO₂. Hydrogen: 8 → 4H₂O. Oxygen on the right: 6 + 4 = 10 → 5O₂. **C₃H₈ + 5O₂ → 3CO₂ + 4H₂O**.

**Ionic equations** show only the ions that change. Write the full equation, split soluble ionic compounds into ions, cross out **spectator ions** that appear unchanged on both sides. Zinc displacing copper: Zn + CuSO₄ → ZnSO₄ + Cu becomes **Zn + Cu²⁺ → Zn²⁺ + Cu** (sulfate is a spectator). Neutralisation: **H⁺ + OH⁻ → H₂O**. Precipitation: **Ag⁺ + Cl⁻ → AgCl**. Ionic equations must balance for **charge** as well as atoms.

::: method
1. **Formula of an ionic compound**: write the two ions with charges → find the smallest numbers that cancel the charges → brackets for multiple polyatomic ions → drop the charges.
2. **Mr**: list each element, multiply Ar by the number of atoms (brackets multiply everything inside), add. Water of crystallisation: add 18 per H₂O.
3. **Balancing**: correct formulae first (remember the diatomic elements), then coefficients only. Count with a table under the equation.
4. **State symbols** on every balanced equation when asked — (aq) for anything dissolved, including acids.
5. **Ionic equations**: full equation → ions → delete spectators → check atoms *and* charge balance.
:::

::: example Formula from ions
Write the formulae of calcium nitrate, iron(III) oxide and ammonium sulfate. (3)

Ca²⁺ with NO₃⁻: two nitrates needed → Ca(NO₃)₂ (1). Fe³⁺ with O²⁻: 2 Fe (6+) and 3 O (6−) → Fe₂O₃ (1). NH₄⁺ with SO₄²⁻: two ammoniums → (NH₄)₂SO₄ (1).
:::

::: example Mr
Calculate the relative formula mass of (a) Ca(OH)₂ and (b) MgSO₄·7H₂O. (Ar: Ca 40, O 16, H 1, Mg 24, S 32) (3)

(a) $40 + 2 \times (16 + 1) = 74$ (1). (b) $24 + 32 + 64 = 120$; water $7 \times 18 = 126$; total $246$ (2).
:::

::: example Balance
Balance: Al + Cl₂ → AlCl₃, and add state symbols for the reaction of solid aluminium with chlorine gas forming solid aluminium chloride. (3)

Cl: 2 on the left, 3 on the right → lowest common multiple 6: 3Cl₂ and 2AlCl₃; then 2Al (1). 2Al(s) + 3Cl₂(g) → 2AlCl₃(s) (2).
:::

::: example Ionic equation
Write the ionic equation for the reaction between aqueous sodium hydroxide and aqueous copper(II) sulfate, which forms a precipitate of copper(II) hydroxide. (3)

Full: 2NaOH + CuSO₄ → Cu(OH)₂ + Na₂SO₄ (1). Ions: Na⁺ and SO₄²⁻ are unchanged — spectators (1). Ionic: Cu²⁺(aq) + 2OH⁻(aq) → Cu(OH)₂(s); charge 2+ and 2− balance to zero (1).
:::

::: q
Write the formulae of sodium carbonate, aluminium oxide and magnesium hydroxide. (3)
---
Na₂CO₃; Al₂O₃; Mg(OH)₂.
:::

::: q
Calculate the Mr of sulfuric acid, H₂SO₄. (Ar: H 1, S 32, O 16) (1)
---
$2 + 32 + 64 = 98$.
:::

::: q
Calculate the Mr of (NH₄)₂SO₄. (Ar: N 14, H 1, S 32, O 16) (2)
---
$2 \times (14 + 4) + 32 + 64 = 132$.
:::

::: q
Calculate the Mr of Na₂CO₃·10H₂O. (Ar: Na 23, C 12, O 16, H 1) (2)
---
$46 + 12 + 48 = 106$; $10 \times 18 = 180$; total $286$.
:::

::: q
Balance: Fe + O₂ → Fe₂O₃. (1)
---
4Fe + 3O₂ → 2Fe₂O₃.
:::

::: q
Balance and add state symbols: sodium reacts with water to form sodium hydroxide solution and hydrogen. (2)
---
2Na(s) + 2H₂O(l) → 2NaOH(aq) + H₂(g).
:::

::: q
Balance: C₂H₆ + O₂ → CO₂ + H₂O. (2)
---
2C₂H₆ + 7O₂ → 4CO₂ + 6H₂O.
:::

::: q
Why must you never change a subscript when balancing an equation? (1)
---
Changing a subscript changes the formula, i.e. the substance itself (H₂O to H₂O₂ is water to hydrogen peroxide).
:::

::: q
Write the ionic equation for hydrochloric acid neutralising potassium hydroxide. (2)
---
H⁺(aq) + OH⁻(aq) → H₂O(l); K⁺ and Cl⁻ are spectator ions.
:::

::: q
What are spectator ions? (1)
---
Ions present in the solution that take no part in the reaction and appear unchanged on both sides.
:::

::: watch
- **Coefficients only, never subscripts.** Balance one element at a time; H and O last.
- **Diatomic elements**: H₂, O₂, N₂, Cl₂, Br₂, I₂ — as elements they are never written as single atoms.
- Ionic formulae: charges must **cancel**; **brackets** round repeated polyatomic ions.
- Mr with **water of crystallisation**: add 18 for each H₂O.
- Ionic equations must balance **charge as well as atoms**; remove only the ions that are unchanged.
:::
