## What it is

**Derivational morphology** means building a new word from one you already know, by adding a piece to the front (a **prefix**) or to the end (a **suffix**). Pearson lists a small set of these rules in Appendix 2, and they matter mostly for **Paper 3 Reading**. If a word is on the vocabulary list, its derived forms can appear in a reading text without a gloss: *cinq* is listed, so *cinquième* may turn up. It works the other way too: *particulièrement* is listed, so the base word *particulier* may appear. Learn the rules and a 1,700-word list quietly becomes much bigger.

**The "one affix" rule.** Pearson adds only **one** prefix or suffix from this section to a base word at a time. From *patient* you may meet *impatient* (prefix) or *patiemment* (suffix), but never *impatiemment* (both). Ordinary grammar endings for gender and number can still be added on top: *impatiente, impatients, impatientes*.

| Foundation + Higher | Higher only |
|---|---|
| prefix *in-* / *im-* = un-, in-, "the opposite of" | agent nouns in *-eur* / *-ateur* from a verb stem |
| ordinal numbers in *-ième* | |
| adjectives in *-able* / *-eable* (English -able / -ible) | |
| nouns in *-ion* / *-ation* (English -ion / -ation) | |
| adverbs in *-ment*, *-amment*, *-emment* (English -ly) | |

Notice the condition built into each rule: the English equivalent must have the matching ending. That is why these words are guessable. If the French and the English don't line up, the rule doesn't apply and the word would be glossed.

**1. The prefix in- / im-: "un-", "in-", "not".** It goes on adjectives, adverbs and nouns. It becomes **im-** before *p*, *b* and *m*.

| base word (on the list) | derived form | meaning |
|---|---|---|
| *juste* (fair) | *injuste* | unfair |
| *capable* | *incapable* | unable, incapable |
| *utile* (useful) | *inutile* | useless |
| *possible* | *impossible* | impossible |
| *patient* | *impatient(e)* | impatient |
| *prudent* (careful) | *imprudent(e)* | careless, unwise |
| *la sécurité* (safety) | *l'insécurité* (f) | insecurity, lack of safety |
| *également* (equally) | *inégalement* | unequally |

**Not every word starting in- or im- is a negative.** Take the prefix off: if what is left is not a word with the opposite meaning, it isn't this rule. *Important, intéressant, inviter, l'information, imaginer* and *l'immeuble* (block of flats) are ordinary words. Pronunciation helps the read-aloud too: before a consonant *in-* / *im-* is the nasal sound in *fin* (*impossible*, *injuste*); before a vowel it is not nasal, so *inutile* sounds like 'ee-noo-TEEL'.

**2. Ordinal numbers: -ième.** Add *-ième* to the number, or drop a final *-e* first.

| cardinal | ordinal | note |
|---|---|---|
| *un / une* | *premier / première* | irregular: learn it |
| *deux* | *deuxième* (or *second / seconde*) | |
| *trois* | *troisième* | |
| *quatre* | *quatrième* | drop the *-e* |
| *cinq* | *cinquième* | add *u* to keep the 'k' sound |
| *neuf* | *neuvième* | *f* becomes *v* |
| *onze, douze, seize* | *onzième, douzième, seizième* | drop the *-e* |
| *vingt et un* | *vingt et unième* | never *premier* in a compound |
| *cent* | *centième* | |

Short forms: *1er / 1re, 2e, 3e*. Ordinals go before the noun like adjectives; only *premier / première* changes for gender: *le troisième étage* (the third floor), *la cinquième fois* (the fifth time), *au vingt et unième siècle* (in the twenty-first century). Two traps:
- **Dates use the cardinal**, except the first: *le premier mai*, but *le deux mai, le trois juin*.
- **French school years count down.** In a *collège*, *la sixième* is the first year (Year 7 in England) and *la troisième* is the last (Year 10). *Je suis en quatrième* means "I'm in Year 9", not "fourth year".

**3. Adjectives in -able / -eable.** Add *-able* to the verb stem. After *-g-*, write *-eable* to keep the *g* soft (as in *nous mangeons*).
- *accepter* → *acceptable*; *comparer* → *comparable*; *imaginer* → *imaginable*; *respecter* → *respectable*;
- *recycler* → *recyclable*; *utiliser* → *utilisable* (usable);
- *changer* → *changeable*; *manger* → *mangeable* (edible: English uses -ible here, which the rule allows).

The rule only applies where English also ends in -able or -ible. *Aimable* (from *aimer*) means "kind", not "lovable", which is exactly why Pearson would gloss it rather than expect you to derive it.

**4. Nouns in -ion / -ation.** Add *-ation* (or *-ion*) to the verb stem. These nouns are **all feminine**, which is a free gender rule for your writing.
- *préparer* → *la préparation*; *réserver* → *la réservation* (booking); *inviter* → *l'invitation*;
- *organiser* → *l'organisation*; *participer* → *la participation*; *augmenter* (increase) → *l'augmentation*;
- *utiliser* → *l'utilisation* (use); *imaginer* → *l'imagination*.

Some -ion nouns change the stem, and those are on the list in their own right: *décider* → *la décision*, *discuter* → *la discussion*, *protéger* → *la protection*. The ending *-tion* is said 'syon' (see G8).

**5. Adverbs in -ment, -amment and -emment ("-ly").**
- **Feminine adjective + -ment:** *heureux* → *heureuse* → *heureusement* (fortunately); *lent* → *lente* → *lentement* (slowly); *premier* → *première* → *premièrement* (firstly); *dernier* → *dernière* → *dernièrement* (lately, recently); *certain* → *certainement*; *complet* → *complète* → *complètement*; *sérieux* → *sérieusement*; *normal* → *normalement*; *général* → *généralement*.
- Adjectives ending in a vowel use the masculine: *vrai* → *vraiment*, *facile* → *facilement*, *rapide* → *rapidement*.
- **-ant → -amment, -ent → -emment:** *indépendant* → *indépendamment*; *patient* → *patiemment*; *prudent* → *prudemment*; *différent* → *différemment*; *récent* → *récemment*; *évident* → *évidemment* (obviously).
- *Lent* is the exception: *lentement*, not *lemment*.
- In the dictation, *-amment* and *-emment* sound the same, 'a-mahn': *récemment* is 'ray-sa-MAHN'.

**6. Higher: agent nouns in -eur / -ateur ("the person who does it").** Add *-eur* to the verb stem, or *-ateur* to an *-er* verb's stem. Feminines: *-eur* → *-euse*, *-ateur* → *-atrice*.

| verb | person (m) | person (f) | meaning |
|---|---|---|---|
| *porter* | *porteur* | *porteuse* | carrier, porter |
| *chanter* | *chanteur* | *chanteuse* | singer |
| *danser* | *danseur* | *danseuse* | dancer |
| *vendre* | *vendeur* | *vendeuse* | sales assistant |
| *voyager* | *voyageur* | *voyageuse* | traveller |
| *visiter* | *visiteur* | *visiteuse* | visitor |
| *créer* | *créateur* | *créatrice* | creator, designer |
| *organiser* | *organisateur* | *organisatrice* | organiser |
| *utiliser* | *utilisateur* | *utilisatrice* | user |

**7. Cognates, glosses and inferred words.** Derivation is one of three ways in to a word you haven't learnt.
- **Cognates** look like English and mean the same: *la musique, le problème, la situation*. Reading texts may include a small number of unlisted cognates (up to 2% of a text) without a gloss. Handy patterns (reading tips, not Pearson rules): *-é* = -y (*la société, la qualité*); *-eux* = -ous (*dangereux*); *-ique* = -ic or -ical (*électrique*); an accent where English has an *s* (*la forêt* = forest, *l'hôpital*, *la côte* = coast); *é-* at the start for English s- (*l'école* = school, *l'étudiant* = student).
- **Glosses**: any other off-list word in a text is translated for you, so don't panic over it.
- **Inferred words**: Paper 3 deliberately leaves **two single words** off the list and unglossed, 1 mark each, usually as "Which is the best translation of the word X?" with A/B/C. You work these out from context, not from a rule.

**8. False friends.** These look like English words but mean something else, and readers who trust their eyes lose marks.

| French | means | not |
|---|---|---|
| *actuellement* | currently, at the moment | actually |
| *la librairie* | bookshop | library (*la bibliothèque*) |
| *sensible* | sensitive | sensible |
| *la journée* | day (the whole day) | journey |
| *rester* | to stay | to rest |
| *le car* | coach | car (*la voiture*) |
| *la veste* | jacket | vest |
| *le collège* | secondary school (11–15) | college |
| *le stage* | course, work placement | stage |
| *large* | wide | large (*grand*) |
| *blesser* | to injure | to bless |
| *la monnaie* | change (coins) | money (*l'argent*) |
| *attendre* | to wait (for) | to attend (*assister à*) |

::: terms
- **la morphologie dérivationnelle**: building new words from a listed base word with one prefix or one suffix
- **le préfixe in- / im-**: un-, in- or "not": injuste (unfair), impossible; im- before p, b, m
- **le nombre ordinal**: number + -ième: troisième, quatrième, cinquième, neuvième; but premier
- **-able / -eable**: verb stem + -able = -able / -ible in English: recyclable, changeable
- **-ion / -ation**: verb stem + -ation gives a feminine noun: la préparation, la réservation
- **-ment**: feminine adjective + -ment = -ly: heureusement, lentement, dernièrement
- **-amment / -emment**: -ant / -ent adjectives become adverbs: patiemment, récemment; both said 'a-mahn'
- **-eur / -ateur**: Higher; the person who does the verb: chanteur, vendeur, créateur, utilisateur
- **un mot apparenté**: a cognate that looks and means the same as English: la musique, le problème
- **un faux ami**: a false friend: actuellement = currently, la librairie = bookshop
- **un mot à déduire**: one of Paper 3's two off-list words you must infer from context, 1 mark each
- **la règle d'un seul affixe**: Pearson adds one affix only: impatient or patiemment, never impatiemment
:::

::: method
1. **Strip the word.** Take off any gender or plural ending (*-e, -s, -es*), then look for a prefix (*in-, im-*) or a suffix (*-ième, -able, -ation, -ion, -ment, -emment, -amment, -eur, -euse, -ateur, -atrice*).
2. **Find the base word** that is left and recall its meaning: *dernièrement* → *dernière* → *dernier* (last).
3. **Apply the meaning of the affix**: *in-* = not; *-ième* = -th; *-able* = can be -ed; *-ation* = the act of; *-ment* = -ly; *-eur* = the person who.
4. **Check the word class** against the sentence: an article before it means a noun, a verb before it often means an adverb.
5. **Test the false-friend list** before trusting a lookalike.
6. **For an inferred word**, read the whole sentence and the one after, decide what kind of word fits, and eliminate options that contradict the context.
7. **Write natural English**: *heureusement* = fortunately (not "happily"), *dernièrement* = recently or lately.
:::

::: example Building and translating with in- / im- (4)
Add the prefix and translate: (a) *juste* (b) *possible* (c) *utile* (d) *la sécurité*

(a) *injuste* = unfair (1)
(b) *impossible* = impossible (1): *im-* before *p*.
(c) *inutile* = useless (1)
(d) *l'insécurité* = insecurity, lack of safety (1)

In a reading text, *Les élèves trouvent cette règle injuste* gives "The pupils find this rule unfair", even though *injuste* is not on the list.
:::

::: example Ordinals in context (3)
Translate: (a) *J'habite au cinquième étage.* (b) *C'est la troisième fois que je vais en Martinique.* (c) *Mon anniversaire, c'est le premier avril.*

(a) I live on the fifth floor. (1)
(b) It's the third time I've been (I'm going) to Martinique. (1)
(c) My birthday is (on) the first of April. (1) Other dates use plain numbers: *le deux avril*.
:::

::: example Adverbs from adjectives (4)
Form the adverb and translate: (a) *heureux* (b) *lent* (c) *récent* (d) *évident*

(a) *heureusement* = fortunately (1): feminine *heureuse* + *-ment*.
(b) *lentement* = slowly (1): the exception to the *-ent* rule.
(c) *récemment* = recently (1): *-ent* → *-emment*.
(d) *évidemment* = obviously (1)
:::

::: example Inferring an off-list word (1)
*Mon voisin écoute de la musique très fort tous les soirs. Il est vraiment bruyant et je ne peux pas dormir.*

Which is the best translation of the word *bruyant*? A — noisy; B — lazy; C — generous. (1)

A (1). *Bruyant* follows *il est*, so it is an adjective describing the neighbour. The context is loud music every night and not being able to sleep, so "noisy" is the only option that fits. "Lazy" and "generous" are possible adjectives, but nothing in the text supports them.
:::

::: example Higher: agent nouns in a text (3)
*Pendant le festival, les visiteurs peuvent rencontrer les organisateurs et écouter une chanteuse canadienne.*

Who can the visitors meet, and who can they listen to? (3)

They are "visitors" (1): *visiter* + *-eur*. They can meet the organisers (1): *organiser* + *-ateur*. They can listen to a Canadian (female) singer (1): *chanteuse*, the feminine of *chanteur*.
:::

(a) *complètement* (b) *patiemment* (c) *vraiment* (d) *différemment*. Four = 2; two or three = 1.

---

::: q
Which of these is NOT a word with the prefix in- meaning "not"? A — inutile; B — important; C — injuste. Explain. (2)
---
B (1). Without *im-*, *portant* is not a word with an opposite meaning, so *important* is a base word in its own right (1).
:::

::: q
Translate into English: *Actuellement, mon frère travaille dans une librairie et il passe toute la journée avec des livres.* (2)
---
Currently (at the moment), my brother works in a bookshop and he spends the whole day with books. (2) 1 if one false friend is mistranslated ("actually", "library" or "journey").
:::

::: watch
- **False friends cost easy marks**: *actuellement* = currently, *la librairie* = bookshop, *sensible* = sensitive, *la journée* = day, *rester* = to stay, *attendre* = to wait.
- **Heureusement means "fortunately"** in almost every exam text, not "happily".
- **Dates are cardinal** except *le premier*: *le trois mai*, not *le troisième mai*.
- **School years count down**: *en troisième* is the final year of *collège*, not "third year".
- **Not every in- is negative**: *important, intéressant, inviter* are base words.
- **Spellings of ordinals**: *cinquième* (with *u*), *neuvième* (with *v*), *quatrième* (no *e* before *-ième*).
- **-emment and -amment sound alike** in the dictation; the spelling follows the adjective (*récent* → *récemment*, *indépendant* → *indépendamment*).
- **Inferred words**: an answer that fits the grammar but not the context is wrong. Read the sentence after the word too.
- **Gender of -ion nouns** is always feminine: *la préparation*, not *le préparation*.
:::

::: test
Translate the passage into English.

*Récemment, mon collège a organisé une journée contre l'insécurité dans les rues. Premièrement, les élèves ont préparé des présentations. Deuxièmement, un chanteur célèbre est venu parler aux visiteurs. Évidemment, tout le monde l'a écouté patiemment. Il a plu, mais les organisateurs étaient contents. L'année prochaine, la troisième journée sera encore plus grande !* (10)
---
Holistic bands. 9–10: the meaning is fully transferred in natural English. 6–8: most of the meaning, with occasional wrong or missing words. 3–5: parts of the meaning, with derived words guessed wrongly or tenses lost. 1–2: isolated words or phrases.
**Model:** Recently, my school organised a day against crime / insecurity in the streets. Firstly, the pupils prepared presentations. Secondly, a famous singer came to talk to the visitors. Obviously, everyone listened to him patiently. It rained, but the organisers were happy. Next year, the third day will be even bigger!
**Deciding details:** *récemment* = recently; *journée* = day (not journey); *l'insécurité* = lack of safety / insecurity; *premièrement / deuxièmement* = firstly / secondly; *visiteurs* and *organisateurs* from *visiter* and *organiser*; *l'a écouté patiemment* = listened to him patiently; *sera* = will be; *encore plus grande* = even bigger.
:::

::: test
Translate the paragraph into French.

Fortunately, my sister is very patient. She lives on the fourth floor of a building in Paris. Recently, she organised a party for her friends. Firstly, she prepared the invitations, then she cooked a meal. Obviously, it was impossible to invite everyone. Next year, she wants to become a singer. (10)
---
**AO2 meaning (6):** 5–6 the meaning is transferred consistently, with rare lack of clarity; 3–4 most of it is transferred, with the occasional message unclear or missing; 1–2 some parts are transferred, and the message sometimes breaks down.
**AO3 accuracy (4):** 4 consistently accurate, any errors minor; 3 generally accurate, minor errors, major errors rare; 2 sometimes accurate, including some major errors; 1 limited accuracy, frequent major and minor errors.
**Model:** *Heureusement, ma sœur est très patiente. Elle habite au quatrième étage d'un immeuble à Paris. Récemment, elle a organisé une fête pour ses amis. Premièrement, elle a préparé les invitations, puis elle a préparé un repas. Évidemment, c'était impossible d'inviter tout le monde. L'année prochaine, elle veut devenir chanteuse.*
**Key points:** *patiente* (agreement); *au quatrième étage*; *a organisé* (perfect); *premièrement*; *c'était impossible de* (accept *il était impossible de*); *veut devenir chanteuse* (no article). Minor errors: *patient* for a sister, *quatrieme* without the accent, *une chanteuse*. Major errors: *elle organisé* without *a*, *elle veut devient*, *est impossible* for "was impossible".
:::
