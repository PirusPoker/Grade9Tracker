## What it is

Every computer system, from a games console to a smart thermostat, is made of two things that cannot work without each other: **hardware** and **software**.

**Hardware** is the **physical components** that make up a computer system: the parts you could, in principle, pick up, open and wire together. Examples:
- **Inside the box:** the processor (CPU), RAM, the motherboard, a graphics card, a solid state drive, a hard disk drive, the power supply, the network interface card.
- **Input devices:** keyboard, mouse, touchscreen, microphone, webcam, scanner, sensors such as a temperature sensor.
- **Output devices:** monitor, printer, speakers, headphones, actuators such as motors and LEDs.

**Software** is the **programs**: sets of instructions that tell the hardware what to do, together with the data those programs use. Examples:
- an **operating system** such as Windows, macOS, Linux, Android or iOS;
- **utility programs** such as antivirus, backup and compression software;
- **application software** such as a web browser, word processor, spreadsheet, game or photo editor.

Software is stored on hardware (as binary on a drive or in memory), but it is not the drive or the memory itself. A program is the same program whether it is on a USB stick, an SSD or downloaded over the Internet.

**Why "you can touch hardware but not software" is not a full definition.** It is a handy memory aid, but examiners want the key idea: hardware is the **physical** equipment; software is the **instructions/programs** that run on it. Write it that way and you will get the mark.

### The relationship between hardware and software

The spec asks you to **understand the relationship** between the two. The core ideas:

| Idea | What it means |
|---|---|
| **Hardware needs software** | Without software the hardware does nothing useful. A processor only ever carries out instructions; with no program there are no instructions to carry out. |
| **Software needs hardware** | Software is just stored instructions. It needs a processor to **execute** it, memory to **hold** it while it runs, storage to **keep** it, and input/output devices to interact with the user. |
| **Software controls hardware** | Programs send instructions that make the hardware act: read a key press, display a pixel, spin a fan, send data over a network. |
| **Hardware limits software** | A program can only run if the hardware can cope: enough RAM, a fast enough processor, the right instruction set, the right devices. A game needing a powerful graphics card will not run well on a basic laptop. |
| **Software is processor-specific at the lowest level** | The processor executes **machine code**, and each type of processor has its own instruction set (3.4.4), so programs must be translated for the hardware they will run on. |

A useful way to picture this is as **layers**. Each layer uses the one beneath it and provides services to the one above:

| Layer | Example | Its job |
|---|---|---|
| **User** | a student writing an essay | gives inputs, reads outputs |
| **Application software** | word processor | performs the task the user wants |
| **System software (operating system and utilities)** | Windows | manages the hardware and provides a platform for applications (3.4.3) |
| **Hardware** | CPU, RAM, SSD, keyboard, screen | physically stores data and carries out instructions |

When you press a key in a word processor: the keyboard (hardware) sends a signal; the operating system (system software) receives it through a device driver and passes it to the word processor; the word processor (application) decides to add a letter to the document; the operating system and graphics hardware then display that letter on the screen. Hardware and software take turns all the way through.

**Firmware** is a borderline case worth one line: it is **software** (instructions) permanently stored in a chip on the hardware, such as the start-up program in ROM (3.4.5b) or the program inside a washing machine. It is still software, because it is a program.

### Classifying items

Exam questions often give a list and ask you to sort it. Use the test: **is it a physical component, or is it a program/instructions?**

| Item | Hardware or software? | Why |
|---|---|---|
| Graphics card | Hardware | physical component |
| Device driver | Software | a program that lets the OS control a device |
| Web browser | Software | application program |
| Touchscreen | Hardware | physical input and output device |
| Antivirus | Software | utility program |
| RAM | Hardware | physical memory chips |
| Operating system | Software | system software |
| Router | Hardware | physical network device (it runs firmware, which is software) |

::: terms
- **Hardware**: the physical components that make up a computer system, such as the processor, memory, storage and input/output devices.
- **Software**: the programs (sets of instructions) that run on a computer system and tell the hardware what to do.
- **Program**: a sequence of instructions that a computer can carry out to perform a task.
- **Input device**: hardware that sends data into a computer system, such as a keyboard, microphone or sensor.
- **Output device**: hardware that presents or acts on results from a computer system, such as a screen, speaker or motor.
- **Execute**: to carry out the instructions of a program; this is done by the processor.
- **Firmware**: software stored permanently in a chip on a hardware device, such as the start-up program or the control program of an appliance.
- **Computer system**: hardware and software working together to take inputs, process them and produce outputs.
:::

::: method
1. **Define hardware**: the **physical** components of a computer system. Give an example if there is space.
2. **Define software**: the **programs / instructions** that run on the hardware. Give an example.
3. **Classify** an item by asking: physical part, or program? Firmware and drivers are software.
4. **Explain the relationship** with linked points: hardware needs software to do anything useful; software needs hardware to be stored and executed; software controls the hardware; hardware limits what software can run.
5. **Use the device in the question.** Name its actual hardware (sensor, processor, screen) and its actual software (control program, app) and show them working together.
6. For 4 marks, aim for **two developed points**, each a statement plus a "so" or "because".
:::

::: example Define both terms
Define the terms hardware and software. (2)

Hardware is the physical components of a computer system, such as the processor or a keyboard (1).

Software is the programs (sets of instructions) that run on a computer and control the hardware, such as an operating system (1).
:::

::: example Classify a list
Tick whether each item is hardware or software: mouse; spreadsheet program; solid state drive; device driver. (2)

Mouse: hardware. Spreadsheet program: software. Solid state drive: hardware. Device driver: software (2).

All four correct for 2 marks; two or three correct for 1 mark.
:::

::: example Relationship using a smartphone
Explain the relationship between hardware and software, using a smartphone as an example. (4)

The phone's hardware, such as its processor, memory and touchscreen, can do nothing useful on its own; it needs software to give it instructions (1). For example, the processor executes the instructions of the camera app and the operating system (1).

The software needs hardware to run on: apps are stored on the phone's flash storage and loaded into RAM, and the processor carries them out (1). So an app that needs more memory or a faster processor than the phone has will not run well, because the hardware limits what software can do (1).
:::

::: example Why a program will not run
Ali downloads a game, but it will not run on his old laptop. Explain one hardware reason and one software reason why. (4)

Hardware: the laptop may not have enough RAM or a powerful enough graphics card (1), so it cannot hold or process the game's data fast enough to run it (1).

Software: the game may be written for a different operating system, or compiled for a different type of processor (1), so the laptop's system software cannot run its instructions (1).
:::

::: example Firmware
A washing machine has a control program stored permanently on a chip. State whether this program is hardware or software, and justify your answer. (2)

Software (1), because it is a set of instructions that controls the machine, even though it is stored on a physical chip (1).
:::

::: q
State two examples of hardware found inside a desktop computer. (2)
---
Any two of: processor/CPU; RAM; motherboard; hard disk drive; solid state drive; graphics card; power supply; network interface card (1 each).
:::

::: q
State two examples of software. (2)
---
Any two named programs or types of program, e.g. operating system; web browser; word processor; antivirus; game; device driver (1 each). Do not accept physical items.
:::

::: q
A student writes: "Software is the bits of the computer you cannot touch." Explain why this definition is not good enough, and give a better one. (2)
---
It does not say what software actually is; data you cannot touch, such as a signal, is not necessarily software (1). Better: software is the programs/instructions that tell the hardware what to do (1).
:::

::: q
Explain why hardware cannot do anything useful without software. (2)
---
The processor can only carry out instructions (1); without a program there are no instructions to execute, so the hardware does nothing (1).
:::

::: q
A games console is given a software update. Explain how this changes what the console can do even though the hardware is unchanged. (2)
---
The update provides new or changed instructions (1), so the same hardware is controlled differently, e.g. new features or bug fixes, because the behaviour of a system depends on the software it runs (1).
:::

::: q
Classify each as hardware or software: webcam; operating system; printer; antivirus. (2)
---
Webcam hardware; operating system software; printer hardware; antivirus software. All four correct (2); two or three correct (1).
:::

::: watch
- Define hardware as the **physical components**, and software as the **programs/instructions**. "Can't touch" alone rarely earns the mark.
- Drivers, firmware, operating systems and utilities are all **software**.
- A **storage device** is hardware; the **program stored on it** is software.
- In "explain the relationship" questions, give **both directions**: hardware needs software, and software needs hardware.
- Use the device in the question. Generic answers that never mention the given device are capped.
- Examples must be specific: "a keyboard" is fine; "parts of the computer" is not.
:::

::: test
Explain the relationship between hardware and software, using a self-service checkout in a supermarket as an example. (4)
---
Any four linked points, applied to the checkout, e.g.:
- The checkout's hardware (barcode scanner, touchscreen, scales, card reader, processor) can do nothing useful without software (1); its software (the checkout program and operating system) gives the processor instructions, e.g. to look up the price when a barcode is scanned (1).
- The software needs hardware: it is stored on the checkout's storage, loaded into memory and executed by its processor (1); it receives input from the scanner and sends output to the screen and receipt printer, so it depends on those devices (1).
- The hardware limits the software, e.g. the program can only use devices that are fitted (1).
Max 4. Generic answers that do not refer to the checkout: max 2.
:::

::: test
Explain how hardware and software work together when a user presses a key in a word processor and the letter appears on the screen. (4)
---
The keyboard (hardware) detects the key press and sends a signal (1). The operating system (software) receives the signal, e.g. through a driver, and passes it to the word processor (1). The word processor (application software) is executed by the processor and adds the character to the document in memory (1). The operating system and graphics hardware then update the screen (output hardware) to show the letter (1).
:::

::: test
A new version of a video-editing program will not run on a school's older computers. Explain two possible reasons, one about hardware and one about software. (4)
---
Hardware: e.g. not enough RAM / processor too slow / no suitable graphics card (1), so the computers cannot hold or process the video data fast enough to run the program (1).
Software: e.g. the program needs a newer version of the operating system / is built for a different type of processor (1), so the computers' system software cannot load or run it (1).
:::

::: test
Explain why a computer system is described as hardware and software working together, rather than as just a machine. (3)
---
The hardware provides the physical ability to input, store, process and output data (1); the software provides the instructions that decide what is done with the data (1); so the same hardware can carry out many different tasks just by running different software (1).
:::
