## What it is

Sound in the real world is a vibration travelling through the air. A microphone turns it into an electrical signal that rises and falls smoothly, matching the wave. That signal is **analogue**: it changes **continuously** and can take any value at any moment. A computer can only store and process **digital** data, a fixed number of binary values, so the analogue signal must be **converted to digital** before it can be stored, edited or sent, and converted back to analogue to drive a speaker.

**Sampling** is how the conversion is done. At regular, very short intervals, the **amplitude** (height) of the sound wave is measured and the measurement is stored as a binary number. Each measurement is called a **sample**: **a measure of amplitude at a point in time**. Played back in order, the samples rebuild an approximation of the original wave.

*The smooth curve is the analogue sound. Each dot is a sample: the amplitude measured at one moment in time, stored as a binary number.*

Two settings decide how good the digital copy is and how much space it takes.

**Sampling rate** is the **number of samples taken per second**. It is measured in **hertz (Hz)**, where **1 Hz = 1 sample per second**. CD-quality audio uses 44,100 Hz (44.1 kHz): 44,100 measurements every second. A voice call might use 8,000 Hz.
- A **higher** sampling rate measures the wave more often, so the samples follow its shape **more closely** and quick changes (high-pitched sounds) are captured: **better quality**.
- But there are more samples per second to store: a **bigger file**.

**Sample resolution** is the **number of bits used to store each sample**. It sets how many different amplitude values each sample can take: n bits give 2 to the power n levels. 8 bits give 256 levels; 16 bits give 65,536.
- A **higher** resolution means each measurement can be recorded **more precisely**, closer to the true amplitude, so the sound is more accurate with less distortion: **better quality**.
- But every sample uses more bits: a **bigger file**.

A useful picture: the sampling rate sets how many **vertical** measurement lines there are each second, and the resolution sets how finely each line's **height** can be recorded.

**Calculating file size.** Each second there are (rate) samples, each of (resolution) bits, so:

| | Formula |
|---|---|
| File size in **bits** | sampling rate × sample resolution × number of seconds |
| File size in **bytes** | the bits ÷ 8 |

This assumes one channel of sound, which is what AQA uses.

Worked example: 10 seconds of sound sampled at 44,100 Hz with a resolution of 16 bits.
- Bits per second: 44,100 × 16 = 705,600.
- Bits for 10 seconds: 705,600 × 10 = 7,056,000 bits.
- Bytes: 7,056,000 ÷ 8 = 882,000 bytes = **882 kB**.

Worked example with minutes: 2 minutes at 20,000 Hz and 8 bits. Convert the time to **seconds** first: 120 s.
- 20,000 × 8 × 120 = 19,200,000 bits.
- ÷ 8 = 2,400,000 bytes = **2.4 MB**.

**Working backwards.** You may be given the size and asked for the length or another setting. Rearrange: seconds = bits ÷ (rate × resolution). For example, a 400,000-byte recording at 10,000 Hz and 8 bits: 400,000 × 8 = 3,200,000 bits; 10,000 × 8 = 80,000 bits per second; 3,200,000 ÷ 80,000 = **40 seconds**.

**Choosing settings** is a trade-off between **quality** and **file size**. Music for a streaming service needs a high rate and resolution; a voice message or a phone call can use much lower settings, because speech is understandable at lower quality and smaller files are quicker to send. Halving the sampling rate halves the file size; doubling the resolution doubles it.

::: terms
- **Analogue**: a signal that varies continuously and can take any value, such as a real sound wave.
- **Digital**: data stored as a fixed set of separate binary values.
- **Sampling**: measuring the amplitude of an analogue signal at regular intervals to create a digital version.
- **Sample**: a measure of the amplitude of a sound wave at a point in time.
- **Amplitude**: the height of a sound wave, which relates to how loud it is.
- **Sampling rate**: the number of samples taken per second, measured in hertz.
- **Hertz (Hz)**: the unit of sampling rate; 1 hertz is 1 sample per second.
- **Sample resolution**: the number of bits used to store each sample.
:::

::: method
1. **Write down the rate (Hz), the resolution (bits) and the length.** Convert minutes to **seconds**.
2. **Multiply rate × resolution × seconds** to get **bits**.
3. **Divide by 8** for bytes; then by 1,000 for kB and again for MB, as the question asks.
4. **Show each step** with its unit.
5. **To find a missing value**, turn the size into bits, then divide by the other two values.
6. **For "effect of increasing"**: say what changes (more samples per second, or more bits per sample), the effect on **quality**, and the effect on **file size**.
7. **Definitions**: rate = samples **per second** (Hz); resolution = **bits per sample**.
:::

::: example Calculate a sound file size
Calculate the size, in kilobytes, of a 60-second recording sampled at 8,000 Hz with a sample resolution of 8 bits. Show your working. (3)

8,000 × 8 × 60 = 3,840,000 bits (1).

3,840,000 ÷ 8 = 480,000 bytes (1).

480,000 ÷ 1,000 = 480 kB (1).
:::

::: example Define the terms
Define (a) sampling rate; (b) sample resolution. (2)

(a) The number of samples taken per second (1).

(b) The number of bits used to store each sample (1).
:::

::: example Effect of a higher sampling rate
Explain the effect of increasing the sampling rate of a recording. (2)

More samples are taken each second, so the digital version is closer to the original analogue sound and the quality is better (1). More samples must be stored, so the file size increases (1).
:::

::: example Working backwards
A sound file is 1,200,000 bytes. It was sampled at 25,000 Hz with a resolution of 16 bits. Calculate the length of the recording in seconds. Show your working. (3)

1,200,000 × 8 = 9,600,000 bits (1).

25,000 × 16 = 400,000 bits per second (1).

9,600,000 ÷ 400,000 = 24 seconds (1).
:::

::: example Why sampling is needed
Explain why sound must be sampled before it can be stored on a computer. (2)

Sound is analogue, varying continuously (1), but computers can only store digital / binary data, so the amplitude is measured at intervals and stored as binary numbers (1).
:::

---

::: q
A recording's sampling rate is halved and its resolution is doubled. State the effect on the file size and explain why. (2)
---
The file size stays the same (1), because file size is rate × resolution × time, and halving one factor while doubling another leaves the product unchanged (1).
:::

::: watch
- **Rate** = samples **per second** (Hz). **Resolution** = **bits per sample**. Swapping them loses both marks.
- Convert **minutes to seconds** before multiplying.
- The formula gives **bits**: divide by 8 for bytes before using kB or MB.
- "Effect" answers need **both** sides: better quality **and** bigger file.
- A sample is a measure of **amplitude** at a point in **time**: use both words.
- Use 1 kB = 1,000 bytes.
:::
