## What it is

Every value a program stores has a **data type**. The data type tells the computer **what kind of value it is**, and therefore **how to store it** and **which operations make sense on it**. You can add two numbers or join two pieces of text, but you cannot sensibly divide a name by 3. Choosing the right data type for each item of data is the first step in writing any program, and Paper 1 tests it directly.

AQA uses five general data types:

| Data type | What it holds | Examples | Typical uses |
|---|---|---|---|
| **Integer** | whole numbers, positive, negative or zero | 15, -3, 0, 2027 | ages, counts, scores, number of items |
| **Real** | numbers that can have a fractional (decimal) part | 3.14, -0.5, 19.99, 2.0 | prices, heights, temperatures, averages |
| **Boolean** | one of exactly two values: True or False | True, False | flags such as found, isMember, gameOver |
| **Character** | a single letter, digit, symbol or space | 'A', '7', '?', ' ' | a grade letter, a menu choice, an initial |
| **String** | a sequence of characters (text), of any length, including empty | 'Hello', 'SW1A 1AA', '07700 900123', '' | names, postcodes, phone numbers, passwords |

**Languages use different names.** AQA uses the general names above in exams, but your programming language may not:

| AQA name | Python | C# | VB.NET |
|---|---|---|---|
| Integer | `int` | `int` | `Integer` |
| Real | `float` | `double` (or `float`) | `Double` (or `Single`) |
| Boolean | `bool` | `bool` | `Boolean` |
| Character | no separate type: a string of length 1 | `char` | `Char` |
| String | `str` | `string` | `String` |

In C# and VB.NET you **declare** a variable's type when you create it: `int age = 15;` or `Dim age As Integer = 15`. In Python the type comes from the value you assign: `age = 15` makes an integer, `age = 15.0` makes a real (float), and `age = "15"` makes a string. In AQA pseudo-code types are usually left out of assignments, but they appear in record definitions, such as `price : Real`.

**Choosing a data type.** Ask two questions about each item:
1. **Will I do arithmetic with it?** If not, it is probably text, even if it is made of digits.
2. **Can it have a fractional part?** If yes, it is real. If it can only ever be whole, it is integer.

Some choices catch people out:
- **Telephone numbers are strings.** You never add or multiply phone numbers. They often start with **0**, which an integer would drop (07700 would become 7700), and they can contain spaces or a + sign.
- The same goes for **postcodes, account numbers, barcodes and student IDs** that are used as codes rather than quantities.
- **Money is usually real** (£4.99), because it has a decimal part. Some programs store pence as an integer to avoid rounding errors, which is also acceptable if the question allows it.
- **Yes/no facts are Boolean**, not the strings 'yes' and 'no'. A Boolean takes less storage, cannot be misspelt ('Yes', 'Y', 'yes '), and can be used directly as a condition: `IF isMember THEN`.
- **A single letter is a character**: a grade 'A' or a choice 'Y'. A word or any longer text is a string.
- **Age in years and number of people are integers.** You cannot have 2.5 people.

**Why data types matter:**
- **Memory:** different types take different amounts of storage, so the right type avoids waste.
- **Valid operations:** the type decides what an operator does. With numbers, `+` adds: 7 + 3 is 10. With strings, `+` **concatenates** (joins): '7' + '3' is '73'.
- **Errors:** using the wrong type causes problems. In Python, `"5" + 3` stops the program with a type error, because you cannot add text to a number.
- **Validation:** if the program expects an integer, it can reject input that is not a whole number.

**Converting between types.** Input from the keyboard always arrives as a **string**, even if the user types digits. Before calculating with it, you must **convert** it. In AQA pseudo-code you write `age ← STRING_TO_INT(USERINPUT)`. In Python you write `age = int(input("Age: "))` (or `float(...)` for a real). The reverse conversions, such as `INT_TO_STRING(score)` in pseudo-code or `str(score)` in Python, turn numbers into text so they can be joined into a message. String handling (3.2.8) covers these conversions in full.

::: terms
- **Data type**: the kind of value a variable holds, which decides how it is stored and which operations can be used on it.
- **Integer**: a data type for whole numbers, positive, negative or zero, such as 42 or -7.
- **Real**: a data type for numbers that can have a fractional part, such as 3.75; often called float or double.
- **Boolean**: a data type with only two possible values, True and False.
- **Character**: a data type holding a single letter, digit, symbol or space, such as 'Q'.
- **String**: a data type holding a sequence of characters, such as a name or a postcode.
- **Declaration**: creating a variable, and in many languages stating its data type, before it is used.
- **Type conversion (casting)**: changing a value from one data type to another, such as the string '42' to the integer 42.
- **Type error**: an error caused by using a value of the wrong data type, such as adding a string to a number.
:::

::: method
1. **"State the most suitable data type":** use AQA's names: integer, real, Boolean, character or string. Python names (float, str, bool) are usually accepted, but the general names are safest.
2. **Ask whether it is a quantity you calculate with.** Codes, phone numbers, IDs and postcodes are **strings**, even if made of digits.
3. **Ask whether it can have a decimal part:** if so, **real**; if only whole values make sense, **integer**.
4. **Two possible states** (on/off, paid/unpaid, member/not) means **Boolean**. Exactly one symbol means **character**.
5. **"Explain why" questions:** give the reason from the data: "string, because it starts with 0, which would be lost as an integer, and no calculations are done on it".
6. **In code questions**, convert input before calculating with it, and use sensible types for every variable you create.
:::

::: example Choose the data types
A gym stores these details about each member. State the most suitable data type for each: (a) membership number, e.g. 004817; (b) monthly fee, e.g. 24.50; (c) whether the member has paid this month; (d) number of classes attended. (4)

(a) String: it is an identifier, never calculated with, and starts with zeros that an integer would lose (1).

(b) Real: the fee has a decimal part (1).

(c) Boolean: it has only two possible values, paid or not paid (1).

(d) Integer: a count is always a whole number (1).
:::

::: example Why a phone number is a string
Explain why a telephone number should be stored as a string and not as an integer. (2)

Telephone numbers usually begin with 0, and storing one as an integer would remove the leading zero, changing the number (1).

No arithmetic is ever carried out on a telephone number, and it may contain spaces or a + sign, which an integer cannot hold (1).
:::

::: example The effect of type on +
In Python, `a = "12"` and `b = "30"`. State what `print(a + b)` displays, and what `print(int(a) + int(b))` displays. Explain the difference. (3)

`print(a + b)` displays 1230 (1).

`print(int(a) + int(b))` displays 42 (1).

a and b are strings, so `+` concatenates them; after conversion to integers, `+` adds them (1).
:::

::: example Declaring typed variables
Write program code that declares variables to store a pupil's name, their year group and their average test score, sets them to 'Maya', 10 and 72.5, and outputs all three. (3)

In C#, each type is stated: `string name = "Maya";` and `int yearGroup = 10;` (1).

`double average = 72.5;` uses a real type for the decimal score (1).

`Console.WriteLine(name + " " + yearGroup + " " + average);` outputs them (1). In Python the same is `name = "Maya"`, `year_group = 10`, `average = 72.5`, `print(name, year_group, average)`.
:::

---

::: watch
- **Phone numbers, postcodes and IDs are strings**, not integers. The giveaway is a leading zero, or no arithmetic.
- **Money and measurements are real.** Only counts and whole-number quantities are integer.
- **Character means exactly one symbol.** A name is a string, even a short one.
- Use AQA's names in the exam: **integer, real, Boolean, character, string**.
- Input arrives as a **string**. Code that calculates with it before converting it either crashes or joins text by mistake.
- Justify your choice from the **data**: "real, because the price has pence" scores; "real, because it is a number" does not.
:::
