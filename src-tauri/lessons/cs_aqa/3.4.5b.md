## What it is

A computer uses several kinds of memory and storage, because **no single technology is fast, large, cheap and permanent all at once**. This lesson sorts them out.

### Types of memory

| Memory | Where | What it holds | Volatile? | Why it is needed |
|---|---|---|---|---|
| **Registers** | inside the CPU | the instruction, addresses and data being processed at this instant | yes | the CPU needs somewhere to hold the values it is working on that is as fast as the CPU itself |
| **Cache** | on or very near the CPU | copies of frequently used instructions and data from main memory | yes | main memory is too slow to keep up with the CPU; cache reduces waiting (3.4.5a) |
| **RAM** (random access memory) | main memory, on the motherboard | the operating system, programs and data **currently in use** | **yes** | programs must be in main memory for the CPU to fetch and execute them; it can be read **and written** quickly |
| **ROM** (read-only memory) | main memory, a chip on the motherboard | the **start-up instructions** (the boot program / firmware) | **no** | when the computer is switched on, RAM is empty, so the instructions to start the computer and load the OS must be kept somewhere permanent |

Going from registers to cache to RAM, each level is **slower** but **larger** and **cheaper per byte**. Secondary storage is slower again but much larger and cheaper.

**Volatile** memory **loses its contents when the power is switched off**. **Non-volatile** memory **keeps** its contents without power.

**RAM against ROM:**

| RAM | ROM |
|---|---|
| volatile | non-volatile |
| can be read from **and written to** | can normally only be **read**; its contents are set when it is made (or updated only by special means) |
| holds the OS, programs and data in use, which change all the time | holds the start-up instructions, which rarely change |
| usually large (several GB) | usually small |

### Main memory and secondary storage

**Main memory** is any memory the CPU can **access directly** (other than cache and registers): RAM and ROM. **Secondary storage** is **non-volatile** storage that the CPU **cannot access directly**, such as an SSD or hard disk drive. To run a program, it is first **loaded** from secondary storage into RAM.

**Why secondary storage is needed:**
- RAM is **volatile**: without secondary storage, every file, program and even the operating system would be lost each time the computer was switched off.
- It provides **much larger capacity** at a **lower cost per gigabyte** than RAM, so it can hold all of a user's programs and files, not just those in use.
- It can be **portable** (USB stick, external drive) to move files between computers, and it can store **backups**.

### Magnetic storage

A **hard disk drive (HDD)** contains one or more rigid **platters** coated with a **magnetic material**, spinning at high speed. A **read/write head** on a moving **arm** sits just above each surface.
- To **write**, the head **magnetises** tiny areas of the surface in one of **two directions**, which represent **0 and 1**.
- To **read**, the head detects the direction of magnetisation as each area passes underneath.
- To reach data, the arm must move the head to the right track and wait for the platter to spin round to the right place, so there is a short delay before data is found.

**Magnetic tape** works on the same principle, on a long reel of tape; data has to be wound to, so it is used for large backups and archives.

### Solid state storage

A **solid state drive (SSD)**, like a USB memory stick or a phone's storage, has **no moving parts**. It uses **electrical circuits** that can **trap electric charge** to store data **persistently**, keeping it without power. (You do not need to know how the circuits are built.)

| | **Solid state (SSD)** | **Magnetic (HDD)** |
|---|---|---|
| **Speed** | **faster** to read and write; no waiting for parts to move, so programs load and the computer starts quickly | slower; the head must move and the platter spin round |
| **Durability** | **no moving parts**, so much more resistant to being dropped or knocked | moving parts can be **damaged** by shocks; a head crash can destroy data |
| **Cost** | **more expensive per GB** | **cheaper per GB** |
| **Capacity** | large, but very large capacities cost much more | very **large capacities** are affordable |
| **Other** | silent, light, small, low power (good battery life) | noisier, heavier, uses more power |
| **Lifespan** | each part can be rewritten a limited number of times before it wears out | can be rewritten many times, but mechanical parts eventually wear |
| **Best for** | laptops, phones, tablets, boot drives, anything portable or needing speed | large cheap storage: desktop file storage, servers holding huge amounts of data, backups |

### Cloud storage

**Cloud storage** means storing data on **servers at a remote location**, usually owned by a provider, and accessing it **over the Internet**. The data is still stored on **magnetic and/or solid state** drives: they are simply somewhere else. **Local storage** means drives in or attached to the user's own device or on the organisation's own premises.

| Advantages of cloud storage | Disadvantages of cloud storage |
|---|---|
| **Access from anywhere**, on any device with an Internet connection | **Needs an Internet connection**; no connection, no access |
| **Easy sharing and collaboration**: several people can work on the same files | Transfers are limited by the **connection speed**, so large files can be slow to upload or download |
| **Scalable**: buy more space when needed, without buying hardware | **Ongoing subscription** costs, which can add up over time |
| The provider handles **maintenance, backups and hardware failures** | **Less control**: the data is held by a third party, which raises **security and privacy** concerns |
| Data is **off-site**, so it survives a fire, flood or theft at the user's premises | If the **provider has an outage** or goes out of business, data may be unavailable or lost |
| No up-front cost for drives | Data may be stored in **other countries**, which may raise legal questions |

### Embedded systems

An **embedded system** is a computer system **built into a larger device** to carry out **one dedicated function** (or a small set of functions). Examples: the controller in a **washing machine**, **microwave oven**, **central heating thermostat**, **car engine management system**, **traffic lights**, **fitness tracker** or **digital camera**.

| | Embedded system | Non-embedded (general-purpose) system |
|---|---|---|
| **Purpose** | one dedicated task, part of a bigger device | many tasks; the user can install and run any software |
| **Software** | a fixed control program, often stored in **ROM** as firmware; rarely changed by the user | operating system plus many applications, installed and updated by the user |
| **Hardware** | small, cheap, **low power**, limited memory and processing power | more powerful, more memory and storage |
| **Examples** | dishwasher controller, smart meter, pacemaker | desktop PC, laptop, tablet |

Embedded systems are often programmed in **assembly language** or compact high-level code (3.4.4), because they must be efficient and control specific hardware.

::: terms
- **RAM**: volatile main memory that can be read and written, holding the OS, programs and data currently in use.
- **ROM**: non-volatile main memory that can normally only be read, holding the instructions needed to start the computer.
- **Volatile**: describes memory that loses its contents when the power is switched off.
- **Non-volatile**: describes memory or storage that keeps its contents when the power is switched off.
- **Main memory**: memory that the CPU can access directly, apart from cache and registers; RAM and ROM.
- **Secondary storage**: non-volatile storage that the CPU cannot access directly, used to keep programs and files long term.
- **Magnetic storage**: storage that records 0s and 1s by magnetising areas of a surface in one of two directions, as in a hard disk drive.
- **Solid state storage**: storage with no moving parts that keeps data using electrical circuits, as in an SSD or USB stick.
- **Cloud storage**: magnetic or solid state storage on servers at a remote location, accessed over the Internet.
- **Embedded system**: a computer system built into a larger device to perform a dedicated function.
:::

::: method
1. **RAM vs ROM**: always contrast volatile/non-volatile **and** read-write/read-only **and** what each holds.
2. **Why secondary storage**: RAM is volatile; larger, cheaper capacity; portability/backups.
3. **How storage works**: HDD = spinning magnetic platters + moving read/write head + two directions of magnetisation; SSD = electrical circuits, no moving parts.
4. **Recommend storage**: pick a type, then justify with **the scenario's needs**: speed, durability, capacity, cost, portability. Mention a drawback and why it matters less here.
5. **Cloud**: say it is still magnetic/solid state, **remote**, accessed **over the Internet**. Give advantages and disadvantages **compared with local** storage.
6. **Embedded**: built into a larger device, dedicated function, plus a named example.
7. **9-mark discuss**: cover every bullet, apply to the organisation, reach a justified conclusion.
:::

::: test
Explain why cache, RAM and secondary storage are all needed, rather than using only one type. (3)
---
Cache is very fast but small and expensive, so it holds only the most frequently used data close to the CPU (1). RAM is larger and cheaper but slower and volatile, holding the programs currently running (1). Secondary storage is slowest but has a much larger capacity at low cost and is non-volatile, so it keeps everything permanently (1).
