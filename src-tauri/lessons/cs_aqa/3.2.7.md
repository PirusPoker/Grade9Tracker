## What it is

Almost every program needs to **take data in** from the user and **give results back**. The spec asks for two skills: **obtaining input from the keyboard**, and **outputting data and information to the screen**. They are small skills, but they appear in nearly every code-writing question on Paper 1, so they are worth getting exactly right.

**Input in AQA pseudo-code.** `USERINPUT` stands for whatever the user types. It is always assigned to a variable:
1. `OUTPUT 'Enter your name'`
2. `name ← USERINPUT`

The `OUTPUT` line before it is a **prompt**: it tells the user what to type. Without one, the user sees a blinking cursor and has no idea what the program wants.

**Input arrives as text.** Whatever the user types, digits included, the program receives it as a **string**. If you are going to calculate with it, **convert** it first:
1. `age ← STRING_TO_INT(USERINPUT)`
2. `price ← STRING_TO_REAL(USERINPUT)`

In Python, `input()` shows its prompt and returns a string. You wrap it in `int()` or `float()` to convert:
1. `name = input("Enter your name: ")`
2. `age = int(input("Enter your age: "))`
3. `price = float(input("Enter the price: "))`

If you forget the conversion, two things can go wrong. Adding two inputs **joins** them instead of adding them: '2' + '3' gives '23', not 5. Mixing an input with a number, as in `input() + 1`, stops the program with a **type error**. Converting text that is not a number, such as `int("ten")`, also causes a run-time error. Validation (3.2.11a) deals with that.

In C#, input is `Console.ReadLine()`, converted with `int.Parse(...)` or `double.Parse(...)`. In VB.NET it is `Console.ReadLine()`, converted with `CInt(...)` or `CDbl(...)`.

**Output in AQA pseudo-code.** `OUTPUT` displays one or more items. Separate items with commas, or join strings with `+`:
1. `OUTPUT 'Hello'`
2. `OUTPUT 'Total: ', total`
3. `OUTPUT 'Welcome back, ' + name`

In Python, `print()` displays items. Commas put a **space** between items automatically, and `+` joins strings with no space:
1. `print("Total:", total)`
2. `print("Welcome back, " + name)`
3. `print("Score: " + str(score))`

Line 3 needs `str()`, because `+` cannot join a string to a number. Using commas instead, as in line 1, avoids that problem.

**Data versus information.** The spec says programs output **data and information**. Raw data is a bare value such as `17.5`. Information is that value given **meaning**: `Average mark: 17.5 out of 20`. Good output always says what the numbers are.

**Formatting money and decimals.** Money should show **two decimal places**, with a £ sign:

| Language | Code | Shows |
|---|---|---|
| Python | `print(f"Total: £{total:.2f}")` | Total: £7.50 |
| Python | `print("Total: £" + format(total, ".2f"))` | Total: £7.50 |
| C# | `Console.WriteLine("Total: £" + total.ToString("F2"));` | Total: £7.50 |
| VB.NET | `Console.WriteLine("Total: £" & total.ToString("F2"))` | Total: £7.50 |

Without formatting, 7.5 prints as `7.5`, and real-number arithmetic can produce values like `7.499999999`. Formatting is only for **display**. The variable keeps its full value.

**Putting it together: a menu.** Menus combine output (the options), input (the choice), selection and iteration:
1. `REPEAT`
2. `    OUTPUT '1 - Start game'`
3. `    OUTPUT '2 - Show high scores'`
4. `    OUTPUT '3 - Quit'`
5. `    choice ← USERINPUT`
6. `    IF choice = '1' THEN`
7. `        OUTPUT 'Starting…'`
8. `    ELSE IF choice = '2' THEN`
9. `        OUTPUT 'High score: ', highScore`
10. `    ELSE IF choice ≠ '3' THEN`
11. `        OUTPUT 'Please choose 1, 2 or 3'`
12. `    ENDIF`
13. `UNTIL choice = '3'`

The choice is compared with the **string** '1', not the number 1, because it was not converted. Either approach works as long as it is consistent. Comparing as strings means a user typing a letter by mistake does not crash the program.

**Another example: a receipt.** Input feeding later processing, then clear output:
1. `total = 0`
2. `items = int(input("How many items? "))`
3. `for i in range(items):`
4. `    price = float(input("Price of item " + str(i + 1) + ": £"))`
5. `    total = total + price`
6. `print("Items:", items)`
7. `print(f"Total to pay: £{total:.2f}")`

**Inputs can also be checked as they arrive.** A prompt can say what is allowed ("Enter a number from 1 to 10"), and a validation loop can re-prompt until the input is acceptable. That is covered fully in 3.2.11a.

::: terms
- **Input**: data entered into a program, here typed on the keyboard by the user.
- **Output**: data or information sent from a program, here displayed on the screen.
- **USERINPUT**: the AQA pseudo-code keyword for a value typed by the user, always assigned to a variable.
- **OUTPUT**: the AQA pseudo-code keyword that displays one or more values on the screen.
- **Prompt**: a message displayed before an input, telling the user what to enter.
- **Type conversion**: changing input from a string to a number, such as with STRING_TO_INT in pseudo-code or int() in Python.
- **Formatting**: controlling how output looks, such as showing money to two decimal places with a £ sign.
- **Information**: data given context and meaning, such as a value with a label and units.
:::

::: method
1. **"Identify the line where input happens":** look for `USERINPUT` (or `input()`, `Console.ReadLine()`).
2. **Every input you write:** prompt first, store it in a meaningfully named variable, and convert it if it will be used as a number.
3. **Every output you write:** label it so it is information, not a bare number: `'Total: £', total`.
4. **Money:** two decimal places and a £ sign.
5. **Joining text and numbers in Python:** use commas in `print`, or convert numbers with `str()` before using `+`.
6. **Menus:** loop until the quit option is chosen; show the options inside the loop; give a message for an invalid choice.
:::

::: example Fix the joined input
`a = input("First number: ")`, `b = input("Second number: ")`, `print(a + b)`. The user enters 4 and 6, and the program prints 46. Explain why and correct the program. (3)

`input()` returns strings, so a and b are '4' and '6' (1).

`+` between two strings concatenates them, giving '46' (1).

Convert each input: `a = int(input("First number: "))` and the same for b; the program then prints 10 (1).
:::

::: example Format money
`cost = 12.5`. Write a Python statement that outputs `Cost: £12.50`. (2)

`print(f"Cost: £{cost:.2f}")` (accept `"Cost: £" + format(cost, ".2f")`).

The label and £ sign are included (1), and the value is shown to exactly two decimal places (1).
:::

::: watch
- Input is a **string**. Convert it before any arithmetic, or numbers get **joined**: '2' + '3' is '23'.
- Every input you write should have a **prompt**, and every output a **label**.
- In Python, `+` needs **strings on both sides**. Use `str()` or commas.
- Show money with a **£ sign and two decimal places**.
- `USERINPUT` must be **assigned**: `x ← USERINPUT`. A line that just says `USERINPUT` stores nothing.
- Compare a menu choice with the **same type** you stored: '1' if it is a string, 1 if converted.
:::
