## What it is

Every piece of data in a computer is binary (3.3.1), so data is measured by counting binary digits. This topic gives you the units and the prefixes, and asks you to **convert** and **compare** amounts of data, which then feeds the image and sound file-size calculations in 3.3.6 and 3.3.7.

**The bit** is the **fundamental unit of information**: a single binary digit, either **0 or 1**. It is the smallest amount of data a computer can store. Its symbol is a lower-case **b**.

**The byte** is a group of **8 bits**. Its symbol is a capital **B**. One byte can hold 2 × 2 × 2 × 2 × 2 × 2 × 2 × 2 = **256** different patterns, enough for one character of text or a number from 0 to 255. (Half a byte, 4 bits, is called a **nibble**, useful for hex.)

**More bits, more patterns.** Each extra bit doubles the number of different patterns, which is why the number of bits used for something sets how many different values it can have:

| Bits | Different patterns | Example use |
|---|---|---|
| 1 | 2 | yes/no, black/white pixel |
| 2 | 4 | a 4-colour pixel (3.3.6) |
| 4 | 16 | one hex digit |
| 7 | 128 | one 7-bit ASCII character (3.3.5) |
| 8 | 256 | one byte: a number 0–255 |
| 16 | 65,536 | a CD-quality sound sample (3.3.7) |

The capital letter matters: **8 Mb** is eight megabits, but **8 MB** is eight megabytes, which is eight times as much data.

**Prefixes.** Large quantities of bytes are described with **decimal prefixes**, each **1,000 times** the one before:

| Prefix | Symbol | Value | In bytes |
|---|---|---|---|
| kilo | kB | 1,000 bytes | 1,000 |
| mega | MB | 1,000 kB | 1,000,000 |
| giga | GB | 1,000 MB | 1,000,000,000 |
| tera | TB | 1,000 GB | 1,000,000,000,000 |

So moving one step along the table is always a factor of **1,000**, while moving between bits and bytes is a factor of **8**.

A note on 1,024. You will see kilobytes described as 1,024 bytes in older books and in some operating systems, because 1,024 is a power of 2. The international (SI) prefixes kilo, mega, giga and tera mean powers of **10**; the powers-of-2 units have different names (kibibyte, mebibyte and so on). **AQA uses the decimal prefixes**, so in the exam 1 kB = 1,000 bytes. You do not need to know the kibi names.

**Converting.** Think of the chain:

| bits | → ÷ 8 → | bytes | → ÷ 1,000 → | kB | → ÷ 1,000 → | MB | → ÷ 1,000 → | GB | → ÷ 1,000 → | TB |
|---|---|---|---|---|---|---|---|---|---|---|

- Going **to a bigger unit** (to the right), **divide**: there will be fewer of them.
- Going **to a smaller unit** (to the left), **multiply**: there will be more of them.
- **Bits ↔ bytes is always the 8 step**, and it comes first (or last) in the chain. Do it at the right moment and don't use 8 anywhere else.

Worked conversions:
- 24,000 bits to kB: 24,000 ÷ 8 = 3,000 bytes; 3,000 ÷ 1,000 = **3 kB**.
- 4 MB to bits: 4 × 1,000 × 1,000 = 4,000,000 bytes; × 8 = **32,000,000 bits**.
- 2.5 GB to MB: 2.5 × 1,000 = **2,500 MB**.
- 1.2 TB to MB: 1.2 × 1,000 = 1,200 GB; × 1,000 = **1,200,000 MB**.
- 16,000,000 bits to MB: ÷ 8 = 2,000,000 bytes; ÷ 1,000 = 2,000 kB; ÷ 1,000 = **2 MB**.

**Comparing quantities.** To compare amounts given in different units, convert them all to **one common unit** first, usually the smallest one given or bytes. Which is largest: 0.75 MB, 780,000 bytes, 6,400,000 bits, or 0.0009 GB?
- 0.75 MB = 750 kB.
- 780,000 bytes = 780 kB.
- 6,400,000 bits ÷ 8 = 800,000 bytes = 800 kB.
- 0.0009 GB = 0.9 MB = 900 kB.

So in order, smallest first: 0.75 MB, 780,000 bytes, 6,400,000 bits, 0.0009 GB. The largest is **0.0009 GB**, even though the number looks tiny, because gigabytes are such a large unit.

**How many fit?** A common real-world calculation. How many 4 MB photos fit on a 32 GB memory card? Make the units match first: 32 GB = 32,000 MB. Then 32,000 ÷ 4 = **8,000 photos**. (Real devices hold slightly fewer, because some space is used by the file system, but in the exam use the simple calculation.)

**Typical sizes**, to help you judge whether an answer is sensible:
- one character of text: about 1 byte;
- a page of plain text: a few kB;
- a photo from a phone: a few MB;
- a film: a few GB;
- a large hard disk: a few TB.

If your answer says a short text message is 3 GB, something has gone wrong with the multiplying and dividing.

**Where these units appear in the rest of the course.** Image and sound file sizes (3.3.6, 3.3.7) are calculated **in bits** first, then converted to bytes (÷ 8) and on to kB or MB (÷ 1,000 each step). Huffman coding (3.3.8) compares numbers of **bits**. Storage devices (3.4) are sold in GB and TB. So the same conversion chain turns up in many Paper 2 questions; getting it automatic here saves marks elsewhere.

**Showing working.** These questions are often 2–3 marks with "show your working". Write each step with its unit, e.g. "40,000 bits ÷ 8 = 5,000 bytes; 5,000 ÷ 1,000 = 5 kB". A method mark is usually available even if one step has an arithmetic slip.

::: terms
- **Bit**: a single binary digit, 0 or 1; the fundamental unit of information, with symbol b.
- **Byte**: a group of 8 bits, with symbol B.
- **Nibble**: a group of 4 bits, or half a byte.
- **Kilobyte (kB)**: 1,000 bytes.
- **Megabyte (MB)**: 1,000 kilobytes, or 1,000,000 bytes.
- **Gigabyte (GB)**: 1,000 megabytes, or 1,000,000,000 bytes.
- **Terabyte (TB)**: 1,000 gigabytes.
- **Decimal prefix**: a prefix such as kilo or mega that stands for a power of 10, each 1,000 times the previous one.
:::

::: method
1. **Write down the starting quantity and the target unit.** Note whether either is in bits (b) or bytes (B).
2. **Bits to bytes: ÷ 8. Bytes to bits: × 8.** Do this once only.
3. **Each prefix step is × or ÷ 1,000.** To a bigger unit, divide; to a smaller unit, multiply.
4. **Count the steps**: bytes to MB is two steps, so ÷ 1,000,000.
5. **To compare**, convert every quantity to the same unit, then order them.
6. **For "how many fit"**, put both sizes in the same unit, then divide the capacity by the item size.
7. **Write each step with its unit**, and check the answer is a sensible size.
:::

::: example Bits to kilobytes
Convert 40,000 bits into kilobytes. Show your working. (2)

40,000 ÷ 8 = 5,000 bytes (1).

5,000 ÷ 1,000 = 5 kB (1).
:::

::: example Megabytes to bits
Convert 3 MB into bits. Show your working. (2)

3 MB = 3 × 1,000 × 1,000 = 3,000,000 bytes (1).

3,000,000 × 8 = 24,000,000 bits (1).
:::

::: example Ordering
Put these in order of size, smallest first: 2 MB, 1,500 kB, 0.003 GB. (2)

In MB: 1,500 kB = 1.5 MB; 0.003 GB = 3 MB (1).

1,500 kB, 2 MB, 0.003 GB (1).
:::

::: example How many fit
A memory stick has 64 GB of space. How many 250 MB video clips can it store? Show your working. (2)

64 GB = 64,000 MB (1).

64,000 ÷ 250 = 256 clips (1).
:::

::: example Spotting the error
A student calculates that 2 kB is 2,048 bytes. Explain why this is wrong for AQA. (2)

AQA uses the decimal (SI) prefixes, so kilo means 1,000 (1). 2 kB = 2,000 bytes; 1,024 is the powers-of-2 convention, which uses different names such as kibibyte (1).
:::

::: example Bits needed for values
A game stores each player's level as a whole number from 0 to 200. State the smallest number of bits needed and explain why. (2)

8 bits (1): 7 bits give only 128 patterns (0 to 127), which is not enough, while 8 bits give 256 patterns (0 to 255) (1).
:::

::: watch
- **1 kB = 1,000 bytes** in AQA exams. Using 1,024 gives a different answer that will not get the mark.
- Bits ↔ bytes is **8**; every prefix step is **1,000**. Don't mix them.
- **Lower-case b is bits, capital B is bytes.** Read the units in the question carefully.
- Going to a **bigger** unit, **divide**; going to a **smaller** unit, **multiply**.
- To compare or divide sizes, **convert to the same unit first**.
- Show each step with its unit when asked for working.
:::

::: test

---

::: test
Explain why AQA uses 1 kB = 1,000 bytes when some computers report 1 kB as 1,024 bytes. (2)
---
Kilo is an SI / decimal prefix meaning 1,000, a power of 10 (1); the value 1,024 is a power of 2 and strictly should be called a kibibyte (1).

::: test
