## What it is

**Malware** (short for **mal**icious soft**ware**) is an **umbrella term** for any form of **hostile or intrusive software**: programs written to damage a system, steal data, spy on users or give an attacker control, without the owner's consent.

"Umbrella term" matters: malware is the general category, and viruses, trojans and spyware are **types** of malware. The spec requires these three.

### Computer virus

A **computer virus** is malware that **attaches itself to another program or file** (its host). When the host is run or opened, the virus code runs too, and it **replicates**: it **copies itself into other files**, which can then be shared to other computers.

Key features:
- it needs a **host** file or program;
- it needs a **user action** to activate it, such as running the program or opening the file;
- it **spreads by copying itself** to other files, and then travels when those files are shared by email, download, network drive or USB stick;
- it carries a **payload**: the harmful part, which may delete or corrupt files, slow the computer, display messages, or open the way for other malware.

**Example:** a virus is attached to a free game shared on a USB stick. A pupil runs the game at home; the virus copies itself into other programs on the computer, and then into files on the stick, which spread it to the school's computers.

### Trojan

A **trojan** is malware that **pretends to be legitimate, useful software** (a free game, a "video player update", an invoice attachment) so that the user **chooses to install or run it**. Once running, it carries out a **hidden harmful function** as well as, or instead of, what it claimed to do.

Key features:
- it relies on **deception**: the user installs it willingly because they think it is genuine;
- it **does not replicate itself**. It spreads only when people are tricked into downloading or sharing it;
- common payloads: opening a **backdoor** so the attacker can control the computer remotely, installing other malware, stealing data, or locking files.

The name comes from the wooden horse of the Greek legend: something welcomed inside that hides an attacker.

**Example:** a user downloads a free "PDF converter" from an unofficial website. It converts files as promised, but also quietly gives the attacker remote access to the computer.

### Spyware

**Spyware** is malware that **secretly monitors the user's activity** and **sends the information to a third party** without the user's knowledge.

What it might collect:
- **keystrokes** (a **keylogger** records every key pressed, which captures passwords and card numbers);
- websites visited and search history;
- screenshots, files, contacts, location;
- login details entered into forms.

Key features:
- it aims to **stay hidden** and **not disrupt** the computer, so the user does not notice and remove it;
- it usually arrives **bundled with other software** or through a trojan, a malicious download or an attachment;
- the harm is **theft of data and loss of privacy**, leading to fraud, identity theft or account takeover.

### Comparing the three

| | **Virus** | **Trojan** | **Spyware** |
|---|---|---|---|
| **How it gets in** | attached to a file or program that is shared | user is tricked into installing it because it looks useful | bundled with other software, via a trojan or a download |
| **Replicates itself?** | **yes**, copies into other files | **no** | normally no |
| **Disguised?** | hidden inside a host | **disguised as useful software** | hidden; runs in the background |
| **Main harm** | damages/corrupts/deletes files; spreads | hidden payload, e.g. backdoor for remote control | **monitors activity and sends data** to a third party |
| **User notices?** | often, from damage or slowdown | often not | designed **not** to be noticed |

### How to protect against malware

| Protection | How it helps |
|---|---|
| **Anti-malware (antivirus) software** | **scans** files, downloads, email attachments and removable media, comparing them with a database of known malware **signatures** and watching for suspicious behaviour; **quarantines or removes** what it finds. It must be **kept up to date** to recognise new malware. |
| **Automatic software updates** | patches close the vulnerabilities that malware uses to install itself without the user's help (3.6.3) |
| **Only install software from trusted sources** | official app stores and developer sites; avoids trojans hidden in "free" or cracked software |
| **Care with email attachments and links** | don't open unexpected attachments; phishing emails often deliver malware (3.6.2.1) |
| **Firewall** | can block a trojan's backdoor connection or spyware sending data out, by blocking unauthorised network traffic |
| **Limited user access rights** | ordinary accounts without administrator rights cannot install software, limiting what malware can do |
| **Scanning or blocking removable media** | stops viruses arriving on USB sticks (3.6.2) |
| **Regular backups** stored separately | if malware destroys or locks files, they can be restored |
| **Staff and user training** | people are the route in for trojans and infected attachments |

**Protection is layered.** Anti-malware cannot detect every new piece of malware, so other measures (updates, careful downloading, access rights, backups) are needed too. Backups do not **prevent** infection; they reduce the **damage**.

### Why malware matters to organisations

Malware can steal personal or financial data (breaking the organisation's duty to protect it), destroy records, stop systems working and spread across a network to every connected computer. Recovery is expensive, and customers lose trust. For individuals, spyware in particular leads to stolen banking details and identity theft.

::: terms
- **Malware**: an umbrella term for hostile or intrusive software designed to harm, steal from or spy on a system without consent.
- **Computer virus**: malware that attaches itself to a host file or program and replicates by copying itself into other files when run.
- **Trojan**: malware disguised as legitimate, useful software so that the user installs it, which then carries out a hidden harmful function.
- **Spyware**: malware that secretly monitors a user's activity and sends the information to a third party.
- **Keylogger**: a type of spyware that records every key pressed, capturing passwords and card numbers.
- **Payload**: the harmful action carried out by malware, such as deleting files or opening a backdoor.
- **Backdoor**: a hidden way into a computer that lets an attacker control it remotely, bypassing normal security.
- **Anti-malware software**: software that scans for, quarantines and removes malware, using signatures and suspicious behaviour.
- **Malware signature**: a pattern of code that identifies a known piece of malware, used by anti-malware software to detect it.
- **Quarantine**: isolating a suspicious file so that it cannot run or spread until it is checked or deleted.
:::

::: method
1. **Define malware** as hostile or intrusive software (an umbrella term). Don't define it as "a virus".
2. **Describe each type by its distinguishing feature**: virus = **attaches to a file and replicates**; trojan = **disguised as useful software**, user installs it, **does not replicate**; spyware = **secretly monitors and sends data** to a third party.
3. **Give the harm** each one does, applied to the scenario.
4. **Protection**: name the measure and explain **how** it stops or limits that type (scan, update, trusted sources, firewall, access rights, backups, training).
5. **Compare** questions: write "whereas" sentences on the same feature for each type.
6. **9-mark Discuss**: cover each bullet, match protections to the type of malware, recognise that no single measure is enough.
:::

::: watch
- **Malware** is the umbrella term. A virus is one type of malware, not the other way round.
- **Virus**: attaches to a host and **replicates**. **Trojan**: **disguised** as useful, **does not replicate**. Swapping these is the most common lost mark.
- **Spyware**: you must say it **sends** the data to someone else, not just that it "watches".
- "Antivirus" alone is a thin answer. Explain **how** it works (scanning, signatures, quarantine) and that it needs **updating**.
- Backups **reduce the damage**; they do not **prevent** infection.
- A firewall does not scan files for viruses. Credit it only for blocking unauthorised **network traffic**, e.g. spyware sending data out.
:::
