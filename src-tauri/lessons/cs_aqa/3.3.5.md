## What it is

A computer can only store binary (3.3.1), so every letter, digit, space and symbol you type must be turned into a number, and that number stored in binary. **Character encoding** is the agreed system that matches each character to a number, its **character code**. For text to be read correctly, the computer that saves it and the computer that opens it must use the **same** encoding.

**A character set** is the complete list of characters a computer can represent, together with the code for each one. Two are named in the spec: **7-bit ASCII** and **Unicode**.

**7-bit ASCII** (American Standard Code for Information Interchange) uses **7 bits** per character, which gives 2 to the power 7 = **128** different codes, numbered **0 to 127**. That is enough for:
- the upper-case and lower-case English letters;
- the digits 0 to 9;
- punctuation and common symbols, and the space;
- a set of **control codes** (such as new line and tab) that are not printed but control how text is displayed.

In practice each ASCII character is usually stored in a byte, with the extra bit set to 0, but the code itself is 7 bits.

**Codes are grouped and run in sequence.** This is the key exam skill. Related characters sit together, in order:

| Group | First | Code | Last | Code |
|---|---|---|---|---|
| Digits | '0' | 48 | '9' | 57 |
| Upper-case letters | 'A' | 65 | 'Z' | 90 |
| Lower-case letters | 'a' | 97 | 'z' | 122 |

(The space is 32.) Because each group runs in order, once you know **one** code you can work out the rest of that group by counting:
- 'A' is 65, so 'E' (4 letters later) is 69 and 'Z' (25 letters later) is 90.
- 'a' is 97, so 'm' (the 13th letter, 12 after 'a') is 109.
- '0' is 48, so '7' is 55.
- Each lower-case letter is exactly **32 more** than its upper-case partner: 'G' is 71 and 'g' is 103.

Questions usually give you a small extract of the table and ask you to use it, for example: "the code for 'P' is 80; what is the code for 'S'?" (83) or "which character has the code 100?" ('d', if you are told 'a' is 97).

**Converting with a table.** To encode, look up each character and write its code; to decode, look up each code. 'Cab' encodes as 67, 97, 98. In 7-bit binary, 'C' = 67 = 64 + 2 + 1 = **100 0011**. Decoding 72, 105 gives 'H', 'i'.

**Digits as characters are not numbers.** The character '7' has the code 55, not 7. A program that reads '7' from the keyboard holds the code 55 until it converts the character to a number (3.2.8). This is also why '10' sorts before '9' when strings are compared: the codes are compared character by character, and '1' (49) is less than '9' (57).

**The problem with ASCII.** 128 codes cover English, but not:
- accented letters used in other European languages (é, ñ, ü, …);
- other alphabets and writing systems: Greek, Cyrillic, Arabic, Hebrew, Hindi, Chinese, Japanese, and many more;
- mathematical and technical symbols, currency signs such as £ and €, and emoji.

Different countries invented their own extended codes to fill the gap, which meant the same code could show a different character on a different computer, and text was garbled when shared.

**Unicode** was created to solve this. Its **purpose** is to give a **unique code to every character in every writing system**, plus a large range of symbols and emoji, in one single, worldwide standard. Its advantages over ASCII:
- It can represent **far more characters**, so text in almost any language, mixed languages in one document, and special symbols can all be stored.
- Because it is **one international standard**, text created on one device displays correctly on any other device that supports Unicode, whatever its country or language.
- It is **compatible with ASCII**: the first 128 Unicode codes are **the same as ASCII** (0 to 127). So 'A' is 65 in both, and plain English ASCII text is also valid Unicode.

The cost is that Unicode needs **more bits** per character than 7-bit ASCII for most characters, so the same text can take up more storage. (Unicode has several ways of storing its codes, but you do not need to know about them.)

**Why this matters.** Text messages, web pages and documents are shared internationally all the time. Without a common encoding, names with accents, non-English messages and emoji would appear as the wrong characters or as boxes.

::: terms
- **Character**: a single letter, digit, space, punctuation mark or symbol.
- **Character code**: the number that represents a character in a character set, e.g. 65 for 'A'.
- **Character set**: a defined list of characters a computer can represent, with the code for each one.
- **ASCII**: a 7-bit character set with 128 codes (0 to 127) covering English letters, digits, punctuation and control codes.
- **Unicode**: a character set that gives a unique code to characters from almost all writing systems and many symbols, and matches ASCII for codes 0 to 127.
- **Control code**: a non-printing character code, such as new line, used to control how text is handled.
- **Encoding**: converting characters into their character codes so they can be stored as binary.
:::

::: method
1. **Find the anchor**: the code you are given (e.g. 'A' = 65), or use 'A' 65, 'a' 97, '0' 48.
2. **Count along the group**: add the number of places between the two characters. Stay inside the same group.
3. **Switch case** by adding 32 (upper to lower) or subtracting 32 (lower to upper).
4. **To give binary**, convert the decimal code using 64 32 16 8 4 2 1 for 7 bits.
5. **For "purpose of Unicode"**: to represent characters from all the world's languages and many symbols in one standard.
6. **For "advantage over ASCII"**: far more characters (other alphabets, symbols, emoji), so name an example; plus same codes as ASCII up to 127.
7. Never just say "Unicode is better" or "newer": say **what** it can represent that ASCII cannot.
:::

::: example Sequence reasoning
In ASCII, the character code for 'K' is 75. State the code for (a) 'N'; (b) 'k'. (2)

(a) 78: 'N' is three letters after 'K' (1).

(b) 107: lower case is 32 more than upper case (1).
:::

::: example Decode a message
The ASCII code for 'a' is 97. Decode the message 98, 101, 100. (2)

98 = 'b', 101 = 'e', 100 = 'd' (1 for two correct).

'bed' (1).
:::

::: example Character to binary
The ASCII code for 'S' is 83. Give the 7-bit binary code for 'S'. (1)

83 = 64 + 16 + 2 + 1, so 101 0011 (1).
:::

::: example Purpose of Unicode
Explain the purpose of Unicode and one advantage it has over ASCII. (3)

Unicode's purpose is to provide a single standard that gives every character from the world's writing systems, and many symbols, its own unique code (1).

Advantage: it can represent far more characters than ASCII's 128 (1), so text in other alphabets such as Arabic or Chinese, and symbols such as emoji, can be stored and shared correctly (1).
:::

::: example Compatibility
Explain why a program that only understands ASCII can still read a Unicode file containing only English letters and digits. (2)

Unicode uses the same codes as ASCII for codes 0 to 127 (1); English letters and digits all fall in this range, so their codes are identical in both character sets (1).
:::

::: watch
- Unicode's advantage is **more characters** (other alphabets, symbols, emoji). "It is newer" or "it is better" scores nothing.
- 7-bit ASCII has **128** codes, from **0 to 127**, not 0 to 128 or 256.
- Unicode **matches ASCII up to 127**: state it when asked about compatibility.
- Codes run **in sequence within a group**: count carefully, and remember 'A' is the 1st letter, so 'E' is 65 + 4.
- Lower case is **32 more** than upper case; lower-case codes are the **larger** ones.
- The character '5' is code 53, not the number 5.
:::

::: test
In a character set, 'P' has the code 80 and 'p' has the code 112.
(a) State the code for 'T'.
(b) State the code for 't'.

(d) Explain why this character set could be Unicode as well as ASCII. (4)
---
(a) 84 (1). (b) 116 (1). (c) Letters are in alphabetical order in consecutive codes, so 'T' is four codes after 'P' and 't' four codes after 'p' (1). (d) Unicode uses the same codes as ASCII for the first 128 characters, and all these codes are below 128 (1).
:::

::: test
A program sorts the strings 'Zebra' and 'apple' by comparing character codes. Explain why 'Zebra' is placed first. (2)
---
'Z' has the code 90 and 'a' has the code 97 (1); upper-case codes are lower than lower-case codes, so 'Z' is less than 'a' (1).
:::

::: test
Explain one advantage and one disadvantage of storing a text document in Unicode rather than 7-bit ASCII. (4)
---
Advantage: it can represent many more characters (1), e.g. other alphabets, accented letters, symbols or emoji, so any language can be stored (1).
Disadvantage: characters often need more bits (1), so the document takes up more storage space / takes longer to transmit (1).
:::

::: test
Explain why using a character set is necessary for a computer to store text. (2)

Computers can only store binary / numbers (1); a character set assigns each character a unique number so it can be stored and then converted back to the correct character (1).
