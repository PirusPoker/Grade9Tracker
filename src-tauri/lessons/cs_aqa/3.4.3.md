## What it is

All software (3.4.1) falls into one of two classes, depending on **who it works for**: the **computer** or the **user**.

| | System software | Application software |
|---|---|---|
| **What it does** | **manages the computer system's resources** (processor, memory, devices, files) and acts as a **platform** that application software runs on | performs **end-user tasks**: the jobs people actually want to do |
| **Who it serves** | the computer system itself | the user |
| **Examples** | operating systems (Windows, macOS, Linux, Android, iOS); utility programs (antivirus, backup, disk defragmenter, file compression); device drivers | word processor, spreadsheet, web browser, email client, games, photo editor, music player, a school's timetable app |
| **Could the computer run without it?** | not usefully: without an OS, applications cannot be loaded or use the hardware | yes, but it would not do anything the user needs |

A quick test: **does it do something the user set out to do (write, browse, play, calculate)?** Then it is application software. **Does it look after the computer, so that other programs can run safely and efficiently?** Then it is system software.

### The operating system (OS)

The **operating system** is the most important piece of system software. It is loaded when the computer starts and runs the whole time.

**Why an OS is needed.** Without one, every application would have to contain its own code to control the processor, share memory, talk to every possible printer and keyboard, store files on the disk and keep other users out. That would be enormously repetitive, and programs running at the same time would clash. The OS does these jobs **once, for everyone**: it **hides the complexity of the hardware** and **shares the hardware fairly and safely** between programs and users.

The spec lists five things the OS manages:

| The OS manages… | How it does it |
|---|---|
| **Processor(s)** | Decides **which program or process gets the processor, and for how long** (scheduling). By switching between tasks very quickly it lets many programs appear to run **at the same time** (multitasking). On a multi-core processor it allocates work to the different **cores**. It also handles **interrupts**, for example pausing a task when a key is pressed. |
| **Memory** | **Allocates RAM** to each program when it is loaded, keeping programs **separate** so that one cannot overwrite another's data. **Frees** memory when a program closes so that it can be reused. Moves data between RAM and storage as needed, for example when RAM is nearly full. |
| **Input/output (I/O) devices** | Communicates with hardware such as keyboards, screens and printers through **device drivers**, small programs that translate between the OS and a particular device. It sends data to and from devices, and **queues** jobs, for example several documents waiting for one printer. |
| **Applications** | **Loads** programs from storage into memory and **runs** them; **installs**, updates and removes them; provides a **platform** of common services (opening files, drawing windows) that applications use; and closes programs that stop responding. |
| **Security** | Controls **who** can use the computer with **user accounts and passwords** (authentication); controls **what** each user can do with **access rights / permissions** to files and settings; installs **security updates**; can include a firewall and encryption. |

Most operating systems also provide a **user interface** (a graphical interface with windows, icons and menus, or a command line) and **file management** (creating, naming, moving, deleting and organising files and folders). These are useful extras to mention, but the five above are the ones the spec lists.

### Utility programs

**Utility programs** are **system software** that help to **maintain, configure, optimise or secure** the computer. They do not perform end-user tasks. Some come with the OS; others are installed separately.

| Utility | What it does | Why it is needed |
|---|---|---|
| **Antivirus / anti-malware** | scans files and memory for known malware signatures and suspicious behaviour; quarantines or removes it | protects data and the system from malicious code (3.6) |
| **Backup** | copies files to another device or to cloud storage, often automatically on a schedule; full or incremental | lets data be restored after deletion, hardware failure or ransomware |
| **Disk defragmenter** | rearranges the parts of files on a **magnetic** hard disk so that each file is stored in one continuous area | the read head moves less, so files load faster. Not used on SSDs, which do not need it |
| **File compression** | reduces the size of files (3.3.8) | saves storage space and makes files quicker to send |
| **Disk clean-up** | finds and deletes temporary and unneeded files | frees storage space |
| **Encryption utility** | scrambles files or whole drives so that they cannot be read without the key | protects data if a device is lost or stolen |
| **Firewall** | monitors network traffic and blocks traffic that breaks its rules (3.5a) | stops unauthorised access over a network |

**Device drivers** are often counted as system software too: each one lets the OS control one type of hardware device.

::: terms
- **System software**: software that manages the computer system's resources and provides a platform for application software to run on.
- **Application software**: software that performs end-user tasks, such as a word processor, web browser or game.
- **Operating system (OS)**: system software that manages the processor, memory, I/O devices, applications and security, and lets the user and programs use the hardware.
- **Utility program**: system software that maintains, optimises or secures the computer, such as antivirus, backup or defragmentation software.
- **Device driver**: a program that lets the operating system communicate with and control a particular hardware device.
- **Multitasking**: the OS switching the processor between programs so quickly that they appear to run at the same time.
- **Memory management**: the OS allocating RAM to programs, keeping them separate and freeing memory when they close.
- **Access rights**: permissions set by the OS that control which files and settings each user can read, change or delete.
- **Defragmentation**: rearranging the scattered parts of files on a magnetic disk so each file is stored together and loads faster.
:::

::: method
1. **Classify**: system software looks after the **computer**; application software does the **user's task**. Utilities and drivers are **system** software.
2. **Define with both halves**: system software manages resources **and** provides a platform for applications.
3. **OS functions**: name the resource (processor, memory, I/O, applications, security) **and** say how the OS manages it.
4. **For 6 marks**: give three developed points, each **what the OS does + why or how**, using the scenario (e.g. a school network, a smartphone).
5. **Utilities**: name the utility, say what it does, then say **why** that helps the user or the computer.
6. Don't confuse antivirus (a utility) with a firewall: one scans files for malware; the other filters network traffic.
:::

::: example Classify software
State whether each is system software or application software: antivirus; spreadsheet; operating system; web browser. (2)

Antivirus: system. Spreadsheet: application. Operating system: system. Web browser: application (2).

All four correct for 2 marks; two or three for 1 mark.
:::

::: example Define system software
Explain what is meant by system software. (2)

Software that manages the resources of the computer system, such as memory and devices (1), and acts as a platform for application software to run on (1).
:::

::: example Memory management
Explain how an operating system manages memory when a user has several programs open. (3)

The OS allocates a section of RAM to each program when it is loaded (1). It keeps each program's memory separate so that one program cannot overwrite another's data (1). When a program is closed, the OS frees its memory so that it can be reused by other programs (1).
:::

::: example A utility
Explain how a backup utility helps a small business. (2)

It makes copies of the business's files on another device or in cloud storage, automatically at set times (1), so if the original files are deleted, corrupted or encrypted by ransomware they can be restored (1).
:::

::: example Why an OS is needed
Explain two reasons why a computer needs an operating system. (4)

It hides the complexity of the hardware (1), so application programmers do not have to write code to control every device; they use the services the OS provides (1).

It shares resources between programs (1), for example scheduling processor time and allocating memory, so that several programs can run at once without clashing (1).
:::

---
System software manages the computer's resources/runs the computer and provides a platform for other software (1); application software performs tasks for the user (1).

---

::: q
Explain why a disk defragmenter speeds up a computer with a magnetic hard disk. (2)
---
It moves the parts of each file so they are stored together/contiguously (1), so the read/write head moves less and files are read more quickly (1).
:::

::: q
Explain how the operating system helps to keep a shared school computer secure. (3)
---
Each user must log in with a username and password, so only authorised users get access (1). It sets access rights so students cannot open or change other users' files or system settings (1). It installs security updates to fix weaknesses / runs a firewall or antivirus (1).
:::

::: watch
- **Utilities are system software**, not applications, even though some (like antivirus) have a window you open.
- A definition of system software needs **both**: manages resources **and** is a platform for applications.
- For OS functions, say **how**, not just what: "manages memory" alone is 1 mark at most; "allocates RAM to each program and frees it on close" earns more.
- The five spec functions are **processor, memory, I/O devices, applications, security**. Learn them as a list.
- **Defragmentation** is for **magnetic** disks only.
- Don't call a firewall an antivirus, or say antivirus "blocks hackers".
:::

::: test
A user has a web browser, a music player and a word processor open at the same time. Explain how the operating system manages the processor and memory so that all three programs can run. (6)
---
Award up to 6 for developed points, 3 on each resource.
Processor:
- The OS schedules processor time, giving each program a short time slice in turn (1).
- It switches between them so quickly that they appear to run at the same time / multitasking (1).
- It can allocate programs to different cores, and handles interrupts, e.g. pausing to process a key press, then resuming (1).
Memory:
- When each program is opened, the OS allocates it a section of RAM (1).
- It keeps the programs' memory separate so one cannot overwrite another's data (1).
- When a program is closed, its memory is freed for reuse; if RAM is nearly full the OS can move data to secondary storage (1).
Max 4 if only one resource is covered.
:::

::: test
A school has 200 students who share computers on a network. Explain how the operating system manages security and input/output devices on these computers. (6)
---
Award up to 6 for developed points applied to the school, 3 on each area.
Security:
- Each student logs in with their own username and password, so only authorised users can use the computers (1).
- The OS sets access rights so students can only open their own files and cannot change system settings (1).
- It installs security updates/patches and can run a firewall, so known weaknesses cannot be exploited (1).
I/O devices:
- The OS uses device drivers to communicate with keyboards, mice, screens and printers (1).
- It manages data being sent to and from devices, e.g. passing key presses to the program in use (1).
- It queues print jobs from many students so that the shared printer prints them one at a time (1).
Max 4 if only one area is covered.
:::
