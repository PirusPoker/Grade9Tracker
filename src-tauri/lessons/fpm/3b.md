## What it is

An inequality is solved the same way as an equation — with one rule that equations do not have: **multiplying or dividing both sides by a negative number flips the sign.** Everything hard about inequalities comes from forgetting that, or from the fact that a quadratic inequality has an answer that is a *region*, not a point.

Linear inequalities give one interval: $x > 3$, or $-1 \le x < 4$. Quadratic inequalities give either the part **between** the roots or the two parts **outside** them — and the only reliable way to tell which is to sketch the parabola.

The answer to an inequality is a set of $x$ values. You must write it as an inequality (or two), not as "$x = \dots$".

::: method
1. **Linear:** collect $x$ terms on one side, numbers on the other, exactly as for an equation. If you divide by a negative, flip the sign. (Or avoid it: move the $x$ terms to whichever side keeps the coefficient positive.)
2. **Quadratic:** get everything on one side with $0$ on the other, so it reads $ax^2 + bx + c > 0$ (or $<$, $\ge$, $\le$). If $a$ is negative, multiply through by $-1$ and flip the sign, so the parabola is the right way up.
3. **Find the roots** by factorising or the formula. These are the **critical values**.
4. **Sketch** the U-shaped parabola through the two roots. Above the axis is where the expression is positive; below is negative. Read off the region the inequality asks for:
   - $> 0$: outside the roots — $x < \text{smaller}$ **or** $x > \text{larger}$ (two separate pieces)
   - $< 0$: between the roots — $\text{smaller} < x < \text{larger}$ (one piece)
   - $\ge$ or $\le$: the same regions, with the roots included.
5. **Two inequalities at once** (e.g. a linear and a quadratic): solve each separately, draw both on a number line, and give the overlap.
6. **Quadratic on both sides**, like $px^2 + qx + r < sx^2 + tx + u$: bring everything to one side first; it becomes a single quadratic (or occasionally linear) inequality.
:::

::: example Linear, with a negative coefficient
Solve $5 - 3x \ge 2x - 10$.

Move the $x$ terms to the right to keep them positive: $5 + 10 \ge 2x + 3x$, so $15 \ge 5x$, so $x \le 3$.

(Doing it the other way: $-5x \ge -15$, then dividing by $-5$ **flips** the sign: $x \le 3$. Same answer.)
:::

::: example Quadratic, "less than"
Solve $x^2 - 5x + 6 < 0$.

Roots: $(x - 2)(x - 3) = 0$, so $x = 2$ and $x = 3$.

The parabola is U-shaped; it is below the axis **between** the roots.

$2 < x < 3$.
:::

::: example Quadratic, "greater than or equal"
Solve $2x^2 + 5x \ge 12$.

Rearrange: $2x^2 + 5x - 12 \ge 0$. Factorise: $(2x - 3)(x + 4) \ge 0$, roots $x = \dfrac32$ and $x = -4$.

U-shaped, at or above the axis **outside** the roots:

$x \le -4$ or $x \ge \dfrac{3}{2}$.
:::

::: example When the $x^2$ coefficient is negative
Solve $3 + 2x - x^2 > 0$.

Multiply by $-1$ and flip: $x^2 - 2x - 3 < 0$, so $(x - 3)(x + 1) < 0$, roots $-1$ and $3$.

Between the roots: $-1 < x < 3$.
:::

::: example Two conditions together
Find the set of values of $x$ for which both $3x - 7 > 2$ and $x^2 - 6x + 5 \le 0$.

First: $3x > 9$, so $x > 3$.

Second: $(x - 1)(x - 5) \le 0$, so $1 \le x \le 5$.

Both: $3 < x \le 5$.
:::

::: example Quadratic on both sides
Solve $2x^2 - 3x + 1 < x^2 + x - 2$.

Bring everything to the left: $x^2 - 4x + 3 < 0$, so $(x - 1)(x - 3) < 0$.

$1 < x < 3$.
:::

::: q
Solve $4x - 9 > 7 - 2x$.
---
$6x > 16$, so $x > \dfrac{8}{3}$.
:::

::: q
Solve $2(1 - 3x) \le 5x + 13$.
---
$2 - 6x \le 5x + 13$, so $-11 \le 11x$, so $x \ge -1$.
:::

::: q
Solve $x^2 - 3x - 10 > 0$.
---
$(x - 5)(x + 2) > 0$: outside the roots, $x < -2$ or $x > 5$.
:::

::: q
Solve $x^2 + 2x \le 15$.
---
$x^2 + 2x - 15 \le 0$, $(x + 5)(x - 3) \le 0$: $-5 \le x \le 3$.
:::

::: q
Solve $3x^2 - 7x + 2 < 0$.
---
$(3x - 1)(x - 2) < 0$: $\dfrac13 < x < 2$.
:::

::: q
Solve $6 - x - x^2 \ge 0$.
---
Multiply by $-1$, flip: $x^2 + x - 6 \le 0$, $(x + 3)(x - 2) \le 0$: $-3 \le x \le 2$.
:::

::: q
Solve $x(x - 4) > 2x - 9$.
---
$x^2 - 4x - 2x + 9 > 0$, so $x^2 - 6x + 9 > 0$, so $(x - 3)^2 > 0$.

A square is positive for every $x$ except where it is zero: all $x$ except $x = 3$, i.e. $x \ne 3$.
:::

::: q
Find the values of $x$ satisfying both $x^2 - 4x - 12 < 0$ and $2x + 1 \ge 3$.
---
$(x - 6)(x + 2) < 0$ gives $-2 < x < 6$. $2x \ge 2$ gives $x \ge 1$.

Both: $1 \le x < 6$.
:::

::: q
Solve $3x^2 + 2x - 8 \ge 2x^2 + 4x + 7$.
---
$x^2 - 2x - 15 \ge 0$, $(x - 5)(x + 3) \ge 0$: $x \le -3$ or $x \ge 5$.
:::

::: q
Find the range of values of $k$ for which $x^2 + kx + 2k - 3 = 0$ has no real roots.
---
Discriminant $< 0$: $k^2 - 4(2k - 3) < 0$, so $k^2 - 8k + 12 < 0$, so $(k - 2)(k - 6) < 0$.

$2 < k < 6$.
:::

::: q
Solve $\dfrac{x^2 - 9}{4} > 4$.
---
$x^2 - 9 > 16$, so $x^2 > 25$, so $x < -5$ or $x > 5$.
:::

::: watch
- **$x^2 > 25$ is not $x > 5$.** It is $x < -5$ or $x > 5$. A quadratic inequality almost always has two critical values; find both.
- The "or" answer must be written as **two separate inequalities**. $-2 > x > 5$ is meaningless and scores nothing.
- Dividing by a negative flips the sign. Multiplying an inequality by $-1$ to make $x^2$ positive flips the sign too.
- When you rearrange, get **zero on one side** before you factorise. Factorising $x^2 + 2x = 15$ as $x(x + 2) = 15$ leads nowhere.
- Draw the sketch. Two roots and a U — three seconds — and you will never pick the wrong region.
- A combined condition ("both … and …") is the **overlap**. Draw a number line if in doubt.
:::
