## What it is

Integration reverses differentiation. If $\dfrac{dy}{dx} = 2x$, then $y = x^2 + c$ — the $+c$ because any constant would have vanished on differentiating. The results to know, each the reverse of one from the differentiation table:

| $f(x)$ | $\displaystyle\int f(x)\,dx$ |
|---|---|
| $x^n$ ($n \ne -1$) | $\dfrac{x^{n+1}}{n + 1} + c$ |
| $\sin ax$ | $-\dfrac{1}{a}\cos ax + c$ |
| $\cos ax$ | $\dfrac{1}{a}\sin ax + c$ |
| $e^{ax}$ | $\dfrac{1}{a}e^{ax} + c$ |

($\dfrac{1}{x}$ is excluded on this course — you will not be asked to integrate it.)

A **definite integral** $\displaystyle\int_a^b f(x)\,dx$ has limits: integrate, then evaluate at the top limit minus the bottom limit. No $+c$ needed. Its meaning is the **area** between the curve and the $x$-axis from $x = a$ to $x = b$ — counted negative where the curve is below the axis.

**Volume of revolution:** spin the region under $y = f(x)$ round the $x$-axis and the solid has volume

$$V = \pi\int_a^b y^2\,dx$$

Rotating round the $y$-axis instead: $V = \pi\displaystyle\int x^2\,dy$ with $y$-limits and $x$ written in terms of $y$.

::: method
1. **Rewrite as powers** first, exactly as for differentiating: $\sqrt x = x^{1/2}$, $\dfrac{1}{x^3} = x^{-3}$. Expand brackets; split fractions with a single term on the bottom.
2. **Power rule:** add one to the power, divide by the new power. Check by differentiating your answer in your head.
3. **Trig and exponential:** divide by the coefficient of $x$ — and $\sin$ integrates to **minus** $\cos$.
4. **Indefinite → always $+c$.** If you are told a point the curve passes through, substitute it to find $c$.
5. **Definite:** write the integrated expression in square brackets with the limits, then $[\ ]_{\text{top}} - [\ ]_{\text{bottom}}$. Show the substitution line.
6. **Area:** sketch. If the curve dips below the axis within the limits, split the integral at the crossing and take the modulus of the negative part. Area **between two curves**: $\int (\text{top} - \text{bottom})\,dx$ between the $x$-values where they meet.
7. **Volume:** square $y$ first (expand it properly), then integrate, then multiply by $\pi$. Leave $\pi$ in the answer unless told otherwise.
:::

::: example Indefinite integrals
Find $\displaystyle\int \left(6x^2 - \dfrac{4}{x^3} + \sqrt x\right)dx$.

$= \displaystyle\int \left(6x^2 - 4x^{-3} + x^{1/2}\right)dx = 2x^3 + 2x^{-2} + \dfrac23 x^{3/2} + c = 2x^3 + \dfrac{2}{x^2} + \dfrac23 x\sqrt x + c$.
:::

::: example Trig and exponentials
Find $\displaystyle\int (3\cos 2x - \sin 4x + e^{-3x})\,dx$.

$= \dfrac32\sin 2x + \dfrac14\cos 4x - \dfrac13 e^{-3x} + c$.
:::

::: example Finding the constant
A curve has $\dfrac{dy}{dx} = 3x^2 - 4x$ and passes through $(2, 5)$. Find its equation.

$y = x^3 - 2x^2 + c$. At $(2, 5)$: $5 = 8 - 8 + c \Rightarrow c = 5$.

$y = x^3 - 2x^2 + 5$.
:::

::: example A definite integral
Evaluate $\displaystyle\int_1^4 \left(2x + \dfrac{1}{\sqrt x}\right)dx$.

$= \left[x^2 + 2x^{1/2}\right]_1^4 = (16 + 4) - (1 + 2) = 17$.
:::

::: example Area partly below the axis
Find the total area enclosed between $y = x^2 - 4x$, the $x$-axis, and the lines $x = 0$ and $x = 5$.

The curve crosses the axis at $x = 0$ and $x = 4$; it is below the axis between them and above from $4$ to $5$.

$\displaystyle\int_0^4 (x^2 - 4x)\,dx = \left[\dfrac{x^3}{3} - 2x^2\right]_0^4 = \dfrac{64}{3} - 32 = -\dfrac{32}{3}$ — area $\dfrac{32}{3}$.

$\displaystyle\int_4^5 (x^2 - 4x)\,dx = \left(\dfrac{125}{3} - 50\right) - \left(\dfrac{64}{3} - 32\right) = \dfrac{61}{3} - 18 = \dfrac{7}{3}$.

Total area $= \dfrac{32}{3} + \dfrac73 = 13$.
:::

::: example Area between a curve and a line
Find the area enclosed between $y = x^2$ and $y = x + 2$.

They meet where $x^2 = x + 2$, $(x - 2)(x + 1) = 0$: $x = -1$ and $x = 2$. The line is on top in between.

Area $= \displaystyle\int_{-1}^{2} (x + 2 - x^2)\,dx = \left[\dfrac{x^2}{2} + 2x - \dfrac{x^3}{3}\right]_{-1}^{2} = \left(2 + 4 - \dfrac83\right) - \left(\dfrac12 - 2 + \dfrac13\right) = \dfrac{10}{3} + \dfrac{7}{6} = \dfrac{9}{2}$.
:::

::: example Volume of revolution
The region under $y = x^2 + 1$ from $x = 0$ to $x = 2$ is rotated through $360°$ about the $x$-axis. Find the volume of the solid formed.

$y^2 = (x^2 + 1)^2 = x^4 + 2x^2 + 1$.

$V = \pi\displaystyle\int_0^2 (x^4 + 2x^2 + 1)\,dx = \pi\left[\dfrac{x^5}{5} + \dfrac{2x^3}{3} + x\right]_0^2 = \pi\left(\dfrac{32}{5} + \dfrac{16}{3} + 2\right) = \dfrac{206\pi}{15}$.
:::

---
$x^4 - 3x^2 + 5x + c$.

::: q
Find $\displaystyle\int \left(\dfrac{3}{x^2} + 2\sqrt x\right)dx$.
---
$\displaystyle\int (3x^{-2} + 2x^{1/2})\,dx = -3x^{-1} + \dfrac43 x^{3/2} + c = -\dfrac3x + \dfrac43 x\sqrt x + c$.
:::

Find $\displaystyle\int \dfrac{x^4 + 2x^2}{x^2}\,dx$.
---
$\displaystyle\int (x^2 + 2)\,dx = \dfrac{x^3}{3} + 2x + c$.
:::

Find $\displaystyle\int (2\sin 3x + \cos\tfrac{x}{2})\,dx$.
---
$-\dfrac23\cos 3x + 2\sin\dfrac x2 + c$.
:::

Find $\displaystyle\int (e^{4x} - 3e^{-x})\,dx$.
---
$\dfrac14 e^{4x} + 3e^{-x} + c$.

::: q
A curve has gradient $\dfrac{dy}{dx} = 6x - 5$ and passes through $(1, -2)$. Find its equation.
---
$y = 3x^2 - 5x + c$; $-2 = 3 - 5 + c \Rightarrow c = 0$. $y = 3x^2 - 5x$.
:::

::: q
Evaluate $\displaystyle\int_0^3 (x^2 - 2x + 4)\,dx$.
---
$\left[\dfrac{x^3}{3} - x^2 + 4x\right]_0^3 = 9 - 9 + 12 = 12$.
:::

::: q
Evaluate $\displaystyle\int_0^{\pi/6} \cos 3x\,dx$.
---
$\left[\dfrac13\sin 3x\right]_0^{\pi/6} = \dfrac13\sin\dfrac\pi2 - 0 = \dfrac13$.
:::

::: q
Find the area between $y = 6x - x^2$ and the $x$-axis.
---
Roots $x = 0, 6$. $\displaystyle\int_0^6 (6x - x^2)\,dx = \left[3x^2 - \dfrac{x^3}{3}\right]_0^6 = 108 - 72 = 36$.
:::

::: q
Find the area enclosed between the curve $y = x^2 - 2x$ and the line $y = 3x - 4$.
---
They meet where $x^2 - 2x = 3x - 4$, i.e. $x^2 - 5x + 4 = 0$, $(x - 1)(x - 4) = 0$: at $x = 1$ and $x = 4$, with the line on top between.

$\displaystyle\int_1^4 (3x - 4 - x^2 + 2x)\,dx = \displaystyle\int_1^4 (5x - 4 - x^2)\,dx = \left[\dfrac{5x^2}{2} - 4x - \dfrac{x^3}{3}\right]_1^4 = \left(40 - 16 - \dfrac{64}{3}\right) - \left(\dfrac52 - 4 - \dfrac13\right) = \dfrac83 + \dfrac{11}{6} = \dfrac92$.
:::

::: q
The region between $y = \sqrt{x}$, the $x$-axis and the line $x = 4$ is rotated fully about the $x$-axis. Find the volume.
---
$y^2 = x$: $V = \pi\displaystyle\int_0^4 x\,dx = \pi\left[\dfrac{x^2}{2}\right]_0^4 = 8\pi$.
:::

::: q
The region between $y = 2x$, the $x$-axis and $x = 3$ is rotated about the $x$-axis. Find the volume, and check it against the formula for a cone.
---
$V = \pi\displaystyle\int_0^3 4x^2\,dx = \pi\left[\dfrac{4x^3}{3}\right]_0^3 = 36\pi$.

Cone: radius $6$, height $3$: $\dfrac13\pi r^2 h = \dfrac13\pi \times 36 \times 3 = 36\pi$. ✓
:::

::: q
The region bounded by $y = x^2$, the $y$-axis and the line $y = 4$ is rotated about the $y$-axis. Find the volume.
---
$x^2 = y$: $V = \pi\displaystyle\int_0^4 y\,dy = \pi\left[\dfrac{y^2}{2}\right]_0^4 = 8\pi$.
:::

::: watch
- **$+c$ on every indefinite integral.** It is a mark, and without it you cannot find the curve through a point.
- $\sin$ integrates to **$-\cos$**; $\cos$ to **$+\sin$** — the opposite way round from differentiation. And **divide** by the coefficient of $x$ (don't multiply).
- Area below the axis comes out **negative**. Sketch, split at the roots, and add the sizes. Integrating straight across a root gives an answer that is too small — and wrong.
- Volume: square $y$ **before** integrating — $(x^2 + 1)^2$ is $x^4 + 2x^2 + 1$, not $x^4 + 1$. And don't forget the $\pi$.
- Definite integrals: show the square-bracket line and the substitution of both limits. A number on its own gets no method marks if it is wrong.
- Rotating about the $y$-axis: everything in terms of $y$, $y$-limits, $\pi\int x^2\,dy$.
:::
