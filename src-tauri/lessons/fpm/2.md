## What it is

A quadratic is anything of the form $ax^2 + bx + c$ with $a \ne 0$. You already solve them by factorising and by the formula

$$x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}$$

Further Maths adds three things. **Completing the square** turns $ax^2 + bx + c$ into $a(x + p)^2 + q$, which tells you the vertex, the minimum or maximum value, and lets you solve without the formula. The **discriminant** $b^2 - 4ac$ — the bit under the square root — tells you how many real roots there are before you find them. And the **sum and product of the roots** let you work with the roots $\alpha$ and $\beta$ without ever finding them:

$$\alpha + \beta = -\frac{b}{a}, \qquad \alpha\beta = \frac{c}{a}$$

That last idea is the one that is new, and the one exam questions build on.

::: method
1. **Complete the square** for $x^2 + bx + c$: halve $b$, write $\left(x + \frac{b}{2}\right)^2$, then subtract $\left(\frac{b}{2}\right)^2$ and add $c$. If $a \ne 1$, take $a$ out of the $x^2$ and $x$ terms first. The vertex is at $x = -p$ where the bracket is $(x + p)$; the minimum value (for $a > 0$) is $q$.
2. **Discriminant:** $b^2 - 4ac > 0$ means two different real roots; $= 0$ means one repeated root (the curve touches the axis); $< 0$ means no real roots. "Equal roots" in a question means *set the discriminant to zero*; "real roots" means $\ge 0$.
3. **Sum and product:** for $ax^2 + bx + c = 0$, $\alpha + \beta = -\dfrac{b}{a}$ and $\alpha\beta = \dfrac{c}{a}$. Write both down at the start of any question that mentions $\alpha$ and $\beta$.
4. **Rewrite the expression you are asked for** in terms of $\alpha + \beta$ and $\alpha\beta$. The ones to know by heart:
   - $\alpha^2 + \beta^2 = (\alpha + \beta)^2 - 2\alpha\beta$
   - $(\alpha - \beta)^2 = (\alpha + \beta)^2 - 4\alpha\beta$
   - $\alpha^3 + \beta^3 = (\alpha + \beta)^3 - 3\alpha\beta(\alpha + \beta)$
   - $\dfrac{1}{\alpha} + \dfrac{1}{\beta} = \dfrac{\alpha + \beta}{\alpha\beta}$
5. **Form a new equation with given roots:** a quadratic with roots $p$ and $q$ is $x^2 - (p + q)x + pq = 0$. Find the new sum and the new product, then write it down. Multiply through to clear fractions if the question wants integer coefficients.
:::

::: example Completing the square
Write $2x^2 - 12x + 5$ in the form $a(x + p)^2 + q$, and hence find the minimum value and where it occurs.

Take out the 2 from the first two terms: $2(x^2 - 6x) + 5$.

Complete the square inside: $x^2 - 6x = (x - 3)^2 - 9$.

So $2\big((x - 3)^2 - 9\big) + 5 = 2(x - 3)^2 - 18 + 5 = 2(x - 3)^2 - 13$.

The square is never negative and is zero at $x = 3$, so the minimum value is $-13$, at $x = 3$.
:::

::: example Using the discriminant
The equation $kx^2 + 4x + k = 0$ has real roots. Find the range of possible values of $k$.

Real roots need $b^2 - 4ac \ge 0$: $16 - 4k^2 \ge 0$.

$4k^2 \le 16$, so $k^2 \le 4$, so $-2 \le k \le 2$.

(But $k = 0$ would make it not a quadratic, so strictly $-2 \le k \le 2$, $k \ne 0$. Mention it — examiners like it.)
:::

::: example Sum and product
The roots of $2x^2 - 5x + 1 = 0$ are $\alpha$ and $\beta$. Find $\alpha^2 + \beta^2$ and $\dfrac{1}{\alpha} + \dfrac{1}{\beta}$.

$\alpha + \beta = \dfrac{5}{2}$, $\quad \alpha\beta = \dfrac{1}{2}$.

$\alpha^2 + \beta^2 = (\alpha + \beta)^2 - 2\alpha\beta = \dfrac{25}{4} - 1 = \dfrac{21}{4}$.

$\dfrac{1}{\alpha} + \dfrac{1}{\beta} = \dfrac{\alpha + \beta}{\alpha\beta} = \dfrac{5/2}{1/2} = 5$.
:::

::: example Forming a new equation
The roots of $x^2 - 3x + 5 = 0$ are $\alpha$ and $\beta$. Find a quadratic equation with integer coefficients whose roots are $\alpha^2$ and $\beta^2$.

$\alpha + \beta = 3$, $\alpha\beta = 5$.

New sum: $\alpha^2 + \beta^2 = 3^2 - 2 \times 5 = -1$.

New product: $\alpha^2\beta^2 = (\alpha\beta)^2 = 25$.

Equation: $x^2 - (\text{sum})x + (\text{product}) = 0$, so $x^2 + x + 25 = 0$.
:::

::: example New roots with fractions
The roots of $3x^2 + 2x - 4 = 0$ are $\alpha$ and $\beta$. Find an equation with roots $\dfrac{1}{\alpha}$ and $\dfrac{1}{\beta}$.

$\alpha + \beta = -\dfrac{2}{3}$, $\alpha\beta = -\dfrac{4}{3}$.

New sum: $\dfrac{\alpha + \beta}{\alpha\beta} = \dfrac{-2/3}{-4/3} = \dfrac{1}{2}$. New product: $\dfrac{1}{\alpha\beta} = -\dfrac{3}{4}$.

$x^2 - \dfrac{1}{2}x - \dfrac{3}{4} = 0$, and multiplying by 4: $4x^2 - 2x - 3 = 0$.
:::

::: q
Write $x^2 + 10x + 3$ in the form $(x + p)^2 + q$. Hence solve $x^2 + 10x + 3 = 0$, giving your answers in surd form.
---
$(x + 5)^2 - 25 + 3 = (x + 5)^2 - 22$.

$(x + 5)^2 = 22$, so $x = -5 \pm \sqrt{22}$.
:::

::: q
Write $3x^2 + 12x - 1$ in the form $a(x + p)^2 + q$ and state the minimum value of $3x^2 + 12x - 1$.
---
$3(x^2 + 4x) - 1 = 3\big((x + 2)^2 - 4\big) - 1 = 3(x + 2)^2 - 13$. Minimum value $-13$ (at $x = -2$).
:::

::: q
Find the values of $k$ for which $x^2 + (k + 1)x + 4 = 0$ has equal roots.
---
$(k + 1)^2 - 16 = 0$, so $k + 1 = \pm 4$, so $k = 3$ or $k = -5$.
:::

::: q
Show that $2x^2 - 3x + 4 = 0$ has no real roots.
---
$b^2 - 4ac = 9 - 32 = -23 < 0$, so there are no real roots.
:::

::: q
Find the range of values of $p$ for which $px^2 - 6x + p = 0$ has two distinct real roots.
---
$36 - 4p^2 > 0$, so $p^2 < 9$, so $-3 < p < 3$ (and $p \ne 0$).
:::

::: q
The roots of $x^2 - 7x + 2 = 0$ are $\alpha$ and $\beta$. Find $\alpha^2 + \beta^2$ and $(\alpha - \beta)^2$.
---
$\alpha + \beta = 7$, $\alpha\beta = 2$.

$\alpha^2 + \beta^2 = 49 - 4 = 45$. $\quad (\alpha - \beta)^2 = 49 - 8 = 41$.
:::

::: q
The roots of $2x^2 + 3x - 6 = 0$ are $\alpha$ and $\beta$. Find $\alpha^3 + \beta^3$.
---
$\alpha + \beta = -\dfrac{3}{2}$, $\alpha\beta = -3$.

$\alpha^3 + \beta^3 = (\alpha + \beta)^3 - 3\alpha\beta(\alpha + \beta) = -\dfrac{27}{8} - 3(-3)\left(-\dfrac{3}{2}\right) = -\dfrac{27}{8} - \dfrac{27}{2} = -\dfrac{135}{8}$.
:::

::: q
The roots of $x^2 + 4x - 2 = 0$ are $\alpha$ and $\beta$. Find a quadratic equation with integer coefficients whose roots are $\alpha + 1$ and $\beta + 1$.
---
$\alpha + \beta = -4$, $\alpha\beta = -2$.

New sum: $(\alpha + 1) + (\beta + 1) = -4 + 2 = -2$.

New product: $(\alpha + 1)(\beta + 1) = \alpha\beta + \alpha + \beta + 1 = -2 - 4 + 1 = -5$.

$x^2 + 2x - 5 = 0$.
:::

::: q
The roots of $3x^2 - x - 5 = 0$ are $\alpha$ and $\beta$. Find a quadratic equation with integer coefficients whose roots are $\dfrac{\alpha}{\beta}$ and $\dfrac{\beta}{\alpha}$.
---
$\alpha + \beta = \dfrac{1}{3}$, $\alpha\beta = -\dfrac{5}{3}$.

New sum: $\dfrac{\alpha}{\beta} + \dfrac{\beta}{\alpha} = \dfrac{\alpha^2 + \beta^2}{\alpha\beta} = \dfrac{(\alpha+\beta)^2 - 2\alpha\beta}{\alpha\beta} = \dfrac{\frac{1}{9} + \frac{10}{3}}{-\frac{5}{3}} = \dfrac{31/9}{-5/3} = -\dfrac{31}{15}$.

New product: $\dfrac{\alpha}{\beta} \times \dfrac{\beta}{\alpha} = 1$.

$x^2 + \dfrac{31}{15}x + 1 = 0$, so $15x^2 + 31x + 15 = 0$.
:::

::: q
The equation $x^2 + px + q = 0$ has roots $\alpha$ and $\beta$ with $\alpha + \beta = 6$ and $\alpha^2 + \beta^2 = 26$. Find $p$ and $q$.
---
$p = -(\alpha + \beta) = -6$.

$\alpha^2 + \beta^2 = (\alpha + \beta)^2 - 2\alpha\beta$, so $26 = 36 - 2\alpha\beta$, so $\alpha\beta = 5 = q$.
:::

::: q
The line $y = 2x + c$ is a tangent to the curve $y = x^2 - 4x + 7$. Find $c$.
---
Tangent means the equation $x^2 - 4x + 7 = 2x + c$ has equal roots.

$x^2 - 6x + (7 - c) = 0$: discriminant $36 - 4(7 - c) = 0$, so $36 - 28 + 4c = 0$, so $c = -2$.
:::

::: watch
- **Sign of $b$ in the sum:** $\alpha + \beta = -\dfrac{b}{a}$, with a minus. For $x^2 - 7x + 2$, the sum is $+7$. Most lost marks in this topic are this sign.
- **Divide by $a$.** For $2x^2 - 5x + 1$, the product is $\frac12$, not $1$.
- When you form a new equation, it is $x^2 - (\text{sum})x + \text{product}$ — the minus is on the sum. Then clear fractions if asked for integer coefficients.
- "Equal roots" or "tangent" → discriminant $= 0$. "Real roots" → $\ge 0$. "Distinct real roots" → $> 0$. "No real roots" → $< 0$. Read which one it is.
- Completing the square with $a \ne 1$: take $a$ out of the **first two terms only**, and remember the number you subtract inside the bracket gets multiplied by $a$ when it comes out.
- Don't find $\alpha$ and $\beta$ themselves. It is slower, usually gives surds, and the method marks are for using sum and product.
:::
