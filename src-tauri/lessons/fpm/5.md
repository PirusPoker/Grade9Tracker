## What it is

A **sequence** is a list of numbers with a rule; a **series** is what you get when you add them up. Two kinds matter here.

An **arithmetic** series goes up (or down) by the same amount each time — the **common difference** $d$: $3, 7, 11, 15, \dots$ ($a = 3$, $d = 4$).

A **geometric** series multiplies by the same amount each time — the **common ratio** $r$: $2, 6, 18, 54, \dots$ ($a = 2$, $r = 3$).

$\Sigma$ (sigma) notation is just shorthand for "add these up": $\displaystyle\sum_{k=1}^{5} k^2 = 1 + 4 + 9 + 16 + 25 = 55$. The letter under the sigma runs from the bottom value to the top value, and you add up the expression for each.

The formulae — know them cold, they are not all on the formula sheet:

| | Arithmetic | Geometric |
|---|---|---|
| $n$th term | $u_n = a + (n - 1)d$ | $u_n = ar^{n-1}$ |
| Sum of $n$ terms | $S_n = \dfrac{n}{2}\big(2a + (n - 1)d\big) = \dfrac{n}{2}(a + l)$ | $S_n = \dfrac{a(r^n - 1)}{r - 1} = \dfrac{a(1 - r^n)}{1 - r}$ |
| Sum to infinity | — | $S_\infty = \dfrac{a}{1 - r}$, only if $\lvert r \rvert < 1$ |

($l$ is the last term.) A geometric series with $\lvert r \rvert < 1$ has terms shrinking towards zero, so the total settles down to a limit — that is $S_\infty$. If $\lvert r \rvert \ge 1$ the sum just keeps growing and there is no sum to infinity.

::: method
1. **Identify the type.** Subtract consecutive terms: constant → arithmetic. Divide consecutive terms: constant → geometric.
2. **Write down $a$ and $d$ (or $r$).** If they are unknown, write the $n$th-term formula for each piece of information you are given; that gives simultaneous equations.
3. **Pick the formula** for what is asked: a term, or a sum. For an arithmetic sum, use $\frac n2(a + l)$ if you know the last term — it is quicker.
4. **"Find the number of terms"**: set $u_n$ equal to the last term and solve for $n$; for a geometric one this needs logs.
5. **"Find $n$ such that $S_n$ exceeds…"**: set up the inequality, solve (logs again for geometric), and remember $n$ must be a whole number — round **up** to the next integer.
6. **Sum to infinity:** check $\lvert r \rvert < 1$ first and say so — there is a mark for the condition.
7. **Sigma notation:** write out the first two or three terms to see $a$ and $d$/$r$, then count the terms: from $k = m$ to $k = n$ there are $n - m + 1$ terms.
:::

::: example Arithmetic: finding the rule from two terms
The 4th term of an arithmetic series is 17 and the 10th term is 41. Find the first term, the common difference, and the sum of the first 20 terms.

$a + 3d = 17$ and $a + 9d = 41$. Subtracting: $6d = 24$, $d = 4$, so $a = 5$.

$S_{20} = \dfrac{20}{2}\big(2 \times 5 + 19 \times 4\big) = 10 \times 86 = 860$.
:::

::: example Arithmetic: how many terms?
Find the sum $7 + 10 + 13 + \dots + 121$.

$a = 7$, $d = 3$, last term $l = 121$. $a + (n - 1)d = 121$: $7 + 3(n - 1) = 121$, $3(n - 1) = 114$, $n = 39$.

$S_{39} = \dfrac{39}{2}(7 + 121) = \dfrac{39 \times 128}{2} = 2496$.
:::

::: example Geometric: term and sum
A geometric series has first term $3$ and common ratio $2$. Find the 8th term and the sum of the first 8 terms.

$u_8 = 3 \times 2^7 = 384$.

$S_8 = \dfrac{3(2^8 - 1)}{2 - 1} = 3 \times 255 = 765$.
:::

::: example Geometric: finding $r$ then $S_\infty$
The 2nd term of a geometric series is $12$ and the 5th term is $\dfrac{3}{2}$. Find $r$, $a$ and the sum to infinity.

$ar = 12$ and $ar^4 = \dfrac32$. Dividing: $r^3 = \dfrac{3/2}{12} = \dfrac18$, so $r = \dfrac12$. Then $a = 24$.

$\lvert r \rvert = \frac12 < 1$, so $S_\infty$ exists: $S_\infty = \dfrac{24}{1 - \frac12} = 48$.
:::

::: example Geometric: solving for $n$ with logs
A geometric series has $a = 5$, $r = 1.2$. Find the smallest $n$ for which $S_n > 500$.

$\dfrac{5(1.2^n - 1)}{0.2} > 500 \Rightarrow 25(1.2^n - 1) > 500 \Rightarrow 1.2^n > 21$.

$n \log 1.2 > \log 21 \Rightarrow n > \dfrac{\log 21}{\log 1.2} = 16.7$. So $n = 17$.
:::

::: example Sigma notation
Evaluate $\displaystyle\sum_{k=1}^{15} (3k + 2)$ and $\displaystyle\sum_{k=3}^{8} 2 \times 3^{k}$.

First: terms $5, 8, 11, \dots$ — arithmetic with $a = 5$, $d = 3$, $n = 15$. $S = \frac{15}{2}(10 + 14 \times 3) = \frac{15}{2} \times 52 = 390$.

Second: $k$ runs from 3 to 8, so $6$ terms; first term $2 \times 27 = 54$, ratio $3$. $S = \dfrac{54(3^6 - 1)}{2} = 27 \times 728 = 19656$.
:::

::: q
An arithmetic series has first term 8 and common difference $-3$. Find the 15th term and the sum of the first 15 terms.
---
$u_{15} = 8 + 14(-3) = -34$. $S_{15} = \dfrac{15}{2}(8 + (-34)) = \dfrac{15}{2}(-26) = -195$.
:::

::: q
The 3rd term of an arithmetic series is 11 and the 8th term is 31. Find $a$ and $d$, and the sum of the first 30 terms.
---
$a + 2d = 11$, $a + 7d = 31$: $5d = 20$, $d = 4$, $a = 3$.

$S_{30} = 15(6 + 29 \times 4) = 15 \times 122 = 1830$.
:::

::: q
Find the sum of all the multiples of 7 between 100 and 300.
---
First multiple: 105; last: 294. $105 + 7(n - 1) = 294 \Rightarrow n - 1 = 27 \Rightarrow n = 28$.

$S = \dfrac{28}{2}(105 + 294) = 14 \times 399 = 5586$.
:::

::: q
An arithmetic series has $a = 2$ and $d = 5$. Find the smallest $n$ for which $S_n > 1000$.
---
$\dfrac n2(4 + 5(n - 1)) > 1000 \Rightarrow n(5n - 1) > 2000 \Rightarrow 5n^2 - n - 2000 > 0$.

$n = \dfrac{1 + \sqrt{1 + 40000}}{10} = 20.1$, so $n = 21$. (Check: $S_{20} = 10 \times 99 = 990$, $S_{21} = 10.5 \times 104 = 1092$.)
:::

::: q
A geometric series has first term 64 and common ratio $\dfrac34$. Find the 5th term and the sum to infinity.
---
$u_5 = 64 \times \left(\dfrac34\right)^4 = 64 \times \dfrac{81}{256} = \dfrac{81}{4}$.

$\lvert r \rvert < 1$ so $S_\infty = \dfrac{64}{1 - \frac34} = 256$.
:::

::: q
The 3rd term of a geometric series is 18 and the 6th term is 486. Find $r$, $a$ and $S_6$.
---
$ar^2 = 18$, $ar^5 = 486$: $r^3 = 27$, $r = 3$, $a = 2$.

$S_6 = \dfrac{2(3^6 - 1)}{2} = 728$.
:::

::: q
A geometric series has sum to infinity 40 and first term 25. Find the common ratio and the 3rd term.
---
$\dfrac{25}{1 - r} = 40 \Rightarrow 1 - r = \dfrac58 \Rightarrow r = \dfrac38$.

$u_3 = 25 \times \dfrac{9}{64} = \dfrac{225}{64}$.
:::

::: q
Evaluate $\displaystyle\sum_{k=1}^{20} (4k - 1)$.
---
Terms $3, 7, 11, \dots$, $a = 3$, $d = 4$, $n = 20$: $S = 10(6 + 19 \times 4) = 10 \times 82 = 820$.
:::

::: q
Evaluate $\displaystyle\sum_{k=2}^{7} 5 \times 2^{k}$.
---
Six terms, first $5 \times 4 = 20$, ratio 2: $S = \dfrac{20(2^6 - 1)}{1} = 20 \times 63 = 1260$.
:::

::: q
Write $6 + 11 + 16 + \dots + 101$ in sigma notation and evaluate it.
---
$a = 6$, $d = 5$; $6 + 5(n - 1) = 101 \Rightarrow n = 20$. $\displaystyle\sum_{k=1}^{20}(5k + 1)$.

$S = 10(6 + 101) = 1070$.
:::

::: q
A ball is dropped from 2 m and each bounce reaches $\dfrac{3}{5}$ of the previous height. Find the total distance it travels before coming to rest.
---
Down 2 m, then up-and-down $2 \times \left(2 \times \frac35\right) + 2 \times \left(2 \times \frac{9}{25}\right) + \dots$

Bounces: a geometric series with $a = 2 \times 2 \times \frac35 = \frac{12}{5}$, $r = \frac35$: $S_\infty = \dfrac{12/5}{2/5} = 6$.

Total $= 2 + 6 = 8$ m.
:::

::: q
A geometric series has $a = 200$ and $r = 0.9$. Find the smallest $n$ such that $u_n < 10$.
---
$200 \times 0.9^{n-1} < 10 \Rightarrow 0.9^{n-1} < 0.05 \Rightarrow (n - 1)\log 0.9 < \log 0.05$.

$\log 0.9$ is **negative**, so dividing flips the sign: $n - 1 > \dfrac{\log 0.05}{\log 0.9} = 28.4$, so $n - 1 \ge 29$, $n = 30$.
:::

::: watch
- **$(n - 1)$, not $n$**, in $a + (n - 1)d$ and $ar^{n-1}$. The first term has no $d$ and no $r$ in it.
- **Count the terms in a sigma:** from $k = 3$ to $k = 8$ is $6$ terms, not $5$ and not $8$.
- $S_\infty$ needs $\lvert r \rvert < 1$ — **write the condition down**; it is a mark, and if $r$ is negative the modulus matters.
- Dividing by $\log r$ when $0 < r < 1$: $\log r$ is negative, so the inequality **flips**.
- When solving for $n$, the answer must be a whole number. Show the decimal, then state the integer and say why (smallest integer above, etc.).
- The sum formula with $\frac n2(a + l)$ is only for arithmetic series. Never use it for geometric.
:::
