## What it is

$\dfrac{dy}{dx}$ is the gradient, so it tells you two things about the shape of a curve.

**Where the gradient is zero**, the curve is momentarily flat: a **stationary point**. It is a **maximum** (a peak), a **minimum** (a trough) or, occasionally, a **point of inflection** (flat for a moment, then carries on the same way). The second derivative $\dfrac{d^2y}{dx^2}$ tells you which: negative means the gradient is decreasing through zero, so it is a maximum; positive means a minimum.

**At any point**, the gradient gives you the **tangent** — the line touching the curve there — and the **normal**, the line at right angles to the tangent through the same point, whose gradient is $-1 \div$ the tangent's.

Practical questions — the biggest box from a sheet of card, the cheapest tin of a given volume — are maximum/minimum problems in disguise: set up the quantity as a function of one variable, differentiate, set to zero.

::: method
1. **Stationary points:** find $\dfrac{dy}{dx}$, set it equal to $0$, solve for $x$. Substitute back into $y$ (not into the derivative) to get the $y$-coordinate. Give the point as coordinates.
2. **Nature:** find $\dfrac{d^2y}{dx^2}$ and substitute each $x$. Negative → maximum; positive → minimum; zero → test the gradient either side (or the second derivative is inconclusive — say so and check the sign of $\dfrac{dy}{dx}$ just left and just right).
3. **Tangent at $x = a$:** find $y$ at $a$; find $m = \dfrac{dy}{dx}$ at $a$; then $y - y_1 = m(x - a)$.
4. **Normal at $x = a$:** same point, gradient $-\dfrac{1}{m}$.
5. **Tangent parallel to a line:** set $\dfrac{dy}{dx}$ equal to that line's gradient and solve for $x$.
6. **Practical max/min:** name the variables; write the quantity to be optimised; use any constraint (fixed volume, fixed perimeter) to eliminate all but one variable; differentiate; set to zero; **justify** it is a max or min with the second derivative; answer the actual question (the value of the quantity, not just where it happens).
:::

::: example Finding and classifying stationary points
Find the stationary points of $y = x^3 - 6x^2 + 9x + 1$ and determine their nature.

$\dfrac{dy}{dx} = 3x^2 - 12x + 9 = 3(x^2 - 4x + 3) = 3(x - 1)(x - 3)$. Zero at $x = 1$ and $x = 3$.

$x = 1$: $y = 1 - 6 + 9 + 1 = 5$. $x = 3$: $y = 27 - 54 + 27 + 1 = 1$.

$\dfrac{d^2y}{dx^2} = 6x - 12$. At $x = 1$: $-6 < 0$, maximum at $(1, 5)$. At $x = 3$: $6 > 0$, minimum at $(3, 1)$.
:::

::: example A stationary point with a fraction
Find the stationary point of $y = x + \dfrac{4}{x}$ for $x > 0$ and show it is a minimum.

$y = x + 4x^{-1}$, $\dfrac{dy}{dx} = 1 - 4x^{-2} = 0 \Rightarrow x^2 = 4 \Rightarrow x = 2$ (since $x > 0$). $y = 2 + 2 = 4$.

$\dfrac{d^2y}{dx^2} = 8x^{-3} = \dfrac{8}{x^3}$; at $x = 2$, $= 1 > 0$. Minimum at $(2, 4)$.
:::

::: example Tangent and normal
Find the equations of the tangent and the normal to $y = x^2 - 3x + 1$ at the point where $x = 2$.

$y = 4 - 6 + 1 = -1$; point $(2, -1)$.

$\dfrac{dy}{dx} = 2x - 3 = 1$ at $x = 2$.

Tangent: $y + 1 = 1(x - 2) \Rightarrow y = x - 3$.

Normal: gradient $-1$: $y + 1 = -(x - 2) \Rightarrow y = -x + 1$.
:::

::: example Tangent parallel to a given line
Find the point on $y = x^3 - 2x$ where the tangent is parallel to $y = 10x + 3$, with $x > 0$.

$\dfrac{dy}{dx} = 3x^2 - 2 = 10 \Rightarrow x^2 = 4 \Rightarrow x = 2$. $y = 8 - 4 = 4$. Point $(2, 4)$.
:::

::: example A practical maximum
A rectangular enclosure is built against a wall, using 40 m of fencing for the other three sides. Find the maximum area.

Let the sides perpendicular to the wall be $x$ and the side parallel be $y$: $2x + y = 40$, so $y = 40 - 2x$.

Area $A = xy = x(40 - 2x) = 40x - 2x^2$.

$\dfrac{dA}{dx} = 40 - 4x = 0 \Rightarrow x = 10$. $\dfrac{d^2A}{dx^2} = -4 < 0$: a maximum.

$A = 10 \times 20 = 200$ m$^2$.
:::

::: example A practical minimum with a constraint
A closed cylinder has volume $250\pi$ cm$^3$. Find the radius that minimises its surface area.

$V = \pi r^2 h = 250\pi \Rightarrow h = \dfrac{250}{r^2}$.

$S = 2\pi r^2 + 2\pi r h = 2\pi r^2 + 2\pi r \cdot \dfrac{250}{r^2} = 2\pi r^2 + \dfrac{500\pi}{r}$.

$\dfrac{dS}{dr} = 4\pi r - \dfrac{500\pi}{r^2} = 0 \Rightarrow 4r^3 = 500 \Rightarrow r^3 = 125 \Rightarrow r = 5$.

$\dfrac{d^2S}{dr^2} = 4\pi + \dfrac{1000\pi}{r^3} > 0$: minimum. Radius $5$ cm (and then $h = 10$ cm).
:::

::: q
Find the stationary point of $y = 2x^2 - 8x + 3$ and state its nature.
---
$\dfrac{dy}{dx} = 4x - 8 = 0 \Rightarrow x = 2$, $y = 8 - 16 + 3 = -5$. $\dfrac{d^2y}{dx^2} = 4 > 0$: minimum at $(2, -5)$.
:::

::: q
Find the coordinates of the stationary points of $y = x^3 - 3x^2 - 9x + 2$ and determine their nature.
---
$\dfrac{dy}{dx} = 3x^2 - 6x - 9 = 3(x - 3)(x + 1) = 0 \Rightarrow x = 3, -1$.

$x = 3$: $y = 27 - 27 - 27 + 2 = -25$. $x = -1$: $y = -1 - 3 + 9 + 2 = 7$.

$\dfrac{d^2y}{dx^2} = 6x - 6$: at $3$, $12 > 0$ minimum $(3, -25)$; at $-1$, $-12 < 0$ maximum $(-1, 7)$.
:::

::: q
Find the stationary points of $y = 2x + \dfrac{18}{x}$ and their nature.
---
$\dfrac{dy}{dx} = 2 - 18x^{-2} = 0 \Rightarrow x^2 = 9 \Rightarrow x = \pm 3$. $y(3) = 12$, $y(-3) = -12$.

$\dfrac{d^2y}{dx^2} = 36x^{-3}$: at $3$, positive: minimum $(3, 12)$; at $-3$, negative: maximum $(-3, -12)$.
:::

::: q
Find the equation of the tangent to $y = x^3 + 2x$ at the point where $x = 1$.
---
$y = 3$; $\dfrac{dy}{dx} = 3x^2 + 2 = 5$. $y - 3 = 5(x - 1) \Rightarrow y = 5x - 2$.
:::

::: q
Find the equation of the normal to $y = \dfrac{4}{x}$ at the point $(2, 2)$, in the form $ax + by + c = 0$.
---
$\dfrac{dy}{dx} = -4x^{-2} = -1$ at $x = 2$. Normal gradient $1$: $y - 2 = x - 2 \Rightarrow x - y = 0$.
:::

::: q
Find the equation of the tangent to $y = e^{2x}$ at the point where $x = 0$.
---
$y = 1$; $\dfrac{dy}{dx} = 2e^{2x} = 2$. $y = 2x + 1$.
:::

::: q
Find the equation of the tangent to $y = \sin 2x$ at $x = \dfrac{\pi}{4}$.
---
$y = \sin\dfrac\pi2 = 1$; $\dfrac{dy}{dx} = 2\cos 2x = 2\cos\dfrac\pi2 = 0$. Tangent: $y = 1$.
:::

::: q
The curve $y = x^2 + ax + b$ has a stationary point at $(3, -4)$. Find $a$ and $b$.
---
$\dfrac{dy}{dx} = 2x + a = 0$ at $x = 3 \Rightarrow a = -6$. $9 - 18 + b = -4 \Rightarrow b = 5$.
:::

::: q
Find the points on $y = x^3 - 12x$ where the tangent is parallel to the $x$-axis.
---
$3x^2 - 12 = 0 \Rightarrow x = \pm 2$. $(2, -16)$ and $(-2, 16)$.
:::

::: q
The tangent to $y = x^2 - 4x$ at the point $P(3, -3)$ meets the $x$-axis at $Q$. Find the coordinates of $Q$.
---
$\dfrac{dy}{dx} = 2x - 4 = 2$ at $x = 3$. Tangent: $y + 3 = 2(x - 3) \Rightarrow y = 2x - 9$. At $y = 0$, $x = \dfrac92$. $Q = \left(\dfrac92, 0\right)$.
:::

::: q
An open box is made from a square sheet of card of side 12 cm by cutting a square of side $x$ cm from each corner and folding up the sides. Show that the volume is $V = x(12 - 2x)^2$ and find the value of $x$ that maximises it.
---
Base is $(12 - 2x)$ square, height $x$: $V = x(12 - 2x)^2 = 4x^3 - 48x^2 + 144x$.

$\dfrac{dV}{dx} = 12x^2 - 96x + 144 = 12(x^2 - 8x + 12) = 12(x - 2)(x - 6) = 0 \Rightarrow x = 2$ or $6$.

$x = 6$ gives no box (base of zero width). $\dfrac{d^2V}{dx^2} = 24x - 96 = -48 < 0$ at $x = 2$: maximum. $x = 2$ (and $V = 128$ cm$^3$).
:::

::: q
A closed box with a square base of side $x$ cm has volume $32$ cm$^3$. Show that its surface area is $S = 2x^2 + \dfrac{128}{x}$ and find the minimum surface area.
---
Height $h = \dfrac{32}{x^2}$; $S = 2x^2 + 4xh = 2x^2 + \dfrac{128}{x}$.

$\dfrac{dS}{dx} = 4x - \dfrac{128}{x^2} = 0 \Rightarrow x^3 = 32 \Rightarrow x = \sqrt[3]{32} = 2\sqrt[3]{4} \approx 3.17$.

$\dfrac{d^2S}{dx^2} = 4 + \dfrac{256}{x^3} > 0$: minimum. $S = 2x^2 + \dfrac{128}{x}$ at $x^3 = 32$: $S = 2x^2 + 4x^2 = 6x^2 = 6 \times 32^{2/3} \approx 60.5$ cm$^2$.
:::

::: watch
- **Substitute into $y$, not into $\dfrac{dy}{dx}$**, to get the $y$-coordinate of a stationary point. The derivative there is zero — that is not the $y$ value.
- **Justify the nature.** "Maximum" with no second derivative (or gradient table) loses the mark. Write $\dfrac{d^2y}{dx^2} = \dots < 0$, so maximum.
- Normal gradient is $-\dfrac{1}{m}$, the negative reciprocal — from $m = 2$ it is $-\frac12$, not $-2$.
- In a practical problem, the answer is what the question asked for: the maximum **area**, not just the $x$ that gives it. And reject values that make no physical sense (a negative length, a zero-width box).
- $\dfrac{d^2y}{dx^2} = 0$ does **not** automatically mean a point of inflection. Check the gradient either side.
- "Find the tangent at the point where $x = a$": you need the point first, so compute $y$ at $a$ before anything else.
:::
