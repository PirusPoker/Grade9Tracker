## What it is

A **polynomial** is a sum of powers of $x$ — a cubic is $ax^3 + bx^2 + cx + d$. Dividing a polynomial by something like $(x - 2)$ works just like dividing numbers: you get a **quotient** and a **remainder**.

$$f(x) = (x - a) \times \text{quotient} + \text{remainder}$$

Two theorems come straight out of that line by putting $x = a$ into it:

- **Remainder theorem:** the remainder when $f(x)$ is divided by $(x - a)$ is $f(a)$. Dividing by $(ax - b)$, the remainder is $f\!\left(\frac{b}{a}\right)$.
- **Factor theorem:** $(x - a)$ is a factor of $f(x)$ exactly when $f(a) = 0$.

Together they let you factorise a cubic: find one root by trying small numbers, divide out the factor, and factorise the quadratic that is left. The same skills solve a cubic equation, and (the third part of this topic) solve a linear equation together with a quadratic one by substitution.

::: method
1. **Remainder:** to find the remainder on dividing by $(x - a)$, work out $f(a)$. Dividing by $(2x + 1)$? Set $2x + 1 = 0$, so substitute $x = -\frac12$.
2. **Find a factor:** try $x = 1, -1, 2, -2, 3, \dots$ (and fractions like $\pm\frac12$ if the leading coefficient is not 1). The value that gives $f(a) = 0$ hands you the factor $(x - a)$.
3. **Divide** to find the quotient. Either long division, or **compare coefficients**: write $f(x) = (x - a)(px^2 + qx + r)$, match the $x^3$ term to get $p$, the constant to get $r$, then one middle term to get $q$. Check with the other middle term.
4. **Factorise the quadratic** quotient if it factorises; otherwise use the formula to solve. Then write the full factorisation or the full list of roots.
5. **Linear with quadratic (simultaneous):** rearrange the linear one to $y = \dots$ (or $x = \dots$), substitute into the quadratic, solve the resulting quadratic, then find the other variable for **each** solution. Give answers as pairs.
:::

::: example The remainder theorem
Find the remainder when $f(x) = 2x^3 - 3x^2 + x - 5$ is divided by (a) $(x - 2)$, (b) $(2x + 1)$.

(a) $f(2) = 16 - 12 + 2 - 5 = 1$. Remainder $1$.

(b) $2x + 1 = 0$ at $x = -\frac12$: $f\!\left(-\frac12\right) = 2\left(-\frac18\right) - 3\left(\frac14\right) - \frac12 - 5 = -\frac14 - \frac34 - \frac12 - 5 = -\frac{13}{2}$. Remainder $-\dfrac{13}{2}$.
:::

::: example Finding an unknown coefficient
$f(x) = x^3 + kx^2 - 7x + 6$ has $(x - 2)$ as a factor. Find $k$ and factorise $f(x)$ completely.

Factor theorem: $f(2) = 0$. $8 + 4k - 14 + 6 = 0$, so $4k = 0$, so $k = 0$.

So $f(x) = x^3 - 7x + 6 = (x - 2)(x^2 + qx + r)$. Constant: $-2r = 6$, so $r = -3$. $x^2$ term: $q - 2 = 0$, so $q = 2$. Check $x$ term: $r - 2q = -3 - 4 = -7$. ✓

$f(x) = (x - 2)(x^2 + 2x - 3) = (x - 2)(x + 3)(x - 1)$.
:::

::: example Dividing when the leading coefficient is not 1
Factorise $6x^3 + 11x^2 - x - 6$ completely, given that $(2x + 3)$ is a factor.

Write $6x^3 + 11x^2 - x - 6 = (2x + 3)(px^2 + qx + r)$.

$x^3$: $2p = 6$, so $p = 3$. Constant: $3r = -6$, so $r = -2$.

$x^2$: $2q + 3p = 11$, so $2q + 9 = 11$, so $q = 1$. Check $x$: $2r + 3q = -4 + 3 = -1$. ✓

$= (2x + 3)(3x^2 + x - 2) = (2x + 3)(3x - 2)(x + 1)$.
:::

::: example Solving a cubic from scratch
Solve $x^3 - 4x^2 + x + 6 = 0$.

Try $x = 1$: $1 - 4 + 1 + 6 = 4$. No. Try $x = -1$: $-1 - 4 - 1 + 6 = 0$. Yes, so $(x + 1)$ is a factor.

$x^3 - 4x^2 + x + 6 = (x + 1)(x^2 - 5x + 6)$ (the $x^2$ term: $q + 1 = -4$; the constant: $r = 6$; check $x$: $r + q = 6 - 5 = 1$ ✓).

$(x + 1)(x - 2)(x - 3) = 0$, so $x = -1, 2, 3$.
:::

::: example Two remainders, two unknowns
$f(x) = x^3 + ax^2 + bx + 2$. When $f(x)$ is divided by $(x - 1)$ the remainder is $6$, and $(x + 2)$ is a factor. Find $a$ and $b$.

$f(1) = 6$: $1 + a + b + 2 = 6$, so $a + b = 3$.

$f(-2) = 0$: $-8 + 4a - 2b + 2 = 0$, so $4a - 2b = 6$, so $2a - b = 3$.

Adding: $3a = 6$, so $a = 2$, $b = 1$.
:::

::: example Linear and quadratic together
Solve $y = 2x - 1$ and $x^2 + y^2 = 13$.

Substitute: $x^2 + (2x - 1)^2 = 13$, so $x^2 + 4x^2 - 4x + 1 = 13$, so $5x^2 - 4x - 12 = 0$.

$(5x + 6)(x - 2) = 0$, so $x = 2$ or $x = -\dfrac{6}{5}$.

$x = 2 \Rightarrow y = 3$. $\quad x = -\dfrac65 \Rightarrow y = -\dfrac{17}{5}$.

Solutions: $(2, 3)$ and $\left(-\dfrac65, -\dfrac{17}{5}\right)$.
:::

::: q
Find the remainder when $x^3 + 2x^2 - 5x + 1$ is divided by $(x + 3)$.
---
$f(-3) = -27 + 18 + 15 + 1 = 7$.
:::

::: q
Find the remainder when $4x^3 - 2x^2 + 3x - 1$ is divided by $(2x - 1)$.
---
$x = \frac12$: $4\left(\frac18\right) - 2\left(\frac14\right) + \frac32 - 1 = \frac12 - \frac12 + \frac32 - 1 = \dfrac{1}{2}$.
:::

::: q
Show that $(x - 3)$ is a factor of $x^3 - 2x^2 - 5x + 6$ and factorise it completely.
---
$f(3) = 27 - 18 - 15 + 6 = 0$, so $(x - 3)$ is a factor.

$x^3 - 2x^2 - 5x + 6 = (x - 3)(x^2 + x - 2) = (x - 3)(x + 2)(x - 1)$.
:::

::: q
$(x + 1)$ is a factor of $2x^3 + px^2 - 5x - 6$. Find $p$.
---
$f(-1) = -2 + p + 5 - 6 = 0$, so $p = 3$.
:::

::: q
Factorise $x^3 + 3x^2 - 4$ completely.
---
$f(1) = 1 + 3 - 4 = 0$, so $(x - 1)$ is a factor.

$x^3 + 3x^2 - 4 = (x - 1)(x^2 + 4x + 4) = (x - 1)(x + 2)^2$.
:::

::: q
Given that $(3x - 1)$ is a factor of $3x^3 + 2x^2 - 7x + p$, find $p$ and factorise the cubic completely.
---
$f\!\left(\frac13\right) = 0$: $3 \cdot \frac{1}{27} + 2 \cdot \frac19 - \frac73 + p = \frac19 + \frac29 - \frac{21}{9} + p = -2 + p = 0$, so $p = 2$.

$3x^3 + 2x^2 - 7x + 2 = (3x - 1)(x^2 + qx + r)$: constant $-r = 2 \Rightarrow r = -2$; $x^2$ term $3q - 1 = 2 \Rightarrow q = 1$; check $x$ term $3r - q = -6 - 1 = -7$. ✓

$= (3x - 1)(x^2 + x - 2) = (3x - 1)(x + 2)(x - 1)$.
:::

::: q
Solve $2x^3 - 3x^2 - 11x + 6 = 0$.
---
Try $x = 3$: $54 - 27 - 33 + 6 = 0$. ✓ So $(x - 3)$ is a factor.

$2x^3 - 3x^2 - 11x + 6 = (x - 3)(2x^2 + 3x - 2) = (x - 3)(2x - 1)(x + 2)$.

$x = 3, \ \dfrac12, \ -2$.
:::

::: q
$f(x) = x^3 + ax^2 + bx - 6$. Given that $(x - 1)$ is a factor and that the remainder when $f(x)$ is divided by $(x - 2)$ is $4$, find $a$ and $b$.
---
$f(1) = 0$: $1 + a + b - 6 = 0 \Rightarrow a + b = 5$.

$f(2) = 4$: $8 + 4a + 2b - 6 = 4 \Rightarrow 4a + 2b = 2 \Rightarrow 2a + b = 1$.

Subtract: $a = -4$, so $b = 9$.
:::

::: q
Solve $x^3 - 6x^2 + 11x - 6 = 0$.
---
$f(1) = 1 - 6 + 11 - 6 = 0$, so $(x - 1)$ is a factor: $(x - 1)(x^2 - 5x + 6) = (x - 1)(x - 2)(x - 3)$.

$x = 1, 2, 3$.
:::

::: q
Solve the simultaneous equations $x + y = 5$ and $x^2 - y^2 = 15$.
---
$y = 5 - x$, so $x^2 - (5 - x)^2 = 15$, so $x^2 - 25 + 10x - x^2 = 15$, so $10x = 40$, $x = 4$, $y = 1$.

(Quicker: $x^2 - y^2 = (x + y)(x - y)$, so $5(x - y) = 15$, $x - y = 3$.)
:::

::: q
Solve $y = x + 3$ and $xy = 10$.
---
$x(x + 3) = 10$, so $x^2 + 3x - 10 = 0$, so $(x + 5)(x - 2) = 0$.

$x = 2, y = 5$ or $x = -5, y = -2$.
:::

::: q
The cubic $x^3 + px^2 + qx + 12$ has factors $(x - 2)$ and $(x + 3)$. Find $p$ and $q$, and the third factor.
---
$f(2) = 0$: $8 + 4p + 2q + 12 = 0 \Rightarrow 2p + q = -10$.

$f(-3) = 0$: $-27 + 9p - 3q + 12 = 0 \Rightarrow 3p - q = 5$.

Add: $5p = -5$, $p = -1$, $q = -8$.

Divide out: $x^3 - x^2 - 8x + 12 = (x - 2)(x^2 + x - 6)$ (check the $x$ term: $-6 - 2 = -8$ ✓), and $x^2 + x - 6 = (x + 3)(x - 2)$. So $f(x) = (x - 2)^2(x + 3)$ and the third factor is $(x - 2)$ again — a repeated root.
:::

::: watch
- **Dividing by $(x + 3)$ means substituting $x = -3$**, not $+3$. Set the bracket equal to zero and solve — every time.
- Dividing by $(2x - 1)$: substitute $x = \frac12$. The theorem gives the remainder; it does not care about the 2 in front.
- After you find one factor, **always divide out and factorise the rest**. "Factorise completely" means three linear factors if they exist. The mark scheme has marks for the quadratic quotient.
- Check your quotient by the term you did not use — takes five seconds and catches most slips.
- In simultaneous equations, substitute the **linear** into the **quadratic**, never the other way round. Give each $x$ with its own $y$; a bare list of $x$ values is not a solution.
- "Hence" questions: if you were told $(x - 2)$ is a factor, use it — do not start hunting for roots from scratch.
:::
