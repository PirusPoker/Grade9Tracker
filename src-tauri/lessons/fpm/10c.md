## What it is

Two identities — true for **every** angle — connect the three ratios:

$$\sin^2\theta + \cos^2\theta = 1, \qquad \tan\theta = \frac{\sin\theta}{\cos\theta}$$

They let you swap one ratio for another: $\cos^2\theta = 1 - \sin^2\theta$ turns an equation with both $\sin$ and $\cos^2$ into a quadratic in $\sin$ alone; dividing $\sin\theta = 2\cos\theta$ by $\cos\theta$ turns it into $\tan\theta = 2$.

The **addition formulae** give the ratios of a sum or difference of angles (on the formula sheet, but you should know them):

$$\sin(A \pm B) = \sin A\cos B \pm \cos A\sin B$$
$$\cos(A \pm B) = \cos A\cos B \mp \sin A\sin B$$
$$\tan(A \pm B) = \frac{\tan A \pm \tan B}{1 \mp \tan A\tan B}$$

(Note $\cos$ has the **opposite** sign in the middle.) With $A = B$ they give the double-angle results: $\sin 2A = 2\sin A\cos A$ and $\cos 2A = \cos^2 A - \sin^2 A = 2\cos^2 A - 1 = 1 - 2\sin^2 A$.

**Solving equations** in a given interval is the skill everything above feeds into. An equation like $\sin x = 0.5$ has infinitely many solutions; the interval tells you which to give. The calculator gives you one (the **principal value**); the graph or the CAST diagram gives you the rest.

::: method
1. **Rearrange to one ratio equals a number:** $\sin x = k$, $\cos x = k$ or $\tan x = k$. That may need the identities first (see steps 5–6).
2. **Principal value** from the calculator: $x = \sin^{-1} k$ etc. Make sure the mode (degrees or radians) matches the interval.
3. **The other solutions in one full turn:**
   - $\sin x = k$: $x$ and $180° - x$ (or $\pi - x$).
   - $\cos x = k$: $x$ and $360° - x$ (or $2\pi - x$), i.e. $\pm x$.
   - $\tan x = k$: $x$ and $x + 180°$ (or $x + \pi$).
   Then add or subtract $360°$ ($2\pi$) — or $180°$ ($\pi$) for tan — to land every solution in the interval.
4. **Compound arguments** like $\sin(2x + 30°)$ or $\cos(3x)$: let $u$ be the whole bracket. **Change the interval** to one for $u$ (multiply the ends by the coefficient, add the shift), solve for $u$ in that wider interval, then convert each $u$ back to $x$. The wider interval is what catches the extra solutions.
5. **Quadratics in a ratio:** $6\cos^2 x + \sin x - 5 = 0$ — replace $\cos^2 x$ by $1 - \sin^2 x$ to get a quadratic in $\sin x$; factorise; solve each factor as a separate equation. Reject any $\sin x$ or $\cos x$ outside $[-1, 1]$.
6. **$\sin$ equals a multiple of $\cos$:** divide through by $\cos x$ to get $\tan x$. (You may divide because $\cos x = 0$ would force $\sin x = 0$ too, which is impossible.)
7. **Addition formulae:** expand, collect, and it usually reduces to one of the forms above. For exact values, split the angle into two from the table: $75° = 45° + 30°$, $15° = 45° - 30°$.
8. **List every solution**, in order, to the accuracy asked; check the count against a quick sketch.
:::

::: example A basic equation with two solutions
Solve $\cos x = -0.4$ for $0 \le x \le 360°$.

Principal value $\cos^{-1}(-0.4) = 113.6°$. Cos: the other is $360° - 113.6° = 246.4°$.

$x = 113.6°, 246.4°$.
:::

::: example Tan, in radians
Solve $\tan 2x = 1$ for $90° < x < 270°$ — and the same equation, $\tan 2x = 1$ for $0 \le x \le \pi$.

Let $u = 2x$. For $90° < x < 270°$: $180° < u < 540°$. $\tan u = 1$: principal $45°$; add $180°$ repeatedly: $225°, 405°$ are in range. So $x = 112.5°, 202.5°$.

For $0 \le x \le \pi$: $0 \le u \le 2\pi$. $u = \dfrac\pi4, \dfrac{5\pi}{4}$, so $x = \dfrac\pi8, \dfrac{5\pi}{8}$.
:::

::: example A shifted argument
Solve $\cos(3x + 30°) = \dfrac12$ for $-90° < x < 90°$.

Let $u = 3x + 30°$. As $x$ runs from $-90°$ to $90°$, $u$ runs from $-240°$ to $300°$.

$\cos u = \frac12$: principal value $60°$; cos gives $\pm 60°$; then step by $360°$: $-420°, -300°, -60°, 60°, 300°, 420°$.

Inside $-240° < u < 300°$: only $u = -60°$ and $u = 60°$ ($300°$ itself is excluded by the strict inequality).

$x = \dfrac{u - 30°}{3}$: $x = -30°$ and $x = 10°$.
:::

::: example Quadratic in one ratio
Solve $6\cos^2 x + \sin x - 5 = 0$ for $0 \le x < 360°$.

$6(1 - \sin^2 x) + \sin x - 5 = 0 \Rightarrow 6\sin^2 x - \sin x - 1 = 0 \Rightarrow (3\sin x + 1)(2\sin x - 1) = 0$.

$\sin x = \dfrac12$: $x = 30°, 150°$.

$\sin x = -\dfrac13$: principal $-19.5°$; in range, $180° + 19.5° = 199.5°$ and $360° - 19.5° = 340.5°$.

$x = 30°, 150°, 199.5°, 340.5°$.
:::

::: example Sine equals a multiple of cosine
Solve $3\sin x = 2\cos x$ for $-\pi \le x < \pi$.

Divide by $\cos x$: $\tan x = \dfrac23$. Principal $0.588$ rad; tan repeats every $\pi$: $0.588 - \pi = -2.554$.

$x = -2.55, 0.588$ (3 s.f.).
:::

::: example Exact value with the addition formula
Find the exact value of $\sin 75°$.

$\sin 75° = \sin(45° + 30°) = \sin 45°\cos 30° + \cos 45°\sin 30° = \dfrac{\sqrt2}{2} \cdot \dfrac{\sqrt3}{2} + \dfrac{\sqrt2}{2} \cdot \dfrac12 = \dfrac{\sqrt6 + \sqrt2}{4}$.
:::

::: example Proving an identity
Prove that $\dfrac{\sin\theta}{1 + \cos\theta} + \dfrac{1 + \cos\theta}{\sin\theta} = \dfrac{2}{\sin\theta}$.

Left side over a common denominator: $\dfrac{\sin^2\theta + (1 + \cos\theta)^2}{\sin\theta(1 + \cos\theta)} = \dfrac{\sin^2\theta + 1 + 2\cos\theta + \cos^2\theta}{\sin\theta(1 + \cos\theta)}$.

Use $\sin^2 + \cos^2 = 1$: $= \dfrac{2 + 2\cos\theta}{\sin\theta(1 + \cos\theta)} = \dfrac{2(1 + \cos\theta)}{\sin\theta(1 + \cos\theta)} = \dfrac{2}{\sin\theta}$. ∎
:::

::: q
Solve $\sin\left(x - \dfrac\pi3\right) = \dfrac{\sqrt3}{2}$ for $0 < x < 2\pi$.
---
$u = x - \dfrac\pi3 \in \left(-\dfrac\pi3, \dfrac{5\pi}{3}\right)$. $\sin u = \dfrac{\sqrt3}{2}$: $u = \dfrac\pi3, \dfrac{2\pi}{3}$. $x = \dfrac{2\pi}{3}, \pi$.
:::

::: q
Solve $\tan\left(2x + \dfrac\pi4\right) = 1$ for $0 \le x \le \pi$.
---
$u = 2x + \dfrac\pi4 \in \left[\dfrac\pi4, \dfrac{9\pi}{4}\right]$. $\tan u = 1$: $u = \dfrac\pi4, \dfrac{5\pi}{4}, \dfrac{9\pi}{4}$. $x = 0, \dfrac\pi2, \pi$.
:::

::: q
Solve $2\sin^2 x - \sin x - 1 = 0$ for $0 \le x < 360°$.
---
$(2\sin x + 1)(\sin x - 1) = 0$. $\sin x = 1$: $x = 90°$. $\sin x = -\dfrac12$: $x = 210°, 330°$.
:::

::: q
Solve $2\cos^2 x + 3\sin x = 3$ for $0 \le x \le 360°$.
---
$2 - 2\sin^2 x + 3\sin x - 3 = 0 \Rightarrow 2\sin^2 x - 3\sin x + 1 = 0 \Rightarrow (2\sin x - 1)(\sin x - 1) = 0$.

$\sin x = \dfrac12$: $30°, 150°$. $\sin x = 1$: $90°$. $x = 30°, 90°, 150°$.
:::

::: q
Solve $5\sin x = 3\cos x$ for $0 \le x \le 2\pi$, to 3 s.f.
---
$\tan x = 0.6$: $x = 0.540$, $0.540 + \pi = 3.68$.
:::

::: q
Solve $\sin x\cos x = \dfrac14$ for $0 \le x \le 360°$. (Hint: $\sin 2x = 2\sin x\cos x$.)
---
$\sin 2x = \dfrac12$; $u = 2x \in [0, 720°]$: $u = 30°, 150°, 390°, 510°$. $x = 15°, 75°, 195°, 255°$.
:::

::: q
Find the exact value of $\cos 15°$ and of $\tan 75°$.
---
$\cos 15° = \cos(45° - 30°) = \dfrac{\sqrt2}{2}\cdot\dfrac{\sqrt3}{2} + \dfrac{\sqrt2}{2}\cdot\dfrac12 = \dfrac{\sqrt6 + \sqrt2}{4}$.

$\tan 75° = \dfrac{\tan 45° + \tan 30°}{1 - \tan 45°\tan 30°} = \dfrac{1 + \frac{1}{\sqrt3}}{1 - \frac{1}{\sqrt3}} = \dfrac{\sqrt3 + 1}{\sqrt3 - 1} = \dfrac{(\sqrt3 + 1)^2}{2} = 2 + \sqrt3$.
:::

::: q
Given $\sin A = \dfrac35$ with $A$ acute and $\cos B = \dfrac{5}{13}$ with $B$ acute, find the exact value of $\sin(A + B)$.
---
$\cos A = \dfrac45$, $\sin B = \dfrac{12}{13}$. $\sin(A + B) = \dfrac35 \cdot \dfrac{5}{13} + \dfrac45 \cdot \dfrac{12}{13} = \dfrac{15 + 48}{65} = \dfrac{63}{65}$.
:::

::: q
Prove that $(\sin\theta + \cos\theta)^2 = 1 + 2\sin\theta\cos\theta$.
---
$(\sin\theta + \cos\theta)^2 = \sin^2\theta + 2\sin\theta\cos\theta + \cos^2\theta = 1 + 2\sin\theta\cos\theta$, using $\sin^2\theta + \cos^2\theta = 1$. ∎
:::

::: q
Solve $\sin(x + 30°) = \cos x$ for $0 \le x \le 360°$.
---
$\sin x\cos 30° + \cos x\sin 30° = \cos x \Rightarrow \dfrac{\sqrt3}{2}\sin x = \dfrac12\cos x \Rightarrow \tan x = \dfrac{1}{\sqrt3}$.

$x = 30°, 210°$.
:::

::: watch
- **Change the interval for the bracket.** For $\sin 2x$ on $0$ to $360°$ you solve for $2x$ on $0$ to $720°$ — that is where the third and fourth solutions live. Solving for $x$ first and then halving finds only half of them.
- Don't divide by $\sin x$ or $\cos x$ when it could be zero — you lose solutions. $\sin x\cos x = \sin x$ is **not** $\cos x = 1$; it is $\sin x(\cos x - 1) = 0$.
- Reject $\sin x = 1.3$ or $\cos x = -2$ with a sentence: "no solutions since $-1 \le \cos x \le 1$." The rejection is a mark.
- Radians or degrees: the interval tells you. $0 < x < 2\pi$ means radians, calculator in RAD, and answers as multiples of $\pi$ if exact.
- Proving an identity: work on one side only until it becomes the other. Never move terms across the $=$ as if it were an equation.
- Check the count with a sketch: $\sin x = k$ ($0 < k < 1$) has exactly two solutions per full turn; $\tan x = k$ has one per half turn.
:::
