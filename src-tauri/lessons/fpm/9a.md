## What it is

Differentiating finds the **gradient function**: from $y = f(x)$ you get $\dfrac{dy}{dx}$, which tells you the gradient of the curve at any $x$. Everything in the calculus section — tangents, maxima, rates of change, kinematics — starts here.

The results you must know (no proofs needed):

| $y$ | $\dfrac{dy}{dx}$ |
|---|---|
| $x^n$ | $nx^{n-1}$ |
| $\sin ax$ | $a\cos ax$ |
| $\cos ax$ | $-a\sin ax$ |
| $e^{ax}$ | $ae^{ax}$ |

A constant in front stays; terms added together are differentiated one at a time; a constant on its own differentiates to $0$. Angles are in **radians** for the trig results.

Then three rules for combinations — the rules are the whole point of this topic:

- **Chain rule** (a function of a function): if $y = f(u)$ and $u = g(x)$, then $\dfrac{dy}{dx} = \dfrac{dy}{du} \times \dfrac{du}{dx}$. In practice: differentiate the outside, keep the inside, multiply by the derivative of the inside.
- **Product rule:** if $y = uv$, then $\dfrac{dy}{dx} = u\dfrac{dv}{dx} + v\dfrac{du}{dx}$.
- **Quotient rule:** if $y = \dfrac{u}{v}$, then $\dfrac{dy}{dx} = \dfrac{v\dfrac{du}{dx} - u\dfrac{dv}{dx}}{v^2}$. (Top first on top; minus; over bottom squared.)

::: method
1. **Get every term into the form $ax^n$ first.** $\sqrt x = x^{1/2}$, $\dfrac{3}{x^2} = 3x^{-2}$, $\dfrac{x^3 + 1}{x} = x^2 + x^{-1}$. Expand brackets when it is a simple product like $x(2x - 1)$.
2. **Power rule:** multiply by the power, then reduce the power by one. Negative and fractional powers follow the same rule: $x^{-2} \to -2x^{-3}$; $x^{1/2} \to \frac12 x^{-1/2}$.
3. **Chain rule** whenever there is something other than plain $x$ inside a power, a trig function or an exponential: $(3x + 1)^5$, $\sin 2x$, $e^{-x^2}$, $\sqrt{x^2 + 1}$. Differentiate the outer function with the inside left alone, then multiply by the derivative of the inside.
4. **Product rule** when two functions of $x$ are multiplied: $x^2 e^{3x}$, $x \sin x$. Write $u$ and $v$ and their derivatives down first, then assemble.
5. **Quotient rule** when one function is divided by another. Get the order right: $v\,u' - u\,v'$. Simplify the top by factorising if you can.
6. **Tidy up** — factorise out common factors, write negative powers back as fractions if the question wants "in the form…". Second derivatives ($\dfrac{d^2y}{dx^2}$): differentiate again.
:::

::: example Powers, including negative and fractional
Differentiate $y = 4x^3 - \dfrac{2}{x} + 6\sqrt x - 7$.

Rewrite: $y = 4x^3 - 2x^{-1} + 6x^{1/2} - 7$.

$\dfrac{dy}{dx} = 12x^2 + 2x^{-2} + 3x^{-1/2} = 12x^2 + \dfrac{2}{x^2} + \dfrac{3}{\sqrt x}$.
:::

::: example Trig and exponentials
Differentiate $y = 3\sin 2x - \cos 4x + 5e^{-x}$.

$\dfrac{dy}{dx} = 6\cos 2x + 4\sin 4x - 5e^{-x}$.

(The $\cos$ brings a minus, which cancels the minus already there; the $e^{-x}$ brings a factor of $-1$ from the chain rule.)
:::

::: example Chain rule
Differentiate (a) $y = (2x^2 - 3)^5$, (b) $y = \sqrt{1 + 4x}$, (c) $y = e^{x^2}$.

(a) Outside: $(\ )^5 \to 5(\ )^4$; inside: $2x^2 - 3 \to 4x$. $\dfrac{dy}{dx} = 5(2x^2 - 3)^4 \times 4x = 20x(2x^2 - 3)^4$.

(b) $y = (1 + 4x)^{1/2}$: $\dfrac{dy}{dx} = \dfrac12(1 + 4x)^{-1/2} \times 4 = \dfrac{2}{\sqrt{1 + 4x}}$.

(c) $\dfrac{dy}{dx} = e^{x^2} \times 2x = 2xe^{x^2}$.
:::

::: example Product rule
Differentiate $y = x^2 \sin 3x$.

$u = x^2$, $u' = 2x$; $v = \sin 3x$, $v' = 3\cos 3x$.

$\dfrac{dy}{dx} = uv' + vu' = 3x^2\cos 3x + 2x\sin 3x = x(3x\cos 3x + 2\sin 3x)$.
:::

::: example Quotient rule
Differentiate $y = \dfrac{e^{2x}}{x + 1}$.

$u = e^{2x}$, $u' = 2e^{2x}$; $v = x + 1$, $v' = 1$.

$\dfrac{dy}{dx} = \dfrac{(x + 1)(2e^{2x}) - e^{2x}(1)}{(x + 1)^2} = \dfrac{e^{2x}(2x + 2 - 1)}{(x + 1)^2} = \dfrac{e^{2x}(2x + 1)}{(x + 1)^2}$.
:::

::: example Product rule with the chain rule inside
Differentiate $y = x(2x - 1)^3$ and write the answer in factorised form.

$u = x$, $u' = 1$; $v = (2x - 1)^3$, $v' = 3(2x - 1)^2 \times 2 = 6(2x - 1)^2$.

$\dfrac{dy}{dx} = 6x(2x - 1)^2 + (2x - 1)^3 = (2x - 1)^2(6x + 2x - 1) = (2x - 1)^2(8x - 1)$.
:::

::: q
Differentiate $y = 5x^4 - 3x^2 + 2x - 9$.
---
$\dfrac{dy}{dx} = 20x^3 - 6x + 2$.
:::

::: q
Differentiate $y = \dfrac{6}{x^3} + 4\sqrt x - \dfrac{1}{\sqrt x}$.
---
$y = 6x^{-3} + 4x^{1/2} - x^{-1/2}$: $\dfrac{dy}{dx} = -18x^{-4} + 2x^{-1/2} + \dfrac12 x^{-3/2} = -\dfrac{18}{x^4} + \dfrac{2}{\sqrt x} + \dfrac{1}{2x\sqrt x}$.
:::

::: q
Differentiate $y = \dfrac{x^3 - 2x + 5}{x}$.
---
$y = x^2 - 2 + 5x^{-1}$: $\dfrac{dy}{dx} = 2x - \dfrac{5}{x^2}$.
:::

::: q
Differentiate $y = 2\cos 3x + \sin\dfrac{x}{2} - 4e^{2x}$.
---
$\dfrac{dy}{dx} = -6\sin 3x + \dfrac12\cos\dfrac x2 - 8e^{2x}$.
:::

::: q
Differentiate $y = (3x^2 + 1)^4$.
---
$\dfrac{dy}{dx} = 4(3x^2 + 1)^3 \times 6x = 24x(3x^2 + 1)^3$.
:::

::: q
Differentiate $y = \dfrac{1}{(2x - 5)^3}$.
---
$y = (2x - 5)^{-3}$: $\dfrac{dy}{dx} = -3(2x - 5)^{-4} \times 2 = -\dfrac{6}{(2x - 5)^4}$.
:::

::: q
Differentiate $y = \sin^2 x$ (that is, $(\sin x)^2$).
---
$\dfrac{dy}{dx} = 2\sin x \times \cos x = 2\sin x\cos x$ (which is $\sin 2x$).
:::

::: q
Differentiate $y = e^{3x}\cos 2x$.
---
$u = e^{3x}$, $u' = 3e^{3x}$; $v = \cos 2x$, $v' = -2\sin 2x$.

$\dfrac{dy}{dx} = -2e^{3x}\sin 2x + 3e^{3x}\cos 2x = e^{3x}(3\cos 2x - 2\sin 2x)$.
:::

::: q
Differentiate $y = x^3\sqrt{x + 2}$.
---
$u = x^3$, $u' = 3x^2$; $v = (x + 2)^{1/2}$, $v' = \dfrac{1}{2\sqrt{x + 2}}$.

$\dfrac{dy}{dx} = \dfrac{x^3}{2\sqrt{x + 2}} + 3x^2\sqrt{x + 2} = \dfrac{x^3 + 6x^2(x + 2)}{2\sqrt{x + 2}} = \dfrac{x^2(7x + 12)}{2\sqrt{x + 2}}$.
:::

::: q
Differentiate $y = \dfrac{x^2}{2x + 1}$.
---
$\dfrac{dy}{dx} = \dfrac{(2x + 1)(2x) - x^2(2)}{(2x + 1)^2} = \dfrac{4x^2 + 2x - 2x^2}{(2x + 1)^2} = \dfrac{2x^2 + 2x}{(2x + 1)^2} = \dfrac{2x(x + 1)}{(2x + 1)^2}$.
:::

::: q
Differentiate $y = \dfrac{\sin x}{e^{x}}$.
---
$\dfrac{dy}{dx} = \dfrac{e^x\cos x - \sin x\, e^x}{e^{2x}} = \dfrac{\cos x - \sin x}{e^x}$.
:::

::: q
Find $\dfrac{d^2y}{dx^2}$ for $y = 2x^3 - \dfrac{4}{x}$ and evaluate it at $x = 1$.
---
$y = 2x^3 - 4x^{-1}$; $\dfrac{dy}{dx} = 6x^2 + 4x^{-2}$; $\dfrac{d^2y}{dx^2} = 12x - 8x^{-3}$. At $x = 1$: $12 - 8 = 4$.
:::

::: watch
- **Rewrite before you differentiate.** Roots and fractions must become powers; $\dfrac{1}{x^2}$ is $x^{-2}$, and its derivative is $-2x^{-3}$, not $-2x^{-1}$.
- **The chain rule multiplier is not optional.** $\sin 3x$ differentiates to $3\cos 3x$; $(2x + 1)^4$ to $8(2x + 1)^3$. Forgetting the inside derivative is the most common lost mark in the whole paper.
- Quotient rule order: $\dfrac{v\,u' - u\,v'}{v^2}$. Swap them and the sign is wrong. Say "bottom times derivative of top, minus top times derivative of bottom" out loud.
- $\cos$ differentiates to **minus** $\sin$. $\sin$ differentiates to **plus** $\cos$. Two minuses can cancel; write each one out.
- Trig differentiation is in **radians**. If a question mixes degrees in, convert first.
- Factorise your answer when the question says "show that" — the printed form is almost always the factorised one.
:::
