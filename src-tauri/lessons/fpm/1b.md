## What it is

A **surd** is a root that does not come out as a whole number or a fraction — $\sqrt 2$, $\sqrt 3$, $\sqrt{48}$. Surds are how you give an **exact** answer: $\sqrt 2$ is exactly right; $1.414$ is not. Further Maths asks for exact answers constantly, so surds are everywhere: the quadratic formula, trig exact values, lengths from Pythagoras, coordinates.

The two skills are **simplifying** (taking out square factors) and **rationalising** (getting rid of a surd on the bottom of a fraction). Both rest on one fact:

$$\sqrt{a} \times \sqrt{b} = \sqrt{ab}, \qquad \text{so } \sqrt{ab} = \sqrt a \, \sqrt b$$

Indices are the other half of this topic: the laws you know from GCSE, used with fractional and negative powers, and the fact that $\sqrt[n]{x} = x^{1/n}$ ties surds and indices together.

::: terms
- **Surd**: an irrational root that cannot be written exactly as a fraction, such as √3.
- **Simplifying surds**: √(ab) = √a × √b, so take out square factors: √75 = 5√3.
- **Rationalising the denominator**: removing surds from the denominator by multiplying top and bottom by the surd, or by the conjugate.
- **Conjugate**: a + √b and a − √b; their product a² − b is rational.
- **Fractional index**: a^(m/n) = (ⁿ√a)ᵐ.
- **Negative index**: a⁻ⁿ = 1/aⁿ.
:::

::: method
1. **Simplify a surd:** find the biggest square number that divides it. $\sqrt{48} = \sqrt{16 \times 3} = 4\sqrt 3$. If you miss the biggest square, simplify again: $\sqrt{48} = \sqrt{4 \times 12} = 2\sqrt{12} = 2 \times 2\sqrt 3 = 4\sqrt 3$.
2. **Add and subtract** only like surds, exactly like collecting terms: $5\sqrt 3 + 2\sqrt 3 = 7\sqrt 3$. Simplify first so like surds show themselves: $\sqrt{12} + \sqrt{27} = 2\sqrt 3 + 3\sqrt 3 = 5\sqrt 3$.
3. **Multiply** by multiplying numbers with numbers and surds with surds: $2\sqrt 3 \times 5\sqrt 6 = 10\sqrt{18} = 10 \times 3\sqrt 2 = 30\sqrt 2$. Expand brackets the usual way.
4. **Rationalise a single surd** on the bottom by multiplying top and bottom by that surd: $\dfrac{10}{\sqrt 5} = \dfrac{10\sqrt 5}{5} = 2\sqrt 5$.
5. **Rationalise $a + \sqrt b$** on the bottom by multiplying top and bottom by its **conjugate** $a - \sqrt b$ (change the sign in the middle). The bottom becomes $a^2 - b$ by the difference of two squares, with no surd left.
6. **Indices:** $a^m \times a^n = a^{m+n}$, $a^m \div a^n = a^{m-n}$, $(a^m)^n = a^{mn}$, $a^{-n} = \dfrac{1}{a^n}$, $a^{1/n} = \sqrt[n]{a}$, $a^{m/n} = (\sqrt[n]{a})^m$, $a^0 = 1$. For $a^{m/n}$, take the root **first** — the numbers stay small.
:::

::: example Simplifying and collecting
Simplify $\sqrt{75} - \sqrt{12} + \sqrt{27}$.

$\sqrt{75} = \sqrt{25 \times 3} = 5\sqrt 3$, $\quad\sqrt{12} = \sqrt{4 \times 3} = 2\sqrt 3$, $\quad\sqrt{27} = \sqrt{9 \times 3} = 3\sqrt 3$.

$5\sqrt 3 - 2\sqrt 3 + 3\sqrt 3 = 6\sqrt 3$.
:::

::: example Expanding brackets with surds
Expand and simplify $(3 + 2\sqrt 5)(1 - \sqrt 5)$.

$= 3 - 3\sqrt 5 + 2\sqrt 5 - 2\sqrt 5 \times \sqrt 5$

$= 3 - 3\sqrt 5 + 2\sqrt 5 - 2 \times 5$

$= 3 - 10 - \sqrt 5 = -7 - \sqrt 5$.
:::

::: example Rationalising with a conjugate
Write $\dfrac{4}{3 - \sqrt 5}$ in the form $a + b\sqrt 5$.

Multiply top and bottom by the conjugate $3 + \sqrt 5$:

$\dfrac{4(3 + \sqrt 5)}{(3 - \sqrt 5)(3 + \sqrt 5)} = \dfrac{12 + 4\sqrt 5}{9 - 5} = \dfrac{12 + 4\sqrt 5}{4} = 3 + \sqrt 5$.

So $a = 3$, $b = 1$.
:::

::: example A harder rationalisation
Simplify $\dfrac{\sqrt 6 + \sqrt 2}{\sqrt 6 - \sqrt 2}$.

Multiply top and bottom by $\sqrt 6 + \sqrt 2$:

Top: $(\sqrt 6 + \sqrt 2)^2 = 6 + 2\sqrt{12} + 2 = 8 + 4\sqrt 3$.

Bottom: $(\sqrt 6)^2 - (\sqrt 2)^2 = 6 - 2 = 4$.

Result: $\dfrac{8 + 4\sqrt 3}{4} = 2 + \sqrt 3$.
:::

::: example Fractional and negative indices
Evaluate $27^{2/3}$, $16^{-3/4}$ and $\left(\dfrac{4}{9}\right)^{-1/2}$.

$27^{2/3} = (\sqrt[3]{27})^2 = 3^2 = 9$.

$16^{-3/4} = \dfrac{1}{16^{3/4}} = \dfrac{1}{(\sqrt[4]{16})^3} = \dfrac{1}{2^3} = \dfrac{1}{8}$.

$\left(\dfrac{4}{9}\right)^{-1/2} = \left(\dfrac{9}{4}\right)^{1/2} = \dfrac{3}{2}$.
:::

::: example Solving an index equation
Solve $2^{x} \times 4^{x+1} = 8^{5}$.

Write everything in base 2: $2^x \times 2^{2(x+1)} = 2^{15}$.

$2^{x + 2x + 2} = 2^{15}$, so $3x + 2 = 15$, so $x = \dfrac{13}{3}$.
:::

::: q
Simplify $\sqrt{50} + \sqrt{18} - \sqrt{8}$.
---
$5\sqrt 2 + 3\sqrt 2 - 2\sqrt 2 = 6\sqrt 2$.
:::

::: q
Expand and simplify $(2\sqrt 3 - 1)(2\sqrt 3 + 5)$.
---
$= 4 \times 3 + 10\sqrt 3 - 2\sqrt 3 - 5 = 12 - 5 + 8\sqrt 3 = 7 + 8\sqrt 3$.
:::

::: q
Rationalise the denominator of $\dfrac{12}{\sqrt 6}$.
---
$\dfrac{12\sqrt 6}{6} = 2\sqrt 6$.
:::

::: q
Write $\dfrac{5}{2 + \sqrt 3}$ in the form $a + b\sqrt 3$ where $a$ and $b$ are integers.
---
Multiply by $\dfrac{2 - \sqrt 3}{2 - \sqrt 3}$: $\dfrac{5(2 - \sqrt 3)}{4 - 3} = 10 - 5\sqrt 3$. So $a = 10$, $b = -5$.
:::

::: q
Write $\dfrac{\sqrt 7 + 1}{\sqrt 7 - 2}$ in the form $a + b\sqrt 7$.
---
Multiply by $\dfrac{\sqrt 7 + 2}{\sqrt 7 + 2}$.

Top: $(\sqrt 7 + 1)(\sqrt 7 + 2) = 7 + 2\sqrt 7 + \sqrt 7 + 2 = 9 + 3\sqrt 7$.

Bottom: $7 - 4 = 3$.

Answer: $3 + \sqrt 7$.
:::

::: q
A rectangle has area $12$ cm$^2$ and one side of length $(3 - \sqrt 3)$ cm. Find the other side in the form $a + b\sqrt 3$.
---
Other side $= \dfrac{12}{3 - \sqrt 3} = \dfrac{12(3 + \sqrt 3)}{9 - 3} = \dfrac{12(3 + \sqrt 3)}{6} = 6 + 2\sqrt 3$ cm.
:::

::: q
Evaluate $8^{4/3}$, $25^{-1/2}$ and $\left(\dfrac{27}{8}\right)^{-2/3}$.
---
$8^{4/3} = (\sqrt[3]{8})^4 = 2^4 = 16$.

$25^{-1/2} = \dfrac{1}{\sqrt{25}} = \dfrac{1}{5}$.

$\left(\dfrac{27}{8}\right)^{-2/3} = \left(\dfrac{8}{27}\right)^{2/3} = \left(\dfrac{2}{3}\right)^2 = \dfrac{4}{9}$.
:::

::: q
Simplify $\dfrac{(2x^3)^2 \times 3x^{-1}}{6x^{2}}$.
---
$\dfrac{4x^6 \times 3x^{-1}}{6x^2} = \dfrac{12x^5}{6x^2} = 2x^3$.
:::

::: q
Solve $9^{x} = 27^{x - 1}$.
---
Base 3: $3^{2x} = 3^{3(x-1)}$, so $2x = 3x - 3$, so $x = 3$.
:::

::: q
Solve $x^{-2/3} = 4$.
---
$x^{2/3} = \dfrac{1}{4}$, so $x = \left(\dfrac{1}{4}\right)^{3/2} = \left(\dfrac{1}{2}\right)^3 = \dfrac{1}{8}$.

(Check: $\left(\frac18\right)^{-2/3} = 8^{2/3} = 4$. ✓)
:::

::: q
The solutions of $x^2 - 6x + 4 = 0$ are $x = a \pm b\sqrt 5$. Find $a$ and $b$.
---
$x = \dfrac{6 \pm \sqrt{36 - 16}}{2} = \dfrac{6 \pm \sqrt{20}}{2} = \dfrac{6 \pm 2\sqrt 5}{2} = 3 \pm \sqrt 5$.

$a = 3$, $b = 1$.
:::

::: watch
- **"Exact" means leave the surd in.** The moment you write $2.236$ the mark is gone.
- Always give a surd in **simplest form**: $\sqrt{20}$ loses the mark, $2\sqrt 5$ gets it. Check your final surd has no square factor left.
- When rationalising with a conjugate, the sign in the middle flips and **nothing else** changes. $(3 - \sqrt 5)$ pairs with $(3 + \sqrt 5)$, not $(-3 + \sqrt 5)$.
- $\sqrt{a + b}$ is **not** $\sqrt a + \sqrt b$. Only products and quotients split.
- $a^{m/n}$: root first, then power. $27^{2/3}$ as $\sqrt[3]{729}$ works but is hard; as $3^2$ it is instant.
- A negative index means reciprocal, **not** a negative number: $4^{-1/2} = \dfrac12$, not $-2$.
:::
