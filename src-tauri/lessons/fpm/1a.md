## What it is

A logarithm answers one question: **what power do I raise the base to?**

$$\log_a x = y \quad\Longleftrightarrow\quad a^y = x$$

So $\log_2 8 = 3$ because $2^3 = 8$, and $\log_{10} 1000 = 3$ because $10^3 = 1000$. The base $a$ is a positive number other than 1, and you can only take the log of a **positive** number — there is no power of 2 that gives $-8$ or $0$.

Two bases have their own buttons on your calculator: $\log$ means base 10, and $\ln$ means base $e$ ($e \approx 2.718$, the "natural" base). Any other base you handle by the laws below.

The graphs come as a pair. $y = a^x$ (with $a > 1$) passes through $(0, 1)$, is always above the $x$-axis, and climbs steeply to the right; the $x$-axis is an asymptote on the left. $y = \log_a x$ is its reflection in the line $y = x$: it passes through $(1, 0)$, exists only for $x > 0$, and the $y$-axis is its asymptote. You are expected to sketch both, not to find their gradients.

::: method
1. Turn any log statement into an index statement and back: $\log_a x = y$ means $a^y = x$. When stuck, do this first.
2. Know the five laws and which direction you are using them in:
   - $\log_a x + \log_a y = \log_a (xy)$
   - $\log_a x - \log_a y = \log_a \left(\dfrac{x}{y}\right)$
   - $k \log_a x = \log_a x^k$
   - $\log_a a = 1$ and $\log_a 1 = 0$
3. To solve $a^x = b$, take logs of both sides (any base): $x \log a = \log b$, so $x = \dfrac{\log b}{\log a}$.
4. To evaluate a log in an awkward base, change the base: $\log_a x = \dfrac{\log_b x}{\log_b a}$, and in particular $\log_a b = \dfrac{1}{\log_b a}$.
5. When an equation has logs on both sides, collect them into a single log on each side, then drop the logs. Check every answer in the original equation — a log of a negative number is not a solution.
:::

::: example Evaluating without a calculator
Find $\log_3 81$, $\log_5 \dfrac{1}{25}$ and $\log_{16} 2$.

$\log_3 81 = 4$ because $3^4 = 81$.

$\log_5 \dfrac{1}{25} = -2$ because $5^{-2} = \dfrac{1}{25}$.

$\log_{16} 2$: ask what power of 16 gives 2. Since $16^{1/4} = 2$, the answer is $\dfrac{1}{4}$.
:::

::: example Combining logs into one
Write $2\log_a 3 + \log_a 5 - \log_a 15$ as a single logarithm.

Bring the coefficient inside first: $2\log_a 3 = \log_a 9$.

Then add and subtract: $\log_a 9 + \log_a 5 - \log_a 15 = \log_a \dfrac{9 \times 5}{15} = \log_a 3$.
:::

::: example Solving $a^x = b$
Solve $5^x = 40$, giving your answer to 3 significant figures.

Take logs of both sides: $x \log 5 = \log 40$.

$x = \dfrac{\log 40}{\log 5} = \dfrac{1.6021}{0.6990} = 2.29$ (3 s.f.).

The same method handles anything in the exponent: for $3^{2x-1} = 20$, you get $(2x - 1)\log 3 = \log 20$, so $2x - 1 = 2.727$ and $x = 1.86$.
:::

::: example An equation with logs on both sides
Solve $\log_2 (x + 4) + \log_2 (x - 2) = 4$.

Combine the left side: $\log_2 \big((x+4)(x-2)\big) = 4$.

Drop the log: $(x+4)(x-2) = 2^4 = 16$.

Expand: $x^2 + 2x - 8 = 16$, so $x^2 + 2x - 24 = 0$, so $(x + 6)(x - 4) = 0$.

$x = 4$ or $x = -6$. But $x = -6$ makes $\log_2(x - 2) = \log_2(-8)$, which does not exist. So $x = 4$ only.
:::

::: example Change of base
Given that $\log_2 3 = p$, express $\log_8 3$ and $\log_3 2$ in terms of $p$.

$\log_8 3 = \dfrac{\log_2 3}{\log_2 8} = \dfrac{p}{3}$.

$\log_3 2 = \dfrac{1}{\log_2 3} = \dfrac{1}{p}$.
:::

::: q
Evaluate $\log_2 32$, $\log_7 1$ and $\log_4 8$ without a calculator.
---
$\log_2 32 = 5$ since $2^5 = 32$.

$\log_7 1 = 0$ since $7^0 = 1$.

$\log_4 8$: $4^{3/2} = (\sqrt 4)^3 = 8$, so $\log_4 8 = \dfrac{3}{2}$.
:::

::: q
Write $3\log_a 2 - \log_a 4 + \log_a 5$ as a single logarithm.
---
$3\log_a 2 = \log_a 8$. Then $\log_a 8 - \log_a 4 + \log_a 5 = \log_a \dfrac{8 \times 5}{4} = \log_a 10$.
:::

::: q
Solve $7^x = 200$, giving $x$ to 3 significant figures.
---
$x \log 7 = \log 200$, so $x = \dfrac{\log 200}{\log 7} = 2.72$ (3 s.f.).
:::

::: q
Solve $2^{3x + 1} = 50$, giving $x$ to 3 significant figures.
---
$(3x + 1)\log 2 = \log 50$, so $3x + 1 = \dfrac{\log 50}{\log 2} = 5.644$.

$3x = 4.644$, so $x = 1.55$ (3 s.f.).
:::

::: q
Solve $\log_3 x + \log_3 (x - 6) = 3$.
---
$\log_3 \big(x(x-6)\big) = 3$, so $x(x - 6) = 27$.

$x^2 - 6x - 27 = 0$, so $(x - 9)(x + 3) = 0$, so $x = 9$ or $x = -3$.

$x = -3$ would need $\log_3(-3)$, which does not exist. Answer: $x = 9$.
:::

::: q
Solve $\log_5 (2x + 1) - \log_5 (x - 1) = 1$.
---
$\log_5 \dfrac{2x+1}{x-1} = 1$, so $\dfrac{2x+1}{x-1} = 5$.

$2x + 1 = 5x - 5$, so $3x = 6$, so $x = 2$.

Check: $\log_5 5 - \log_5 1 = 1 - 0 = 1$. ✓
:::

::: q
Given $\log_3 5 = k$, write $\log_9 5$, $\log_3 45$ and $\log_5 3$ in terms of $k$.
---
$\log_9 5 = \dfrac{\log_3 5}{\log_3 9} = \dfrac{k}{2}$.

$\log_3 45 = \log_3 (9 \times 5) = \log_3 9 + \log_3 5 = 2 + k$.

$\log_5 3 = \dfrac{1}{\log_3 5} = \dfrac{1}{k}$.
:::

::: q
Solve $\log_2 x = 3 \log_x 2$ for $x > 0$, $x \ne 1$.
---
Change the base of the right-hand side: $\log_x 2 = \dfrac{1}{\log_2 x}$.

Let $u = \log_2 x$. Then $u = \dfrac{3}{u}$, so $u^2 = 3$, so $u = \pm\sqrt 3$.

$x = 2^{\sqrt 3}$ or $x = 2^{-\sqrt 3}$.
:::

::: q
Solve $4^x - 6 \cdot 2^x + 8 = 0$.
---
$4^x = (2^x)^2$. Let $u = 2^x$: $u^2 - 6u + 8 = 0$, so $(u - 2)(u - 4) = 0$.

$2^x = 2$ gives $x = 1$; $2^x = 4$ gives $x = 2$.
:::

::: q
Sketch $y = 3^x$ and $y = \log_3 x$ on the same axes. State the coordinates of the point where each crosses an axis, and the equation of each asymptote.
---
$y = 3^x$: crosses the $y$-axis at $(0, 1)$; never crosses the $x$-axis; asymptote $y = 0$ (the $x$-axis, approached as $x \to -\infty$).

$y = \log_3 x$: crosses the $x$-axis at $(1, 0)$; never crosses the $y$-axis; asymptote $x = 0$ (the $y$-axis, approached as $x \to 0^+$).

Each is the reflection of the other in the line $y = x$.
:::

::: q
The number of bacteria in a dish after $t$ hours is $N = 500 \times 1.8^t$. After how many hours, to 2 decimal places, does the population first exceed $20\,000$?
---
$1.8^t = 40$, so $t \log 1.8 = \log 40$, so $t = \dfrac{\log 40}{\log 1.8} = 6.28$ hours (2 d.p.).
:::

::: watch
- **Log of a negative number or zero does not exist.** Every log equation that turns into a quadratic will give you a spare solution to reject — and the mark scheme has a mark for rejecting it.
- $\log_a (x + y)$ is **not** $\log_a x + \log_a y$. The addition law is about a product inside the log.
- Bring coefficients inside before combining: $2 \log x$ becomes $\log x^2$, not $\log 2x$.
- When solving $a^x = b$, any base of log works — use the $\log$ or $\ln$ button, but be consistent on both sides.
- Give the exact form when the question says "exact": $x = \dfrac{\log 40}{\log 5}$, not $2.29$.
:::
