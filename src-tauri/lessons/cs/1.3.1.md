## What it is

A **network** is two or more devices connected together so they can communicate and share resources — files, an internet connection, a printer. Networks are classified first by the *area* they cover.

- A **LAN (Local Area Network)** covers a **small geographical area on a single site** — a home, a school, one office building. The organisation that uses it **owns all the hardware and infrastructure**: the cabling, the switches and the wireless access points.
- A **WAN (Wide Area Network)** connects LANs across a **large geographical area** — between cities or countries. No single organisation owns the links between sites, so the infrastructure is **leased from telecommunications companies** (fibre lines, satellite links). The **internet is the world's largest WAN**.

For full marks name *two* differences: the **area covered** *and* **who owns the infrastructure** — not size alone.

**Factors that affect network performance** — how fast the network actually feels:
- **Bandwidth** — the maximum amount of data that can be carried per second. Bandwidth is **shared** between every device on the network.
- **Number of users/devices** — the more devices transmitting at once, the more thinly that shared bandwidth is split, so each connection slows.
- **Transmission media** — fibre-optic carries more data, faster and further, than copper; a wired link usually beats wireless.
- **Interference and distance** — on wireless, thick walls, distance from the access point and other radio devices weaken the signal, so corrupted data has to be re-sent, cutting the usable speed.

**Client-server and peer-to-peer** describe how the *roles* are shared out:
- In a **client-server** network one or more powerful **servers** provide resources and services (central file storage, security, email, backups) and the **clients** request them. Security, user accounts and backups are managed **centrally**. It costs more and needs a specialist to run, and the server is a single point of failure, but data is kept safe and in one place. Used by schools and businesses.
- In a **peer-to-peer (P2P)** network every computer is **equal** — each is both client and server and shares files directly with the others. It is cheap and simple with no dedicated server, and one machine failing does not stop the rest, but there is **no central backup or security**, files are scattered, and a machine must be switched on to share its files. Used by small home networks.

**Hardware needed to build a LAN**:
- **NIC (Network Interface Card)** — the component inside a device that lets it join a network; each NIC has a unique **MAC address**. Wired or wireless.
- **Switch** — connects devices on a LAN. It reads the destination **MAC address** on each frame of data and sends that frame **only to the one device it is addressed to**. (A **hub**, by contrast, copies incoming data to *every* device — slower and less secure. Being able to state this difference is where the mark is.)
- **Router** — connects different networks and forwards data between them, using **IP addresses** to send each packet along the best route; it is what joins a LAN to the internet.
- **WAP (Wireless Access Point)** — lets wireless devices join a wired network over Wi-Fi by converting between radio signals and the wired network.
- **Transmission media** — **copper** twisted-pair (cheap, but the signal fades over distance and picks up interference), **fibre-optic** (light pulses: very high bandwidth, long range, no electrical interference, but dearer), and **wireless** radio (convenient but slower, shorter-range and less secure).

**The internet** is a **network of networks** — the largest WAN — connecting billions of devices worldwide. Two systems make it usable:
- **Hosting** means storing files (such as a website) on a powerful, always-on **web server** so they are available over the internet. A **web client** (your browser) requests a page and the **web server** sends it back — a client-server relationship.
- **The DNS (Domain Name System)** lets us use memorable **domain names** (like www.example.com) while computers route using numeric **IP addresses**. The DNS is a network of servers that **translates a domain name into its IP address** (see the method below).

**The cloud** means storing data and running software on remote internet servers instead of on your own machine — Google Drive for storage, Google Docs for software. You can reach your files from anywhere, the provider handles backups, security and upgrades, and storage scales up easily; but you **depend on a reliable internet connection**, pay an ongoing subscription, and must trust a third party with your data.

**Star and mesh topologies** describe the *layout* of the connections:
- In a **star topology** every device has its **own cable to a central switch**. If one cable fails only **that one device** is cut off, performance is high because each device has a dedicated link, and adding a device is easy — but the **central switch is a single point of failure**, and all the cabling costs more.
- In a **mesh topology** every node is connected to other nodes and **relays data for its neighbours**, so data can take several routes to its destination. There is **no single point of failure** — if one node or link goes down the data simply reroutes — but a full wired mesh needs a great deal of cabling. Wireless mesh avoids most of that cabling, which is why it is increasingly common.

::: terms
- **Network**: two or more computers connected together to share resources and communicate.
- **LAN (local area network)**: a network covering a small geographical area, such as one building, where the hardware is usually owned by the organisation.
- **WAN (wide area network)**: a network covering a large geographical area, connecting LANs using infrastructure leased from telecommunications companies; the Internet is the largest WAN.
- **Bandwidth**: the amount of data that can be transferred across a network in a given time.
- **Client-server network**: a network in which a central server provides services such as files, email and security to client computers.
- **Peer-to-peer network**: a network with no central server, in which every computer has equal status and can share resources with the others.
- **Wireless access point (WAP)**: a device that lets wireless devices connect to a wired network.
- **Router**: a device that sends data packets between different networks, such as a LAN and the Internet.
- **Switch**: a device that connects devices on a LAN and sends each packet only to the device it is addressed to.
- **NIC (network interface controller)**: the hardware that lets a device connect to a network.
- **Transmission media**: the cables or wireless signals that carry data — copper cable, fibre-optic cable, radio waves.
- **Internet**: a worldwide network of networks.
- **DNS (domain name system)**: a system that translates a domain name, such as www.ocr.org.uk, into the IP address of the web server.
- **Hosting**: storing a website or files on a server that is connected to the Internet so others can access them.
- **The cloud**: remote servers accessed over the Internet that store files and run software and services.
- **Web server**: a computer that stores web pages and sends them to clients on request.
- **Star topology**: a network layout in which every device is connected to a central switch.
- **Mesh topology**: a network layout in which devices are connected to many or all of the other devices, so data has several possible routes.
:::

::: method
**Resolving a domain name with the DNS** — what happens between typing a URL and the page loading:
1. You type a **URL** (e.g. www.example.com) into the browser and press enter.
2. The browser asks a **DNS server** for the **IP address** that matches that domain name.
3. If that DNS server holds the record, it returns the IP address. If it does not, it **queries other DNS servers** up the hierarchy until one can resolve the name, then the IP address is passed back.
4. The browser now has the **IP address** and sends its request straight to the **web server** at that address.
5. The web server returns the web page, which the browser displays.

If asked to "describe how the DNS works", the marks are for *translating the domain name into an IP address* and for the idea that the query is passed between DNS servers until it is resolved.
:::

::: example LAN versus WAN [4]
Compare a LAN and a WAN. [4]

A LAN covers a small geographical area on a single site, such as a school, and the organisation using it owns all of the network hardware and cabling. A WAN covers a large geographical area, for example between cities or countries, and its infrastructure is leased from telecommunications companies rather than owned, because no single organisation owns the connections between distant sites. The internet is an example of a WAN.
:::

::: example The job of a switch [3]
Explain how a switch handles data differently from a hub. [3]

A switch receives a frame of data and reads its destination MAC address, then forwards the frame only to the single device that address belongs to. A hub instead copies any data it receives to every device connected to it. The switch therefore reduces unnecessary traffic and is more secure, because data is not sent to devices it is not meant for.
:::

::: example Choosing a network type [4]
A small design studio of four computers wants to share files cheaply, with no dedicated server. Recommend a network type and justify your choice. [4]

A peer-to-peer network is suitable. Every computer is an equal peer that shares its files directly with the others, so there is no need for an expensive dedicated server or a specialist to manage it, keeping costs low for such a small setup. If one machine fails the other three keep working. The trade-off is no central backup or security and files spread across machines, but for only four computers that is manageable.
:::

::: example Star topology trade-off [4]
Describe one advantage and one disadvantage of a star topology. [4]

Advantage: each device has its own cable to the central switch, so if a single cable develops a fault only that one device loses its connection while the rest of the network carries on working. Disadvantage: every device depends on the central switch, so if the switch fails the entire network goes down — the switch is a single point of failure.
:::

::: example Factors affecting network performance [4]
A school network becomes slow at lunchtime. Explain two factors that could cause this. [4]

Number of users (1): at lunchtime many pupils are online at once, all sharing the same bandwidth, so each gets a smaller share and data takes longer to arrive (1).

Bandwidth and transmission media (1): if the connection to the Internet or some of the cabling has low bandwidth, it cannot carry all the data requested at once, creating a bottleneck (1).
:::

::: example How DNS works [4]
A user types www.example.com into a browser. Describe how DNS is used to load the web page. [4]

The browser sends the domain name to a DNS server (1).

The DNS server looks up the domain name in its records to find the matching IP address; if it does not know it, it asks another DNS server (1).

The IP address is returned to the browser (1).

The browser uses the IP address to send a request to the web server, which sends back the web page (1).
:::

::: example The job of a router and a WAP [4]
A home network has a router and a wireless access point. Describe the role of each. [4]

Router: it connects the home LAN to the Internet (1), sending data packets from devices in the house to the right destination network and directing incoming packets to the right device (1).

Wireless access point: it lets wireless devices such as phones and laptops connect to the network (1) by sending and receiving data as radio waves and passing it to the wired network (1).
:::

::: example Mesh topology [4]
Describe one advantage and one disadvantage of a mesh topology. [4]

Advantage: each device is connected to several others, so data has more than one possible route (1); if one connection or device fails, data is sent another way, so the network keeps working (1).

Disadvantage: many connections are needed (1), so a wired mesh uses a lot of cable and is expensive and complicated to set up (1).
:::

::: example Using the cloud [4]
A small business is deciding whether to store its files in the cloud. Give two advantages and two disadvantages. [4]

Advantages: files can be accessed from anywhere with an Internet connection (1); the cloud provider looks after backups and storage hardware, so the business does not need its own servers (1).

Disadvantages: without an Internet connection the files cannot be reached (1); the business relies on the provider's security and pays an ongoing subscription (1).
:::

::: watch
- A **switch sends a frame only to the device it is addressed to** (using the MAC address); a **hub copies it to everything**. If you cannot state that difference you cannot earn the mark.
- **LAN vs WAN is about area *and* ownership** — a WAN's infrastructure is leased, a LAN's is owned. "A WAN is just a big LAN" drops marks.
- The **DNS turns a domain name into an IP address**, not the other way round.
- **Star:** one cable fault isolates a single device, but the **central switch is a single point of failure** — do not claim a star has no weak spot.
- **Mesh:** its strength is **no single point of failure**; say *why* (data reroutes), don't just call it "reliable".
- **Bandwidth is shared**, which is why "more users" slows a network — an easy explanation mark people miss.
:::
