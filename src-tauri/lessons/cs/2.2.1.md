## What it is

Every program is built from a handful of ideas. You store values in **variables** and **constants**, read and show data with **input** and **output**, and control the order things happen with the **three programming constructs** — sequence, selection and iteration. You combine values using **operators**. Master these and you can read or write any J277 program in the exam's Reference Language.

A **variable** is a named store whose value *can change* while the program runs. You put a value in with the assignment operator `=`, and the name always sits on the left: `score = 0` sets it up, then `score = score + 10` works out the right-hand side and stores it back, adding ten.

A **constant** is a named store whose value is *fixed* when the program is written and never changes as it runs. Writing it once and using it by name — `const VAT = 0.2` — makes a program clearer and easier to change later.

**Input** reads what the user types; **output** displays a value. The Reference Language uses `input(...)` and `print(...)`, so `name = input("What is your name? ")` reads a line and `print("Hello " + name)` shows a greeting.

The **three constructs** are the only ways to control the flow of a program:
- **Sequence** — instructions run one after another, top to bottom.
- **Selection** — the program *chooses* a path with `if` or `switch`.
- **Iteration** — the program *repeats* instructions with a loop.

**Operators** let you calculate, compare and combine:
- **Arithmetic:** `+`  `-`  `*`  `/`  `MOD` (remainder)  `DIV` (whole-number quotient)  `^` (power).
- **Comparison:** `==`  `!=`  `<`  `>`  `<=`  `>=`.
- **Boolean:** `AND`  `OR`  `NOT`.

::: terms
- **Variable**: a named location in memory whose value can change while the program runs.
- **Constant**: a named value that does not change while the program runs.
- **Assignment**: giving a variable a value, e.g. total = 0.
- **Operator**: a symbol that carries out an operation — arithmetic (+ − * /), comparison (== != < >) or Boolean (AND OR NOT).
- **Sequence**: instructions carried out one after another, in order.
- **Selection**: choosing which instructions to run based on a condition — if, elseif, else, switch/case.
- **Iteration**: repeating instructions — a loop.
- **Count-controlled loop**: a loop that repeats a set number of times — for.
- **Condition-controlled loop**: a loop that repeats until, or while, a condition is met — while, do until.
- **MOD**: the remainder after whole-number division, e.g. 17 MOD 5 = 2.
- **DIV**: whole-number (integer) division, e.g. 17 DIV 5 = 3.
- **Exponentiation**: raising a number to a power, e.g. 2 ^ 3 = 8.
:::

::: method
Choose and write the right construct:
1. Decide what to **store** — a variable if the value changes as the program runs, a constant (`const`) if it is fixed. Give it a meaningful name and set it with `=`.
2. Write the ordinary steps in **sequence**, top to bottom.
3. When the program must **choose**, use **selection**: `if ... then` / `elseif` / `else` / `endif`, or `switch` / `case` when one variable is tested against several fixed values.
4. When it must **repeat**, use **iteration**: a count-controlled `for` loop when you know how many repeats, or a condition-controlled `while` (tests first) or `do ... until` (tests last) when you do not.
5. Build the tests and calculations from **operators** — arithmetic to work values out, comparison to test them, and `AND` / `OR` / `NOT` to combine tests.
:::

::: example Variables, constants and assignment
A shop adds 20% VAT to every price. Read a price and print the total to pay. [3]

1. `const VAT = 0.2`
2. `netPrice = float(input("Enter the price: "))`
3. `total = netPrice + netPrice * VAT`
4. `print("Total to pay: " + str(total))`

`VAT` never changes, so it is a **constant**; `netPrice` and `total` change each run, so they are **variables**. The input arrives as a string, so it is cast with `float(...)` before the arithmetic, and the answer is cast back with `str(...)` to join it to the message.
:::

::: example MOD and DIV — remainder and quotient
Turn a number of seconds into whole minutes and the seconds left over.

1. `seconds = 200`
2. `minutes = seconds DIV 60`
3. `remainder = seconds MOD 60`
4. `print(str(minutes) + " min " + str(remainder) + " sec")`

`200 DIV 60` is `3` — how many whole minutes fit — and `200 MOD 60` is `20` — what is left over — so this prints "3 min 20 sec". In the same way `17 MOD 5` is `2` and `17 DIV 5` is `3`.
:::

::: example Selection with if / elseif / else
Print a grade band from a mark out of 100.

1. `mark = int(input("Enter the mark: "))`
2. `if mark >= 70 then`
3. `    print("Grade 9")`
4. `elseif mark >= 40 then`
5. `    print("Pass")`
6. `else`
7. `    print("Below pass")`
8. `endif`

The conditions are tested **in order**, and only the first true branch runs, so the boundaries are listed highest first. Using `>` in place of `>=` would wrongly push a mark of exactly 70 into the lower band.
:::

::: example switch / case for a menu
When one variable is compared against several fixed options, `switch` / `case` is clearer than a long chain of `if`s.

1. `choice = input("Choose a, b or c: ")`
2. `switch choice:`
3. `    case "a":`
4. `        print("You chose apples")`
5. `    case "b":`
6. `        print("You chose bananas")`
7. `    default:`
8. `        print("Not on the menu")`
9. `endswitch`

Use `switch` / `case` only for testing equality against set values; use `if` when you need a range such as `mark >= 50`.
:::

::: example Count-controlled and condition-controlled loops
Add up the numbers 1 to 10 with a count-controlled loop.

1. `total = 0`
2. `for i = 1 to 10`
3. `    total = total + i`
4. `next i`
5. `print(total)`

`for i = 1 to 10` runs with `i` as 1, 2, and so on up to and **including** 10, so this prints 55. When you do not know the number of repeats in advance, test a condition instead. A `do ... until` loop tests **after** each pass, so it always runs at least once:

1. `do`
2. `    guess = int(input("Guess the number: "))`
3. `until guess == 7`

A `while` loop is similar but tests **before** the first pass, so it can run zero times.
:::

::: q
What is the difference between a variable and a constant?
---
A variable's value can change while the program runs; a constant's value is fixed when the program is written and cannot change as it runs.
:::

::: q
State the value of `17 MOD 5` and the value of `17 DIV 5`.
---
`17 MOD 5` is 2, the remainder; `17 DIV 5` is 3, the whole-number quotient.
:::

::: q
Name the three programming constructs.
---
Sequence, selection and iteration.
:::

::: q
Which loop is best when you know exactly how many times to repeat, and what is it called?
---
A count-controlled loop — a `for` loop — because the number of repeats is fixed in advance.
:::

::: q
What is the difference between a `while` loop and a `do ... until` loop?
---
A `while` loop tests its condition before the first pass, so it may run zero times; a `do ... until` loop tests after each pass, so it always runs at least once.
:::

::: q
A program should continue only if the user is at least 18 AND holds a ticket. Write the condition.
---
`if age >= 18 AND hasTicket == true then` — both parts must be true for the whole condition to be true.
:::

::: q
Why does `if score = 5` fail to test the score correctly?
---
`=` is the assignment operator; to compare values you must use `==`, so it should be `if score == 5 then`.
:::

::: q
Give one reason to use a constant such as `const VAT = 0.2` rather than typing 0.2 throughout a program.
---
It makes the code clearer and, if the value ever changes, you edit one line instead of many, which reduces the chance of mistakes.
:::

::: watch
- **MOD gives the remainder, DIV the whole-number quotient.** `17 MOD 5` is 2; `17 DIV 5` is 3 — these are examined directly, so never swap them.
- `for i = 1 to 10` **includes** 10, so it runs ten times, not nine.
- A `while` loop can run **zero** times; a `do ... until` loop always runs **at least once** — choose the one the question needs.
- Use `==` to **compare** and `=` to **assign**: `if x = 5` is wrong, it should be `if x == 5`.
- `switch` / `case` tests equality against fixed values only; use `if` for ranges like `>= 50`.
- Give variables and constants **meaningful names** — it earns marks and prevents errors.
:::

::: test
Write a program for a guessing game: the secret number is 7; the user keeps guessing until correct; after each wrong guess the program says "Too high" or "Too low"; at the end it outputs the number of guesses taken. (6)
---
1. `secret = 7`
2. `count = 0` (1)
3. `guess = 0`
4. `while guess != secret` (1)
5. `    guess = int(input("Guess"))` (1)
6. `    count = count + 1` (1)
7. `    if guess > secret then print("Too high")`
8. `    elseif guess < secret then print("Too low")` (1)
9. `    endif`
10. `endwhile`
11. `print("Correct in " + str(count) + " guesses")` (1)
Marking: 1 mark for each correctly working part of the algorithm, as listed; accept any logically equivalent pseudocode or Python.
