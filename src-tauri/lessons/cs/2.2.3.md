## What it is

This topic is a toolbox of techniques you combine to build real programs, each one solving a different problem.

**String manipulation.** A string is a sequence of characters, and you often need to pick it apart or join pieces together:
- `name.length` — the number of characters.
- `name.substring(start, number)` — pulls out part of a string, counting from position **0** and taking `number` characters.
- `name.upper` and `name.lower` — a copy in upper or lower case.
- `+` — **concatenation**, joining strings end to end.
- `ASC(ch)` gives the ASCII code of a character, and `CHR(code)` gives the character for a code.

**File handling.** Variables are lost when a program ends. To keep data you write it to a **text file** and read it back later. You `open` the file, use `readLine()` or `writeLine(...)`, and always `close()` it when finished; `endOfFile()` tells you when there is no more to read.

**Records.** A record stores several **fields** about one thing together, like a single row of a table — a `Student` record might hold a name (string), an age (integer) and a form (string). Records keep related data of different types in one structure instead of separate loose variables.

**Arrays.** An array stores **many values of the same type** under one name, each reached by an **index** counting from 0. A **1-D array** is a single list (`scores[0]`, `scores[1]`, and so on). A **2-D array** is a grid with a row and a column index, `board[row, column]`, useful for tables and game boards. `array.length` gives the number of elements.

**SQL.** To search a database you use Structured Query Language: `SELECT` the fields you want, `FROM` the table, `WHERE` a condition is met.

**Sub programs.** A sub program is a named block of code you can call whenever you need it. A **function returns a value**; a **procedure does not** — it just does a job. They take **parameters**, the values passed in. Sub programs avoid repeated code and break a big problem into named pieces.

**Random numbers.** `random(a, b)` returns a random whole number from `a` to `b` inclusive — for dice, games and generating test data.

::: terms
- **String manipulation**: working with parts of a string — its length, substrings, upper/lower case, character codes.
- **Concatenation**: joining two or more strings together.
- **File handling**: opening a file, reading from or writing to it, and closing it.
- **Record**: a data structure that stores related fields of different data types about one item.
- **Field**: one item of data within a record.
- **Array**: a data structure that stores a fixed number of values of the same data type under one name, accessed by an index.
- **Two-dimensional array**: an array of arrays, accessed by two indexes — like a grid of rows and columns.
- **SQL**: a language used to search and manage data in a database; SELECT, FROM and WHERE retrieve records that match a condition.
- **Sub program**: a named block of code that can be called from elsewhere in the program.
- **Function**: a sub program that returns a value.
- **Procedure**: a sub program that carries out a task but does not return a value.
- **Parameter**: a value passed into a sub program when it is called.
- **Local variable**: a variable that can only be used inside the sub program where it is declared.
- **Global variable**: a variable that can be used anywhere in the program.
- **Random number generation**: producing an unpredictable number within a range, e.g. random(1,6).
:::

::: method
Pick the right technique for the job:
1. Working with **text**? Use string handling — `.length`, `.substring(start, number)`, `.upper` / `.lower`, `+` to concatenate, and `ASC` / `CHR` for character codes.
2. Data must **survive after the program closes**? Use a file — `open`, then `readLine()` / `writeLine(...)`, then `close()`.
3. Several **fields about one thing**? Use a record. **Many values of the same type**? Use a 1-D array. A **grid or table**? Use a 2-D array, indexed `[row, column]`.
4. Searching a **database**? Write SQL: `SELECT ... FROM ... WHERE ...`.
5. A block of code you **reuse or want to name**? Write a sub program — a **function** if it returns a value, a **procedure** if it does not — passing **parameters** in.
6. Need an **unpredictable** value? Use `random(a, b)`.
:::

::: example Taking a string apart
Work out what each line prints for the username below.

1. `username = "Grade9Student"`
2. `print(username.length)`
3. `print(username.substring(0, 6))`
4. `print(username.upper)`

`username.length` is 13. `substring(0, 6)` starts at position 0 and takes six characters, giving "Grade9". `username.upper` gives "GRADE9STUDENT". To build an email you concatenate with `+`, for example `username.lower + "@school.uk"`.
:::

::: example Character codes with ASC and CHR
Characters have number codes you can convert between.

1. `print(ASC("A"))`
2. `print(CHR(97))`

`ASC("A")` returns 65, the code for capital A, and `CHR(97)` returns "a", the character with code 97. Because "A" is 65 and "a" is 97, you can switch a letter's case by adding or subtracting 32 from its code.
:::

::: example Reading a file line by line
Print every line of a text file, then close it.

1. `myFile = open("scores.txt")`
2. `while NOT myFile.endOfFile()`
3. `    line = myFile.readLine()`
4. `    print(line)`
5. `endwhile`
6. `myFile.close()`

`open` connects to the file, the loop reads one line each pass until `endOfFile()` is true, and `close()` releases the file. Writing works the same way — `myFile.writeLine("new line")` adds a line before you `close()`.
:::

::: example A 1-D array and a loop
Store four test scores and add them up.

1. `array scores[4]`
2. `scores[0] = 8`
3. `scores[1] = 5`
4. `scores[2] = 9`
5. `scores[3] = 7`
6. `total = 0`
7. `for i = 0 to scores.length - 1`
8. `    total = total + scores[i]`
9. `next i`
10. `print(total)`

The array holds four values, indexed 0 to 3. The loop runs from 0 to `scores.length - 1`, which is 3, so it visits every element and prints 29.
:::

::: example A 2-D array as a grid
A noughts-and-crosses board is a 3 by 3 grid, addressed by row and column.

1. `array board[3, 3]`
2. `board[0, 0] = "X"`
3. `board[1, 1] = "O"`
4. `board[2, 0] = "X"`
5. `print(board[1, 1])`

`board[row, column]` picks one cell, and both indexes count from 0, so `board[1, 1]` is the centre square and prints "O".
:::

::: example A record of fields
A record groups several fields of different types about one thing, like a single row of a table:

| Field | Type | Value |
| --- | --- | --- |
| name | string | "Ada" |
| age | integer | 15 |
| form | string | "10B" |

1. `print(student.name + " is in " + student.form)`
2. `student.age = student.age + 1`

Each field is reached with a dot, and because `student.age` is an integer you can do arithmetic on it, as the second line does. Storing name, age and form together keeps one pupil's data in a single structure instead of three separate variables.
:::

::: example Function versus procedure
A **function returns a value** you can use; a **procedure** just carries out a task. First a function:

1. `function areaOfRectangle(width, height)`
2. `    return width * height`
3. `endfunction`
4. `a = areaOfRectangle(4, 3)`

Now a procedure:

1. `procedure greet(name)`
2. `    print("Hello " + name)`
3. `endprocedure`
4. `greet("Sam")`

`width`, `height` and `name` are **parameters** — the values passed in when the sub program is called. The function hands back 12 to store in `a`; the procedure returns nothing, it only prints.
:::

::: example Searching data with SQL
A table `Products` holds the fields Name, Category and Price. List the name and price of every product costing more than 10.

1. `SELECT Name, Price`
2. `FROM Products`
3. `WHERE Price > 10`

`SELECT` chooses the fields (a `*` means every field), `FROM` names the table, and `WHERE` keeps only the rows that match. Conditions can be combined, for example `WHERE Price > 10 AND Category = 'Toys'`.
:::

::: example Random numbers for a dice
Simulate rolling a six-sided dice twice and adding the two rolls.

1. `roll1 = random(1, 6)`
2. `roll2 = random(1, 6)`
3. `print("You rolled " + str(roll1 + roll2))`

`random(1, 6)` returns a whole number from 1 to 6 **inclusive**, so each roll can be any face. Random numbers make games and simulations unpredictable, and are handy for generating test data.
:::

::: q
In `name.substring(0, 6)`, what do the two numbers mean?
---
The 0 is the start position, counting from 0, and the 6 is how many characters to take.
:::

::: q
What is the difference between a function and a procedure?
---
A function returns a value; a procedure carries out a task but does not return a value.
:::

::: q
What does `ASC("A")` return, and what does `CHR(65)` return?
---
`ASC("A")` returns 65; `CHR(65)` returns the character "A".
:::

::: q
Why must a program `close()` a file it has opened?
---
To make sure the data is saved properly and to release the file so it is not left locked or corrupted for other programs.
:::

::: q
A 1-D array `scores` has 5 elements. What are the indexes of the first and last?
---
The first is index 0 and the last is index 4, one less than the length.
:::

::: q
What does `random(1, 6)` return?
---
A random whole number from 1 to 6 inclusive, so it can be 1 or 6.
:::

::: q
Write SQL to select all fields from a table `Members` where Age is under 18.
---
`SELECT * FROM Members WHERE Age < 18`.
:::

::: q
What is a parameter in a sub program?
---
A value passed into the sub program when it is called, which the sub program then uses.
:::

::: q
How is an element of a 2-D array addressed, and what does each index mean?
---
With two indexes, `board[row, column]` — the first selects the row and the second the column, both counting from 0.
:::

::: q
Give one reason programmers use sub programs.
---
They avoid repeating code and break a large problem into smaller named parts that are easier to write, read and test.
:::

::: watch
- **A function returns a value; a procedure does not.** Use the right word and structure — it is examined in the Reference Language.
- Arrays and strings **index from 0**, so the last element of a 5-item array is index 4, and a loop runs `0 to length - 1`.
- `substring(start, number)` takes a **start position and a count**, not a start and an end position.
- Always `close()` a file after `open` — leaving it open can lose or corrupt data.
- In SQL, `SELECT` the fields, `FROM` the table, `WHERE` the condition — and `*` means every field.
- `random(a, b)` **includes both** ends, so `random(1, 6)` can return 1 or 6.
:::
