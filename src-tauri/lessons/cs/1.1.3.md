## What it is

An **embedded system** is a **computer built into a larger device to carry out one dedicated task** (or a small fixed set of tasks). It is **not** a general-purpose computer like a PC, laptop or smartphone that runs many different programs the user chooses to install — it is hidden inside a device whose main purpose is something other than computing.

**Characteristics**
- **Dedicated function** — it does **one specific job**, and its control program is fixed. The program is usually stored in **ROM**, so it is ready the instant the device is switched on and does not normally change.
- **Built into a larger device** — it is a part (a chip or controller), not a standalone computer.
- **Small, cheap and low-power** — it has only as much processing power and memory as the job needs, so it can be tiny, run on little electricity and be **mass-produced cheaply**.
- **Limited or no user interface** — often just a few buttons or a small display, not a keyboard and full screen.
- **Reliable and often real-time** — because it runs a fixed job with fixed software, there is less to go wrong and it can respond immediately.

**Examples (and what makes each one embedded)**
- A **washing machine controller** — runs the wash programs, controlling the motor, water valves and heater; the user only selects a cycle.
- A **microwave** or **dishwasher** timer/controller.
- A car's **engine management unit** or **anti-lock braking (ABS)** controller.
- A **central-heating thermostat**, **traffic lights**, a **digital camera**, a **fitness tracker** or a **pacemaker**.
- In each case the device's **main purpose is not to be a computer** — the computer is embedded to control it.

**Why they are built this way**
Because an embedded system only ever does **one job**, it does not need the powerful processor, large memory, expandability or complex operating system of a general-purpose computer. This lets it be **cheaper, smaller and lower-power**, which matters when it must fit inside a product and be manufactured in huge numbers. Fixing the program in **ROM** makes it start instantly, stay reliable and resist being altered.

**Not embedded:** a laptop, desktop PC, tablet or smartphone — these are **general-purpose**, run many different programs and let the user install new software.

::: method
Answering embedded-system questions:
1. **Define it:** a computer built into a larger device to do a single dedicated task.
2. **To identify one, ask:** "Is the device's main purpose to be a computer?" If **no**, but a processor inside runs a fixed job, it is embedded.
3. **List the marking characteristics:** dedicated function, part of a larger device, small, cheap, low-power, program in ROM, limited interface.
4. **When asked "why built like this",** link each feature back to the fact that it only has **one job** to do.
5. **Give a concrete example and name its task** — "a washing machine controller that runs the wash cycles", not just "a washing machine".
:::

::: example Defining an embedded system
Describe what is meant by an embedded system. [2]

An embedded system is a computer built into a larger device to perform one specific, dedicated task. Unlike a general-purpose computer it does not run a range of user-chosen programs; its control program is fixed and it forms part of the device it controls.
:::

::: example What makes it embedded
Name an example of an embedded system and explain what makes it an embedded system. [2]

A washing machine's controller. It is a computer built into the machine that does one dedicated job — running the wash cycles by controlling the motor, water and heater — rather than being a general-purpose computer the user can install programs on.
:::

::: example Why the hardware is small and cheap
Explain why embedded systems are usually built with low-power, low-cost hardware. [3]

An embedded system only has to perform a single, fixed task, so it does not need a powerful processor, large memory or a complex operating system. Limited hardware is enough, which keeps it cheap to manufacture in large numbers and lets it be small and use little power, so it fits inside the product and can run continuously without expensive cooling or a large power supply.
:::

::: example Spotting what is not embedded
A student claims their laptop is an embedded system. Explain why it is not. [2]

A laptop is a general-purpose computer: it runs many different programs and lets the user install new software of their choice. An embedded system does one fixed, dedicated task inside a larger device, so a laptop does not qualify.
:::

::: example Why ROM is used
Explain why an embedded system usually stores its program in ROM. [2]

ROM is non-volatile, so the control program is kept even when the power is off and is ready the instant the device is switched on. The program does not need to change, so read-only storage is suitable, and it cannot easily be altered or lost, which makes the system reliable.
:::

::: q
Define an embedded system.
---
A computer built into a larger device to carry out one dedicated, specific task.
:::

::: q
Is a smartphone an embedded system? Give a reason.
---
No — it is a general-purpose computer that runs many different programs the user can install.
:::

::: q
Where is an embedded system's program usually stored, and why?
---
In ROM, because it is non-volatile and the fixed program must be available immediately at power-on.
:::

::: q
Give two examples of embedded systems.
---
Any two, for example a washing machine controller, a microwave, a car engine-management unit or traffic lights.
:::

::: q
Why are embedded systems usually cheap and low-powered?
---
They only need to do one task, so limited hardware is enough, and they are mass-produced.
:::

::: q
State one characteristic that separates an embedded system from a general-purpose computer.
---
It performs a single dedicated function rather than running many different user-chosen programs.
:::

::: q
Give one reason embedded systems tend to be very reliable.
---
They run a single fixed program from ROM with no user-installed software, so there is less to go wrong.
:::

::: q
A washing machine's job is washing, not computing — so why is its controller still a computer?
---
Because a processor is embedded inside it to control the wash cycles; the computer is built in to run the device.
:::

::: watch
- An embedded system is a **computer inside a device that is not itself a general-purpose computer** — a laptop, PC or smartphone is **not** embedded.
- **Name the dedicated task**, not just the device: "the controller that runs the wash cycles", not "a washing machine".
- "Small and cheap" earns more marks when you **link it to "only needs to do one job"**.
- Mention the program is in **ROM (non-volatile)** — it explains instant start-up and reliability.
- Don't say it "isn't a computer" — it **is** a computer, just a dedicated one built into a larger device.
- Give a **real example**; a vague "a chip in a machine" rarely scores.
:::
