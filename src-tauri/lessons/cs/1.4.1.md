## What it is

A **threat** is anything that can harm a computer system, its data or its users. Attacks exploit either a **technical weakness** (unpatched software, weak passwords, insecure code) or a **human weakness** — because the biggest vulnerability in most systems is the **people** using them. In the exam you must **name the attack, then say what it does and what it is after**; the name alone is only one mark.

**Malware** (malicious software) is any program written to damage a system or gain unauthorised access. Its main forms:
- **Virus** — malicious code that **attaches itself to a file or program** and only spreads when the user **opens or runs** that infected file; it then replicates into other files, corrupting data or disrupting the system.
- **Worm** — like a virus but **self-replicating**: it **spreads by itself across networks without needing a host file or any user action**, exploiting security holes and consuming bandwidth as it goes. This independence is what separates it from a virus.
- **Trojan** — malware **disguised as a legitimate program** that the user is tricked into installing. It does **not** replicate, but once run it typically opens a **backdoor** or installs other malware.
- **Spyware** — secretly **monitors and records what the user does**, for example **keylogging** every keystroke, then sends the captured passwords and personal data to the attacker.
- **Ransomware** — **encrypts the user's files** and demands a **ransom payment** (often in cryptocurrency) for the key to unlock them, locking the victim out of their own data.

**Social engineering** is manipulating **people** into handing over confidential information or access, rather than attacking the technology directly — which is why no antivirus can stop it. Its forms:
- **Phishing** — sending **fraudulent emails or messages that look like they come from a trusted organisation** (a bank, a delivery firm) containing a link to a **fake website** designed to trick the victim into entering login or financial details.
- **Shouldering (shoulder surfing)** — simply **watching someone** enter information, such as a **PIN at a cash machine** or a password as they type, to steal it.
- **Blagging (pretexting)** — inventing a **believable scenario** to persuade a victim to give information, for instance phoning while pretending to be IT support who needs their password.

**Brute-force attack** — a **trial-and-error** method that **tries many or all possible password combinations** until it finds the right one, usually **automated** with software. It is defeated by long, strong passwords and by locking an account after several failed attempts.

**Denial of Service (DoS)** — an attack that **floods a server or website with so many requests that it cannot cope**, so it slows down or crashes and **legitimate users are denied access**. A **DDoS (Distributed DoS)** launches the flood from many hijacked computers (a **botnet**) at once. Note that DoS **denies access — it does not steal data**.

**Data interception and theft** — **capturing data as it travels across a network**, for example with **packet-sniffer** software, to steal confidential information such as passwords or personal details; it also covers stealing physical devices. Encryption is the main defence, as it makes intercepted data unreadable.

**SQL injection** — typing **SQL database code into an input box** (such as a login or search field) instead of ordinary data. If the website **does not validate the input**, the database runs the injected code, letting the attacker **view, change, delete or bypass** data — for example reading every user record, or logging in without a valid password.

::: method
**How an SQL injection attack works** — the concept, step by step:
1. A website takes what a user types into a box and **builds it straight into an SQL query** that it sends to its database.
2. Instead of a normal value, the attacker enters **SQL code** — for example a condition that is **always true**, like `' OR '1'='1`.
3. Because the site **does not validate or sanitise** the input, the database receives the attacker's code as part of the query.
4. The database **executes it**: an always-true condition makes the check match **every row**, so the attacker is logged in without a password, or can read, alter or delete records.
5. The attacker gains **unauthorised access** to confidential data or bypasses the login entirely.

The weakness being exploited is **unvalidated input**; the fix — validation — belongs to the prevention topic (1.4.2).
:::

::: example Virus versus worm [4]
Explain the difference between a computer virus and a worm. [4]

A virus is malicious code that attaches itself to a file or program and only spreads when the user opens or runs that infected file, after which it replicates into other files. A worm is self-replicating and spreads by itself across a network without needing to attach to a host file or wait for any user action, exploiting security weaknesses to move from computer to computer. The worm's ability to spread unaided is the key difference.
:::

::: example Describing phishing [3]
Describe how a phishing attack works. [3]

The attacker sends a fraudulent email or message that appears to come from a trusted organisation, such as a bank. It contains a link to a fake website that looks genuine. The victim is tricked into entering their login details or financial information, which is then captured by the attacker and used to access the victim's accounts.
:::

::: example Denial of Service [3]
Explain what a Denial of Service (DoS) attack is and its effect. [3]

A DoS attack floods a server or website with an overwhelming number of requests so that it cannot cope with the volume of traffic. As a result the server slows down or crashes. This denies legitimate users access to the service, rather than stealing any data from it.
:::

::: example SQL injection [4]
Explain the concept of an SQL injection attack and what it allows an attacker to do. [4]

An attacker types SQL database code into an input box on a website, such as a login field, instead of ordinary data. If the website does not validate the input, the database executes the injected code as part of its query. This can let the attacker bypass a login using an always-true condition, or view, change and delete records in the database, giving them unauthorised access to confidential data.
:::

::: q
What is a trojan, and does it replicate?
---
A trojan is malware disguised as a legitimate program that the user is tricked into installing; it does not replicate, but it opens a backdoor or installs other malware.
:::

::: q
What does ransomware do to a victim's data?
---
It encrypts the victim's files and demands a ransom payment for the key needed to decrypt them, locking the victim out of their own data.
:::

::: q
Why are people described as the weak point that social engineering targets?
---
Social engineering tricks people into giving away information or access rather than attacking the technology, so even a well-protected system is at risk if a user is deceived.
:::

::: q
What is shouldering?
---
Shouldering, or shoulder surfing, is watching someone directly as they enter information, such as a PIN or password, in order to steal it.
:::

::: q
How does a brute-force attack try to gain access?
---
It uses automated software to try many or all possible password combinations by trial and error until it finds the correct one.
:::

::: q
What is spyware, and give one example of what it records.
---
Spyware secretly monitors and records a user's actions; for example a keylogger records every keystroke, capturing passwords and personal data to send to the attacker.
:::

::: q
How is data intercepted as it crosses a network?
---
Using packet-sniffer software that captures the data packets as they travel, allowing confidential information such as passwords to be read and stolen.
:::

::: watch
- **Name, then explain, then say what it targets.** Naming the attack is one mark; the mechanism and the goal are where the rest of the marks are.
- A **virus needs a host file and a user to run it; a worm self-replicates across networks unaided** — the most common distinction tested.
- A **trojan does not replicate** — it is disguised software that lets other malware in.
- **DoS denies access to legitimate users; it does not steal data.** Do not describe it as data theft.
- **Social engineering attacks the person, not the technology**, so antivirus and firewalls will not stop phishing — awareness will.
- **SQL injection exploits unvalidated input** on a database-driven site; that missing validation is the real weakness.
:::
