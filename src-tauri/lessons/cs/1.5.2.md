## What it is

**Utility software** is a category of **system software** made up of small programs that **maintain, protect, optimise and configure** a computer system — the housekeeping tools that keep it running well. They sit alongside the operating system rather than doing the user's actual work. OCR names three you must be able to describe — **encryption software, defragmentation and data compression** — and **backup** is closely related.

- **Encryption software** scrambles data using an algorithm and a **key** so that it becomes unreadable **ciphertext**. Anyone who intercepts the data, or steals the device, sees only meaningless characters; only someone with the correct key can **decrypt** it back into readable **plaintext**. It protects confidentiality — for example on a stolen laptop, or when data is sent across the internet.
- **Defragmentation** reorganises the files on a **magnetic hard disk drive (HDD)** so that each file is stored in one continuous block again (the method below explains why this speeds the disk up). It also gathers the free space together, so new files are less likely to be split up in the first place.
- **Data compression** reduces the size of a file so it uses **less storage space** and can be **transferred faster**, for example as an email attachment or a download. **Lossless** compression (such as a ZIP file) lets the original be restored exactly; **lossy** compression (such as JPEG or MP3) permanently removes some detail to shrink the file further.
- **Backup** software makes a **copy** of data and stores it **separately** so it can be **restored** if the original is lost, corrupted, deleted or held to ransom. Backups are often **scheduled** to run automatically and kept **off-site or in the cloud**, so a single fire or theft cannot destroy both copies. A **full** backup copies everything; an **incremental** backup copies only what has changed since the last one.

The defragmentation point — and why it helps an HDD but not an SSD — is the most heavily examined idea here, so make sure you can explain the mechanism, not just the word.

::: method
**Explaining how defragmentation speeds up a magnetic hard disk** — give this chain:
1. As files are saved, changed and deleted, gaps of free space are left scattered across the disk.
2. A new or enlarged file often will not fit in a single gap, so it is split into pieces (**fragments**) stored in different physical places — the file is **fragmented**.
3. To read that file, the drive's **read/write head** must physically move to each separate location, which is slow.
4. **Defragmentation** moves the fragments so each file is stored **contiguously** (in one block) and consolidates the free space.
5. Now the head moves far less to read a file, so **access is faster**.
6. Always add: an **SSD** has **no moving read/write head**, so fragmentation does not slow it down — defragmenting one gives no benefit and the extra writes only **wear it out**.
:::

::: example What encryption does
Describe what encryption software does. [2]

It uses an algorithm and a key to scramble data into ciphertext that is unreadable to anyone without the key. The data can only be turned back into readable plaintext by decrypting it with the correct key, which protects it if it is intercepted or the device is stolen.
:::

::: example Why fragmentation is slow
Explain why a heavily fragmented magnetic hard disk is slow to read files. [3]

On a magnetic hard disk the pieces of a fragmented file are stored in scattered physical locations across the platters. Reading the file means the read/write head has to move to each of those locations in turn, and this physical movement takes time. The more fragmented the file, the more the head must move, so the longer the file takes to load.
:::

::: example Defragmenting an SSD
A student defragments the SSD in their laptop to try to speed it up. Explain why this is a bad idea. [2]

An SSD has no moving read/write head, so where data is physically stored makes no difference to how fast it is read — defragmentation therefore gives no speed benefit. Worse, it performs a large number of extra write operations, and because flash memory can only be written a limited number of times, this shortens the drive's life for no gain.
:::

::: example Benefits of compression
State two benefits of compressing a file before emailing it. [2]

It takes up less storage space, and it can be transferred more quickly because there is less data to send.
:::

::: example Why back up
Explain why a business schedules regular automatic backups that are stored off-site. [3]

If data is lost through hardware failure, accidental deletion, theft or a ransomware attack, a backup allows the original to be restored so the business can keep operating. Making the backups automatic and scheduled means they are never forgotten, and keeping them off-site or in the cloud means a single event such as a fire cannot destroy both the original and the copy.
:::

::: q
What is utility software, and what is it for?
---
It is system software made up of small programs that maintain, protect, optimise and configure a computer system, keeping it running smoothly.
:::

::: q
In encryption, what are plaintext, ciphertext and the key?
---
Plaintext is the readable original data, ciphertext is the scrambled unreadable version, and the key is the secret value needed to encrypt or decrypt the data.
:::

::: q
Explain the difference between lossless and lossy compression.
---
Lossless compression lets the exact original file be restored, while lossy compression permanently discards some detail to make the file smaller, so the original cannot be perfectly recovered.
:::

::: q
Which type of drive benefits from defragmentation, and which does not?
---
A magnetic hard disk drive (HDD) benefits; a solid-state drive (SSD) does not.
:::

::: q
Give one reason defragmenting an SSD is actively harmful, not just pointless.
---
It causes many extra write operations, and flash memory can only be written a limited number of times, so it wears the drive out and shortens its life.
:::

::: q
Why should a backup be stored in a different place from the original data?
---
So that a single event such as a fire, flood or theft cannot destroy both the original and the backup at once.
:::

::: q
State the difference between a full backup and an incremental backup.
---
A full backup copies all of the data, while an incremental backup copies only the data that has changed since the previous backup.
:::

::: q
Other than saving storage space, give one reason data compression is useful on the internet.
---
Compressed files transfer faster because there is less data to send, so pages and downloads load more quickly.
:::

::: q
Why is utility software classed as system software rather than application software?
---
Because it maintains and manages the computer system itself rather than doing a task for the user, such as writing a document or editing a photo.
:::

::: watch
- **Defragment an HDD, never an SSD.** The classic question asks which drive benefits — the answer is the magnetic hard disk, because only it has a moving read/write head. Defragmenting an SSD wastes write cycles and wears it out.
- **Explain the mechanism, not just the word.** "Defrag puts files back together so it is faster" is thin — say the read/write head has to move less, so access is quicker.
- **Encryption protects data if it is stolen or intercepted; it does not stop it being stolen.** It makes the stolen data unreadable without the key.
- **Encryption is not the same as a password.** A password controls access to a system; encryption scrambles the data itself.
- **Compression and backup are utilities too.** Know two benefits of compression (less space, faster transfer) and why backups are kept separate and scheduled.
:::
