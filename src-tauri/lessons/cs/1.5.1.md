## What it is

The **operating system (OS)** is the software that **manages the hardware** and **provides a platform** for application software to run on. When a program wants to save a file or print a page, it does not control the disk or printer itself — it asks the OS, which does the hardware work and hands back the result. This is why one copy of a game can run on machines with different disks, graphics cards and printers: the OS hides the messy hardware detail behind one consistent set of services. Examples are Windows, macOS, Linux, Android and iOS.

OCR expects you to know **five functions**, and in the exam each is usually a separate mark. Learn them as a list you can reel off, then say what each one does:

- **User interface** — the way the user interacts with the computer. Most systems provide a **GUI** (graphical user interface) built from windows, icons, menus and a pointer, so you can click instead of memorising commands; some provide a **command-line interface (CLI)** where you type text commands, which is more powerful for experts but harder to learn.
- **Memory management and multitasking** — the OS decides where in **RAM** each running program and its data are placed, records what is free and what is used, and reclaims memory when a program closes, keeping programs in separate areas so one cannot overwrite another. **Multitasking** means it lets several programs appear to run at once by switching the CPU between them many times a second, giving each a small slice of processor time. When RAM runs low it can use **virtual memory**, moving data it is not currently using out to the disk.
- **Peripheral management and drivers** — the OS controls the input, output and storage devices attached to the computer and manages the flow of data to and from them, for example holding print jobs in a queue. It does this using a **device driver**: a small piece of software that translates the OS's general commands into the exact signals one particular model of device understands. Plug in a new printer and you install its driver.
- **User management and access levels** — the OS allows separate **user accounts**, each with its own login, files and settings, and sets an **access level** for each. An **administrator** can install software and change system settings; a **standard user** cannot. This keeps one user's files private from another and limits the damage a single account can do.
- **File management** — the OS organises data into a **hierarchy of folders (directories)** and provides the operations to create, name, save, open, move, copy, rename, search and delete files. It keeps track of where each file is physically stored on the disk and enforces who is allowed to open it.

::: terms
- **Operating system (OS)**: system software that manages the computer's hardware and provides a platform for applications to run.
- **User interface**: the way a user interacts with the computer — a graphical user interface (GUI) or a command-line interface.
- **Memory management**: the OS deciding which programs and data are held in RAM, and moving them in and out as needed.
- **Multitasking**: the OS switching the CPU between several programs so quickly that they appear to run at the same time.
- **Peripheral management**: the OS controlling input and output devices such as printers and keyboards.
- **Device driver**: software that translates the OS's instructions into commands a particular hardware device understands.
- **User management**: the OS controlling user accounts, logins and access rights.
- **File management**: the OS organising files into folders, naming, moving, copying and deleting them, and controlling access.
:::

::: method
To answer a "describe the functions of an operating system" question:
1. **Name** the function using the exam's own term — user interface, memory management, and so on.
2. **Say what it does** in one clear sentence: the job it performs for the user or for other software.
3. **Add one concrete detail** that proves you understand it — a GUI is windows-icons-menus-pointer; multitasking is time-slicing the CPU; a driver translates commands for one device.
4. **Match the number of points to the marks.** A 4-mark question wants two functions each described, or four functions each named with a job — not one function written about at length.
:::

::: example Describing two functions
Describe two functions of an operating system. [4]

**Memory management:** the operating system allocates space in RAM to each program as it starts, tracks which memory is used and which is free, and reclaims it when a program closes, keeping programs in separate areas so they cannot corrupt one another. **Peripheral management:** it controls the input and output devices and manages the data flowing to them, using a device driver to translate its commands into the signals each specific device understands.
:::

::: example Running several programs at once
Explain how an operating system lets a user run several programs at the same time. [3]

The computer has only one CPU per core, so the operating system uses **multitasking**: it gives each running program a small slice of processor time in turn and switches between them many times a second, far faster than a person can notice, so the programs appear to run simultaneously. It also gives each program its own area of memory, so switching between them never lets one overwrite another's data.
:::

::: example The role of a driver
Explain the purpose of a device driver. [2]

A device driver is software that lets the operating system communicate with a particular piece of hardware. It translates the operating system's general input and output commands into the specific signals one model of device understands, so a new device can be added to the system without changing the OS itself.
:::

::: example Access levels and security
Explain how user access levels help keep a computer system secure. [2]

Each account is given an access level that limits what it may do: a standard user can run everyday programs but cannot install software or change system settings, while only an administrator can. This means that if an ordinary account is misused or compromised, the damage is limited because that account lacks the rights to alter the whole system.
:::

::: example Managing files
Describe how the operating system manages files. [3]

It organises data into a hierarchy of folders so files can be located logically, and it provides the operations to create, open, save, move, copy, rename, search and delete them. It records where each file is physically stored on the disk, so the user works with a name and a folder rather than a disk address, and it enforces the access permissions that decide who may open each file.
:::

::: q
State what an operating system is, in terms of what it manages and what it provides.
---
It is system software that manages the computer's hardware and provides a platform on which application software can run.
:::

::: q
Name the five functions of an operating system that OCR expects you to know.
---
User interface, memory management and multitasking, peripheral management and drivers, user management and access levels, and file management.
:::

::: q
What is the difference between a GUI and a CLI?
---
A GUI (graphical user interface) uses windows, icons, menus and a pointer that the user clicks; a CLI (command-line interface) requires the user to type text commands.
:::

::: q
Why does the operating system keep each running program in its own area of memory?
---
So that one program cannot read or overwrite the memory used by another, which stops programs corrupting each other and improves stability and security.
:::

::: q
A user plugs in a brand-new printer and installs a small program before it works. What is that software, and what does it do?
---
It is a device driver; it translates the operating system's general commands into the specific signals that this particular printer understands.
:::

::: q
Give one task an administrator account can do that a standard user account cannot.
---
Install new software, or change system settings (either is acceptable).
:::

::: q
What is virtual memory, and when does the operating system use it?
---
It is disk space used as if it were extra RAM; the OS moves data that is not currently needed out to it when RAM is running low.
:::

::: q
State three file operations the operating system provides.
---
Any three of: create, open, save, move, copy, rename, search, delete.
:::

::: q
Explain why an application program does not need to know which model of hard disk is installed.
---
Because it asks the operating system to store and retrieve data, and the OS, through the correct driver, deals with the specific hardware, so the application only needs the OS's standard services.
:::

::: watch
- **Five functions, five marks.** Learn the list so you can name all five, then attach a job to each — a bare list of names does not score the "describe" marks.
- **Memory management is allocating and tracking RAM; multitasking is time-slicing the CPU.** They are linked but not the same thing — mention both when the question says "at the same time".
- **A driver is software, not hardware,** and it works for one specific device — "it lets the OS talk to the hardware" is too vague on its own.
- **User management is about accounts and access levels,** not the user interface. Do not mix them up just because both contain the word "user".
- **The OS provides a platform for other software** — it does not do the user's actual work; a spreadsheet does the calculations. Say "manages hardware and runs applications".
:::

::: test
Describe how the operating system manages memory and the CPU so that a user can run a web browser, a music player and a word processor at the same time. (6)
---
Memory: the OS loads each program into RAM, allocates it space, keeps programs separate so they do not overwrite each other, and uses virtual memory if RAM is full (2–3).
CPU / multitasking: the OS schedules the processes, giving each a short time slice on the CPU and switching between them so quickly that they appear to run at once (2–3).
Peripherals: it manages the sound card and screen through drivers so each program can use them (1).
Levels: 5–6 — detailed, well-explained points applied to the context; 3–4 — some explained points; 1–2 — basic points.
:::
