## What it is

**Primary storage** (also called **main memory**) is the memory the CPU can read from and write to **directly and very quickly**. It is where the processor gets the instructions and data it works on during the fetch-execute cycle, and it includes **RAM**, **ROM** and **cache**. A computer needs it because **secondary storage** (a hard disk or SSD) is far **too slow** for the CPU to work from directly — the data a program needs right now must be held in fast primary storage.

**RAM (Random Access Memory)**
- **Volatile** — it **loses its contents when the power is turned off**.
- Holds the **programs, data and parts of the operating system that are currently in use**. When you open a program it is copied from secondary storage into RAM so the CPU can run it.
- It can be **read from and written to** (changed) freely.
- **More RAM** lets **more programs, or larger programs, run at once** without slowing down.

**ROM (Read Only Memory)**
- **Non-volatile** — it **keeps its contents when the power is off**.
- **Read-only** — the contents are fixed by the manufacturer and are not normally changed.
- Holds the **start-up (boot) instructions**: when the computer is switched on these run and tell it how to start and load the operating system from secondary storage into RAM.

The distinction examiners want is **volatility**: **RAM is volatile, ROM is non-volatile.**

**Cache**
- A **small** amount of **very fast** memory **inside or very close to the CPU**.
- Stores copies of frequently used or likely-next instructions and data, so the CPU can get them faster than fetching from RAM. This means the CPU **waits less and processes more per second**. (Levels L1, L2, L3 — smallest and fastest first.)

**Virtual memory**
- When **RAM becomes full**, the operating system uses **part of the secondary storage as if it were extra RAM**. Data not being used right now is moved out of RAM to this area to free space for what is needed.
- It **slows the computer down** because **secondary storage is much slower than RAM**, and constantly **moving data back and forth (swapping/paging)** between RAM and disk takes time. If this happens a lot, the machine crawls.
- Virtual memory is therefore a way to **cope with too little RAM**, at the cost of speed — it is not a type of RAM and not literally "more RAM".

::: terms
- **Primary storage (main memory)**: memory that the CPU can access directly — RAM, ROM and cache.
- **RAM (random access memory)**: volatile memory that holds the operating system, programs and data currently in use.
- **ROM (read-only memory)**: non-volatile memory that holds the boot-up instructions (the BIOS); it cannot normally be changed.
- **Volatile**: loses its contents when the power is switched off.
- **Non-volatile**: keeps its contents when the power is switched off.
- **Boot-up (bootstrap)**: the instructions that start the computer and load the operating system into RAM.
- **Virtual memory**: part of secondary storage used as if it were RAM when RAM is full.
- **Cache**: very fast memory close to the CPU that holds frequently used instructions and data.
:::

::: method
Answering primary-storage questions:
1. **Why primary storage exists:** the CPU needs fast, directly accessible memory; secondary storage is too slow to run programs from.
2. **RAM vs ROM — lead with volatility:** RAM is volatile and holds what is **running now**; ROM is non-volatile and holds the **start-up/boot instructions**.
3. **Cache:** small, fast and close to the CPU; holds likely-next data so there are **fewer slow trips to RAM**.
4. **Virtual memory:** when RAM is **full**, secondary storage is used as extra RAM; it is **slow** because disk is slower than RAM and swapping data takes time.
5. In a **"compare RAM and ROM"** answer, cover **volatility, read/write vs read-only, and what each stores**.
:::

::: example RAM against ROM
State two differences between RAM and ROM. [2]

RAM is volatile, losing its contents when the power is off, whereas ROM is non-volatile and keeps its contents. RAM can be both read from and written to and holds the programs currently in use, while ROM is read-only and holds the fixed start-up instructions.
:::

::: example The job of ROM
Explain the purpose of ROM in a computer. [2]

ROM stores the boot-up instructions that run the moment the computer is switched on. Because it is non-volatile these instructions are always present, and they tell the computer how to start and load the operating system from secondary storage into RAM.
:::

::: example Virtual memory
Explain what virtual memory is and why using it can slow a computer down. [4]

Virtual memory is an area of secondary storage that the operating system uses as if it were extra RAM when the RAM is full. Data not currently in use is moved from RAM into this area to free space for what is needed. It slows the computer because secondary storage is much slower to access than RAM, and repeatedly moving data back and forth between RAM and disk takes time, so heavy use of virtual memory makes the whole system run slowly.
:::

::: example Too little RAM
A computer slows down badly when many programs are open at once. Using the idea of RAM and virtual memory, explain why. [3]

Each open program must be held in RAM. When the RAM fills up, the operating system starts using virtual memory — part of the much slower secondary storage — to hold data that will not fit. The CPU then has to wait while data is swapped between RAM and disk, and this constant swapping makes the computer slow.
:::

::: example The role of cache
Explain the role of cache in a computer. [3]

Cache is a small amount of very fast memory inside or very close to the CPU. It stores copies of instructions and data the CPU has recently used or is likely to use next, so the CPU can fetch them from cache instead of from the slower RAM. This reduces the time the CPU spends waiting, so it can process more instructions per second.
:::

---
Volatile — it loses its contents when the power is turned off.

What does ROM store?
---
The start-up (boot) instructions that run when the computer is switched on and load the operating system.
:::

::: q
Why can't the CPU simply work directly from the hard disk?
---
Secondary storage is far too slow; the CPU needs fast primary storage to fetch instructions and data from.
:::

::: q
What is virtual memory?
---
Part of secondary storage used by the operating system as if it were extra RAM when the RAM is full.
:::

::: q
Why does heavy use of virtual memory slow a computer down?
---
Secondary storage is much slower than RAM, and constantly swapping data between them takes time.
:::

::: q
Where is cache located, and why does that help?
---
Inside or very close to the CPU, so it can be accessed faster than RAM, reducing the time the CPU waits.

---
To hold the programs, data and parts of the operating system currently in use.
:::

Can a user normally change the contents of ROM?
---
No — ROM is read-only and its contents are fixed.
:::

::: watch
- **RAM is volatile; ROM is non-volatile.** This contrast is where the marks are — state it explicitly.
- **Virtual memory is secondary storage used as extra RAM when RAM is full** — it is not a kind of RAM and not literally "more RAM".
- Give virtual memory's slowness **two** reasons: disk is slower than RAM **and** swapping data takes time.
- **ROM holds the start-up/boot instructions**, not the whole operating system and not user files.
- For cache, say **why** it helps (fewer slow RAM fetches) and that it is **small and close to the CPU**.
- Don't confuse **cache** (primary, fast) with **virtual memory** (secondary, slow) — they pull in opposite directions.
:::

Explain why a computer needs both RAM and ROM. (2)

ROM holds the start-up instructions (BIOS/bootloader) permanently, so the computer can begin when switched on (1); RAM holds the programs and data currently in use, which change constantly (1).
:::

::: test
Describe what happens when a program is opened, in terms of storage and memory. (2)
---
The program is copied from secondary storage (e.g. SSD) into RAM (1); the CPU then fetches its instructions from RAM (1).
:::

::: test
Explain how virtual memory works. (3)
---
When RAM is full, the operating system moves data from RAM that is not currently needed to an area of secondary storage (1); this frees RAM for the running program (1); the data is swapped back when needed (1).
:::

::: test
Explain why adding more RAM can make a computer faster. (2)
---
More programs and data fit in RAM at once (1); less swapping to slow virtual memory on the disk is needed (1).
:::

::: test
State two differences between RAM and ROM. (2)
---
RAM is volatile, ROM is non-volatile (1); RAM can be written to freely, ROM is read-only (or written once) (1).
:::

::: test

---
They are lost — RAM is volatile and needs power to keep its data.
:::

::: test
Explain why the CPU does not fetch instructions directly from an SSD. (2)
---
Secondary storage is far slower than RAM (1); the CPU would spend most of its time waiting, so programs are loaded into RAM first (1).
:::

ROM only needs to hold the small start-up program; all working programs and data go in RAM.
:::
