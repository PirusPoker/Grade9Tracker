## What it is

When a nucleus decays it changes into a different nucleus, and we can write the change as a **nuclear equation**. The rule is simple: the **nucleon numbers (top) add up** on both sides and the **proton numbers (bottom) add up** on both sides. Mass and charge are conserved.

**Alpha decay.** The nucleus emits a helium nucleus, $^{4}_{2}\text{He}$ (or $^{4}_{2}\alpha$). The nucleon number falls by **4** and the proton number by **2**, so the atom becomes the element **two places to the left** in the periodic table.

$$^{238}_{92}\text{U} \rightarrow ^{234}_{90}\text{Th} + ^{4}_{2}\text{He}$$

**Beta decay.** A neutron in the nucleus turns into a proton and an electron; the electron is fired out as the beta particle, $^{0}_{-1}\text{e}$ (or $^{0}_{-1}\beta$). The nucleon number is **unchanged** and the proton number rises by **1**, so the atom becomes the element **one place to the right**.

$$^{14}_{6}\text{C} \rightarrow ^{14}_{7}\text{N} + ^{0}_{-1}\text{e}$$

Check: nucleons 14 = 14 + 0; protons 6 = 7 + (−1).

**Gamma emission.** After an alpha or beta decay the new nucleus is often left with surplus energy, which it sheds as a gamma photon, $^{0}_{0}\gamma$. Gamma emission changes **neither** number — the nucleus stays the same isotope, just with less energy.

**Neutron emission.** A few nuclei emit a neutron, $^{1}_{0}\text{n}$: the nucleon number falls by 1, the proton number is unchanged, so it is the **same element** with one fewer neutron (a different isotope).

Summary of the changes:

| Emission | Symbol | Nucleon number A | Proton number Z |
|---|---|---|---|
| Alpha | $^{4}_{2}\text{He}$ | −4 | −2 |
| Beta | $^{0}_{-1}\text{e}$ | 0 | +1 |
| Gamma | $^{0}_{0}\gamma$ | 0 | 0 |
| Neutron | $^{1}_{0}\text{n}$ | −1 | 0 |

**Decay chains.** Heavy nuclei often decay through a series of alpha and beta steps until they reach a stable nucleus (uranium-238 ends up as lead-206). You can track a chain by applying the changes one step at a time, or plot it on a graph of neutron number against proton number: alpha moves diagonally down-left by 2 and 2; beta moves one step right (proton number up) and one down (neutron number down).

::: method
1. Write the parent nucleus with its numbers and the emitted particle with its numbers ($^{4}_{2}$He, $^{0}_{-1}$e, $^{0}_{0}$γ, $^{1}_{0}$n).
2. **Top numbers balance; bottom numbers balance.** Solve for the daughter's A and Z.
3. Use Z to name the daughter element from the periodic table (two left for alpha, one right for beta).
4. Check the arithmetic on **both** rows — an equation that balances on only one is wrong.
5. For a chain, apply each step to the previous daughter, keeping a running total.
:::

::: example Alpha decay equation
Radium-226 ($^{226}_{88}$Ra) decays by alpha emission. Write the equation and identify the daughter nucleus. (3)

$^{226}_{88}\text{Ra} \rightarrow ^{222}_{86}\text{X} + ^{4}_{2}\text{He}$ (1). A = 226 − 4 = 222, Z = 88 − 2 = 86 (1). Z = 86 is **radon**, $^{222}_{86}$Rn (1).
:::

::: example Beta decay equation
Strontium-90 ($^{90}_{38}$Sr) is a beta emitter. Write the equation and name the product. (3)

$^{90}_{38}\text{Sr} \rightarrow ^{90}_{39}\text{Y} + ^{0}_{-1}\text{e}$ (1). A unchanged at 90; Z rises to 39 (1). Element 39 is **yttrium** (1).
:::

::: example Finding the missing particle
Complete: $^{212}_{83}\text{Bi} \rightarrow ^{208}_{81}\text{Tl} + \ ?$ and state the type of decay. (2)

Missing nucleon number 212 − 208 = 4, proton number 83 − 81 = 2: the particle is $^{4}_{2}$He (1), so this is alpha decay (1).
:::

::: example A two-step chain
Thorium-234 ($^{234}_{90}$Th) undergoes beta decay, and the product undergoes a second beta decay. Give the final nucleus. (3)

First beta: $^{234}_{90}\text{Th} \rightarrow ^{234}_{91}\text{Pa} + ^{0}_{-1}\text{e}$ (1). Second beta: $^{234}_{91}\text{Pa} \rightarrow ^{234}_{92}\text{U} + ^{0}_{-1}\text{e}$ (1). Final nucleus: **uranium-234**, $^{234}_{92}$U (1).
:::

::: q
State the two rules for balancing a nuclear equation. (2)
---
Nucleon (mass) numbers add up to the same on both sides (1); proton (atomic) numbers add up to the same on both sides (1).
:::

::: q
How do the nucleon and proton numbers change in alpha decay? (2)
---
Nucleon number decreases by 4 (1); proton number decreases by 2 (1).
:::

::: q
How do the nucleon and proton numbers change in beta decay? (2)
---
Nucleon number unchanged (1); proton number increases by 1 (1).
:::

::: q
Explain why beta emission increases the proton number. (2)
---
A neutron in the nucleus changes into a proton and an electron (1); the electron leaves as the beta particle, so there is one more proton (1).
:::

::: q
What happens to the nucleus when it emits gamma radiation? (1)
---
It loses energy only; nucleon and proton numbers are unchanged.
:::

::: q
Write the symbol for a beta particle in nuclide notation. (1)
---
$^{0}_{-1}$e.
:::

::: q
Polonium-210 ($^{210}_{84}$Po) emits an alpha particle. Give the nucleon and proton numbers of the product. (2)
---
206 (1); 82 (lead) (1).
:::

::: q
Iodine-131 ($^{131}_{53}$I) emits a beta particle. Write the equation. (2)
---
$^{131}_{53}$I → $^{131}_{54}$Xe + $^{0}_{-1}$e (1 for the product numbers, 1 for the electron).
:::

::: q
A nucleus emits a neutron. What happens to its nucleon and proton numbers? (2)
---
Nucleon number falls by 1 (1); proton number unchanged — it becomes a different isotope of the same element (1).
:::

::: q
A nucleus decays by alpha then beta emission. What is the overall change in its proton number? (1)
---
−2 + 1 = −1.
:::

::: watch
- Balance **both** rows: top numbers and bottom numbers. Check each explicitly.
- Beta: nucleon number **unchanged**, proton number **+1**. The electron's −1 charge is what makes the bottom row balance.
- Alpha is $^{4}_{2}$He — **4 on top, 2 below** — not $^{2}_{4}$.
- Gamma changes **nothing** in the numbers; it is energy only.
- Name the daughter **element** from its new proton number; keeping the parent's name is a lost mark.
:::

:::

$^{14}_{6}\text{C} \rightarrow ^{14}_{7}\text{N} + ^{0}_{-1}\text{e}$ (1); nitrogen-14 (1).
:::

::: test
A nucleus $^{238}_{92}$U emits an alpha particle, and the product then emits a beta particle. Give the nucleon and proton numbers of the final nucleus. (3)
---
After alpha: 234, 90 (1); after beta: 234 (1), 91 (1).
:::

::: test
Explain, in terms of particles, what happens inside a nucleus during beta-minus decay. (2)
---
A neutron changes into a proton (1) and an electron, which is emitted as the beta particle (1).
:::

::: test
A nucleus emits gamma radiation. State what happens to its nucleon number, proton number and energy. (2)
---
Nucleon and proton numbers are unchanged (1); the nucleus loses energy (1).
:::

::: test
Complete: $^{60}_{27}\text{Co} \rightarrow ^{60}_{28}\text{Ni} + \ ?$ (1)
---
$^{0}_{-1}\text{e}$ — a beta particle.
:::

::: test
Thorium-232 decays to lead-208 by a series of alpha and beta emissions. How many alpha particles are emitted? ($^{232}_{90}$Th $\rightarrow$ $^{208}_{82}$Pb) (2)
---
Nucleon number falls by 24, and only alpha decay changes it, by 4 each time (1); $24 \div 4 = 6$ alpha particles (1).
:::

::: test
Explain why the total charge and total nucleon number are the same before and after a nuclear decay. (1)
---
Charge and nucleon number are conserved — particles are rearranged, not created or destroyed.
:::
