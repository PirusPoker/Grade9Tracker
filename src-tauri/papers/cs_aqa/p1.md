**13.** Write a program for a number-guessing game. The program must:

- generate a random whole number from 1 to 100 inclusive;
- let the player make up to seven guesses;
- reject any guess outside 1 to 100 without counting it, and ask again;
- after each wrong guess, output `Higher` or `Lower`;
- if the player guesses correctly, output `Correct` and the number of guesses used, and stop;
- if all seven guesses are wrong, output `Out of guesses` and the number.

Use program code in your school's language, meaningful variable names and indentation. (8)
---
Example (Python):

```
import random

secret = random.randint(1, 100)
guesses = 0
won = False
while guesses < 7 and not won:
    guess = int(input("Guess a number from 1 to 100: "))
    while guess < 1 or guess > 100:
        guess = int(input("Out of range. Guess again: "))
    guesses = guesses + 1
    if guess == secret:
        won = True
        print("Correct", guesses)
    elif guess < secret:
        print("Higher")
    else:
        print("Lower")
if not won:
    print("Out of guesses", secret)
```

- A: a random integer from 1 to 100 inclusive, generated once before the loop (1).
- B: the guess is input and converted to an integer (1).
- C: a loop that allows at most seven counted guesses (1).
- D: the loop stops early when the guess is correct (1).
- E: out-of-range guesses are rejected, the player is asked again and the guess is not counted (1).
- F: `Higher` and `Lower` are output the right way round (1).
- G: `Correct` and the number of guesses are output on a win (1).
- H: `Out of guesses` and the secret number are output only if all seven guesses fail (1).

In C#, accept `new Random().Next(1, 101)`; in VB.NET, `rnd.Next(1, 101)`. An off-by-one range, such as Python's `randrange(1, 100)`, loses A.

**14.** A shop's product codes must be exactly six characters: two upper-case letters followed by four digits, for example `KT4082`.

In character code tables, 'A' to 'Z' are 65 to 90 and '0' to '9' are 48 to 57.

(a) Write a subroutine `validCode` that takes a code as a parameter and returns True if it follows the rule and False otherwise. Check the letters and digits using character codes. (7)

(b) Write the main program. It must ask for a code, call `validCode`, and keep asking until a valid code is entered. It then outputs `Accepted` and the number of attempts it took. (4)

Use program code in your school's language, meaningful variable names and indentation. (11)
---
Example (Python):

```
def validCode(code):
    if len(code) != 6:
        return False
    for i in range(0, 2):
        c = ord(code[i])
        if c < 65 or c > 90:
            return False
    for i in range(2, 6):
        c = ord(code[i])
        if c < 48 or c > 57:
            return False
    return True

attempts = 0
valid = False
while not valid:
    code = input("Enter product code: ")
    attempts = attempts + 1
    valid = validCode(code)
print("Accepted", attempts)
```

(a) Subroutine, 7 marks:

- A: a subroutine defined with one parameter (1).
- B: the length is checked to be exactly 6 (1).
- C: the first two characters are checked, with a loop or two separate tests (1).
- D: `ord`/`CHAR_TO_CODE` used to get each character's code (1).
- E: the letters are tested against 65 to 90 inclusive (1).
- F: the last four characters are tested against 48 to 57 inclusive (1).
- G: True is returned only when every test passes, and False otherwise (1).

(b) Main program, 4 marks:

- H: the code is input inside a loop (1).
- I: `validCode` is called with the entered code and its result is used (1).
- J: the loop repeats until the result is True (1).
- K: attempts are counted correctly, and `Accepted` and the count are output once after the loop (1).

The length check must happen before the character checks, or a short code would cause an error: no credit for G if the program would crash on a code shorter than six characters. An answer that compares characters directly (`'A' <= c <= 'Z'`) can earn E and F but not D, because the question asks for character codes.
