Grade 9 Tracker

A two-year study planner for GCSE and IGCSE. It works out what to do each week, teaches every topic with its own lesson, worked examples and end-of-topic test, and reads the lesson aloud if you want it to. Free, works offline, and keeps itself up to date.

Download for Windows

Windows 10 or 11 · about 50 MB · installs in a minute

On a phone or tablet

The same app runs in the browser — no app store, nothing to download. Open it and add it to your home screen so it opens full-screen like any other app and works offline.

Open in the browser
  1. iPhone / iPad: open the link in Safari, tap the Share button (the square with an arrow), then Add to Home Screen.
  2. Android: open it in Chrome, tap the ⋮ menu, then Add to Home screen (or Install app).

Your progress stays in that browser on that device. Use Export in the profile menu to move it between devices.

Installing on Windows

  1. Run the downloaded Grade9Tracker-Setup.exe.
  2. Windows will show "Windows protected your PC" because the app is not from the Microsoft Store. Click More info, then Run anyway. This happens once.
  3. Open Grade 9 Tracker from the Start menu, add yourself as a profile, and tick the subjects you take.

Antivirus software sometimes flags it. The app is new, carries no paid-for signing certificate, and reads your school email and calendar out of Outlook if you let it — a combination that looks unusual to a scanner even though nothing is wrong with it. Every line is public on GitHub and the installer is built there in the open. If yours quarantines it, restore it from that program's own history, or use the browser version above, which needs no install at all.

Updates

You never download it again. The app checks for new versions while it runs and installs them itself (you can turn that off in Settings and click Update when you prefer). Your progress, plan and notes stay on your own PC and survive every update.

What's inside

  • A week-by-week plan through to the exams, rebalanced around what you tick off.
  • A full lesson for every topic in ten subjects — explanation, worked examples, practice questions with answers, an end-of-topic test, and an intro video.
  • Recall checks, a mistakes log, mock papers with a grade estimate, a quote bank for English, and a read-aloud narrator that works offline (each voice is a one-off 60 MB download the first time you pick it).
